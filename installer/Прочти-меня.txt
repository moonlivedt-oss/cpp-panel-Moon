Документация C++ — установка на компьютер
==========================================

Что это:
  Расширение для VS Code со справочником, примерами и задачником по C++
  на русском языке. Работает офлайн. Все материалы уже внутри расширения.

Что нужно заранее:
  Visual Studio Code (подойдут и VS Code Insiders, и VSCodium).
  Права администратора НЕ нужны.

--- ОСНОВНОЕ: боковая панель (работает везде) --------------------

  1. Запустите  "Установить.bat"  (двойным щелчком), дождитесь "Готово!".
     Батник сам проверит, что расширение встало, и покажет версию.
     Если рядом лежит Moon Core, батник предложит поставить и его (см. ниже).
     В конце предложит открыть VS Code.
  2. (по желанию) "Проверить.bat" — версии VS Code, расширения, Moon Core
     и состояние плавающего окна.
  3. Откройте VS Code и нажмите иконку книги слева — "Документация C++".

  Удаление:  "Удалить.bat"  и перезапустите VS Code
             (заодно снимет плавающее окно; Moon Core удалит только по вашему "да").

--- ПЛАВАЮЩЕЕ ОКНО поверх кода (не обязательно) ------------------

  При первом запуске VS Code расширение само предложит его включить.
  Позже:  F1 (или Ctrl+Shift+P) -> "Документация C++: подключить плавающее окно".
  Выключить:  F1 -> "Документация C++: отключить плавающее окно".
  Запасной способ снаружи:  "Плавающее-окно.bat" / "Убрать-окно.bat"
  (делают то же самое тем же кодом расширения).

  С Moon Core окно включается само — ничего делать не нужно.

  БЕЗ ПРАВ АДМИНИСТРАТОРА:
    Если VS Code установлен "для всех пользователей" (в Program Files),
    окно поверх кода без прав администратора не встанет. Тогда:
    * то же окно работает во вкладке VS Code — ничего не меняя в VS Code:
        F1 -> "Документация C++: открыть окно во вкладке";
    * насовсем — переустановите VS Code вариантом "User Installer"
      (ставится в папку пользователя, настройки и расширения сохранятся).
    Батники это определяют сами и подскажут; права администратора они
    просят только если вы сами согласитесь.

  ЕСЛИ ОКНО НЕ ПОЯВЛЯЕТСЯ:
    Запустите  "Диагностика.bat"  — он соберёт отчёт и сам скопирует его
    в буфер обмена: просто вставьте в сообщение. Копия — в файле otchet.txt
    рядом (или во временной папке, если эта только для чтения).
    Ничего на ПК он не меняет.

  Важно про окно (любой способ):
    * баннер "...appears to be corrupt" — закройте крестиком (ожидаемо);
    * после обновления VS Code окно пропадёт — расширение предложит вернуть;
    * "заморозка"/откат ПК при перезагрузке -> окно слетит после ребута.

--- MOON CORE (не обязательно) -----------------------------------

  Оформление и настройка интерфейса VS Code мышкой: убрать, увеличить,
  перекрасить элементы, профили вида. Через него же само встраивается
  плавающее окно документации. Лежит в этой папке (moon-core-*.vsix),
  отдельно качать не нужно. Работает и без него — документация от Moon Core
  не зависит.

--- Для опытных: тихий режим -------------------------------------

  Любой батник можно запустить с ключом  /q  — без пауз и вопросов
  (берутся ответы по умолчанию), например:  Установить.bat /q

--- Установка вручную (если батник не сработал) ------------------

  VS Code -> Extensions (Ctrl+Shift+X) -> "..." -> Install from VSIX... ->
  выбрать файл  cpp-docs-panel-*.vsix  из этой папки.

--- Состав папки -------------------------------------------------

  cpp-docs-panel-*.vsix — расширение;
  moon-core-*.vsix — Moon Core (по желанию);
  Установить.bat / Проверить.bat / Удалить.bat — установка/проверка/удаление;
  Плавающее-окно.bat / Убрать-окно.bat — окно (запасной способ);
  Диагностика.bat — отчёт о состоянии окна (если не появляется);
  tools — служебные файлы батников (трогать не нужно);
  Прочти-меня.txt — этот файл.
