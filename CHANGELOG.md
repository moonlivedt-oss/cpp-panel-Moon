# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Не выпущено]

### Добавлено

- **Наклейки-иллюстрации** в плавающем окне — на «пустых» местах и приветствии.
  У приветствия наклейка меняется вместе с прогрессом: **смайл** (0%) → **огонёк** (в
  процессе) → **корона** (100%). Плюс наклейки в «ничего не найдено», в пустом навигаторе
  и в поздравлении «Всё изучено!». Пять наклеек уже вырезаны из `dop/emo.jpg` (прозрачный
  фон) и лежат в `extension/stickers/`; встроены в окно командой `npm run embed:stickers`.
  Хочешь свои — замени файлы с теми же именами и запусти команду снова; если наклейки нет,
  рисуется аккуратная SVG-заглушка в том же духе. Спецификация и промпты для генерации —
  в `extension/stickers/README.md`.
- **Главный экран стал наряднее.** Наклейка-настроение теперь крупный «маскот» слева
  (вместо мелкой иконки у текста и дублирующего лого-книги — оно и так в шапке окна):
  наклон, тень, лёгкая анимация при наведении. Плавающая кнопка-запуск показывает
  наклейку-смайл вместо эмодзи 📘 — фирменное лицо даже при закрытом окне.

- **Задачник — прямо в окне.** Новый раздел меню «Задачник»: 10 тем, ~77 задач от 🟢 до 🔴,
  по нарастанию (типы → ввод/вывод → логика → функции → строки → контейнеры → алгоритмы →
  struct/файлы → «ловим баги» → «перепиши по-современному»). **Готовые ответы убраны намеренно** —
  чтобы задача учила: сначала решаешь сам, застрял — раскрываешь подсказку, дальше сверяешься с
  теорией. **Подсказки — сворачиваемые спойлеры** (`<details>`), внутри каждой темы — кликабельная
  ссылка на нужный раздел справочника. Лежит в `docs/zadachnik/`; в проверке `proverka.py` код
  задачника (намеренно битый/старый) из компиляции исключён, ссылки проверяются.
- **Рисованные иконки в меню и у задач.** Карточки «Быстрый доступ» на главном получили
  фирменные иконки (`icon-start/route/ref/examples/cheat/tasks`), а значки сложности 🟢🟡🔴 в
  задачах заменены на рисованные `level-1/2/3`. Встраиваются той же командой `npm run embed:stickers`
  (компактные 128px-версии в `extension/stickers/`).

### Исправлено · надёжность

- **Окно не ломается от подпорченного `localStorage`.** Словари состояния (отметки,
  закладки, прокрутка) санируются; масштаб шрифта клампится в [0.8..1.6] (раньше битое
  значение могло раздуть текст в разы); позиция и размер окна принимаются только числами.
- **Клик по материалу не падает молча.** Если файл исчез — понятное сообщение вместо
  ошибки; если встроенное превью Markdown отключено — материал открывается как текст.
- **«Подключить окно»** предупреждает, если данные документации не записались (нет папки
  `docs` или нет доступа к хранилищу), и не подключает пустое окно.
- **«Проверить окно»** показывает состояние файла данных (размер и когда обновлён) —
  частую причину пустого окна.
- **Упаковщик `.vsix`** делает предполётную проверку: обязательные файлы на месте,
  синтаксис `extension.js`/`cpp-docs-runtime.js` валиден, версии проекта и расширения
  сверены. Заведомо битый пакет больше не соберётся молча.

## [3.0.0] — 2026-09-14

Главное нововведение — **плавающее окно документации** поверх редактора, как окно
настроек у MoonLight custom-bg. По просьбе: удобнее читать всё в одном перетаскиваемом
окне, а не в узкой панели сбоку. Старая панель-сайдбар осталась как запасной вариант.

### Добавлено

- **Плавающее окно** (`extension/cpp-docs-runtime.js`). Перетаскивается за заголовок,
  тянется за края, запоминает позицию и размер. Внедряется в оболочку VS Code тем же
  загрузчиком, что и custom-bg: **Custom UI Style** (`subframe7536.custom-ui-style`) или
  **Custom CSS and JS** (`be5invis.vscode-custom-css`).
- **Чтение прямо в окне.** Markdown рендерится внутри окна: аккуратная типографика,
  **подсветка C++/bash**, кнопки **«копировать код»**, таблицы, врезки, оглавление файла
  (кнопка «Разделы») и **переходы по внутренним ссылкам** между файлами с прыжком к якорю.
- **Навигатор по всем материалам** в окне: группы (сворачиваются), поиск по названию,
  описанию и тексту, полоса прогресса «изучено N из M», кнопка **«Продолжить»**, отметки
  «изучено» и закладки. Плавающая кнопка-запуск **«📘 C++»** в углу редактора.
- **Тема** окна подхватывается из VS Code (светлая/тёмная) автоматически.
- **Акцентный цвет — под твою тему.** Окно красится акцентом из живых CSS-переменных
  оболочки: сначала `--mlbg-accent` от MoonLight custom-bg (акцент из обоев — тогда окно
  совпадает с остальным редактором и меняется вслед за обоями), иначе `--vscode-focusBorder`
  активной темы. Обновляется на лету при смене темы/обоев. Ничего настраивать вручную не надо.
- Команды: **«подключить плавающее окно»**, «отключить», «проверить» (и кнопка-окно в
  шапке панели). При первом запуске, если загрузчик уже стоит, окно предлагается включить.
- Данные материалов расширение генерирует в `cpp-docs-data.js` (globalStorage) и обновляет
  при правке любого `.md`; экспортирована чистая функция `buildDocsData()`.
- Превью окна в браузере: `npm run preview:window` → `docs/preview-window.html`.

### Интерфейс окна — 14 улучшений (доработка 3.0.0)

Всё мышью, без горячих клавиш:

- **Вкладки** внутри окна: ⧉ у файла или Ctrl/средняя кнопка — открыть в новой вкладке;
  полоса вкладок с закрытием, переключение кликом. Повторное открытие не плодит дубли.
- **Сплит** — второй документ рядом (кнопка ⊟ в шапке или у файла): справочник и пример
  бок о бок, каждый со своей прокруткой.
- **«Назад / Вперёд»** по истории переходов (стрелки ‹ › в шапке) + **«‹ Предыдущая /
  Следующая ›»** по порядку маршрута внизу статьи.
- **Боковое оглавление-рейка** вместо выпадашки: следит за прокруткой и подсвечивает
  текущий раздел; кнопка «Разделы» показывает/прячет, на узком окне прячется само.
- **Хлебные крошки** «Файл › текущий раздел» и **полоса прогресса чтения** в шапке читалки.
- **Память позиции**: каждый файл открывается там, где ты его оставил.
- **Вид** (кнопка Aa): размер шрифта A−/A+, ширина колонки (уже/шире), плотность списка.
- **Привязки окна**: половина слева/справа, во весь экран/восстановить (◧ ◨ ▢).
- **Врезки** окрашиваются по значку (⚠️ ✅ ❌ 💡), плавная прокрутка и **подсветка**
  места перехода по ссылке, мягкое проявление статьи, фокус-обводки для доступности,
  «ничего не найдено» в поиске.

### Как включить

1. Убедись, что стоит загрузчик (у автора vscode-bg он уже есть).
2. Палитра команд → **«Документация C++: подключить плавающее окно»** (или кнопка-окно
   в шапке панели) → «Применить».
3. После перезагрузки окна нажми пилюлю **«📘 C++»** справа внизу.

## [2.9.0] — 2026-09-13

Проще и красивее. По просьбе: интерфейс важнее «быстрых кнопок» — убрал лишнее и
навёл вид. Учебные штуки (прогресс, «Продолжить», время чтения, отметки «изучено»)
остались.

### Убрано

- **Ряд кнопок-иконок** над списком (`⚄` наугад, `▤` компактный режим, `▦` сетка/список,
  `✓` скрыть изученное, `⇕` свернуть всё, `◧` в сайдбар) — визуальный шум, которым почти не
  пользуются. Группы по-прежнему сворачиваются кликом по заголовку.
- **Чипы-фильтры** по разделам и чип «Обновлённые» — материалы и так разложены по группам,
  а поиск находит нужное.
- **Мелкие действия у пункта** `⇥` (открыть рядом) и `</>` (открыть как текст) — открытие как
  текст осталось на правом клике.

### Изменено

- **Чистая шапка.** Одно крупное поле поиска с иконкой; под ним — прогресс и **▶ Продолжить**;
  справа тихий счётчик материалов. Ничего лишнего.
- **Красивее список.** Больше воздуха между пунктами, ровная иерархия «заголовок → описание →
  время чтения», аккуратные скруглённые пилюли и мягкие акценты. В отдельной панели материалы
  по-прежнему раскладываются в колонки (автоматически, без кнопки).
- У пункта при наведении осталось три действия: отметить изученным (○/✓), разделы (▸),
  закрепить (★).

## [2.8.0] — 2026-09-13

Пятнадцать улучшений: обучение, поиск, доступность и производительность. Плюс
починка давнего бага с оглавлениями.

### Добавлено

- **Время чтения и число разделов.** У каждого материала под описанием — тихая строка
  «~N мин · M разделов». Видно объём, не открывая файл.
- **Кнопка «▶ Продолжить».** Открывает следующий неизученный материал по порядку списка —
  учёба движется по справочнику сверху вниз, пропуская прочитанное. Гаснет, когда всё изучено.
- **Процент в прогрессе.** Полоса теперь показывает «изучено N из M · %».
- **Ручная отметка «изучено».** Кнопка ○/✓ у пункта ставит и снимает отметку без открытия
  файла — удобно отметить знакомую тему или снять случайную.
- **Фильтр «● Обновлённые».** Чип под поиском оставляет только тронутое за последние сутки.
- **«Наугад» предпочитает неизученное.** При учёбе кнопка `⚄` тянет случайный материал из
  непрочитанных, если такие есть.
- **Открепить всё.** Крестик в шапке группы «Закреплённое» — как у «Недавнего».
- **Внятная заглушка поиска.** Вместо сухого «Ничего не нашлось» — с самим запросом
  («Ничего не нашлось: «…»») и кнопкой «Сбросить поиск».

### Изменено

- **Поиск без учёта регистра и ё/е.** Запрос «всё» находит «все» и наоборот. Подсветка и
  фрагмент-контекст остаются на месте.
- **Кнопка «C++» в статус-баре видна сразу после старта VS Code** (`onStartupFinished`), а не
  только после первого открытия сайдбара.
- **Клавиатура.** `PageUp`/`PageDown` — прыжок по списку страницами; `Ctrl+K` (`Cmd+K`) —
  прыжок в поиск, не выходя из панели.
- **Доступность.** Поиск помечен как `combobox`, а активный пункт — через
  `aria-activedescendant`: скринридер зачитывает его при навигации стрелками. Число находок
  объявляется с правильным окончанием. При системной настройке «меньше движения»
  (`prefers-reduced-motion`) анимации и переходы отключаются.

### Исправлено

- **Оглавления больше не висят раскрытыми.** Правило `.item-toc { display: flex }` перебивало
  атрибут `hidden`, поэтому все оглавления показывались развёрнутыми, а кнопка `▸` только
  крутила стрелку. Теперь свёрнутое оглавление действительно скрыто, список чище.

### Ускорено

- **Файл читается один раз.** Раньше `describe()` открывал каждый файл четырежды (заголовок,
  описание, текст, разделы). Теперь — одно чтение, из него берётся всё.
- **Кэш по `mtime`.** Неизменные файлы не перечитываются и не разбираются заново при каждой
  перерисовке (открытие материала, закладка, срабатывание слежения за файлами).

## [2.7.0] — 2026-09-11

Десять улучшений меню-панели: во всю ширину теперь работает как надо.

### Добавлено

- **Адаптивная сетка колонок.** В широкой панели материалы раскладываются в
  несколько колонок и используют всю ширину; в узком сайдбаре — один столбец.
- **Тумблер «сетка ⇄ список»** (`▦`) — можно принудительно оставить один столбец даже
  в широком окне. Выбор запоминается.
- **Фильтр-чипы по разделам** под поиском: одним кликом — «только Справочник»,
  «только Примеры» и т. д. Выбранный раздел запоминается.
- **Отметки «изучено» (✓)** у материалов, которые открывали. Хранятся между сессиями.
- **Полоса прогресса «изучено N из M»** в шапке + кнопка сброса прогресса (`↺`).
- **«Скрыть изученное»** (`✓` в тулбаре) — оставить в списке только то, что ещё не читал.
- **«Открыть рядом» (`⇥`)** у каждого пункта — материал открывается в соседней колонке,
  меню-панель остаётся видимой.
- **Кнопка «в сайдбар» (`◧`)** — быстро вернуть список в боковую панель.
- **Горячая клавиша `Ctrl+Alt+M`** — открыть меню отдельной панелью.
- **Шапка панели** (название + подсказка) в широком окне — панель больше не выглядит голой.

## [2.6.0] — 2026-09-11

Меню можно открыть отдельной панелью — не только в левом сайдбаре.

### Добавлено

- **Меню отдельной панелью.** То же меню теперь открывается во всю ширину в области
  редактора — через кнопку **«C++»** в статус-баре, кнопку **↗** в шапке вьюхи или команду
  «Документация C++: открыть меню отдельной панелью». Когда в узком сайдбаре тесно —
  открываешь панель.
- Сайдбар и панель **синхронизированы**: общий список, закладки, «недавнее» и подсветка
  открытого файла; обновление одного места обновляет и другое.

### Изменено

- `Ctrl+Alt+D` (фокус поиска) работает с отдельной панелью, если она открыта, — иначе
  с сайдбаром, как раньше.
- Обработка сообщений и сборка HTML вынесены в общий код для обоих мест (без дублирования).

## [2.5.0] — 2026-09-11

Починка багов навигации и путей.

### Исправлено

- **Свёрнутость групп больше не путается.** Раньше состояние сворачивания было привязано
  к порядковому номеру группы, и появление «Недавнего»/«Закреплённого» сверху сдвигало
  индексы — сворачивалась не та группа. Теперь ключ — имя группы.
- **Порядок пунктов не перемешивается после поиска.** При сбросе поиска материалы
  возвращаются в исходном порядке, а не «всплывают» в конец группы.
- **Хоткей открывает закрытую панель.** `Ctrl+Alt+D` теперь сначала открывает панель,
  если она была закрыта, и только потом ставит фокус в поиск.
- **Нет дублей в результатах поиска.** Один и тот же файл (например, из «Недавнего» и из
  «Справочника») показывается в находках один раз.
- **Путь из настройки проверяется.** `cppDocs.path` принимается, только если это
  действительно папка с документацией; иначе — понятная заглушка, а не пустые группы.

### Изменено

- Путь по умолчанию и текст заглушки теперь указывают на
  `D:\Desktop\components\cpp-docs-panel`.

## [2.4.0] — 2026-09-11

Десять улучшений навигации: панель стала быстрее находить и открывать нужное.

### Добавлено

- **Закреплённое.** Звёздочка при наведении прикрепляет материал в группу наверху;
  выбор сохраняется между сессиями. Быстрый доступ к тому, что открываешь чаще всего.
- **Оглавление материала.** У пункта появился раскрывающийся список разделов (`##`/`###`);
  клик по разделу открывает файл сразу на нужной строке.
- **Метка группы в результатах поиска.** В плоском списке находок у каждого пункта видно,
  из какого раздела он пришёл.
- **Память прокрутки.** Список больше не прыгает в начало при возврате на вкладку.
- **Кнопка «наверх».** Появляется при длинном списке; возвращает к поиску.
- **Компактный режим.** Кнопка `▤` в шапке уплотняет список и прячет описания; состояние
  запоминается.
- **Индикатор «недавно изменён».** Зелёная точка у файлов, тронутых за последние сутки —
  видно, что обновилось.
- **«Наугад».** Кнопка `⚄` открывает случайный материал (при поиске — из найденного) —
  удобно для учёбы.
- **Команда и горячая клавиша.** `Ctrl+Alt+D` (`Cmd+Alt+D`) открывает панель и ставит курсор
  в поиск. Команда «Документация C++: искать в панели» есть и в палитре.
- **Доступность.** Активный пункт помечается `aria-selected`, а число находок объявляется
  скринридеру через живую область.

## [2.3.0] — 2026-09-10

Удобство интерфейса: панель теперь показывает контекст и не прячет действия.

### Добавлено

- **Подсветка открытого файла.** Пункт того материала, что сейчас открыт в редакторе,
  выделяется в списке — сразу видно, где ты находишься. Обновляется при переключении
  вкладок и когда панель снова становится видимой, без полной перерисовки.
- **Кнопка «открыть как текст» на пункте.** При наведении справа появляется `</>` —
  открыть исходный Markdown вместо превью. Раньше это был только правый клик, о котором
  никто не догадывался; правый клик тоже работает по-прежнему.
- **Очистка «Недавнего» из панели.** Крестик в шапке группы «Недавнее» — раньше очистить
  список можно было только командой из палитры.
- **Счётчик всего.** В покое справа под поиском видно «N материалов» (с правильным
  окончанием), а не пусто.
- **Кнопка «Открыть настройки»** на экране «папка не найдена» — сразу перейти к `cppDocs.path`,
  а не искать настройку руками.
- **Видимые фокус-рамки** на поиске, кнопках и заголовках групп — панелью удобнее пользоваться
  с клавиатуры.

## [2.2.0] — 2026-09-10

Поиск стал умнее, панель — живее.

### Добавлено

- **Поиск по нескольким словам.** Запрос `map вектор` находит пункты, где есть оба слова
  (в названии, описании или тексте файла), а не ищет всю строку целиком. Подсвечивается
  каждое слово, где бы оно ни встретилось.
- **Фрагмент-контекст.** Когда совпадение нашлось в тексте файла, панель показывает не сухое
  «найдено в тексте файла», а кусочек текста вокруг слова — сразу видно, за что нашлось.
- **Автообновление.** Панель следит за `*.md` в папке документации: добавили, изменили или
  удалили файл — список освежается сам, вручную «обновить» жать не нужно.

### Исправлено

- **Разбивка запроса ломалась на шаблонной строке.** Регулярное выражение `/\s+/` внутри
  встроенного скрипта превращалось в `/s+/` — панель делила запрос по букве «s», а не по
  пробелам. Теперь разбивка по пробелам, поиск нескольких слов работает как надо.
- **Тесты интерфейса молча пропускались.** Смоук-тест искал документацию по жёсткому пути
  `D:/Desktop/C++/docs`; если его нет, 16 проверок вёрстки просто не выполнялись. Теперь тест
  берёт собственный `docs/` проекта — проверок стало 40, и они реально работают.

### Ускорено

- **Дебаунс поиска.** На быстром наборе панель больше не перебирает и не двигает пункты на
  каждой букве — фильтр срабатывает через короткую паузу.

## [2.1.0] — 2026-09-10

Дизайн и удобство: панель стала быстрее в работе, а не только красивее.

### Добавлено

- **Клавиатура.** `↑` `↓` — выбрать пункт, `Enter` — открыть, `Ctrl+Enter` — открыть как текст,
  `Esc` — очистить поиск, `/` — прыгнуть в поиск. Активный пункт подсвечивается и сам
  прокручивается в видимую часть.
- **Поиск по содержимому файлов.** Раньше запрос «тест» не находил ничего, хотя файл про
  тестирование есть: искали только по названию и описанию. Теперь индексируется и текст
  (первые 6 КБ, без блоков кода), а такие совпадения помечаются подписью «найдено в тексте файла».
- **Ранжирование результатов.** При поиске список становится плоским и сортируется: сначала
  совпадения в начале названия, потом в названии и описании, потом в тексте. Без этого по запросу
  «ошибк» файл «Ошибки компилятора» оказывался не на первом месте.
- **Подсветка совпадений** в названиях и описаниях.
- **Сворачивание групп** кликом по заголовку; состояние и текст поиска переживают переключение
  вкладок. Кнопка «⇕» сворачивает и разворачивает всё разом.
- **Группа «Недавнее»** — четыре последних открытых файла.
- **Счётчики** у групп и счётчик найденного при поиске.
- **Цветные маркеры** у групп: справочник, примеры и демо различаются с одного взгляда.

### Исправлено

- Установка через `npm run install:vsix` печатала предупреждение Node о `shell:true`.
  Теперь `code.cmd` вызывается через `cmd.exe` явно, вывод чистый.
- Превью в браузере падало на `getState`: у заглушки моста не было методов состояния,
  из-за чего список выглядел пустым.

## [2.0.0] — 2026-09-10

Переход с простого списка на полноценную панель.

### Добавлено

- **Webview вместо дерева файлов.** Раньше панель была обычным `TreeView` — плоский список
  без описаний. Теперь это HTML-панель: у каждого пункта заголовок и описание, между группами
  видна структура.
- **Живой поиск** по названию, описанию и имени файла. Группы, где ничего не нашлось, скрываются.
- **Описания из самих файлов** — берутся из первой строки цитаты `>`, обрезаются по границе слова.
- **Кнопки задач** внизу панели: «Прогнать тесты» и «Проверить доки».
- **Группа «Один инструмент — разные задачи»** для папки `situacii`.
- **Свой упаковщик `.vsix`** (`scripts/package-extension.js`) — ZIP пишется поверх встроенного
  `zlib`, зависимостей не нужно.
- **Смоук-тест** (`test/smoke.js`) — 24 проверки без запуска VS Code.

### Исправлено

- **Расширение не устанавливалось.** Папка просто клалась в `~/.vscode/extensions`, и VS Code 1.121
  помечал её как удалённую (`Marked extension as removed` в `sharedprocess.log`) — иконка не
  появлялась вовсе. Теперь ставится нормальным пакетом через `code --install-extension`.
- **Описания рвались на полуслове** («…и искать по папкам не при»). Обрезка идёт по границе слова.
- **Экранирование.** Кавычки и угловые скобки в заголовках файлов ломали разметку панели.

### Известные особенности

- При запуске VS Code через **VSCodeLauncher** расширение нужно один раз прописать в
  `extra_categories` его конфига, иначе лаунчер отключит его как незнакомое:

  ```json
  "extra_categories": { "local.cpp-docs-panel": "cpp" }
  ```
