# Окно документации

Справочник, задачник и примеры открываются в **окне поверх редактора** — читаешь тему и тут же пишешь код.

Два способа:

- **Во вкладке** — обычная вкладка VS Code, ничего не меняет в самом редакторе. Хороший старт.
- **Плавающее окно** — поверх кода, его можно двигать, сворачивать в полоску и закреплять справа (редактор тогда сдвигается). Для этого расширение один раз правит оболочку VS Code — появится баннер «…corrupt», его можно закрыть.

При первом открытии окно само покажет три главные кнопки.
