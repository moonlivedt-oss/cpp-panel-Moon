# Прогресс не потеряется

Изученные темы, решённые задачи, карточки и заметки хранятся в окне и **каждый день** копируются в резервную копию (последние 14 дней).

Перед переустановкой VS Code или на другом компьютере: **«Документация C++: сохранить копию прогресса…»**, потом **«…загрузить прогресс из файла…»**.
