# Подсказки по правилам курса

В твоём `.cpp` синей волной подсвечиваются привычки, от которых курс отучает: `using namespace std;`, `rand()`, `std::endl` в цикле, переменная без значения, `(int)x`, `new`/`delete`, `NULL`, `printf`.

Это не ошибки — подсказки. У каждой есть **«📘 Почему так»** (открывает раздел справочника), а где можно — быстрое исправление. Выключить: настройка `cppDocs.styleHints`.
