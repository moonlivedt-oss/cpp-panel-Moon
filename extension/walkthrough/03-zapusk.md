# «Напиши и запусти»

В задачах с кнопкой **«Запустить»** код собирается твоим компилятором (g++, clang++ или MSVC) и прогоняется по тестам прямо в окне.

По умолчанию это выключено: расширение ничего не запускает без спроса. Включи настройку **`cppDocs.localRun`**. Компилятор ищется сам; если не нашёлся — укажи путь в `cppDocs.compiler`.
