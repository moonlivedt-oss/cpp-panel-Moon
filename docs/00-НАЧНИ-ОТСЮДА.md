| Симптом | Причина | Где смотреть |
|---|---|---|

| Все числа вдруг с двумя знаками после точки | `setprecision` действует до отмены | [Ввод и вывод](ref/02-vvod-vyvod.md) |
| Ввёл `5`, получил `53` | `char` вместо `int` | [Основы](ref/01-osnovy.md) |
| Проверка `n >= 0` не срабатывает | `unsigned` вместо `int` | [Основы](ref/01-osnovy.md) |
| Большие числа дают минус | переполнение `int`, нужен `1LL *` | [Основы](ref/01-osnovy.md) |
| Ошибка совсем не про ту строку, на которую показывают | имя занято в `windows.h` (`ERROR`, `SIZE`…) | [Основы](ref/01-osnovy.md) |

| Условие всегда истинно | `=` вместо `==`, или `1 < x < 10` | [Арифметика и циклы](ref/03-logika-cikly.md) |

| Цикл выполняется на раз больше / не выполняется | `<=` вместо `<`; `while (n > 0)` для минуса | [Арифметика и циклы](ref/03-logika-cikly.md) |
| Изменения в цикле не сохраняются | `for (auto x : v)` вместо `for (auto &x : v)` | [Арифметика и циклы](ref/03-logika-cikly.md) |

## Полезное напоследок

**Перед тем как показать работу** — [чеклист](ref/09-spravka.md#25-чеклист-перед-сдачей), это 60 секунд.

**Проверить, что документация не устарела** — запусти из папки `docs`:

```bash
python proverka.py
```

Скрипт соберёт весь код из документации твоим компилятором, сверит примеры с файлами `.cpp` и проверит все ссылки. Полезно после любых правок — и просто чтобы убедиться, что советы здесь всё ещё работают.

**Панель в VS Code.** Если установлено расширение `cpp-docs-panel`, иконка книги в верхнем ряду открывает всё это списком — искать файлы вручную не нужно.

**Где смотреть правду:** [cppreference.com](https://en.cppreference.com/) — не учебник, а справочник. Сначала непривычно, потом окажется, что там есть ответ на любой вопрос.
