## Квест 3. Игровой цикл и первый бой

**Нужна тема:** [Логика и циклы](../ref/03-logika-cikly.md).

Теперь это игра: цикл крутится, пока герой жив и игрок не вышел.

- Меню хода: `1 — идти дальше`, `2 — отдохнуть (+5 HP, не выше максимума)`, `0 — выход`.
- Каждый третий шаг вглубь — встреча с монстром (`шаг % 3 == 0`). Монстр: HP 12, атака 3.
- Бой — **свой цикл**: герой бьёт, монстр отвечает, пока кто-то не упадёт. Победа — +10 золота.
- Герой погиб — «Игра окончена» и итог: сколько шагов прошёл, сколько золота собрал.

Скелет цикла (дополните сами):

```cpp
int step = 0;
bool running = true;
while (running && hp > 0) {
  // показать статус
  // прочитать выбор
  // switch (choice) { ... }
}
```

```checklist
Квест 3 готов, если:
- меню повторяется, пока не выбран выход
- отдых не поднимает здоровье выше максимума
- бой заканчивается, когда у кого-то HP ≤ 0, и не уходит в минус на экране
- после гибели героя игра честно заканчивается
```

## Квест 4. Порядок в коде: функции

**Нужна тема:** [Функции](../ref/04-funkcii.md).

`main` уже длинный — разложите его:

- `void printStatus(const std::string &name, int hp, int maxHp, int gold)`;
- `int readChoice(int min, int max)` — спрашивает, пока не введут число в диапазоне;
- `void rest(int &hp, int maxHp)` — меняет здоровье **по ссылке**;
- `bool fight(int &heroHp, int heroAtk, int monsterHp, int monsterAtk)` — возвращает `true`, если герой победил.

```checklist
Квест 4 готов, если:
- в main нет ни одного вложенного цикла — они ушли в функции
- параметры, которые функция меняет, переданы по ссылке, остальные — по значению или `const &`
- поведение игры не изменилось
```

**Проверь кирпичик автоматически** — отдельная маленькая программа с тем же приёмом, что нужен в игре. Готовых решений нет; тесты скажут, верно ли.

```challenge
@id csgwoa2
@type run
@hint `hp += 5;`, а потом ограничь сверху: `if (hp > maxHp) hp = maxHp;`.
@hint `&` в `int &hp` — это и есть «по ссылке»: функция меняет переменную из `main`, а не свою копию.
Кирпичик квеста: допиши функцию `rest` — отдых даёт +5 HP, но не выше максимума. Здоровье она меняет **по ссылке**, поэтому ничего не возвращает. Вход: `hp maxHp сколько-раз-отдохнуть`, вывод — здоровье после отдыха.
---
#include <iostream>

void rest(int &hp, int maxHp) {
    // твой код: +5 к hp, но не выше maxHp
}

int main() {
    int hp = 0, maxHp = 0, times = 0;
    std::cin >> hp >> maxHp >> times;
    for (int i = 0; i < times; ++i) rest(hp, maxHp);
    std::cout << hp << "\n";
}
---
# упор в максимум — самый частый баг
10 30 2 => 20
28 30 1 => 30
30 30 3 => 30
0 30 0 => 0
```
