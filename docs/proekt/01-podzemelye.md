## Как работать с проектом

- **Один проект на весь курс.** Создайте папку `podzemelye` и в ней `main.cpp`. Каждый квест **дописывает** его, а не начинает заново.
- **Квест открывайте после темы.** Рядом с каждым квестом — ссылка на тему, которая для него нужна. Забегать вперёд не стоит: на квесте 3 ещё не нужны классы.
- **Готовых решений нет — и это нарочно.** Есть цель, список «что добавить» и чек-лист «готово, если». Застряли — вернитесь в тему по ссылке.
- **Сохраняйте работающие версии — коммитами.** Сделайте в папке проекта `git init`, а после каждого квеста — коммит (команда подсказана в конце квеста). Так видно, как игра росла, и всегда есть куда откатиться. Без git — копируйте `main.cpp` в `main-kvest-N.cpp`.

- **[Глава 1. Герой оживает](02-glava-1-osnovy.md)** — карточка героя, ввод с клавиатуры, игровой цикл с первым боем и порядок в коде через функции.

- **[Глава 3. Классы и карта](04-glava-3-klassy-i-karta.md)** — класс героя, семейство монстров через наследование и карта подземелья с движением.
