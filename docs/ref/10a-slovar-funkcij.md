## Тема 1. Основы

**`static_cast<T>(x)`** — явно превратить значение в тип `T`. `static_cast<double>(sum)` заставляет деление считаться в дробных, а не отбрасывать хвост. Читается «взять `x` как `T`». → [раздел 5](03-logika-cikly.md#5-арифметика-и-её-ловушки)

**`const`** — «эта переменная больше не меняется»: `const int max = 100;`. Помечай `const` всё, что не должно меняться — компилятор поймает случайную запись, а читателю сразу видно намерение. → [раздел 3](01-osnovy.md#3-переменные-и-константы)

**`constexpr`** — «значение известно ещё при компиляции»: `constexpr int size = 8;`. Строже `const`: годится под размер массива и считается до запуска программы. → [раздел 3](01-osnovy.md#3-переменные-и-константы)

**`std::numeric_limits<T>::max()` / `::min()`** — самое большое и самое маленькое значение типа `T`. Нужны для стартового значения при поиске минимума/максимума и чтобы проверить границу типа. Нужен `<limits>`. → [раздел 2](01-osnovy.md#2-типы-данных)

**`1LL * ...`** — приём против переполнения: первое слагаемое/множитель делаем `long long`, и всё выражение считается в широком типе. `1LL * a * b` не переполнится там, где `a * b` (два `int`) молча даст бессмыслицу. → [раздел 2](01-osnovy.md#2-типы-данных)

**`sizeof(x)`** — размер типа или переменной в байтах, не длина текста. `sizeof(int)` обычно `4`. У строки покажет размер объекта-«ручки», а не длину — для длины есть `.size()`. → [раздел 2](01-osnovy.md#2-типы-данных)

## Тема 2. Ввод и вывод

**`std::cin >> x`** — прочитать из клавиатуры **одно значение** до пробела/перевода строки. Пробелы в начале пропускает сам. Для чисел останавливается на первом не-числе. → [раздел 4](02-vvod-vyvod.md#4-ввод-и-вывод)

**`std::cout << x`** — напечатать значение. Цепляется: `std::cout << "x = " << x << "\n";`. Перевод строки пиши `"\n"`, а не `std::endl` (последний ещё и сбрасывает буфер — в цикле тормозит). → [раздел 4](02-vvod-vyvod.md#4-ввод-и-вывод)

**`std::getline(cin, s)`** — прочитать из потока **целую строку** вместе с пробелами, до перевода строки (сам символ выбрасывается, в `s` не попадает). Именно так читают имя с пробелом или строку файла — `cin >> s` взял бы только первое слово. Ловушка: после `cin >> n` в буфере остаётся Enter, и следующий `getline` вернёт пустую строку — вставь между ними `cin.ignore(...)`. → [раздел 4](02-vvod-vyvod.md#4-ввод-и-вывод)

**`std::getline(поток, поле, ';')`** — та же функция с третьим аргументом: читать до **своего** разделителя, а не до перевода строки. Так разбирают CSV: `getline(ss, field, ';')`. → [раздел 10](05-stroki.md#разбить-строку-по-разделителю)

**`cin.ignore(n, ch)`** — выбросить из буфера символы (до `n` штук или до символа `ch`). Классика — `std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');` после чтения числа перед `getline`. → [раздел 4](02-vvod-vyvod.md#4-ввод-и-вывод)

**`cin.clear()`** — снять с потока пометку об ошибке, чтобы можно было читать дальше. Нужен, когда пользователь ввёл букву вместо числа: сначала `clear()`, потом `ignore(...)` (выкинуть плохой ввод). → [раздел 4](02-vvod-vyvod.md#4-ввод-и-вывод)

**`while (cin >> x)`** — читать поток чисел, **пока они идут**. Условие ложно на конце ввода (`Ctrl+Z`) или на первом не-числе. Стандартный способ «прочитать неизвестно сколько чисел». → [раздел 4](02-vvod-vyvod.md#4-ввод-и-вывод)

**`std::format("{}", x)`** — собрать строку по шаблону: `{}` — место для значения, `{:.2f}` — дробь с двумя знаками. `std::format("Итог: {:.2f}", sum)`. Нужен `<format>`. → [раздел 4](02-vvod-vyvod.md#4-ввод-и-вывод)

## Тема 3. Логика и циклы

**`a / b`** (целые) — целочисленное деление: дробная часть **отбрасывается**, `7 / 2` даёт `3`. Хочешь дробный результат — сделай один операнд `double`: `static_cast<double>(a) / b`. → [раздел 5](03-logika-cikly.md#5-арифметика-и-её-ловушки)

**`a % b`** — остаток от деления: `7 % 2` даёт `1`. Проверка на чётность — `x % 2 == 0`; последняя цифра числа — `x % 10`. Ловушка: `b == 0` — это UB (программа падает или выдаёт мусор). → [раздел 5](03-logika-cikly.md#5-арифметика-и-её-ловушки)

**`switch (x) { case ...: }`** — разветвление по значению: удобнее лестницы `if-else if`, когда сравниваешь одну переменную с набором вариантов. Не забывай `break;` в конце каждого `case` и `default:` на «всё остальное». → [раздел 7](03-logika-cikly.md#7-ветвления)

**`enum class Имя { A, B }`** — свой тип с именованными вариантами вместо «магических» чисел: `enum class Menu { Add, Remove };`. Не путается с числами; в число превращается только явным `static_cast`. → [раздел 7](03-logika-cikly.md#enum-class--имена-вместо-магических-чисел)

**`std::min(a, b)` / `std::max(a, b)` / `std::clamp(x, lo, hi)`** — меньшее/большее из двух; `clamp` загоняет `x` в диапазон `[lo; hi]` (C++17). `std::clamp(hp, 0, 100)`. Нужен `<algorithm>`. → [раздел 5](03-logika-cikly.md#удержать-число-в-границах-min-max-clamp)

## Тема 4. Функции

**Функция** — именованный кусок кода, который принимает аргументы и (обычно) возвращает результат: `int square(int x) { return x * x; }`. Выносишь повторяющийся код — читается лучше и правишь в одном месте. → [раздел 9](04-funkcii.md#9-функции)

**Параметр по ссылке `T&`** — функция получает **саму** переменную, а не копию: `void grow(int &x) { ++x; }` меняет оригинал у вызывающего. Так же возвращают несколько значений — через несколько ссылок-параметров. → [раздел 9](04-funkcii.md#9-функции)

**Параметр `const T&`** — «дай посмотреть, копировать не нужно». Так передают строки и контейнеры: `void print(const std::string &s)` — без копирования всей строки и без права её испортить. По умолчанию так и передавай всё крупное. → [раздел 9](04-funkcii.md#9-функции)

**Лямбда `[](...){...}`** — безымянная функция прямо в месте использования: `[](int x){ return x % 2 == 0; }`. Квадратные скобки — **захват**: что из окружения ей видно (`[limit]` — копия, `[&limit]` — ссылка). Их принимают алгоритмы вроде `count_if`. → [раздел 9](04-funkcii.md#9-функции)

**`auto`** — «выведи тип сам». Удобно для длинных типов итераторов и в `for (const auto &x : v)`. Не злоупотребляй там, где тип важен читателю. → [раздел 9](04-funkcii.md#9-функции)

**`std::optional<T>`** — «значение либо есть, либо нет»: честный способ вернуть «не нашёл» без магических `-1`. Проверка `if (result)`, само значение — `*result` или `result.value()`. Нужен `<optional>`. → [раздел 9](04-funkcii.md#stdoptional--когда-ответа-может-не-быть)

## Тема 5. Строки

**`std::string`** — текст: имя, слово, строка из файла. Складывается через `+`, ищется, режется. Ловушка: кириллица в UTF-8 — 2 байта на букву, поэтому `s[i]` и `substr` по русскому тексту ломают символы (для посимвольных задач бери латиницу). → [раздел 10](05-stroki.md#10-stdstring)

**`s.size()` / `s.length()`** — длина строки. Это одно и то же. Считает **байты**, не буквы (см. про кириллицу выше). → [раздел 10](05-stroki.md#основные-операции)

**`s.empty()`** — `true`, если строка пустая. Понятнее и надёжнее, чем `s.size() == 0`. → [раздел 10](05-stroki.md#основные-операции)

**`s.substr(pos, len)`** — вырезать подстроку: с позиции `pos`, длиной `len` символов (без `len` — до конца). `s.substr(0, 3)` — первые три. Ловушка: `pos` больше длины — исключение. → [раздел 10](05-stroki.md#основные-операции)

**`s.find(x)`** — найти позицию первого вхождения символа или подстроки `x`. Вернёт `std::string::npos`, если не нашёл (сравнивай **только** с ним, не с `-1`). `s.rfind(x)` — то же, но с конца. → [раздел 10](05-stroki.md#поиск)

**`s.starts_with(x)` / `s.ends_with(x)`** — начинается/кончается ли строка на `x` (C++20). `name.ends_with(".cpp")`. Читается как предложение, не надо возиться с позициями. → [раздел 10](05-stroki.md#starts_with-и-ends_with--начало-и-конец-строки)

**`std::stoi(s)` / `std::stod(s)` / `std::stoll(s)`** — превратить строку в число: `int`, `double`, `long long`. `std::stoi("42")` даёт `42`. Ловушка: на «abc» бросает исключение `std::invalid_argument`. → [раздел 10](05-stroki.md#преобразования-числа-и-строки)

**`std::to_string(n)`** — обратно: число в строку. `std::to_string(42)` даёт `"42"`. У `double` добавит хвост нулей — для аккуратного вида бери `std::format`. → [раздел 10](05-stroki.md#преобразования-числа-и-строки)

**`s.push_back(c)` / `s.append(t)`** — добавить в конец один символ / целую строку. `s += t` — то же, что `append`. → [раздел 10](05-stroki.md#вставка-удаление-замена)

**`s.insert(pos, t)` / `s.erase(pos, n)` / `s.replace(pos, n, t)`** — вставить `t` на позицию, удалить `n` символов, заменить `n` символов на `t`. Правят строку **на месте**, вручную новую собирать не нужно. → [раздел 10](05-stroki.md#вставка-удаление-замена)

**`s.at(i)` против `s[i]`** — оба берут символ по индексу. `s[i]` не проверяет границы (за пределами — мусор или порча памяти), `s.at(i)` проверяет и бросает исключение. Пока учишься — держи флаг `-D_GLIBCXX_ASSERTIONS`, он ловит и `s[i]` за границей. → [раздел 10](05-stroki.md#вставка-удаление-замена)

**`std::reverse(s.begin(), s.end())`** — перевернуть строку (или вектор) на месте: `"hello"` → `"olleh"`. Нужен `<algorithm>`. → [раздел 10](05-stroki.md#типовые-задачи)

**`std::toupper(c)` / `std::tolower(c)`** — сменить регистр одного символа (только латиница). Правильная запись из-за не-ASCII байтов: `c = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));`. Нужен `<cctype>`. → [раздел 10](05-stroki.md#перебор-символов)

**`s.find_first_not_of(set)` / `s.find_last_not_of(set)`** — позиция первого/последнего символа, которого **нет** в наборе `set`. Основа функции `trim` — обрезать пробелы по краям: `find_first_not_of(" \t\n\r")`. → [раздел 10](05-stroki.md#обрезать-пробелы-trim)

**`std::istringstream ss(line)`** — превратить строку в поток, чтобы читать из неё как из `cin`. `while (ss >> word)` разбивает по пробелам (лишние пробелы пропускаются сами). Нужен `<sstream>`. → [раздел 10](05-stroki.md#разбить-строку-по-разделителю)

**`std::string_view`** — «окно» в чужую строку без копирования: удобно для параметра функции, которая текст только читает. Ловушка: не переживает строку, из которой сделано (висячая ссылка). Нужен `<string_view>`. → [строки-обзоры](15-string-view.md)

## Тема 6. Контейнеры

**`std::vector<T>`** — растущий массив элементов типа `T`: `std::vector<int> v;`. Знает свой размер, растёт сам. Основной контейнер в задачах. Нужен `<vector>`. → [раздел 11](06-konteynery.md#11-массивы-и-stdvector)

**`v.push_back(x)`** — добавить элемент в конец вектора. `v.pop_back()` — убрать последний. → [раздел 11](06-konteynery.md#11-массивы-и-stdvector)

**`v.size()` / `v.empty()`** — сколько элементов / пуст ли вектор. Ловушка: `size()` беззнаковый — в обратном цикле не пиши `int i = v.size()-1; i >= 0` без оглядки, а лучше используй `v.at(i)` и range-for. → [раздел 11](06-konteynery.md#11-массивы-и-stdvector)

**`v.at(i)` против `v[i]`** — доступ по индексу. `v[i]` без проверки границ (выход — UB), `v.at(i)` с проверкой (исключение). Для учебных задач `at` безопаснее. → [раздел 11](06-konteynery.md#11-массивы-и-stdvector)

**`v.front()` / `v.back()`** — первый / последний элемент. На пустом векторе — UB, сперва проверь `!v.empty()`. → [раздел 11](06-konteynery.md#11-массивы-и-stdvector)

**`v.clear()` / `v.resize(n)`** — очистить вектор / сделать в нём ровно `n` элементов. → [раздел 11](06-konteynery.md#11-массивы-и-stdvector)

**`std::map<K, V>`** — таблица «ключ → значение», хранит пары **по возрастанию ключа**. `m["Аня"] = 21;`. Обращение к несуществующему ключу через `m[k]` **создаёт** его со значением по умолчанию (`0` для чисел) — так удобно делать счётчик: `++count[word]`. Нужен `<map>`. → [раздел 12](06-konteynery.md#12-словарь-stdmap)

**`m.count(k)` / `m.contains(k)`** — есть ли ключ `k` (не создавая его). `contains` — C++20, читается яснее. Проверяй так перед `m[k]`, если не хочешь случайно добавить ключ. → [раздел 12](06-konteynery.md#12-словарь-stdmap)

**`m.find(k)`** — итератор на пару с ключом `k` или `m.end()`, если ключа нет. Нужен, когда важно и проверить наличие, и взять значение за один поиск. → [раздел 12](06-konteynery.md#12-словарь-stdmap)

**`std::set<T>`** — набор **уникальных** значений, хранит по возрастанию. `s.insert(x)` (дубликат просто игнорируется), `s.count(x)` — есть ли элемент. Нужен для «убрать повторы» и «встречалось ли». Нужен `<set>`. → [раздел 14](06-konteynery.md#14-stdset--только-уникальные)

**`std::pair<A, B>`** — два значения вместе: `p.first`, `p.second`. Пара из `map` — это `pair<const K, V>`. Собрать: `std::make_pair(a, b)` или `{a, b}`. → [раздел 15](06-konteynery.md#15-stdpair--две-вещи-вместе)

**Структурные привязки `auto [k, v] = p;`** — разложить пару или структуру на именованные части. В цикле по map: `for (const auto &[key, value] : m)`. → [раздел 15](06-konteynery.md#структурные-привязки--читай-как-разложить-на-части)

**`std::array<T, N>`** — массив фиксированного размера `N`, но с методами и проверками как у вектора. Когда размер известен заранее и не меняется. Нужен `<array>`. → [раздел 11](06-konteynery.md#stdarray--фиксированный-размер-но-безопасно)

**`std::unordered_map` / `std::unordered_set`** — как `map`/`set`, но находят по ключу почти мгновенно и хранят **без** порядка. Бери, когда порядок не важен, а скорость нужна. Нужны `<unordered_map>` / `<unordered_set>`. → [раздел 13](06-konteynery.md#13-stdunordered_map)

**`std::queue` / `std::stack`** — очередь (первым пришёл — первым вышел) и стек (последним пришёл — первым вышел). Методы: `push`, `front`/`top`, `pop`, `empty`. Нужны `<queue>` / `<stack>`. → [раздел 11](06-konteynery.md#очередь-и-стек-queue-и-stack)

**`std::vector<std::vector<int>>`** — таблица/сетка/поле: вектор строк, каждая строка — вектор ячеек. Доступ `grid[y][x]`. Заводи сразу нужного размера, чтобы не выйти за границу. → [раздел 16](06-konteynery.md#16-вложенные-контейнеры)

## Тема 7. Алгоритмы

**`std::sort(v.begin(), v.end())`** — отсортировать вектор по возрастанию. По убыванию — `std::sort(v.begin(), v.end(), std::greater<>{})`. По своему правилу (например, структуры по полю) — лямбдой-компаратором: `std::sort(v.begin(), v.end(), [](auto &a, auto &b){ return a.age < b.age; })`. Нужен `<algorithm>`. → [раздел 18](07-algoritmy.md#18-алгоритмы)

**`std::count(begin, end, x)` / `std::count_if(begin, end, pred)`** — сколько элементов равны `x` / подходят под условие-предикат. `std::count_if(v.begin(), v.end(), [](int x){ return x > 0; })` — сколько положительных. → [раздел 18](07-algoritmy.md#18-алгоритмы)

**`std::find(begin, end, x)` / `std::find_if(begin, end, pred)`** — итератор на первый подходящий элемент или `end`, если не нашли. Сравнение результата с `v.end()` — стандартное «не нашлось». → [раздел 18](07-algoritmy.md#18-алгоритмы)

**`std::max_element(begin, end)` / `std::min_element(begin, end)`** — итератор на наибольший/наименьший элемент. Ловушка: это **итератор**, значение бери через `*`: `*std::max_element(v.begin(), v.end())`. → [раздел 18](07-algoritmy.md#18-алгоритмы)

**`std::accumulate(begin, end, 0LL)`** — сумма элементов. Стартовое значение `0LL` (а не `0`), чтобы не переполнить на больших данных. Нужен `<numeric>`. → [раздел 18](07-algoritmy.md#18-алгоритмы)

**`std::all_of` / `any_of` / `none_of`** — «все / хоть один / ни один» элемент подходит под предикат. Возвращают `true`/`false`. Читаются как условие: `if (std::all_of(v.begin(), v.end(), pred))`. → [раздел 18](07-algoritmy.md#18-алгоритмы)

**`std::erase_if(v, pred)`** — убрать из контейнера все элементы по условию (C++20), одной строкой вместо старой связки erase-remove. → [раздел 18](07-algoritmy.md#18-алгоритмы)

**`v.begin()` / `v.end()`** — итераторы: «закладка» на первый элемент и **за** последним (не на последний!). Их принимают все алгоритмы. Разыменование `*it` даёт сам элемент. → [раздел 17](07-algoritmy.md#17-итераторы--на-пальцах)

**`std::unique(begin, end)`** — «схлопывает» соседние одинаковые элементы, возвращает итератор на новый конец. Чтобы реально убрать дубликаты: сначала `std::sort`, потом `v.erase(std::unique(v.begin(), v.end()), v.end())`. Нужен `<algorithm>`. → [раздел 18](07-algoritmy.md#18-алгоритмы)

## Тема 8. struct, математика, файлы

**`struct Имя { ... };`** — свой тип, склеивающий несколько полей в одно целое: `struct Point { int x = 0; int y = 0; };`. Обращение к полю через точку: `p.x`. Задавай полям значения по умолчанию — не будет мусора. → [раздел 19](08-struct-fayly.md#19-struct)

**`std::round(x)` / `std::floor(x)` / `std::ceil(x)`** — округлить: к ближайшему / вниз / вверх. `std::round(3.6)` даёт `4`. Нужен `<cmath>`. → [раздел 20](08-struct-fayly.md#20-математика)

**`std::abs(x)`** — модуль числа: `std::abs(-5)` даёт `5`. Для сравнения дробей: `std::abs(a - b) < 1e-9` (напрямую `==` для `double` ненадёжно). Нужен `<cmath>`. → [раздел 20](08-struct-fayly.md#20-математика)

**`std::pow(a, b)` / `std::sqrt(x)`** — возведение в степень / квадратный корень. Ловушка: `pow` работает в `double`, для целых степеней это может дать `8.9999…` — для целого результата округляй. Нужен `<cmath>`. → [раздел 20](08-struct-fayly.md#20-математика)

**`std::ifstream in("file.txt")`** — открыть файл **на чтение**. Читают из него как из `cin`: `in >> x` или `std::getline(in, line)`. Файл закроется сам, когда переменная выйдет из области видимости (RAII). Нужен `<fstream>`. → [раздел 21](08-struct-fayly.md#21-файлы)

**`std::ofstream out("file.txt")`** — открыть файл **на запись** (существующий перезапишет). Пишут как в `cout`: `out << x << "\n"`. Нужен `<fstream>`. → [раздел 21](08-struct-fayly.md#21-файлы)

**`file.is_open()`** — открылся ли файл. Всегда проверяй перед чтением/записью: путь может быть неверным. `if (!in.is_open()) { ... }`. → [раздел 21](08-struct-fayly.md#21-файлы)

**`std::hypot(a, b)`** — длина гипотенузы `sqrt(a*a + b*b)`, но без переполнения и потери точности. Так считают расстояние между точками. Нужен `<cmath>`. → [раздел 20](08-struct-fayly.md#20-математика)

**`std::mt19937` + `std::uniform_int_distribution`** — генератор случайных чисел и «раздатчик» в диапазоне. Заводят один раз: `std::mt19937 gen(std::random_device{}());`, `std::uniform_int_distribution<int> dice(1, 6);`, дальше `dice(gen)`. Не `rand()`. Нужен `<random>`. → [раздел 20](08-struct-fayly.md#случайные-числа)

**`std::shuffle(begin, end, gen)`** — перемешать вектор случайно (тем же генератором `mt19937`). Так тасуют колоду карт. Нужен `<algorithm>`. → [раздел 20](08-struct-fayly.md#перемешать-колоду-и-вероятности)

## Тема 10. Перепиши по-современному

Старый код из учебников — и чем его заменить в современном C++. Подробно — в [разделе 24](09-spravka.md#24-устаревшее-что-встретишь-в-учебниках-и-чем-это-заменить).

**`printf(...)` → `std::cout` или `std::format`** — типобезопасный вывод без строк-форматов вроде `%d`, где легко перепутать тип.

**`char s[100]` / C-строки → `std::string`** — растёт сам, знает длину, не переполняется.

**`NULL` / `0` для указателя → `nullptr`** — отдельное значение указателя, не путается с числом.

**C-приведение `(int)x` → `static_cast<int>(x)`** — видно в коде и ищется поиском; компилятор проверяет допустимость.

**`typedef` → `using`** — то же самое, но читается слева направо: `using Slovar = std::map<std::string, int>;`.

**Ручные `new` / `delete` → `std::vector`, `std::string`, умные указатели** — память освобождается сама (RAII), нет утечек и висячих указателей. → [раздел 33](18-umnye-ukazateli.md#33-умные-указатели)

## Проверь себя

Карточки на повторение — вспомни ответ сам, потом проверь и отметь, насколько было легко.

```cards
Q: Чем `getline` отличается от `cin >> s`?
A: `getline` читает всю строку с пробелами до перевода строки; `cin >> s` берёт только одно слово.

Q: Что делает `s.substr(2, 3)`?
A: вырезает подстроку — 3 символа начиная с позиции 2.

Q: Что вернёт `find`, если ничего не нашёл?
A: `std::string::npos` (сравнивай только с ним, не с `-1`).

Q: Как превратить `"42"` в число и обратно?
A: `std::stoi("42")` → 42; `std::to_string(42)` → "42".

Q: Чем опасен `m[k]` у `std::map` при чтении?
A: создаёт ключ `k` со значением по умолчанию. Сначала проверь `m.count(k)` / `m.contains(k)`.

Q: Почему значение `max_element` берут через `*`?
A: он возвращает итератор, а не число: `*std::max_element(...)`.

Q: Как отсортировать вектор по убыванию?
A: `std::sort(v.begin(), v.end(), std::greater<>{})` или лямбдой-компаратором.

Q: Как убрать дубликаты из вектора?
A: `std::sort`, затем `v.erase(std::unique(v.begin(), v.end()), v.end())`.
```
