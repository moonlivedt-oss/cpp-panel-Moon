### За 30 секунд

- `std::string` — текст: `+` склеивает, `==` сравнивает по содержимому.
- `s.size()` — длина в **байтах**: русская буква занимает 2 байта.
- `s.find(x)` — позиция находки или `std::string::npos`, если не нашлось.
- `s.substr(pos, n)` — кусок строки; `std::stoi(s)` / `std::to_string(x)` — строка ↔ число.
- Разбить на слова — `std::istringstream`.

```cpp
std::string s = "кот и пёс";
if (s.find("пёс") != std::string::npos) { /* нашли */ }
std::string first = s.substr(0, 6);               // "кот" — 3 буквы = 6 байт
int n = std::stoi("42");                          // строка → число
std::string t = "Итог: " + std::to_string(n);     // число → строка
```

Если совсем с нуля: `std::string` — это **текст**: имя, слово, строка из файла. Его можно складывать через `+`, искать в нём, резать на части. Здесь — как это делать (и почему с русским всё сложнее, чем кажется).

## 10. `std::string`

```cpp
#include <string>

std::string s = "Привет";
std::string empty;                    // пустая строка, не мусор — это безопасно
std::string repeated(5, 'x');         // → xxxxx   пять одинаковых символов
```

<details>
<summary>Разбор: три способа создать строку</summary>

- **`std::string s = "Привет";`** — завести строку и сразу положить в неё текст. `std::string` — стандартный тип для текста (подключается заголовком `<string>`).
- **`std::string empty;`** — строка без начального значения — это **пустая** строка (`""`), а не мусор. С ней сразу безопасно работать.
- **`std::string repeated(5, 'x');`** — особая форма создания: «повтори символ `'x'` пять раз» → `"xxxxx"`. Круглые скобки с аргументами — это вызов конструктора строки.

</details>

<details>
<summary>Копнуть глубже: что такое строка внутри</summary>

`std::string` — это не сам текст, а маленький управляющий объект, который держит три вещи: **указатель** на буфер с байтами, **длину** (`size`) и **вместимость** (`capacity` — сколько байт уже выделено под рост). Сами символы лежат в непрерывном куске памяти; для длинных строк это участок в **куче** (heap), выделенный динамически. Поэтому `s.size()` мгновенный — длина хранится готовым числом, а не пересчитывается, — а `s += "…"` при нехватке места выделяет буфер побольше и копирует туда старое содержимое (ровно как `vector`, см. [как вектор растёт](06-konteynery.md#как-вектор-растёт-size-и-capacity)). Есть и оптимизация: очень короткие строки (обычно до 15 байт) многие реализации хранят прямо внутри самого объекта, без обращения к куче, — это «small string optimization», поэтому короткое имя или слово не стоят ни одного выделения памяти.

</details>

Мысленная модель: строка — это «коробка с ручкой». Ручка (сам объект `std::string`) маленькая и лежит там же, где обычные переменные; за ручку ты берёшь всю коробку с текстом, которая может быть где угодно в памяти и любого размера. Когда ты копируешь строку, копируется и содержимое коробки — вот почему большой текст в функцию передают по `const&` (за ручку, без копирования всей коробки), а не по значению.

```badgood
Так пишут в C: массив символов | Так пишут на C++: std::string
#include <cstring>

char name[10];
strcpy(name, "Александр");  // 18 байт в 10 —
                            // запись за край массива
strcat(name, "!");          // ещё дальше
---
#include <string>

std::string name = "Александр";  // память — сама
name += "!";                     // растёт сама
std::cout << name.size();        // длина известна
```

### Основные операции

```cpp
std::string s = "Привет";

s += " мир";                          // приклеить в конец
std::cout << s << "\n";               // → Привет мир

std::cout << s.length() << "\n";      // → 19  ⚠️ БАЙТЫ, не буквы (см. предупреждение ниже)
std::cout << s.size() << "\n";        // → 19  size() и length() — одно и то же
std::cout << s.empty() << "\n";       // → 0   пустая ли строка

std::string part = s.substr(0, 12);   // подстрока: с позиции 0, длиной 12 байт
std::cout << part << "\n";            // → Привет

s.clear();                            // очистить
std::cout << s.empty() << "\n";       // → 1
```

> **Кириллица в `std::string` считается байтами, а не буквами.** У строки `"Привет"` `length()` вернёт **12**, а `s[0]` даст половину буквы: в UTF-8 русская буква занимает два байта. Для латиницы и цифр всё как ожидается. Практический вывод: перебирать русский текст по `s[i]` и резать его через `substr` **нельзя** — получишь битые символы. Как считать и резать русский текст по буквам — в разделе [«Русский текст: буквы, а не байты»](#русский-текст-буквы-а-не-байты).

### Вставка, удаление, замена

Строку можно править на месте — у неё есть готовые методы, не надо собирать новую вручную:

```cpp
#include <iostream>
#include <string>

int main() {
  std::string s = "Hello";
  s.push_back('!');       // добавить один символ в конец  → Hello!
  s.append(" мир");       // добавить строку в конец       → Hello! мир
  s.insert(5, ",");       // вставить "," на позицию 5      → Hello,! мир

  std::string t = "abcdef";
  t.erase(2, 3);          // удалить 3 символа с позиции 2 (cde) → abf
  t.replace(0, 1, "X");   // заменить 1 символ с позиции 0       → Xbf

  std::cout << s << "\n" << t << "\n";   // → Hello,! мир   и   Xbf
  return 0;
}
```

| Метод | Что делает |
|---|---|
| `s += "..."` / `s.append("...")` | приклеить строку в конец |
| `s.push_back(c)` / `s.pop_back()` | добавить / убрать один символ с конца |
| `s.insert(pos, "...")` | вставить на позицию `pos` |
| `s.erase(pos, n)` | удалить `n` символов с позиции `pos` |
| `s.replace(pos, n, "...")` | заменить `n` символов на другую строку |
| `s.front()` / `s.back()` | первый / последний символ |

> `s[i]` не проверяет границы (за пределами — мусор или порча памяти), а `s.at(i)` проверяет и при выходе бросает исключение. Пока учишься — держи флаг `-D_GLIBCXX_ASSERTIONS` (см. [основы](01-osnovy.md#флаг-который-ловит-выход-за-границы)), он ловит и `s[i]` за границей.

### Поиск

```cpp
std::string s = "hello world";

std::size_t pos = s.find("world");             // возвращает позицию начала
if (pos != std::string::npos)                  // npos = «не найдено», особое значение
  std::cout << "Найдено на позиции " << pos;   // → Найдено на позиции 6
else
  std::cout << "Не найдено";

std::cout << s.find('o') << "\n";              // → 4   первое вхождение символа
std::cout << s.rfind('o') << "\n";             // → 7   последнее вхождение
std::cout << s.find("xyz") << "\n";            // → 18446744073709551615 (это и есть npos)
```

```cpp alt: Найти расширение файла
std::string file = "report.final.docx";
std::size_t dot = file.rfind('.');                 // ищем с конца: последняя точка
std::string ext = dot == std::string::npos ? "" : file.substr(dot + 1);
std::cout << ext << "\n";   // docx
```

```cpp alt: Есть ли запрещённое слово в чате
std::string message = "это просто спам и реклама";
std::vector<std::string> banned = {"спам", "казино"};
bool bad = false;
for (const std::string &w : banned)
  if (message.find(w) != std::string::npos) bad = true;
std::cout << (bad ? "сообщение скрыто" : message) << "\n";
```

> `find` **никогда** не возвращает `-1`. Сравнивай только с `std::string::npos`.

### `starts_with` и `ends_with` — начало и конец строки

Частый вопрос — «начинается ли строка с…» или «кончается ли на…». Через `find` это писать неудобно и легко ошибиться (`find(x) == 0` для начала — да, но для конца формула громоздкая). В C++20 для этого есть прямые методы:

```cpp
std::string s = "hello.txt";

std::cout << s.starts_with("hello") << "\n";   // → 1
std::cout << s.ends_with(".txt") << "\n";      // → 1
std::cout << s.ends_with(".cpp") << "\n";      // → 0
std::cout << s.starts_with('h') << "\n";       // → 1   можно проверить и один символ
```

Читается как предложение и не требует возиться с позициями. Типичное применение — разбор команд и имён файлов:

```cpp
if (command.starts_with("add "))          // команда вида "add молоко"
  std::cout << "добавляем: " << command.substr(4) << "\n";

if (fileName.ends_with(".cpp"))
  std::cout << "это исходник C++\n";
```

> Работает по тем же байтам, что и остальная строка, — для сравнения с латинскими префиксами (команды, расширения файлов) это ровно то, что нужно. С русскими префиксами помни про [двухбайтовость](#10-stdstring), но там обычно и не проверяют «начинается ли с буквы».

### Разбить строку по разделителю

Строку часто нужно разложить на части. Если разделитель — **пробел**, работает `istringstream` и `>>` (как из `cin`):

```cpp
std::string line = "10 20 30 40";
std::istringstream stream(line);       // строка как поток
int x = 0;
int sum = 0;
while (stream >> x)                     // читаем числа по одному, как из cin
  sum += x;
// sum == 100
```

А если разделитель — **не пробел** (`;`, `,`, `-`), у `getline` есть третий аргумент — символ-разделитель. Так разбирают CSV:

```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <vector>

int main() {
  std::string csv = "Аня;21;Москва";
  std::istringstream stream(csv);
  std::string field;
  std::vector<std::string> fields;

  while (std::getline(stream, field, ';'))   // третий аргумент — разделитель полей
    fields.push_back(field);

  std::cout << fields.size() << "\n";        // → 3
  std::cout << fields[0] << "\n";            // → Аня
  return 0;
}
```

Разделять по пробелам через `getline(..., ' ')` **не стоит**: два пробела подряд дадут пустое поле. Для пробелов — `>>` (он сам пропускает лишние), для остального — `getline` с разделителем. Разбиение на слова целиком — в [типовых задачах](#типовые-задачи) ниже.

### Перебор символов

```cpp
std::string s = "hello";

// Чтение
for (char c : s)
  std::cout << c << "-";                 // → h-e-l-l-o-

// Изменение — нужна ссылка
for (char &c : s)
  c = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));
std::cout << s;                             // → HELLO

// По индексам, если нужна позиция
for (std::size_t i = 0; i < s.length(); ++i)
  std::cout << i << ":" << s[i] << " ";     // → 0:H 1:E 2:L 3:L 4:O
```

> **Почему у `toupper` два преобразования подряд.** Внутрь надо передать `unsigned char`: у обычного `char` для не-ASCII байта значение отрицательное, а `toupper` от отрицательного числа — неопределённое поведение (может и упасть). Наружу `toupper` отдаёт `int`, и обратно в `char` его кладём явно — иначе `-Wconversion` справедливо поругается. Выглядит громоздко, зато это единственная запись, которая верна всегда:
> `c = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));`
>
> На кириллицу это всё равно не подействует: `toupper` работает только с латиницей. Как сделать русские буквы заглавными — [ниже](#почему-toupper-не-делает-русские-буквы-заглавными).

**Проверка на палиндром:**

```cpp
bool isPalindrome(const std::string &s) {
  std::size_t left = 0;
  std::size_t right = s.length();               // ⚠️ не length()-1: для пустой строки будет беда
  while (left + 1 < right) {                    // идём навстречу друг другу
    if (s[left] != s[right - 1])
      return false;                             // нашли расхождение — не палиндром
    ++left;
    --right;
  }
  return true;
}

std::cout << isPalindrome("level") << "\n";     // → 1
std::cout << isPalindrome("hello") << "\n";     // → 0
```

```cpp alt: Проверка пароля по символам
std::string pass = "Secret42";
bool digit = false, upper = false;
for (char c : pass) {
  unsigned char u = static_cast<unsigned char>(c);
  if (std::isdigit(u)) digit = true;
  if (std::isupper(u)) upper = true;
}
std::cout << (digit && upper && pass.size() >= 8 ? "OK" : "слабый") << "\n";
```

```cpp alt: Шифр Цезаря для латиницы
std::string text = "attack at dawn";
int shift = 3;
for (char &c : text)
  if (c >= 'a' && c <= 'z') c = static_cast<char>('a' + (c - 'a' + shift) % 26);
std::cout << text << "\n";   // dwwdfn dw gdzq
```

**Замена всех вхождений:**

```cpp
std::string s = "a-b-c-d";
std::size_t pos = 0;

while ((pos = s.find('-', pos)) != std::string::npos) {   // ищем начиная с pos
  s[pos] = '+';                                           // заменяем
  ++pos;                                                  // сдвигаемся, иначе зациклимся
}
std::cout << s;                                           // → a+b+c+d
```

<details>
<summary>Разбор: как читается замена всех вхождений</summary>

Самая хитрая строка здесь — условие цикла. Разберём по шагам:

- **`s.find('-', pos)`** — ищет `'-'`, начиная с позиции `pos` (второй аргумент — «искать не с начала, а отсюда»). Возвращает позицию находки или `npos`, если больше нет.
- **`(pos = s.find('-', pos))`** — результат поиска тут же кладём в `pos`. Это присваивание (`=`), а не сравнение; скобки вокруг обязательны.
- **`… != std::string::npos`** — и сразу проверяем: нашли символ или дошли до конца. Пока находки есть — цикл продолжается.
- **`s[pos] = '+';`** — заменяем найденный символ.
- **`++pos;`** — продолжаем поиск со следующей позиции. Здесь это экономия: найденный `'-'` уже заменён. Но если замена **содержит** искомое (например, `'-'` → `"--"`), без сдвига на длину замены поиск будет снова и снова находить только что вставленное — вечный цикл. Поэтому сдвиг пишут всегда: `pos += длина_замены`.

</details>

<details>
<summary>Трассировка: pos по шагам на строке «a-b-c-d»</summary>

| шаг | `pos` перед поиском | `s.find('-', pos)` | строка после замены | `pos` после `++pos` |
|---|---|---|---|---|
| 1 | 0 | 1 | `a+b-c-d` | 2 |
| 2 | 2 | 3 | `a+b+c-d` | 4 |
| 3 | 4 | 5 | `a+b+c+d` | 6 |
| 4 | 6 | `npos` | — цикл окончен | — |

Поиск каждый раз стартует **после** предыдущей находки — поэтому строка проходится один раз, слева направо.

</details>


### Обрезать пробелы (trim)

Ввод часто приходит с лишними пробелами по краям («` да `» вместо «`да`»), и они ломают сравнения. Готового `trim` в стандартной библиотеке нет — вот короткая надёжная заготовка на `find_first_not_of` / `find_last_not_of`:

```cpp
#include <iostream>
#include <string>

std::string trim(const std::string &s) {
  std::size_t start = s.find_first_not_of(" \t\n\r");   // первый непробельный символ
  if (start == std::string::npos)
    return "";                                          // строка из одних пробелов
  std::size_t end = s.find_last_not_of(" \t\n\r");      // последний непробельный
  return s.substr(start, end - start + 1);
}

int main() {
  std::cout << "[" << trim("   привет   ") << "]\n";     // → [привет]
  std::cout << "[" << trim("\t да \n") << "]\n";         // → [да]
  return 0;
}
```

`find_first_not_of(" \t\n\r")` находит первый символ, которого **нет** в наборе пробельных, а `find_last_not_of` — последний; между ними и лежит полезная часть. Пробелы внутри строки функция не трогает — только по краям.

bool equalIgnoreCase(const std::string &x, const std::string &y) {

### Русский текст: буквы, а не байты

Выше было сказано: `"Привет".size()` — это **12**, а не 6. Почему так и как с этим жить.

Строки в наших программах хранятся в кодировке **UTF-8**. В ней символ занимает от 1 до 4 байтов, и `std::string` про буквы ничего не знает — только про байты:

| Символы | Байтов на символ | Первый байт в двоичном виде |
|---|---|---|
| латиница, цифры, `.,!?` | 1 | `0xxxxxxx` |
| кириллица, включая `ё` | 2 | `110xxxxx` |
| «ёлочки», `—`, `€` | 3 | `1110xxxx` |
| эмодзи | 4 | `11110xxx` |

Все следующие байты одной буквы («байты-продолжения») выглядят как `10xxxxxx`. На этом держатся все рецепты: **символ начинается с любого байта, кроме `10xxxxxx`**. Проверка — `(c & 0xC0) != 0x80`: маска `0xC0` оставляет два старших бита, а `0x80` — это `10` в них.

```
   "Пр!" в памяти:

   байт:     0xD0     0x9F     0xD1     0x80     0x21
             110…     10…      110…     10…      0…
            └──── П ────┘     └──── р ────┘     └ ! ┘
   s.size() == 5, а символов — 3
```

Три рецепта — посчитать буквы, разрезать строку на символы, взять первые N или перевернуть:

```cpp
#include <windows.h>
#include <iostream>
#include <string>
#include <vector>

// Сколько байтов занимает символ UTF-8, который начинается с байта lead.
std::size_t charLen(unsigned char lead) {
  if (lead < 0x80) return 1;             // 0xxxxxxx — латиница, цифры, знаки
  if ((lead >> 5) == 0x6) return 2;      // 110xxxxx — кириллица, ё
  if ((lead >> 4) == 0xE) return 3;      // 1110xxxx — «ёлочки», тире, €
  return 4;                              // 11110xxx — эмодзи
}

// Количество букв (символов), а не байтов.
std::size_t countChars(const std::string &s) {
  std::size_t n = 0;
  for (char c : s)
    if ((static_cast<unsigned char>(c) & 0xC0) != 0x80) ++n;   // байт-продолжение 10xxxxxx не считаем
  return n;
}

// Разрезать строку на символы: каждый элемент — одна буква (1–4 байта).
std::vector<std::string> splitChars(const std::string &s) {
  std::vector<std::string> out;
  for (std::size_t i = 0; i < s.size();) {
    std::size_t len = charLen(static_cast<unsigned char>(s[i]));
    out.push_back(s.substr(i, len));
    i += len;
  }
  return out;
}

int main() {
  SetConsoleCP(CP_UTF8);
  SetConsoleOutputCP(CP_UTF8);

  std::string word = "Привет, мир!";
  std::cout << "байтов: " << word.size() << ", букв: " << countChars(word) << "\n";

  std::vector<std::string> letters = splitChars(word);
  std::cout << "первая буква: " << letters[0] << "\n";

  std::string firstThree;
  for (std::size_t i = 0; i < 3 && i < letters.size(); ++i) firstThree += letters[i];
  std::cout << "первые три: " << firstThree << "\n";

  std::string reversed;
  for (std::size_t i = letters.size(); i > 0; --i) reversed += letters[i - 1];
  std::cout << "наоборот: " << reversed << "\n";
  return 0;
}
```

наоборот: !рим ,тевирП

Главная идея — `splitChars`: после неё `std::vector<std::string>` ведёт себя как «строка из букв». Индекс `letters[i]` — это i-я **буква**, `letters.size()` — число букв, и все привычные приёмы (перебор, переворот, подсчёт одинаковых через `map<std::string, int>`) снова работают.

#### Почему `toupper` не делает русские буквы заглавными

`std::toupper` работает с **одним байтом**. Русская буква — два байта, и ни один из них по отдельности буквой не является: `toupper` возвращает их без изменений. (Можно переключить локаль, но на Windows это ненадёжно и зависит от настроек системы.)

Для русского алфавита правило простое, потому что буквы в UTF-8 идут подряд: строчные `а`–`п` отличаются от заглавных `А`–`П` на `0x20` во втором байте, у `р`–`я` меняется ещё и первый байт, а `ё`/`Ё` стоят отдельно. Всё это умещается в одну функцию:

```cpp
#include <windows.h>
#include <cctype>
#include <iostream>
#include <string>

// Заглавные буквы для русского и английского текста в UTF-8.
// Русские строчные: а–п = D0 B0..D0 BF, р–я = D1 80..D1 8F, ё = D1 91.
// Их заглавные:     А–П = D0 90..D0 9F, Р–Я = D0 A0..D0 AF, Ё = D0 81.
std::string toUpperRu(const std::string &s) {
  std::string out = s;
  for (std::size_t i = 0; i < out.size(); ++i) {
    unsigned char c = static_cast<unsigned char>(out[i]);
    if (c < 0x80) {                                   // латиница — обычный toupper
      out[i] = static_cast<char>(std::toupper(c));
      continue;
    }
    if (i + 1 >= out.size()) break;
    unsigned char n = static_cast<unsigned char>(out[i + 1]);
    if (c == 0xD0 && n >= 0xB0 && n <= 0xBF) {        // а..п → А..П
      out[i + 1] = static_cast<char>(n - 0x20);
    } else if (c == 0xD1 && n >= 0x80 && n <= 0x8F) { // р..я → Р..Я
      out[i] = static_cast<char>(0xD0);
      out[i + 1] = static_cast<char>(n + 0x20);
    } else if (c == 0xD1 && n == 0x91) {              // ё → Ё
      out[i] = static_cast<char>(0xD0);
      out[i + 1] = static_cast<char>(0x81);
    }
    ++i;                                              // второй байт этой буквы уже обработан
  }
  return out;
}

int main() {
  SetConsoleCP(CP_UTF8);
  SetConsoleOutputCP(CP_UTF8);
  std::cout << toUpperRu("Ёжик в тумане, hello!") << "\n";
  std::cout << toUpperRu("съешь ещё этих мягких булок") << "\n";
  return 0;
}
```
