## Проверка 1 · Этапы 1–2: типы, ввод-вывод, логика и циклы

Темы [1. Основы](ref/01-osnovy.md), [2. Ввод и вывод](ref/02-vvod-vyvod.md), [3. Логика и циклы](ref/03-logika-cikly.md).

```quiz
@exam etap-1-2 1-3
В: Что напечатает `std::cout << 7 / 2 << " " << 7 % 2;`?
+ `3 1`
- `3.5 1`
- `3.5 0`
= Оба операнда `int` — деление целое, дробь отбрасывается. `%` — остаток. → [целочисленное деление](ref/03-logika-cikly.md#ловушка-целочисленное-деление)

В: `int big = 50000 * 50000;` — что окажется в `big`?
+ Мусорное значение — произведение не влезает в `int`, ошибки не будет
- 2 500 000 000
- Ошибка компиляции
= `int` держит примерно до 2,1 млрд. Для больших значений — `long long` и `1LL * a * b`. → [переполнение](ref/01-osnovy.md#ловушка-int-переполняется-молча)

В: Что в переменной после `int count; count++;`?
+ Неизвестно — начального значения не было, в переменной мусор
- 1
- 0
= Локальная переменная без инициализации содержит что угодно. Всегда `int count = 0;`. → [мусор](ref/01-osnovy.md#переменная-без-начального-значения-содержит-мусор)

В: Пользователь вместо числа ввёл `abc` для `std::cin >> n;`. Что со следующими `cin >>`?
+ Молча ничего не читают, пока не вызвать `std::cin.clear()` и `std::cin.ignore(…)`
- Прочитают следующее число как обычно
- Программа завершится с ошибкой
= Плохой ввод переводит поток в состояние ошибки. Проверяй каждое чтение. → [безопасное чтение](ref/02-vvod-vyvod.md#безопасное-чтение--держи-под-рукой)

В: После `std::cin >> age;` сразу `std::getline(std::cin, name);`. Что в `name`?
+ Пустая строка
- Имя, которое введёт пользователь
- Число `age` строкой
= `>>` оставляет в буфере Enter, `getline` читает до него. Между ними нужен `std::cin.ignore(10000, '\n');`. → [трассировка буфера](ref/02-vvod-vyvod.md#разные-ситуации-ввода)

В: Чем заменить `if (1 < x < 10)`?
+ `if (x > 1 && x < 10)`
- Ничем, это правильно
- `if (1 < x || x < 10)`
= Цепочка считается как `(1 < x) < 10` — это всегда истина. → [цепочки сравнений](ref/03-logika-cikly.md#цепочки-сравнений--так-нельзя)

В: Что делает `if (x = 5)`?
+ Присваивает `x` пятёрку, условие всегда истинно
- Сравнивает `x` с пятёркой
- Не компилируется
= Сравнение — `==`. С флагом `-Wall` g++ предупредит: `suggest parentheses around assignment`.

В: Сколько раз выполнится `for (int i = 10; i > 0; i -= 3)`?
+ 4 раза: `i = 10, 7, 4, 1`
- 3 раза
- 10 раз
= После `1` будет `-2`, условие `i > 0` ложно. Выписывай значения счётчика.

В: В `switch` у `case 1:` нет `break`. Что будет при `choice == 1`?
+ Выполнится `case 1`, а потом и код следующих `case` — до первого `break`
- Выполнится только `case 1`
- Ошибка компиляции
= Это «проваливание» (fallthrough). В конце каждого `case` — `break`. → [ветвления](ref/03-logika-cikly.md#7-ветвления)

В: Как правильно проверить `double a` и `double b` на равенство?
+ `std::abs(a - b) < 1e-9`
- `a == b`
- `(int)a == (int)b`
= Дробные числа хранятся с погрешностью: `0.1 + 0.2 == 0.3` — ложь. Сравнивают с допуском.
```

## Проверка 2 · Этапы 3–4: функции и строки

Темы [4. Функции](ref/04-funkcii.md) и [5. Строки](ref/05-stroki.md).

```quiz
@exam etap-3-4 4-5
В: `void f(int x) { x = 10; }` вызвана как `f(a)`. Что с `a`?
+ Не изменилась — функция получила копию
- Стала 10
- Ошибка компиляции
= Изменить аргумент вызывающего можно только через ссылку: `void f(int &x)`. → [три способа](ref/04-funkcii.md#три-способа-передать-аргумент)

В: Как лучше передать большую строку, которую функция только читает?
+ `const std::string &s`
- `std::string s`
- `std::string &s`
= Константная ссылка: без копии и без риска случайно изменить.

В: Функция объявлена ниже `main`, а вызывается в `main`. Что будет?
+ Ошибка `was not declared in this scope` — нужно объявление выше вызова
- Всё соберётся
- Функция вызовется, но вернёт 0
= Компилятор читает файл сверху вниз. Либо перенеси функцию выше, либо напиши её прототип перед `main`.

В: Что обязательно должно быть у рекурсивной функции?
+ База — случай, который решается без вызова себя
- Цикл внутри
- Параметр `static`
= Без базы вызовы идут бесконечно, пока не кончится стек. → [рекурсия](ref/04-funkcii.md#рекурсия--функция-вызывает-саму-себя)

В: Функция ищет элемент и может его не найти. Что вернуть?
+ `std::optional<T>` — «значение или ничего»
- `-1` и надеяться, что вызывающий проверит
- Ссылку на пустой объект
= `optional` не даст забыть о случае «не нашлось». → [optional](ref/04-funkcii.md#stdoptional--когда-ответа-может-не-быть)

В: Чему равно `std::string("Привет").size()`?
+ 12
- 6
- 7
= `size()` считает байты, а русская буква в UTF-8 — два байта. → [русский текст](ref/05-stroki.md#русский-текст-буквы-а-не-байты)

В: Как проверить, что `s.find("кот")` ничего не нашёл?
+ `== std::string::npos`
- `== -1`
- `== 0`
= `0` — это находка в самом начале строки, а `-1` `find` не возвращает никогда.

В: Что сделает `std::stoi("12abc")`?
+ Вернёт 12 — читает число с начала строки, пока цифры идут подряд
- Бросит исключение
- Вернёт 0
= Исключение `stoi` бросает, только если в начале вообще нет числа (`"abc"`). Строгую проверку делают через второй параметр — позицию, где чтение остановилось.

В: Как склеить `"Привет, "` и `"мир"` в `std::string`?
+ `std::string("Привет, ") + "мир"`
- `"Привет, " + "мир"`
- `std::string s = "Привет, " , "мир";`
= Два литерала в кавычках — это массивы символов, их `+` не складывает. Хотя бы один операнд должен быть `std::string`. → [ошибка](ref/11-oshibki.md#invalid-operands-of-types-const-char-15-and-const-char-7-to-binary-operator)

В: Как разбить строку на слова по пробелам?
+ `std::istringstream in(s); while (in >> word) …`
- `s.split(' ')`
- `std::getline(s, word)`
= Метода `split` у `std::string` нет. `>>` из строкового потока читает по одному слову. → [разбить строку](ref/05-stroki.md#разбить-строку-по-разделителю)
```

## Проверка 3 · Этапы 5–6: контейнеры и алгоритмы

Темы [6. Контейнеры](ref/06-konteynery.md) и [7. Итераторы и алгоритмы](ref/07-algoritmy.md).

```quiz
@exam etap-5-6 6-7
В: Вектор `v` из трёх элементов. Что делает `v[3]`?
+ Читает чужую память — ошибки нет, результат мусорный
- Бросает исключение
- Возвращает 0
= Индексы — от `0` до `size() - 1`. `v.at(3)` бросил бы `std::out_of_range`. → [выход за границы](ref/06-konteynery.md#главная-опасность--выход-за-границы)

В: `std::map<std::string, int> m;` Что сделает `if (m["Вера"] > 0)`?
+ Создаст запись «Вера → 0»
- Только проверит, ничего не меняя
- Бросит исключение
= `[]` при чтении добавляет отсутствующий ключ. Проверяй через `contains` или `find`. → [главная ловушка](ref/06-konteynery.md#главная-ловушка--при-чтении-создаёт-элемент)

В: Какой контейнер выбрать для «имя → телефон» с выводом по алфавиту?
+ `std::map<std::string, std::string>`
- `std::vector<std::string>`
- `std::set<std::string>`
= Поиск по ключу и порядок ключей — это `map`. → [какой контейнер выбрать](ref/06-konteynery.md#какой-контейнер-выбрать)

В: Как убрать из вектора все повторы?
+ `std::sort`, затем `v.erase(std::unique(v.begin(), v.end()), v.end());`
- Только `std::unique(v.begin(), v.end());`
- `v.erase(v.begin(), v.end());`
= `unique` схлопывает только соседей и не меняет размер — поэтому `sort` до и `erase` после. → [трассировка unique](ref/07-algoritmy.md#ещё-несколько-нужных-алгоритмов)

В: Почему `std::cout << std::max_element(v.begin(), v.end());` не собирается?
+ `max_element` возвращает итератор; значение — `*std::max_element(…)`
- Нужен `#include <max>`
- `max_element` работает только со строками
= Алгоритмы возвращают позицию, а не значение.

В: Что такое `v.end()`?
+ Позиция «за последним элементом» — не элемент
- Последний элемент
- Размер вектора
= Разыменовывать `end()` нельзя. С ним сравнивают: `it == v.end()` — «не нашлось».

В: Как посчитать отрицательные числа в векторе без ручного цикла?
+ `std::count_if(v.begin(), v.end(), [](int x) { return x < 0; })`
- `std::count(v.begin(), v.end(), < 0)`
- `v.count(x < 0)`
= `count_if` принимает правило — лямбду, которая говорит «подходит / не подходит». → [лямбда](ref/07-algoritmy.md#со-своим-правилом--через-лямбду)

В: Как отсортировать студентов по убыванию баллов?
+ `std::sort(v.begin(), v.end(), [](const Student &a, const Student &b) { return a.score > b.score; });`
- `std::sort(v.begin(), v.end());`
- `std::sort(v.rbegin(), v.end());`
= У структуры нет встроенного «меньше» — нужно правило сравнения. `>` в лямбде даёт убывание. → [сортировка структур](ref/07-algoritmy.md#сортировка-структур)

В: Цикл в цикле по одному вектору из 100 000 элементов. Как быстро это будет?
+ Медленно — это O(n²), порядка 10 миллиардов шагов
- Мгновенно — компьютер быстрый
- Так же, как один цикл
= Каждый с каждым — n², при n = 100 000 это уже секунды и больше. → [как оценить скорость](ref/07-algoritmy.md#как-оценить-скорость-o1-olog-n-on-on²)

В: `for (auto s : students) s.score += 5;` — что будет с вектором?
+ Не изменится — `s` каждый раз копия
- Всем прибавится 5
- Ошибка компиляции
= Чтобы менять элементы, нужна ссылка: `for (auto &s : students)`.
```

## Проверка 4 · Этап 7: свой тип, файлы и всё вместе

Тема [8. struct, математика, файлы](ref/08-struct-fayly.md) плюс сквозные вопросы по всему курсу.

```quiz
@exam etap-7-8 8
В: Что не так в `struct Point { int x; int y; }` перед `int main()`?
+ После `}` нужна `;`
- `struct` нельзя объявлять вне `main`
- Поля должны быть `double`
= Ошибка компилятора: `expected ';' after struct definition`. И лучше сразу задать значения: `int x = 0;`.

В: Как на твоей сборке правильно проверить, что файл открылся?
+ `if (!in.is_open())`
- `if (!in)`
- `if (in == nullptr)`
= На g++ из MSYS2 UCRT64 `if (!in)` не ловит отсутствующий файл — проверено. → [файлы](ref/08-struct-fayly.md#сначала--главная-ловушка-на-твоей-сборке)

В: Как читать файл построчно до конца?
+ `while (std::getline(in, line)) { … }`
- `while (!in.eof()) { std::getline(in, line); … }`
- `for (int i = 0; i < in.size(); ++i)`
= Цикл по `eof()` обрабатывает последнюю строку дважды или читает пустую — проверяй сам результат чтения.

В: Как дописать строку в конец файла, не стирая старое?
+ `std::ofstream out("log.txt", std::ios::app);`
- `std::ofstream out("log.txt");`
- `std::ifstream out("log.txt");`
= Без `std::ios::app` файл при открытии очищается.

В: Функция печатает студента. Как её объявить?
+ `void print(const Student &s)`
- `void print(Student s)`
- `void print(Student *s)`
= Структуру передают по константной ссылке: без копии и без риска изменить.

В: Что вернёт `std::round(2.5)` и как округлить `x` до двух знаков?
+ `3`; до двух знаков — `std::round(x * 100) / 100`
- `2`; до двух знаков — `std::round(x, 2)`
- `2.5`; округлить до знаков нельзя
= `std::round` округляет половину от нуля. Второго параметра у него нет. → [округление](ref/08-struct-fayly.md#округление-до-n-знаков)

В: Как сравнить две структуры `Point` на равенство?
+ По полям: `a.x == b.x && a.y == b.y` (или объявить `operator==`)
- `a == b` работает само
- `std::equal(a, b)`
= Для своей структуры компилятор не знает, что такое «равны», пока не объяснишь.

В: Программа с `std::vector<Student>` и чтением из файла выводит мусор в конце. Первое, что проверить?
+ Что чтение идёт `while (in >> s.name >> s.score)`, а не по `eof()`
- Перезагрузить компьютер
- Поменять `vector` на `map`
= Мусорная последняя запись — классический симптом цикла по `eof()`.

В: Где хранить таблицу игроков «имя + очки», которую нужно сортировать по очкам?
+ `std::vector<Player>` со структурой `Player`
- Два отдельных вектора имён и очков
- `std::map<int, std::string>` — очки → имя
= Две параллельные таблицы легко рассинхронизировать, а `map` по очкам потеряет игроков с одинаковыми очками.

В: Что из этого — привычка качества, которую стоит держать всегда?
+ Собирать со строгими флагами и читать первое предупреждение
- Отключать предупреждения, если программа работает
- Писать всё в `main`, чтобы не путаться
= Предупреждение сегодня — баг завтра. → [маршрут, этап 8](00-marshrut.md#этап-8--собрать-всё-вместе-и-закрепить-привычки-качества)
```
