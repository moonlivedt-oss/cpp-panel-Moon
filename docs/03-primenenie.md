# Один инструмент — разные задачи

> Обычно инструмент показывают на одном примере, и остаётся ощущение, что он для этого одного и нужен.
> Здесь наоборот: каждый приём показан в **пяти-шести разных ситуациях**, чтобы стало видно,
> что у него общего и по какому признаку его узнавать в новой задаче.
>
> Все программы целиком лежат в [`situacii/`](situacii) — открой и запусти `Ctrl+Alt+R`.
> Весь код проверен сборкой со строгими флагами.

## `std::map` — пять ролей

Полностью: [situacii/01-map.cpp](situacii/01-map.cpp)

### Роль 1: счётчик — «сколько раз что встретилось»

```cpp
std::vector<std::string> words = {"кот", "пёс", "кот", "ёж", "кот"};
std::map<std::string, int> counter;
for (const auto &w : words)
  ++counter[w];              // нет ключа -> создастся 0 -> станет 1
// counter["кот"] == 3
```

Здесь `[]` — именно то, что нужно: новое слово само заводится со значением `0`.

### Роль 2: справочник — «найти значение по имени»

```cpp
std::map<std::string, std::string> phones = {{"Аня", "+7 900 111"}};

auto it = phones.find("Аня");    // find, а не [] — чтобы не создать пустышку
if (it != phones.end())
  std::cout << it->second;
```

А здесь `[]` уже ловушка: `phones["Гриша"]` при чтении **создаст** пустую запись.

### Роль 3: группировка — «для каждого ключа список»

```cpp
std::map<std::string, std::vector<int>> marks;

marks["Аня"].push_back(5);   // вектора ещё нет — [] создаст пустой
marks["Аня"].push_back(4);
marks["Борис"].push_back(3);
```

Значением может быть что угодно, в том числе другой контейнер.

### Роль 4: таблица перевода — «символ или код → значение»

```cpp
// ⚠️ Ключом char берём только латиницу: русская буква в char не помещается
std::map<char, int> roman = {{'I', 1}, {'V', 5}, {'X', 10}, {'L', 50}};

int total = 0;
for (char c : std::string("XVI"))
  total += roman.contains(c) ? roman.at(c) : 0;   // неизвестный символ пропускаем
// total == 16
```

### Роль 5: настройки — «имя параметра → значение»

```cpp
std::map<std::string, int> settings = {{"ширина", 80}, {"высота", 25}};

int width = settings.contains("ширина") ? settings.at("ширина") : 100;   // с запасным значением
```

> **Как узнать, что нужен `map`:** в задаче звучит «для каждого X …» или «найти по имени/названию/коду». Если вместо номера по порядку у элемента есть **имя** — это словарь.
> Подробно — [раздел 12](ref/06-konteynery.md#12-словарь-stdmap).

## Лямбда — шесть ролей

Полностью: [situacii/02-lambda.cpp](situacii/02-lambda.cpp)

Лямбда — это способ **передать правило** внутрь чужого кода. Меняется только вопрос, на который она отвечает.

### Роль 1: правило сортировки — «кто идёт раньше?»

```cpp
std::sort(group.begin(), group.end(),
          [](const Student &a, const Student &b) { return a.score > b.score; });
```

### Роль 2: условие отбора — «этот элемент подходит?»

```cpp
auto negatives = std::count_if(v.begin(), v.end(), [](int x) { return x < 0; });
```

### Роль 3: что удалять

```cpp
std::erase_if(cleaned, [](int x) { return x < 0; });
```

Правило то же, что в роли 2, — но алгоритм с ним делает другое.

### Роль 4: короткая проверка, которая повторяется

```cpp
auto outOfBoard = [](int coord) { return coord < 1 || coord > 8; };

if (outOfBoard(x1) || outOfBoard(y1) || outOfBoard(x2) || outOfBoard(y2))
  std::cout << "координаты вне доски\n";
```

Здесь лямбда просто заменяет четырежды повторённое условие. Отдельная функция тоже подошла бы — лямбда удобна тем, что живёт рядом с местом использования.

### Роль 5: правило накопления — «как присоединить очередной элемент?»

```cpp
int totalScore = std::accumulate(group.begin(), group.end(), 0,
                                 [](int sum, const Student &s) { return sum + s.score; });
```

### Роль 6: лямбда помнит внешнюю переменную (захват)

```cpp
int limit = 50;
auto tooBig = [limit](int score) { return score > limit; };   // [limit] — копия значения
```

Квадратные скобки — это список того, что лямбде видно снаружи: `[limit]` копия, `[&limit]` ссылка на оригинал.

> **Как узнать, что нужна лямбда:** алгоритму нужно объяснить твоё правило — по чему сортировать, что считать подходящим, что удалять. Правило нужно один раз и в одном месте.
> Подробно — [раздел 9](ref/04-funkcii.md#лямбда--безымянная-функция-на-месте).

## `struct` — пять ролей

Полностью: [situacii/03-struct.cpp](situacii/03-struct.cpp)

### Роль 1: величины, которые всегда вместе

```cpp
struct Point {
  double x = 0;
  double y = 0;
};

Point start{0, 0};
Point finish{3, 4};
```

Вместо четырёх переменных `x1, y1, x2, y2`, которые легко перепутать местами.

### Роль 2: запись о ком-то — разнородные поля

```cpp
struct Student {
  std::string name;
  int score = 0;
  bool passed = false;
};
```

### Роль 3: объект со своим поведением (метод)

```cpp
struct Item {
  std::string title;
  double price = 0;
  int count = 0;

  double total() const {      // const = метод ничего не меняет
    return price * count;
  }
};

Item apple{"яблоки", 120.5, 3};
std::cout << apple.total();   // 361.5
```

Считать сумму снаружи тоже можно — но метод держит расчёт рядом с данными, из которых он считается.

### Роль 4: событие, которое копится списком

```cpp
struct Move {
  int row = 0;
  int col = 0;
  char player = '.';
};

std::vector<Move> history;         // история партии
history.push_back({1, 1, 'X'});
```

### Роль 5: настройки вместо кучи отдельных переменных

```cpp
struct Settings {
  int width = 80;          // значения по умолчанию заданы прямо здесь
  int height = 25;
  bool colors = true;
};

Settings cfg;              // всё уже заполнено
cfg.colors = false;        // меняем только нужное
```

> **Как узнать, что нужен `struct`:** несколько переменных всегда передаются вместе, имеют общий смысл или различаются только суффиксом (`x1`, `x2`). Как только захотелось написать `vector` из таких наборов — точно `struct`.
> Подробно — [раздел 19](ref/08-struct-fayly.md#19-struct).

## `while` — шесть ролей

Полностью: [situacii/04-while.cpp](situacii/04-while.cpp)

`while` берут, когда **число повторов заранее неизвестно**. Меняется только условие продолжения.

### Роль 1: пока в числе остались цифры

```cpp
int n = std::abs(-1234);      // ⚠️ модуль сначала, иначе цикл не выполнится ни разу
int digitSum = 0;
while (n > 0) {
  digitSum += n % 10;         // последняя цифра
  n /= 10;                    // отбрасываем её
}
```

### Роль 2: пока не собрали результат

```cpp
int source = 1234;
int reversed = 0;
while (source > 0) {
  reversed = reversed * 10 + source % 10;   // сдвигаем влево и приклеиваем цифру
  source /= 10;
}
// 4321
```

### Роль 3: пока читается — условие это сам результат чтения

```cpp
int value = 0;
int sum = 0;
while (std::cin >> value)     // поток в условии = «удалось прочитать?»
  sum += value;
```

### Роль 4: пока есть строки

```cpp
std::string line;
while (std::getline(in, line))
  ++lineCount;
```

### Роль 5: пока находится следующее вхождение

```cpp
std::size_t pos = 0;
while ((pos = s.find('-', pos)) != std::string::npos) {
  ++dashes;
  ++pos;                      // ⚠️ без сдвига — вечный цикл на том же месте
}
```

### Роль 6: пока пользователь не введёт годное значение

```cpp
while (true) {
  int value = readInt("Число: ");
  if (value > 0)              // условие выхода — «данные годятся»
    return value;
  std::cout << "Нужно положительное\n";
}
```

> **Как узнать, что нужен `while`, а не `for`:** ты не можешь заранее сказать, сколько будет витков. Если можешь («ровно `n` раз», «по всем элементам») — бери `for`.
> Подробно — [раздел 8](ref/03-logika-cikly.md#8-циклы).

## `std::vector` — шесть ролей

Полностью: [situacii/05-vector.cpp](situacii/05-vector.cpp)

### Роль 1: просто список значений

```cpp
std::vector<int> marks = {5, 4, 5, 3};
```

### Роль 2: стопка — последний пришёл, первый ушёл

```cpp
std::vector<std::string> undoStack;
undoStack.push_back("напечатал текст");   // кладём наверх
undoStack.push_back("удалил слово");

std::cout << undoStack.back();            // смотрим верхний
undoStack.pop_back();                     // снимаем его
```

Так устроена отмена действий (Ctrl+Z) в любом редакторе.

### Роль 3: журнал — копим и потом смотрим целиком

```cpp
std::vector<std::string> log;
log.push_back("старт");
log.push_back("готово");

for (const auto &entry : log)     // const & — строки не копируем
  std::cout << entry << " ";
```

### Роль 4: таблица — вектор векторов

```cpp
std::vector<std::vector<int>> table(3, std::vector<int>(3, 0));   // 3x3 нулями
table[2][2] = 9;                                                  // [строка][столбец]
```

### Роль 5: буфер для отобранных элементов

```cpp
std::vector<int> positives;         // сюда складываем подходящие
for (int x : all)
  if (x > 0)
    positives.push_back(x);
```

### Роль 6: рабочая копия, чтобы не портить оригинал

```cpp
std::vector<int> sorted = all;      // копия
std::sort(sorted.begin(), sorted.end());
// all остался в исходном порядке
```

> **Как узнать, что нужен `vector`:** элементов несколько, у них есть порядок, и обращаться к ним удобно по номеру. Это контейнер по умолчанию: берёшь его, пока задача не потребует чего-то другого.
> Подробно — [раздел 11](ref/06-konteynery.md#11-массивы-и-stdvector).

## `std::format` — шесть ролей

Полностью: [situacii/06-format.cpp](situacii/06-format.cpp)

### Роль 1: ровная таблица

```cpp
std::cout << std::format("{:<12}{:>5}\n", "Имя", "Балл");   // влево 12, вправо 5
std::cout << std::format("{:-<17}\n", "");                  // линия из дефисов
for (const auto &s : group)
  std::cout << std::format("{:<12}{:>5}\n", s.name, s.score);
```

### Роль 2: число с нужной точностью

```cpp
std::cout << std::format("Средний балл: {:.2f}\n", avg);    // ровно два знака
```

### Роль 3: собрать строку, а не печатать

```cpp
std::string title = std::format("Отчёт по группе из {} человек", group.size());
```

### Роль 4: строка для файла

```cpp
for (const auto &s : group)
  out << std::format("{};{}\n", s.name, s.score);           // тот же приём, другой поток
```

Формат не знает, куда пойдёт результат — на экран, в файл или в переменную.

### Роль 5: понятное сообщение об ошибке

```cpp
std::cout << std::format("Строка {} испорчена и пропущена: {}\n", line, bad);
```

### Роль 6: свой порядок аргументов и заполнение

```cpp
std::cout << std::format("{1} — {0}\n", "результат", "Итог");   // {1} идёт первым
std::cout << std::format("{:*^21}\n", " МЕНЮ ");                // по центру, звёздочками
```

> **Как узнать, что нужен `format`:** как только в выводе появляются столбцы, точность или повторяющийся шаблон. И обязательно — если в таблице есть русские подписи: `setw` считает байты и разъезжается.
> Подробно — [раздел 4](ref/02-vvod-vyvod.md#stdformat--современный-способ-c20).

## Функции — шесть ролей

Полностью: [situacii/07-funkcii.cpp](situacii/07-funkcii.cpp)

Функции различаются не синтаксисом, а тем, **что они обещают** вызывающему.

### Роль 1: проверка — отвечает «да/нет»

```cpp
bool isLeapYear(int year) {
  return (year % 400 == 0) || (year % 4 == 0 && year % 100 != 0);
}
```

Имя такой функции удобно начинать с `is`/`has` — тогда вызов читается как вопрос.

### Роль 2: проверка данных с ранним выходом

```cpp
bool isValidPassword(const std::string &p) {
  if (p.length() < 8)
    return false;               // нашли причину отказа — дальше проверять нечего
  bool hasDigit = false;
  for (char c : p)
    if (std::isdigit(static_cast<unsigned char>(c)))
      hasDigit = true;
  return hasDigit;
}
```

### Роль 3: преобразователь — из одного вида в другой

```cpp
std::string repeat(const std::string &s, int times) {
  std::string result;
  for (int i = 0; i < times; ++i)
    result += s;
  return result;                // возврат по значению — копии не будет
}
```

### Роль 4: поиск, который может не найти

```cpp
std::optional<std::size_t> findFirstNegative(const std::vector<int> &v) {
  for (std::size_t i = 0; i < v.size(); ++i)
    if (v[i] < 0)
      return i;
  return std::nullopt;          // честное «не нашлось»
}
```

### Роль 5: изменить то, что дали (ссылка без `const`)

```cpp
void addBonus(std::vector<int> &scores, int bonus) {
  for (int &s : scores)         // ⚠️ ссылка, иначе изменится копия
    s += bonus;
}
```

### Роль 6: только прочитать (`const`-ссылка)

```cpp
double average(const std::vector<int> &v) {
  if (v.empty())                // защита: делить на ноль нельзя
    return 0.0;
  ...
}
```

Разница между ролями 5 и 6 видна прямо в заголовке: `&` без `const` предупреждает «я изменю твои данные», `const &` обещает «только посмотрю».

> **Как узнать, что пора выделить функцию:** один и тот же кусок написан дважды; функция не помещается на экран; внутри есть блок, которому хочется дать имя в комментарии — вот это имя и станет именем функции.
> Подробно — [раздел 9](ref/04-funkcii.md#9-функции).

## Итог: как выбрать инструмент

| В задаче звучит | Инструмент |
|---|---|
| «список», «по порядку», «третий элемент» | `vector` |
| «для каждого X», «найти по имени» | `map` |
| «только уникальные», «а это уже было?» | `set` |
| «несколько полей об одном объекте» | `struct` |
| «отсортировать по …», «отобрать те, что …» | алгоритм + лямбда |
| «пока не …», «пока есть …» | `while` |
| «ровно N раз», «по всем элементам» | `for` |
| «вывести таблицей», «два знака после точки» | `format` |
| «может не найтись» | `std::optional` |

Один и тот же инструмент решает разные задачи — и это нормально. Узнавать его стоит не по внешнему виду кода, а по формулировке задачи.
