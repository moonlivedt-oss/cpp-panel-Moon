# Программы к разбору «Один инструмент — разные задачи»

Каждый файл — законченная программа, которая показывает один приём в пяти-шести разных ситуациях.
Открой любой и нажми `Ctrl+Alt+R` — увидишь вывод по всем ситуациям сразу.

[← Начни отсюда](../00-НАЧНИ-ОТСЮДА.md) · [Разбор с пояснениями](../03-primenenie.md) · [Примеры программ](../examples/README.md)

| Файл | О чём |
|---|---|
| [01-map.cpp](01-map.cpp) | `std::map` как счётчик, справочник, группировка, таблица перевода, настройки |
| [02-lambda.cpp](02-lambda.cpp) | лямбда как правило сортировки, отбора, удаления, проверки, накопления |
| [03-struct.cpp](03-struct.cpp) | `struct` для точки, записи о человеке, товара с методом, события, настроек |
| [04-while.cpp](04-while.cpp) | `while` для разбора числа, чтения потока, поиска вхождений, повтора до годного ввода |
| [05-vector.cpp](05-vector.cpp) | `vector` как список, стопка отмены, журнал, таблица, буфер, рабочая копия |
| [06-format.cpp](06-format.cpp) | `std::format` для таблицы, точности, строки, файла, сообщения об ошибке |
| [07-funkcii.cpp](07-funkcii.cpp) | функции: проверка, валидация, преобразование, поиск с `optional`, изменение, чтение |

Разбор с пояснениями — в [03-primenenie.md](../03-primenenie.md).

> ⚠️ Запускай файлы по одному (`Ctrl+Alt+R`). Сборка всей папки не сработает: в каждом файле своя `main`.

Программа `06-format.cpp` создаёт рядом файл `format_demo.csv` — так и задумано, она показывает запись в файл.
