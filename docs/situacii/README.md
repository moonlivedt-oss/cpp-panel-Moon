# Программы к разбору «Один инструмент — разные задачи»

Главная мысль курса в одном месте: **один и тот же инструмент решает совсем разные задачи** — всё зависит от роли, в которой ты его применяешь. Каждый файл ниже — законченная программа, которая прогоняет один инструмент через 5–6 ролей подряд.

**Как пользоваться:** открой файл в VS Code, нажми `Ctrl+Alt+R` — увидишь вывод по всем ролям сразу. Читаешь код рядом с выводом — и роль за ролью складывается картина «где это пригодится». Пояснение к каждой роли — по ссылке в колонке «Разбор».

> **Совет.** Не читай всё подряд. Наткнулся в своём коде на задачу — открой нужную роль и подсмотри готовый приём.

> ⚠️ Запускай файлы **по одному** (`Ctrl+Alt+R`). Сборка всей папки не сработает: в каждом файле своя `main`.

Программа `06-format.cpp` создаёт рядом файл `format_demo.csv` — так и задумано: она показывает запись в файл.
