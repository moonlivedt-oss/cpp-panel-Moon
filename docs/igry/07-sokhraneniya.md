### За 30 секунд

- Сохраняют **состояние**, из которого можно восстановить игру: HP, золото, уровень, инвентарь, позицию. То, что вычисляется, — не сохраняют.
- Удобный формат для начала — текст `ключ=значение`, по строке на поле: его видно глазами и легко читать.
- Первая строка — **номер версии** формата. Новая версия игры сможет понять старые сохранения.
- Чтение: начинаем со значений по умолчанию, незнакомые ключи пропускаем, испорченные числа — повод отказаться от загрузки, а не упасть.
- Запись: сначала во временный файл, потом `std::filesystem::rename` поверх старого. Сбой посередине не уничтожит прошлое сохранение.

## Что сохранять, а что нет

| Сохранять | Не сохранять |
|---|---|
| HP, золото, уровень, опыт | максимальное HP, если оно считается из уровня |
| инвентарь: предмет → количество | описание предметов (оно в коде игры) |
| позиция героя, номер этажа | вся карта, если она генерируется из **семени** — достаточно сохранить семя |
| семя генератора, номер хода | указатели и адреса в памяти — после перезапуска они бессмысленны |
| настройки игрока | то, что пересчитывается за миллисекунду |

Правило: сохраняй **минимум**, из которого восстановится всё остальное. Меньше полей — меньше шансов на рассинхрон («уровень 5, а максимум HP как у первого»).

## Формат: ключ=значение

```text
version=2
name=Ари
hp=25
gold=120
level=3
item=зелье:2
item=меч:1
```

Почему не просто числа подряд (`25 120 3`): через месяц ты добавишь поле «мана» между HP и золотом — и все старые сохранения начнут читаться со сдвигом. С ключами порядок строк не важен, лишнее видно, недостающее заменяется значением по умолчанию.

> Когда данных станет много (карта, сотни предметов), переходят на JSON (библиотека `nlohmann/json`) или двоичный формат. Идеи те же: версия, значения по умолчанию, проверка.

## Номер версии в файле

Игра меняется — меняется и сохранение. Номер версии в первой строке позволяет новой игре понять, **как** читать старый файл:

```cpp
if (save.version < 2) {
  // В версии 1 не было уровня. Значение по умолчанию уже стоит (level = 1),
  // но можно и вычислить: например, по количеству золота.
  save.level = 1 + save.gold / 100;
}
save.version = 2;   // после загрузки сохраним уже в новом формате
```

Это называется **миграция**: старые данные приводятся к новому виду один раз, при загрузке.

## Чтение, которое не падает

Файл сохранения может быть от старой версии, отредактирован игроком вручную или обрезан. Игра не должна от этого падать. Три правила:

1. Начинаем с **чистого** объекта со значениями по умолчанию — отсутствующее поле просто останется по умолчанию.
2. **Незнакомый ключ** — пропускаем. Тогда сохранение от более новой версии хотя бы частично прочитается и не сломает старую.
3. **Испорченное число** (`hp=abc`) — `std::stoi` бросит исключение; ловим и отказываемся от загрузки целиком. Полусломанное сохранение хуже, чем честное «не удалось загрузить».

Пройди загрузку по шагам. Файл от **первой** версии игры: в нём есть поле `mana`, которого новая игра не знает, и нет поля `level`:

## Запись, которая не портит файл

Самый обидный баг сохранений: игра начала записывать файл, и в этот момент выключили свет (или игра упала). Старое сохранение уже стёрто (`std::ofstream` обнуляет файл при открытии), новое записано наполовину. Игрок теряет всё.

Лечится записью в **два шага**:

1. Пишем всё во временный файл `save.txt.tmp` и закрываем его.
2. Проверили, что запись прошла, — `std::filesystem::rename` заменяет `save.txt` временным **одним действием**.

Если сбой случится на шаге 1 — старый `save.txt` цел. Шаг 2 — это одна операция файловой системы: либо уже новый файл, либо ещё старый, половинчатого не бывает.

## Всё вместе: сохранить и загрузить

```cpp
#include <exception>
#include <filesystem>
#include <fstream>
#include <iostream>
#include <map>
#include <string>
#include <system_error>

struct Save {
  int version = 2;
  std::string name = "Герой";
  int hp = 30;
  int gold = 0;
  int level = 1;
  std::map<std::string, int> items;   // предмет → количество
};

bool saveGame(const Save &s, const std::string &path) {
  const std::string tmp = path + ".tmp";
  {
    std::ofstream out(tmp);
    if (!out.is_open()) return false;
    out << "version=" << s.version << "\n"
        << "name=" << s.name << "\n"
        << "hp=" << s.hp << "\n"
        << "gold=" << s.gold << "\n"
        << "level=" << s.level << "\n";
    for (const auto &[item, count] : s.items)
      out << "item=" << item << ":" << count << "\n";
    if (!out) return false;               // запись не удалась (например, нет места)
  }                                       // здесь файл закрыт и дописан до конца
  std::error_code ec;
  std::filesystem::rename(tmp, path, ec); // заменить старое сохранение целиком
  return !ec;
}

bool loadGame(Save &s, const std::string &path) {
  std::ifstream in(path);
  if (!in.is_open()) return false;        // сохранения нет — это не ошибка, просто новая игра
  Save fresh;                             // начинаем со значений по умолчанию
  std::string line;
  while (std::getline(in, line)) {
    auto eq = line.find('=');
    if (eq == std::string::npos) continue;             // строка без «=» — пропускаем
    std::string key = line.substr(0, eq);
    std::string value = line.substr(eq + 1);
    try {
      if (key == "version") fresh.version = std::stoi(value);
      else if (key == "name") fresh.name = value;
      else if (key == "hp") fresh.hp = std::stoi(value);
      else if (key == "gold") fresh.gold = std::stoi(value);
      else if (key == "level") fresh.level = std::stoi(value);
      else if (key == "item") {
        auto colon = value.rfind(':');
        if (colon != std::string::npos)
          fresh.items[value.substr(0, colon)] = std::stoi(value.substr(colon + 1));
      }
      // незнакомый ключ — пропускаем
    } catch (const std::exception &) {
      return false;                       // испорченное число — не грузим полусломанное
    }
  }
  if (fresh.hp < 0 || fresh.gold < 0 || fresh.level < 1) return false;   // явная ерунда
  if (fresh.version < 2) fresh.version = 2;                              // миграция
  s = fresh;
  return true;
}

int main() {
  Save game;
  game.name = "Ари";
  game.gold = 120;
  game.level = 3;
  game.items["зелье"] = 2;
  game.items["меч"] = 1;

  if (!saveGame(game, "save.txt")) { std::cout << "Не удалось сохранить\n"; return 1; }
  game.gold = 999;                        // что-то поменяли и сохранили ещё раз
  if (!saveGame(game, "save.txt")) { std::cout << "Не удалось сохранить\n"; return 1; }

  Save loaded;
  if (!loadGame(loaded, "save.txt")) { std::cout << "Не удалось загрузить\n"; return 1; }
  std::cout << loaded.name << ": HP " << loaded.hp << ", золото " << loaded.gold
            << ", уровень " << loaded.level << "\n";
  for (const auto &[item, count] : loaded.items) std::cout << "  " << item << " × " << count << "\n";
  return 0;
}
```

```console
$ ./save
Ари: HP 30, золото 999, уровень 3
  зелье × 2
  меч × 1
```

Открой `save.txt` блокнотом — внутри читаемый текст. Поменяй `gold=999` на `gold=abc` и запусти загрузку: программа честно скажет «Не удалось загрузить», а не упадёт.

## Типовые ошибки

| Ошибка | Что будет | Как надо |
|---|---|---|
| Писать прямо в `save.txt` | сбой посередине — пустой или обрезанный файл | временный файл + `rename` |
| Числа без ключей в фиксированном порядке | новое поле — и все старые сохранения читаются со сдвигом | `ключ=значение` |
| Нет номера версии | через год не понять, как читать старые файлы | `version=` первой строкой |
| `std::stoi` без `try` | игрок поправил файл руками — игра падает | ловить исключение, отказываться от загрузки |
| Сохранять выводимые значения | «уровень 5, а максимум HP как у первого» | сохранять минимум, остальное вычислять |
