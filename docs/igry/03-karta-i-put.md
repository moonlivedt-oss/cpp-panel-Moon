### За 30 секунд

- Уровень — `std::vector<std::string>`: каждая строка — ряд клеток. Клетка — `map[y][x]`: **сначала строка, потом столбец**.
- Направления хранят в массивах `DX = {1, -1, 0, 0}`, `DY = {0, 0, 1, -1}` — один цикл вместо четырёх `if`.
- Перед шагом: **внутри ли поля** новая клетка и **проходима ли** она.
- Путь к цели в обход стен ищут **поиском в ширину** (BFS): волна расходится от старта, у каждой клетки — расстояние.
- Враг, стоящий на клетке с расстоянием `d`, делает шаг на соседнюю с `d - 1` — и приходит к игроку кратчайшей дорогой.

## Сетка: x — столбец, y — строка

```cpp
std::vector<std::string> map = {
    "#######",
    "#@....#",     // y = 1
    "#..#..#",     // y = 2
    "#######",
};
char c = map[1][1];   // '@' — строка 1, столбец 1
```

Главная путаница: в математике пишут `(x, y)`, а к вектору строк обращаются `map[y][x]` — **сначала строка**. Поэтому удобно завести одну функцию и больше не думать об этом:

```cpp
char &cell(std::vector<std::string> &map, int x, int y) {
  return map[static_cast<std::size_t>(y)][static_cast<std::size_t>(x)];
}
```

`static_cast<std::size_t>` нужен, потому что координаты мы держим в `int` (они бывают отрицательными — например, `x - 1` у левого края), а индексы вектора — беззнаковые.

## Четыре направления без четырёх if

Вместо

```cpp
if (dir == 0) ++x;
if (dir == 1) --x;
if (dir == 2) ++y;
if (dir == 3) --y;
```

— таблица сдвигов:

```cpp
const int DX[4] = {1, -1, 0, 0};   // вправо, влево, вниз, вверх
const int DY[4] = {0, 0, 1, -1};

for (int k = 0; k < 4; ++k) {
  int nx = x + DX[k];
  int ny = y + DY[k];
  // (nx, ny) — сосед номер k
}
```

Нужны диагонали — добавь ещё четыре пары: `{1, 1}`, `{1, -1}`, `{-1, 1}`, `{-1, -1}`. Код обхода соседей не изменится.

## Столкновения: можно ли сюда встать

Две проверки **до** того, как менять координаты:

```cpp
bool inside(const std::vector<std::string> &map, int x, int y) {
  return y >= 0 && y < static_cast<int>(map.size()) &&
         x >= 0 && x < static_cast<int>(map[static_cast<std::size_t>(y)].size());
}

bool walkable(const std::vector<std::string> &map, int x, int y) {
  return inside(map, x, y) && map[static_cast<std::size_t>(y)][static_cast<std::size_t>(x)] != '#';
}

// ход игрока
int nx = x + DX[k], ny = y + DY[k];
if (walkable(map, nx, ny)) { x = nx; y = ny; }   // стена или край — просто стоим
```

Порядок в `inside` важен: сначала проверяем `y`, и только потом берём `map[y]` — иначе обращение за границу вектора случится **до** проверки. `&&` вычисляется слева направо и останавливается на первом `false` — [ленивость `&&`](../ref/03-logika-cikly.md#ленивость--и---это-инструмент) здесь работает на нас.

Столкновение **двух сущностей** на сетке — это просто совпадение координат: `if (enemy.x == hero.x && enemy.y == hero.y) fight();`.

## Поиск пути: волна от игрока

Враг должен дойти до игрока в обход стен. Идея поиска в ширину (BFS) — как круги на воде:

1. У стартовой клетки расстояние 0. Кладём её в **очередь**.
2. Достаём клетку из очереди. Всем её проходимым соседям, у которых расстояния ещё нет, ставим «моё + 1» и кладём их в очередь.
3. Повторяем, пока очередь не опустеет.

Очередь (`std::queue`) гарантирует, что сначала обработаются все клетки на расстоянии 1, потом все на расстоянии 2 и так далее — волна расходится ровно. Поэтому первое найденное расстояние до клетки — **кратчайшее**.

Пройди по шагам на маленькой карте (`#` — стена):

```
S a b
c # d
e f E
```

```steps
@id c1jncpof
# Волна BFS от S до врага E
q.push(start); dist[start] = 0;
while (!q.empty()) {
    Pos cur = q.front(); q.pop();
    for (Pos nb : neighbours(cur))
        if (walkable(nb) && dist[nb] == -1) {
            dist[nb] = dist[cur] + 1;
            q.push(nb);
        }
}
---
1 | очередь=[S], S=0 | Старт: у S расстояние 0, он в очереди.
3 | cur=S, очередь=[] | Достали S. Его соседи: `a` справа и `c` снизу.
6 | a=1 | 
7 | очередь=[a, c], c=1 | Оба соседа получили 0 + 1 = 1 и встали в очередь.
3 | cur=a, очередь=[c] | Достали `a`. Соседи: S (уже есть расстояние — пропуск), `b`, снизу стена.
6 | b=2 | 
7 | очередь=[c, b] | 
3 | cur=c, очередь=[b] | Достали `c`. Сосед снизу — `e`.
?6 | e=2 | Какое расстояние получит `e`?
7 | очередь=[b, e] | Заметь: в очереди все клетки «второго круга».
3 | cur=b, очередь=[e] | 
6 | d=3 | 
7 | очередь=[e, d] | 
3 | cur=e, очередь=[d] | 
6 | f=3 | 
7 | очередь=[d, f] | 
3 | cur=d, очередь=[f] | Сосед снизу — враг!
6 | E=4 | До врага 4 шага.
7 | очередь=[f, E] | 
3 | cur=f, очередь=[E] | Сосед `f` справа — тоже E, но у него расстояние **уже есть** — второй раз не трогаем. Поэтому BFS не зацикливается.
3 | cur=E, очередь=[] | Очередь пуста — волна прошла всю карту.
```

Теперь поиграй с волной сам: `@` — герой, `E` — враг. К врагу ведут три дороги — сверху, справа и слева. Перекрой ту, по которой идёт подсвеченный путь, — волна обойдёт стену и путь перестроится. Перекрой все проходы — враг не дойдёт никогда: у клетки `E` так и останется «нет расстояния».

## Всё вместе: карта расстояний

Программа запускает волну от `@` и печатает расстояние до каждой клетки (последней цифрой, чтобы сетка не разъезжалась):

```cpp
#include <cstddef>
#include <iostream>
#include <queue>
#include <string>
#include <vector>

struct Pos {
  int x = 0;
  int y = 0;
};

const int DX[4] = {1, -1, 0, 0};
const int DY[4] = {0, 0, 1, -1};

int main() {
  std::vector<std::string> map = {
      "#########",
      "#@..#...#",
      "#.#.#.#.#",
      "#.#...#E#",
      "#########",
  };
  const int h = static_cast<int>(map.size());
  const int w = static_cast<int>(map[0].size());
  auto at = [&](int x, int y) -> char & { return map[static_cast<std::size_t>(y)][static_cast<std::size_t>(x)]; };

  std::vector<std::vector<int>> dist(static_cast<std::size_t>(h), std::vector<int>(static_cast<std::size_t>(w), -1));
  auto d = [&](Pos p) -> int & { return dist[static_cast<std::size_t>(p.y)][static_cast<std::size_t>(p.x)]; };

  Pos start, enemy;
  for (int y = 0; y < h; ++y)
    for (int x = 0; x < w; ++x) {
      if (at(x, y) == '@') start = {x, y};
      if (at(x, y) == 'E') enemy = {x, y};
    }

  std::queue<Pos> q;
  d(start) = 0;
  q.push(start);
  while (!q.empty()) {
    Pos cur = q.front();
    q.pop();
    for (int k = 0; k < 4; ++k) {
      Pos nb{cur.x + DX[k], cur.y + DY[k]};
      if (nb.x < 0 || nb.y < 0 || nb.x >= w || nb.y >= h) continue;   // за краем
      if (at(nb.x, nb.y) == '#' || d(nb) != -1) continue;             // стена или уже были
      d(nb) = d(cur) + 1;
      q.push(nb);
    }
  }

  for (int y = 0; y < h; ++y) {
    for (int x = 0; x < w; ++x) {
      int v = d({x, y});
      if (at(x, y) == '#') std::cout << '#';
      else std::cout << static_cast<char>('0' + v % 10);
    }
    std::cout << '\n';
  }
  std::cout << "До врага: " << d(enemy) << " шагов\n";
  return 0;
}
```

```console
#########
#012#890#
#1#3#7#1#
#2#456#2#
#########
До врага: 12 шагов
```

Прочитай карту как волну: `0` у героя, числа растут, огибая стены. Справа вверху `0` и `1` — это 10 и 11 (печатаем последнюю цифру), а `2` у врага — 12.

## Как враг идёт по волне

Запусти волну **от игрока** — и любой враг на карте знает дорогу: достаточно шагнуть на соседнюю клетку, где расстояние на 1 меньше.

```cpp
// враг в (ex, ey); dist — волна от игрока
for (int k = 0; k < 4; ++k) {
  int nx = ex + DX[k], ny = ey + DY[k];
  if (inside(map, nx, ny) && dist[ny][nx] == dist[ey][ex] - 1) {
    ex = nx; ey = ny;       // шаг ближе к игроку
    break;
  }
}
```

Одна волна от игрока обслуживает **сколько угодно** врагов — выгоднее, чем искать путь от каждого врага отдельно. Если `dist` врага равно `-1` — до игрока не добраться (он за стеной), пусть враг бродит случайно.

> **А как в больших играх?** Для огромных карт BFS заменяют на **A\*** — он ищет путь «с подсказкой направления» и обходит меньше клеток. Но идея та же: волна + расстояния. Начни с BFS — на консольной карте его хватит с запасом.

> 🎮 **В настоящих играх.** В рогалике Brogue монстры ходят по «картам Дейкстры» — это та же волна из этой темы, посчитанная один раз для всей карты: каждый монстр просто шагает в соседнюю клетку с меньшим числом. В стратегиях с огромными картами используют A* — волну, которая растёт в сторону цели, а не во все стороны.

## Типовые ошибки

| Ошибка | Что будет | Как надо |
|---|---|---|
| `map[x][y]` | персонаж ходит «по диагонали зеркально» или падает | `map[y][x]` — сначала строка |
| Проверка стены до проверки границ | чтение за пределами вектора | сначала `inside`, потом символ |
| Координаты в `size_t` | `x - 1` у левого края → огромное число | координаты `int`, в индекс — через `static_cast` |
| BFS без проверки «уже были» | очередь растёт бесконечно | `if (dist[nb] != -1) continue;` |
| Стек вместо очереди | путь находится, но **не** кратчайший (это уже поиск в глубину) | `std::queue` |

#include <iostream>
#include <queue>
#include <string>
#include <vector>

int main() {
  int rows = 0;
  std::cin >> rows;
  std::vector<std::string> map(rows);
  for (auto &row : map)
    std::cin >> row;

  const int DX[4] = {1, -1, 0, 0};
  const int DY[4] = {0, 0, 1, -1};
  std::vector<std::vector<int>> dist(rows);
  std::queue<std::pair<int, int>> q;
  for (int y = 0; y < rows; ++y) {
    dist[y].assign(map[y].size(), -1);
    for (int x = 0; x < static_cast<int>(map[y].size()); ++x)
      if (map[y][x] == 'S') {
        dist[y][x] = 0;
        q.push({x, y});
      }
  }
  while (!q.empty()) {
    auto [x, y] = q.front();
    q.pop();
    if (map[y][x] == 'E') {
      std::cout << dist[y][x] << "\n";
      return 0;
    }
    for (int k = 0; k < 4; ++k) {
      int nx = x + DX[k], ny = y + DY[k];
      if (ny < 0 || ny >= rows || nx < 0 ||
          nx >= static_cast<int>(map[ny].size()))
        continue;
      if (map[ny][nx] == '#' || dist[ny][nx] != -1)
        continue;
      dist[ny][nx] = dist[y][x] + 1;
      q.push({nx, ny});
    }
  }
  std::cout << -1 << "\n";
}

## Проверь себя

```quiz
В: Как обратиться к клетке со столбцом `x` и строкой `y` в `std::vector<std::string> map`?
+ `map[y][x]`
- `map[x][y]`
- `map(x, y)`
= Вектор строк: сначала выбираем строку (`y`), потом символ в ней (`x`).

В: Почему BFS находит именно кратчайший путь?
+ Очередь обрабатывает клетки «кругами»: все на расстоянии 1, потом все на 2 и т. д. — первое найденное расстояние минимально
- Потому что он проверяет все пути по очереди
- Не находит, это случайность
= Если заменить очередь на стек, порядок нарушится, и путь может оказаться длиннее.

В: Враг стоит на клетке с расстоянием 5 (волна от игрока). Куда ему шагнуть?
+ На соседнюю проходимую клетку с расстоянием 4
- На клетку с расстоянием 6
- Куда угодно — всё равно дойдёт
= Каждый шаг на «−1» приближает к игроку по кратчайшему пути.
```

```cards
В: Зачем массивы `DX` и `DY`?
О: Чтобы обходить соседей одним циклом по `k` вместо четырёх `if`. Диагонали — добавить пары.

В: Что хранит `dist` в BFS и что значит `-1`?
О: Расстояние от старта до каждой клетки; `-1` — клетка ещё не достигнута (или недостижима).

Q: Почему BFS находит кратчайший путь на сетке без весов?
A: Он обходит клетки волнами: сначала все на расстоянии 1, потом 2 и так далее. Первая встреча с целью и есть кратчайший путь.

Q: Какую структуру данных использует BFS?
A: Очередь `std::queue`: новые клетки добавляются в конец, а берутся из начала.
H: Первым пришёл — первым обслужен.

Q: Как восстановить сам путь после BFS?
A: Для каждой клетки хранить, откуда в неё пришли (`prev`), и пройти от цели назад до старта, а потом развернуть путь.

Q: Зачем помечать клетку посещённой сразу при добавлении в очередь?
A: Иначе одна клетка попадёт в очередь несколько раз — лишняя работа, а на больших картах BFS сильно замедлится.
```

```findbug
bool walkable(const std::vector<std::string> &map, int x, int y) {
  return map[y][x] != '#' && y >= 0 && y < (int)map.size() && x >= 0;
}
---
Сначала читается `map[y][x]`, и только **потом** проверяются границы. У края поля это обращение за пределы вектора.

**Исправление:** сначала границы, потом символ: `return inside(map, x, y) && map[y][x] != '#';` — `&&` остановится на первой ложной проверке.
```

## Босс темы

```boss
# Погоня
@id c1f4gqjw
Игрок убегает от двух врагов по лабиринту.

1. Лабиринт — `std::vector<std::string>` с `#`, `@`, двумя `E` и выходом `>`.
2. После каждого хода игрока (`w a s d`) — волна BFS **от игрока**, и каждый враг делает шаг по ней.
3. Враг встал на клетку игрока — поражение. Игрок дошёл до `>` — победа, счёт ходов.
4. Со звёздочкой: враги двигаются через ход (игрок чуть быстрее) — иначе в узком коридоре не уйти.
5. Проверь недостижимого врага (закрой его стенами): он не должен падать или «телепортироваться».

<details>
<summary>Подсказка</summary>

Вынеси BFS в функцию `std::vector<std::vector<int>> wave(const std::vector<std::string> &map, Pos from)` и вызывай её каждый ход. Для карты 20×40 это мгновенно.

</details>
```

## Закрепление прошлых тем

Три вопроса из тем, на которых стоит карта:

```quiz
В: Тема 6. Какой элемент удаляет `q.pop()` у `std::queue`?
+ Самый ранний из добавленных (первым пришёл — первым ушёл)
- Последний добавленный
- Наибольший
= Именно поэтому волна BFS расходится ровно: сначала все клетки первого круга, потом второго.

В: Тема 6. Как взять символ в столбце `x` и строке `y` из `std::vector<std::string> map`?
+ `map[y][x]`
- `map[x][y]`
- `map[x * y]`
= Сначала строка (вектор), потом символ в ней. Перепутать порядок — самая частая ошибка с сетками.

В: Тема 3. Почему `if (y < rows && map[y][x] != '#')` безопасно, даже когда `y` за краем?
+ `&&` не вычисляет правую часть, если левая ложна
- `map[y]` сам проверяет границы
- Не безопасно — будет падение
= Ленивость `&&` работает на нас: обращения к `map[y]` просто не происходит.
```
