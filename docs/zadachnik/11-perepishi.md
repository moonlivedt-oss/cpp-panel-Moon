# Тема 10. Перепиши по-современному

Много кода в интернете, учебниках и старых репозиториях написано в стиле «до 2011 года».
Он **работает**, поэтому его надо уметь читать — но так уже не пишут. В этой теме ты берёшь
рабочий, но устаревший фрагмент и переписываешь на современный C++. Это тренирует то, что не
тренирует «напиши с нуля»: **узнавать старьё и видеть современную замену**.

## Чему ты здесь научишься

- **Узнавать** устаревшие конструкции в чужом коде — половина кода вокруг именно такая.
- Заменять их на современные: почему `vector` вместо `new[]`, `std::` вместо `using namespace std;`.
- Понимать **не только «как», но и «почему»** — каждая замена чинит конкретную проблему (утечки, конфликты имён, отсутствие проверки типов).

## Где это пригодится

Читать чужой код придётся всегда — в туториалах, на форумах, в проектах, к которым присоединяешься.
Умение мгновенно опознать «о, это старьё, я знаю современную замену» отличает того, кто просто
копирует, от того, кто понимает. И собственный код сразу будешь писать правильно.

## Как работать с темой

Здесь нет «Формата ввода» — вход у программ прежний. Задача одна: **тот же результат, но современным
кодом**. Собирай со строгими флагами и добивайся **нуля предупреждений** — часто именно они и
подсказывают, что старый код делал что-то сомнительное.

**⭐ Бонус** под задачей — дополнительная старая привычка, которую стоит заменить в том же фрагменте.

## 10.1. `using namespace std;` 🟢

Перепиши так, чтобы не было `using namespace std;`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int count;
    cout << "Сколько? ";
    cin >> count;
    cout << "Ввели: " << count << endl;
}
```

**Что тренирует:** явные имена из `std`, привычку не тащить всё пространство имён разом.
**Где пригодится:** любой файл, который ты пишешь; в заголовках `using namespace` вообще запрещён.
**Как подступиться:** убери строку `using namespace std;` и допиши `std::` перед `cout`, `cin`, `endl`.
Заодно посмотри на имя `count` — оно совпадает с `std::count` из `<algorithm>`, и с `using namespace` это могло бы конфликтовать.
**⭐ Бонус:** заодно замени `endl` на `"\n"` — `endl` лишний раз сбрасывает буфер.

## 10.2. `new[]` / `delete[]` → `std::vector` 🟡

Перепиши, убрав ручное управление памятью.

```cpp
#include <iostream>

int main() {
    int n;
    std::cin >> n;

    int* arr = new int[n];          // выделили руками
    for (int i = 0; i < n; ++i)
        arr[i] = i * i;

    long long sum = 0;
    for (int i = 0; i < n; ++i)
        sum += arr[i];

    std::cout << sum << "\n";
    delete[] arr;                   // забудешь — утечка
}
```

**Что тренирует:** `std::vector` вместо ручной памяти; идея RAII.
**Где пригодится:** любой динамический массив; `new[]`/`delete[]` в современном коде почти не встречается.
**Как подступиться:** замени `new int[n]` на `std::vector<int> arr(n);`. Строка `delete[]` больше не нужна — память освободится сама.
**⭐ Бонус:** посчитай сумму через `std::accumulate` из `<numeric>` вместо второго цикла.

## 10.3. `char[]` и `strcpy` → `std::string` 🟡

Перепиши работу с текстом на `std::string`.

```cpp
#include <iostream>
#include <cstring>

int main() {
    char name[50];
    std::strcpy(name, "Аня");       // длина не проверяется — переполнишь буфер и не заметишь
    std::strcat(name, " Иванова");

    std::cout << name << " (" << std::strlen(name) << " байт)\n";
}
```

**Что тренирует:** `std::string` вместо C-строк; безопасная работа с текстом.
**Где пригодится:** везде, где есть текст; C-строки — источник переполнений буфера.
**Как подступиться:** `std::string name = "Аня";`, склейка — обычным `+`/`+=`, длина — `name.size()`. Заголовок `<cstring>` больше не нужен.
**⭐ Бонус:** добавь к имени отчество через `getline` (ввод с пробелами) — с `char[]` это была бы боль.

## 10.4. `#define` и C-style cast 🟢

Перепиши, убрав макрос и C-приведение.

```cpp
#include <iostream>

#define SIZE 10                     // препроцессор: не знает типов и области видимости

int main() {
    int sum = 45;
    double avg = (double)sum / SIZE; // C-style cast

    std::cout << avg << "\n";
}
```

**Что тренирует:** `const` вместо `#define`, `static_cast` вместо `(тип)`.
**Где пригодится:** любые константы; C-cast молча делает опасные преобразования, `static_cast` — только осмысленные.
**Как подступиться:** `const int SIZE = 10;` внутри `main`, и `static_cast<double>(sum)` вместо `(double)sum`.
**⭐ Бонус:** если константа известна на этапе компиляции — попробуй `constexpr int SIZE = 10;`.

## 10.5. `printf` / `scanf` → потоки 🟡

Перепиши ввод-вывод на потоки.

```cpp
#include <cstdio>

int main() {
    int n;
    double x;
    scanf("%d %lf", &n, &x);            // легко перепутать спецификатор и тип
    printf("n = %d, x = %.2f\n", n, x); // %d для double = мусор, и никто не поймает
}
```

**Что тренирует:** `std::cin`/`std::cout`, безопасный ввод-вывод с проверкой типов.
**Где пригодится:** любой ввод-вывод; `printf`/`scanf` не сверяют тип с форматом.
**Как подступиться:** `std::cin >> n >> x;` и `std::cout`. Два знака после точки — через `std::fixed`/`std::setprecision(2)` (`<iomanip>`) или `std::format("{:.2f}", x)`.
**⭐ Бонус:** собери строку вывода через `std::format` из `<format>` — та же краткость, что у `printf`, но с проверкой типов на этапе компиляции.

## 10.6. `rand() % n` → `<random>` 🟡

Перепиши генерацию случайных чисел.

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    std::srand(std::time(nullptr));
    for (int i = 0; i < 5; ++i)
        std::cout << std::rand() % 6 + 1 << " ";   // распределение слегка неравномерное
    std::cout << "\n";
}
```

**Что тренирует:** генератор из `<random>` вместо старого `rand()`.
**Где пригодится:** игры, симуляции, случайные выборки; у `rand() % n` распределение перекошено.
**Как подступиться:** `std::mt19937 gen(std::random_device{}());` и `std::uniform_int_distribution<int> dist(1, 6);`, потом `dist(gen)` в цикле.
**⭐ Бонус:** сделай кубик функцией `int roll(std::mt19937 &gen)` — генератор передай по ссылке, чтобы он был один на всю программу.

# Подсказки

> 📖 Мало подсказки? Открой теорию темы: [раздел справочника](../ref/09-spravka.md).

<details>
<summary>10.1 — using namespace std;</summary>

Убери строку `using namespace std;`. Перед каждым именем из библиотеки поставь `std::`:
`std::cout`, `std::cin`. `endl` — это `std::endl`, но его лучше заменить на `"\n"`.
</details>

<details>
<summary>10.2 — new[] / delete[]</summary>

`std::vector<int> arr(n);` создаёт вектор из `n` нулей. Дальше `arr[i]` работает как у массива.
Строку `delete[] arr;` удали — вектор освобождает память сам на выходе из `main`.
</details>

<details>
<summary>10.3 — char[] и strcpy</summary>

`std::string name = "Аня";` затем `name += " Иванова";`. Длина — `name.size()`.
Заголовок `<cstring>` можно убрать. `std::string` сам следит за размером — переполнить буфер нечем.
</details>

<details>
<summary>10.4 — #define и C-cast</summary>

`const int SIZE = 10;` (или `constexpr`) вместо `#define`. `static_cast<double>(sum)` вместо `(double)sum`.
`static_cast` откажется от бессмысленного преобразования, а `(тип)` сделает что угодно молча.
</details>

<details>
<summary>10.5 — printf / scanf</summary>

`std::cin >> n >> x;` — типы определяются сами, перепутать спецификатор нельзя.
Вывод: `std::cout << std::fixed << std::setprecision(2) << ...;` (нужен `<iomanip>`).
</details>

<details>
<summary>10.6 — rand()</summary>

```cpp
std::random_device rd;
std::mt19937 gen(rd());
std::uniform_int_distribution<int> dist(1, 6);
int value = dist(gen);
```
Распределение равномерное, и не нужно вручную приводить диапазон через `% 6 + 1`.
</details>

## Проверь себя

Тема закрыта, когда:

- в переписанном коде **нет** ни `using namespace std;`, ни `new`/`delete`, ни `char[]` с `strcpy`, ни `#define` для констант, ни `printf`/`scanf`, ни `rand()`;
- всё собирается со строгими флагами **без единого предупреждения**;
- результат совпадает со старой версией (тот же вывод на том же вводе).

✅ Настоящая проверка: сможешь взять любой чужой фрагмент из интернета и с ходу сказать, что в нём устарело и чем заменить.
