# Тема 2. Ввод и вывод

Программа почти всегда что-то читает и что-то печатает. Здесь ты научишься делать
это надёжно: читать заранее неизвестное количество чисел, останавливаться по
сигналу или по концу ввода, и выводить результат ровно так, как требуют (нужная
точность, ширина поля). Кривой ввод-вывод — причина половины «странных» багов.

> 📖 **Опирается на раздел 4 справочника** ([теория в справочнике](../ref/02-vvod-vyvod.md)).
> Там разобраны безопасное чтение, `getline`, `std::format` и почему `cin` иногда «ломается».

> 🔗 **Тот же приём в целой программе:** «Угадай число» (`../examples/04-ugaday-chislo.md`) —
> чтение ввода в цикле и реакция на каждое значение.

## Чему ты здесь научишься

- Три способа читать поток чисел: «известно сколько», «до стоп-значения», «до конца ввода».
- Правильно заводить накопитель суммы (`long long`) и счётчик.
- Форматировать вывод: ширина поля (`setw`), точность (`setprecision`, `fixed`).
- Не начинать поиск максимума с нуля (типовая ошибка).

## Где это пригодится

Любая программа обработки данных читает поток значений неизвестной длины:
строки лога, показания датчиков, числа из файла, ответы пользователя. Умение
корректно остановиться и красиво вывести — базовый навык, который отличает
работающую программу от «зависла и печатает одно и то же».

---

## 2.1. Сумма N чисел 🟢

Сначала дано, сколько будет чисел, затем сами числа. Напечатайте их сумму.

**Формат ввода.** Первое число `N` (0 ≤ N ≤ 1000), затем `N` целых чисел.

**Формат вывода.** Одно число — сумма всех `N` чисел.

**Пример:**
```
Ввод
4
10 20 30 40
Вывод
100
```

**Что тренирует:** цикл «фиксированное число повторений» + накопление суммы.
**Где пригодится:** подсчёт итога по списку (сумма чека, суммарный вес, общее время).
**Как подступиться:** прочитай `N`, заведи `long long sum = 0`, крути цикл ровно `N` раз.

---

## 2.2. Пока не ноль 🟢

Читайте числа по одному, пока не встретится `0`. Ноль — это сигнал «стоп»,
в подсчёте он не участвует. Напечатайте, сколько чисел было и какова их сумма.

**Формат ввода.** Последовательность целых чисел, заканчивающаяся нулём.

**Формат вывода.** Два числа через пробел: количество чисел (без нуля) и их сумма.

**Пример:**
```
Ввод
5 3 8 0
Вывод
3 16
```

**Что тренирует:** цикл с «сигнальным» (sentinel) значением — выход по `break`.
**Где пригодится:** ввод «вводите товары, пустая строка — конец», меню «0 — выход», чтение до маркёра конца.
**Как подступиться:** читай в бесконечном цикле, а на стоп-значении делай `break` **до** того, как учтёшь его.

---

## 2.3. Максимум до конца ввода 🟡

Читайте числа до тех пор, пока ввод не закончится (файл кончился или нажали
`Ctrl+Z` и `Enter`). Напечатайте наибольшее из них. Гарантируется, что хотя бы
одно число будет.

**Формат ввода.** Одно или несколько целых чисел, разделённых пробелами и
переводами строк, до конца ввода.

**Формат вывода.** Наибольшее число.

**Пример:**
```
Ввод
3 -1 7 4 7 2
Вывод
7
```

**Что тренирует:** чтение «пока получается» (`while (std::cin >> x)`), корректная инициализация максимума.
**Где пригодится:** обработка файла или потока неизвестной длины; поиск рекорда, пика, самой поздней даты.
**Как подступиться:** сам факт удачного чтения — это условие цикла. Максимум нельзя начинать с `0`.

---

## 2.4. Ровный столбик 🟡

Дано число `N`, затем `N` целых чисел. Напечатайте их **по одному в строке**,
выровняв по правому краю в поле шириной 6 символов.

**Формат ввода.** `N` (0 ≤ N ≤ 100), затем `N` целых чисел, по модулю до 99999.

**Формат вывода.** `N` строк, в каждой одно число, прижатое к правому краю поля из 6 символов.

**Пример:**
```
Ввод
3
5 -142 30000
Вывод
     5
  -142
 30000
```

**Что тренирует:** форматированный вывод фиксированной ширины (`std::setw`).
**Где пригодится:** таблицы, отчёты, выравнивание чисел в столбик, ценники, любой «человекочитаемый» вывод.
**Как подступиться:** `setw` действует только на **следующий** вывод — ставь его перед каждым числом.

---

## 2.5. Среднее с двумя знаками 🟢

Дано число `N`, затем `N` дробных чисел. Напечатайте их сумму и среднее
арифметическое, каждое — ровно с двумя знаками после запятой.

**Формат ввода.** `N` (1 ≤ N ≤ 1000), затем `N` дробных чисел.

**Формат вывода.** Два числа через пробел: сумма и среднее, по два знака после точки.

**Пример:**
```
Ввод
3
1.5 2 2.5
Вывод
6.00 2.00
```

**Что тренирует:** работа с `double` в цикле, стойкая настройка точности вывода.
**Где пригодится:** финансовые отчёты (всегда две цифры после точки), средние показатели, проценты.
**Как подступиться:** копи в `double`; `std::fixed` + `setprecision(2)` задаются один раз и держатся до конца.

---

## 2.6. Плюсы и минусы 🟢

Дано `N`, затем `N` целых чисел. Напечатайте, сколько среди них положительных и
сколько отрицательных (ноль не считается ни тем, ни другим).

**Формат ввода.** `N` (0 ≤ N ≤ 1000), затем `N` целых чисел.

**Формат вывода.** Два числа через пробел: количество положительных и количество отрицательных.

**Пример:**
```
Ввод
5
3 -1 0 -4 2
Вывод
2 2
```

**Что тренирует:** несколько счётчиков и ветвление внутри цикла чтения.
**Где пригодится:** категоризация данных «на лету» (прибыль/убыток, за/против, вверх/вниз).
**Как подступиться:** два счётчика; `if (x > 0)` — один, `else if (x < 0)` — другой, ноль не попадёт никуда.

---

## 2.7. Столбик «число и квадрат» 🟡

Читайте числа до конца ввода. Для каждого напечатайте в строке само число и его
квадрат, оба выровненные по правому краю в поле шириной 8.

**Формат ввода.** Целые числа (по модулю до 1000) до конца ввода.

**Формат вывода.** По строке на число: число и его квадрат, каждое в поле из 8 символов.

**Пример:**
```
Ввод
2 -3 10
Вывод
       2       4
      -3       9
      10     100
```

**Что тренирует:** чтение до конца ввода + повторное форматирование `setw` в одной строке.
**Где пригодится:** таблицы и отчёты с несколькими колонками.
**Как подступиться:** `setw` ставь перед **каждым** из двух значений; квадрат держи в `long long`.

---

## 2.8. Среднее без известного N 🔴

Читайте числа до конца ввода (хотя бы одно число будет). Напечатайте их количество,
сумму и среднее (с двумя знаками).

**Формат ввода.** Целые числа до конца ввода.

**Формат вывода.** Три величины через пробел: количество, сумма, среднее.

**Пример:**
```
Ввод
2 4 9
Вывод
3 15 5.00
```

**Что тренирует:** соединение трёх приёмов — чтение до конца, накопление, среднее с защитой.
**Где пригодится:** обработка потока данных или файла, когда длина заранее неизвестна.
**Как подступиться:** веди `count` и `sum` прямо в цикле, среднее считай после него.

# Подсказки

> 📖 Мало подсказки? Открой теорию темы: [раздел справочника](../ref/02-vvod-vyvod.md).

<details>
<summary>2.1 — Сумма N чисел</summary>

- Прочитай `N`, заведи `long long sum = 0;`, крути цикл `for (int i = 0; i < N; ++i)`.
- Внутри: `int x; std::cin >> x; sum += x;`.
</details>

<details>
<summary>2.2 — Пока не ноль</summary>

- Цикл с «сигнальным» значением: `while (true) { std::cin >> x; if (x == 0) break; ... }`.
- Внутри до `break` увеличивай счётчик и сумму.
- Так число-сигнал (`0`) не попадёт в подсчёт.
</details>

<details>
<summary>2.3 — Максимум до конца ввода</summary>

- Сам поток в условии значит «удалось прочитать?»: `while (std::cin >> x) { ... }`.
- Заведи `int best;` и прочитай **первое** число до цикла (или заведи флаг «ещё не было чисел»),
  чтобы было с чем сравнивать. Обновляй: `if (x > best) best = x;`.
- Не начинай `best` с `0` — если все числа отрицательные, ответ будет неверным.
</details>

<details>
<summary>2.4 — Ровный столбик</summary>

- Ширина поля: `#include <iomanip>`, затем `std::cout << std::setw(6) << x << "\n";`.
- `setw` действует только на **следующий** вывод, поэтому пиши его перед каждым числом.
- По умолчанию выравнивание идёт вправо — как раз то, что нужно.
</details>

<details>
<summary>2.5 — Среднее с двумя знаками</summary>

- Читай числа в `double`, копи в `double sum`.
- Среднее: `sum / N`. Приводить к `double` не нужно — `sum` уже дробное.
- Два знака: `std::cout << std::fixed << std::setprecision(2) << sum << " " << avg;`
  или `std::format("{:.2f} {:.2f}", sum, avg)`.
</details>

<details>
<summary>2.6 — Плюсы и минусы</summary>

- Два счётчика: `int pos = 0, neg = 0;`.
- В цикле чтения: `if (x > 0) ++pos; else if (x < 0) ++neg;` — ноль не попадёт ни в одну ветку.
</details>

<details>
<summary>2.7 — Столбик «число и квадрат»</summary>

- Чтение до конца: `while (std::cin >> x) { ... }`.
- Квадрат в `long long`: `long long sq = 1LL * x * x;`.
- `std::setw(8)` перед каждым выводом: `std::cout << std::setw(8) << x << std::setw(8) << sq << "\n";`.
</details>

<details>
<summary>2.8 — Среднее без известного N</summary>

- Веди `int count = 0; long long sum = 0;` и обновляй их в `while (std::cin >> x)`.
- Среднее после цикла: `double avg = static_cast<double>(sum) / count;` (хотя бы одно число гарантировано).
- Вывод среднего — `std::fixed` + `std::setprecision(2)`.
</details>

## Проверь себя (мини тест-план)

- **2.1:** `N = 0` — сумма `0`, цикл не выполняется ни разу.
- **2.2:** сразу `0` — количество `0`, сумма `0`; отрицательные числа в потоке.
- **2.3:** все числа отрицательные (`-5 -2 -9` → `-2`) — вот где ломается `best = 0`.
- **2.4:** число из одной цифры и из пяти — оба должны прижаться к правому краю.
- **2.5:** `N = 1`; проверь, что после точки ровно два знака даже у целого (`5` → `5.00`).
- **2.6:** все нули (`0 0`); только положительные; `N = 0`.
- **2.7:** одно число; отрицательное (квадрат положительный); проверь выравнивание трёхзначных.
- **2.8:** одно число (среднее равно ему); одинаковые числа; отрицательные.

✅ Тема закрыта, когда все три способа чтения (по счётчику, до стоп-значения, до конца) пишешь не задумываясь.
