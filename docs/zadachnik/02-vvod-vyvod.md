# Тема 2. Ввод и вывод

Программа почти всегда что-то читает и что-то печатает. Здесь вы научитесь делать
это надёжно: читать заранее неизвестное количество чисел, останавливаться по сигналу
или по концу ввода и выводить результат ровно так, как требуют (нужная точность,
ширина поля). Кривой ввод-вывод — причина половины «странных» багов.

> **Тот же приём в целой программе.** «Угадай число» (`../examples/04-ugaday-chislo.md`) —
> чтение ввода в цикле и реакция на каждое значение.

## Чему вы здесь научитесь

- Три способа читать поток чисел: «известно сколько», «до стоп-значения», «до конца ввода».
- Правильно заводить накопитель суммы (`long long`) и счётчик.
- Форматировать вывод: ширина поля (`setw`), точность (`setprecision`, `fixed`).
- Не начинать поиск максимума с нуля (типовая ошибка).

## Где это пригодится

Любая программа обработки данных читает поток значений неизвестной длины: строки
лога, показания датчиков, числа из файла, ответы пользователя. Умение корректно
остановиться и аккуратно вывести — базовый навык, отличающий работающую программу
от «зависла и печатает одно и то же».

## 2.1. Сумма N чисел 🟢

*Самый честный поток: сначала говорят, сколько будет чисел, потом идут сами числа. Осталось их сложить.*

Сначала дано, сколько будет чисел, затем сами числа. Напечатайте их сумму.

**Формат ввода.** Первое число `N` (0 ≤ N ≤ 1000), затем `N` целых чисел.

**Формат вывода.** Одно число — сумма всех `N` чисел.

**Пример:**
```
Ввод
4
10 20 30 40
Вывод
100
```

- **Тренирует:** цикл «фиксированное число повторений» и накопление суммы.
- **Где пригодится:** подсчёт итога по списку (сумма чека, суммарный вес, общее время).

> **Как подступиться.** Прочитайте `N`, заведите `long long sum = 0`, крутите цикл ровно `N` раз.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# обычный случай (первое число — сколько дальше чисел)
4 10 20 30 40 => 100
# края
0 => 0
1 -5 => -5
3 1000000000 1000000000 1000000000 => 3000000000
```

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Сначала читаю `N` — сколько дальше будет чисел.
2. Завожу накопитель. Беру `long long`: если чисел много, сумма может перерасти `int`.
3. Кручу цикл ровно `N` раз: читаю число и прибавляю к сумме. При `N = 0` цикл не выполнится — сумма останется `0`.

```cpp
#include <iostream>

int main() {
    int n = 0;
    std::cin >> n;
    long long sum = 0;
    for (int i = 0; i < n; ++i) {
        int x = 0;
        std::cin >> x;
        sum += x;
    }
    std::cout << sum << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 2.2. Пока не ноль 🟢

*А что, если заранее не сказано, сколько чисел? Тогда нужен сигнал «стоп» — здесь это ноль, и в сумму он не идёт.*

Читайте числа по одному, пока не встретится `0`. Ноль — это сигнал «стоп», в
подсчёте он не участвует. Напечатайте, сколько чисел было и какова их сумма.

**Формат ввода.** Последовательность целых чисел, заканчивающаяся нулём.

**Формат вывода.** Два числа через пробел: количество чисел (без нуля) и их сумма.

**Пример:**
```
Ввод
5 3 8 0
Вывод
3 16
```

- **Тренирует:** цикл с «сигнальным» (sentinel) значением — выход по `break`.
- **Где пригодится:** ввод «вводите товары, пустая строка — конец», меню «0 — выход», чтение до маркёра конца.

> **Как подступиться.** Читайте в бесконечном цикле, а на стоп-значении делайте `break` **до** того, как учтёте его.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# первый ноль сразу — ноль чисел; всё после нуля игнорируется
5 10 -3 8 0 => 4 20
0 => 0 0
7 7 0 100 => 2 14
```

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Количество чисел заранее неизвестно — читаю в бесконечном цикле.
2. На каждом числе сначала проверяю стоп-значение: если `x == 0` — `break` **до** того, как учту его.
3. Иначе увеличиваю счётчик и прибавляю к сумме. Ноль так не попадёт в подсчёт.

```cpp
#include <iostream>

int main() {
    int count = 0;
    long long sum = 0;
    while (true) {
        int x = 0;
        std::cin >> x;
        if (x == 0) break;         // стоп-значение — выходим ДО учёта
        ++count;
        sum += x;
    }
    std::cout << count << " " << sum << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 2.3. Максимум до конца ввода 🟡

*Ещё честнее — читать, пока читается. Сам факт успешного чтения и есть условие цикла. Только максимум не начинайте с нуля.*

Читайте числа, пока ввод не закончится (файл кончился или нажали `Ctrl+Z` и
`Enter`). Напечатайте наибольшее из них. Гарантируется, что хотя бы одно число будет.

**Формат ввода.** Одно или несколько целых чисел, разделённых пробелами и переводами строк, до конца ввода.

**Формат вывода.** Наибольшее число.

**Пример:**
```
Ввод
3 -1 7 4 7 2
Вывод
7
```

- **Тренирует:** чтение «пока получается» (`while (std::cin >> x)`) и корректную инициализацию максимума.
- **Где пригодится:** обработка файла или потока неизвестной длины; поиск рекорда, пика, самой поздней даты.

> **Как подступиться.** Сам факт удачного чтения — это условие цикла. Максимум нельзя начинать с `0`.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# одно число; и все отрицательные
3 1 4 1 5 => 5
-5 -2 -9 => -2
42 => 42
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Старт максимума — с первого числа, а не с нуля (иначе на одних отрицательных выйдет 0).

```c++
int x;  std::cin >> x;             // первое число — старт
int best = x;
while (std::cin >> x) if (x > best) best = x;   // читаем до конца ввода
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Читаю «пока читается»: сам факт удачного `std::cin >> x` — условие цикла.
2. Первое число читаю **до** цикла и с него начинаю `best` — начинать с `0` нельзя (все числа могут быть отрицательными).
3. В цикле обновляю максимум: `if (x > best) best = x;`.

```cpp
#include <iostream>

int main() {
    int x = 0;
    std::cin >> x;          // хотя бы одно число гарантировано
    int best = x;           // старт — с первого числа, не с нуля
    while (std::cin >> x) {
        if (x > best) best = x;
    }
    std::cout << best << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 2.4. Ровный столбик 🟡

*Ровный столбик чисел — это уже почти таблица. Весь секрет — в одном поле фиксированной ширины `setw`.*

Дано число `N`, затем `N` целых чисел. Напечатайте их **по одному в строке**,
выровняв по правому краю в поле шириной 6 символов.

**Формат ввода.** `N` (0 ≤ N ≤ 100), затем `N` целых чисел, по модулю до 99999.

**Формат вывода.** `N` строк, в каждой одно число, прижатое к правому краю поля из 6 символов.

**Пример:**
```
Ввод
3
5 -142 30000
Вывод
     5
  -142
 30000
```

- **Тренирует:** форматированный вывод фиксированной ширины (`std::setw`).
- **Где пригодится:** таблицы, отчёты, выравнивание чисел в столбик, ценники, любой человекочитаемый вывод.

> **Как подступиться.** `setw` действует только на **следующий** вывод — ставьте его перед каждым числом.

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Ширину поля задаёт `std::setw(6)` из `<iomanip>` — он прижимает число вправо.

```c++
#include <iomanip>
// на каждое из N чисел:
std::cout << std::setw(6) << x << "\n";
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Читаю `N`, затем в цикле по одному числу.
2. Каждое печатаю в поле ширины 6: `std::setw(6)` из `<iomanip>`. По умолчанию выравнивание вправо — как раз нужно.
3. `setw` действует только на **следующий** вывод, поэтому ставлю его перед каждым числом.

```cpp
#include <iostream>
#include <iomanip>

int main() {
    int n = 0;
    std::cin >> n;
    for (int i = 0; i < n; ++i) {
        int x = 0;
        std::cin >> x;
        std::cout << std::setw(6) << x << "\n";
    }
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 2.5. Среднее с двумя знаками 🟡

*Деньги любят ровно два знака после точки. Настроил `fixed` и `setprecision` один раз — и они держатся до конца.*

Дано число `N`, затем `N` дробных чисел. Напечатайте их сумму и среднее
арифметическое, каждое — ровно с двумя знаками после запятой.

**Формат ввода.** `N` (1 ≤ N ≤ 1000), затем `N` дробных чисел.

**Формат вывода.** Два числа через пробел: сумма и среднее, по два знака после точки.

**Пример:**
```
Ввод
3
1.5 2 2.5
Вывод
6.00 2.00
```

- **Тренирует:** работу с `double` в цикле и стойкую настройку точности вывода.
- **Где пригодится:** финансовые отчёты (всегда две цифры после точки), средние показатели, проценты.

> **Как подступиться.** Копите в `double`; `std::fixed` + `setprecision(2)` задаются один раз и держатся до конца.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# одно число; среднее округляется
3 1.5 2.5 4 => 8.00 2.67
1 10 => 10.00 10.00
4 1 2 3 4 => 10.00 2.50
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Сумму копи в `double`, среднее — сумма делить на N; оба с двумя знаками.

```c++
double sum = 0.0;
// в цикле по N: sum += x;   (x читаем как double)
double avg = sum / n;
// std::fixed << std::setprecision(2) << sum << ' ' << avg
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Читаю `N` дробных чисел, коплю сумму в `double`.
2. Среднее — `sum / n`; `sum` уже дробное, значит и деление дробное.
3. Настраиваю `std::fixed` + `setprecision(2)` один раз — держится до конца вывода.

```cpp
#include <iostream>
#include <iomanip>

int main() {
    int n = 0;
    std::cin >> n;
    double sum = 0.0;
    for (int i = 0; i < n; ++i) {
        double x = 0.0;
        std::cin >> x;
        sum += x;
    }
    double avg = sum / n;
    std::cout << std::fixed << std::setprecision(2) << sum << " " << avg << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 2.6. Гистограмма из звёздочек 🟡

*Первый график прямо в консоли: сколько значение — столько звёздочек. Внутренний цикл рисует столбик, внешний идёт по числам.*

Дано число `N`, затем `N` неотрицательных целых чисел. Для каждого напечатайте
строку: само число в поле шириной 3, вертикальную черту и столько звёздочек `*`,
каково значение.

**Формат ввода.** `N` (0 ≤ N ≤ 100), затем `N` целых чисел от 0 до 40.

**Формат вывода.** `N` строк вида `«число | звёздочки»`.

**Пример:**
```
Ввод
3
5 0 8
Вывод
  5 | *****
  0 | 
  8 | ********
```

- **Тренирует:** вложенный цикл (внешний — по числам, внутренний — по звёздочкам) вместе с форматированным выводом.
- **Где пригодится:** простая визуализация данных в консоли, прогресс-бары, ASCII-графики, отладочный вывод «на глаз».

> **Как подступиться.** Внешний цикл читает и печатает число с `setw(3)` и `" | "`, внутренний печатает `x` звёздочек; при нуле внутренний цикл просто не выполнится.

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Внешний цикл — по числам, внутренний рисует столбик из нужного числа звёздочек.

```c++
// на каждое число x:
std::cout << std::setw(3) << x << " | ";
for (int j = 0; j < x; ++j) std::cout << '*';    // столбик длиной x
std::cout << "\n";
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Внешний цикл идёт по числам: печатаю само число в поле ширины 3 и `" | "`.
2. Внутренний цикл печатает столько `*`, каково значение.
3. При `x == 0` внутренний цикл просто не выполнится — получится пустой столбик.

```cpp
#include <iostream>
#include <iomanip>

int main() {
    int n = 0;
    std::cin >> n;
    for (int i = 0; i < n; ++i) {
        int x = 0;
        std::cin >> x;
        std::cout << std::setw(3) << x << " | ";
        for (int j = 0; j < x; ++j)      // внутренний цикл рисует столбик
            std::cout << '*';
        std::cout << "\n";
    }
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 2.7. Второй по величине 🔴

*Золото достаётся максимуму, а нам нужно серебро — второе по величине. Значит, за один проход держим сразу два рекорда.*

Читайте числа до конца ввода. Напечатайте **второе по величине** значение —
то, что идёт сразу за максимумом. Гарантируется, что различных чисел хотя бы два.

**Формат ввода.** Целые числа до конца ввода.

**Формат вывода.** Второе по величине число.

**Пример:**
```
Ввод
3 9 9 5 9 7
Вывод
7
```

- **Тренирует:** отслеживание **двух** «рекордов» за один проход и аккуратную обработку повторов.
- **Где пригодится:** «серебряный призёр», вторая по цене позиция, антипик — везде, где важен не только максимум.

> **Как подступиться.** Держите две переменные — `best` и `second`. При новом числе больше `best` старый `best` становится `second`. Повтор максимума (`x == best`) не должен опускаться в `second`. Начальные значения удобно взять из первых прочитанных чисел, а не из нуля.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# дубликаты максимума; ровно два числа
3 9 5 => 5
5 3 9 9 1 => 5
2 7 => 2
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Держи два максимума. Условие `x < best` не даёт повтору максимума опуститься во второй.

```c++
#include <limits>
int best = std::numeric_limits<int>::min(), second = best, x;
while (std::cin >> x) {
    if (x > best) { second = best; best = x; }
    else if (x < best && x > second) second = x;
}
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Держу два «рекорда»: `best` (максимум) и `second` (второй), оба стартуют с минимально возможного `int`.
2. Новое число больше `best` — старый `best` спускается в `second`, а `best` обновляется.
3. Иначе, если оно строго меньше `best`, но больше `second` — это новый `second`. Условие `x < best` не даёт повтору максимума занять второе место.

```cpp
#include <iostream>
#include <limits>

int main() {
    int best = std::numeric_limits<int>::min();
    int second = std::numeric_limits<int>::min();
    int x = 0;
    while (std::cin >> x) {
        if (x > best) {
            second = best;         // старый максимум становится вторым
            best = x;
        } else if (x < best && x > second) {
            second = x;            // x < best отсекает повтор максимума
        }
    }
    std::cout << second << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 2.8. Мин, макс и среднее за проход 🔴

*Минимум, максимум и среднее — за один проход и не храня весь массив. Ровно так считают метрики в реальных программах.*

Читайте числа до конца ввода (хотя бы одно число будет). За **один** проход
посчитайте и напечатайте минимум, максимум и среднее (с двумя знаками).

**Формат ввода.** Целые числа до конца ввода.

**Формат вывода.** Три величины через пробел: минимум, максимум и среднее.

**Пример:**
```
Ввод
2 9 4 9 1
Вывод
1 9 5.00
```

- **Тренирует:** одновременное ведение нескольких накопителей и защиту от неверной инициализации.
- **Где пригодится:** сводка по данным (мониторинг, метрики, показания за сутки) без второго прохода и без хранения всего массива.

> **Как подступиться.** Ведите `count`, `sum` (в `long long`), `mn` и `mx`. Первое число задаёт стартовые `mn` и `mx` — не берите их с нуля. Среднее считайте после цикла: `static_cast<double>(sum) / count`.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# одно число; отрицательные
4 1 7 2 6 => 1 7 4.00
1 5 => 1 5 3.00
3 -3 -1 -2 => -3 3 -0.75
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Инициализируй min/max/сумму первым числом, дальше обновляй за один проход.

```c++
int x;  std::cin >> x;
int mn = x, mx = x;  long long sum = x;  int count = 1;
while (std::cin >> x) { if (x < mn) mn = x; if (x > mx) mx = x; sum += x; ++count; }
double avg = static_cast<double>(sum) / count;
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Первое число читаю до цикла и задаю им `mn`, `mx`, `sum`, `count` — старт не с нуля.
2. Дальше за один проход обновляю минимум, максимум и накапливаю сумму (в `long long`) и счётчик.
3. Среднее считаю после цикла: `static_cast<double>(sum) / count`, печатаю с двумя знаками.

```cpp
#include <iostream>
#include <iomanip>

int main() {
    int x = 0;
    std::cin >> x;              // первое число задаёт старт
    int mn = x, mx = x;
    long long sum = x;
    int count = 1;

    while (std::cin >> x) {
        if (x < mn) mn = x;
        if (x > mx) mx = x;
        sum += x;
        ++count;
    }

    double avg = static_cast<double>(sum) / count;
    std::cout << mn << " " << mx << " "
              << std::fixed << std::setprecision(2) << avg << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

# Подсказки

> **Мало подсказки?** Откройте теорию темы: [раздел справочника](../ref/02-vvod-vyvod.md).

<details>
<summary>2.1 — Сумма N чисел</summary>

- Прочитайте `N`, заведите `long long sum = 0;`, крутите цикл `for (int i = 0; i < N; ++i)`.
- Внутри: `int x; std::cin >> x; sum += x;`.
</details>

<details>
<summary>2.2 — Пока не ноль</summary>

- Цикл с «сигнальным» значением: `while (true) { std::cin >> x; if (x == 0) break; ... }`.
- Внутри, до `break`, увеличивайте счётчик и сумму — тогда сам ноль не попадёт в подсчёт.
</details>

<details>
<summary>2.3 — Максимум до конца ввода</summary>

- Сам поток в условии значит «удалось прочитать?»: `while (std::cin >> x) { ... }`.
- Прочитайте **первое** число до цикла (или заведите флаг «чисел ещё не было»), чтобы было с чем сравнивать. Обновляйте: `if (x > best) best = x;`.
- Не начинайте `best` с `0` — если все числа отрицательные, ответ будет неверным.
</details>

<details>
<summary>2.4 — Ровный столбик</summary>

- Ширина поля: `#include <iomanip>`, затем `std::cout << std::setw(6) << x << "\n";`.
- `setw` действует только на **следующий** вывод, поэтому пишите его перед каждым числом.
- По умолчанию выравнивание идёт вправо — как раз то, что нужно.
</details>

<details>
<summary>2.5 — Среднее с двумя знаками</summary>

- Читайте числа в `double`, копите в `double sum`.
- Среднее: `sum / N`. Приводить к `double` не нужно — `sum` уже дробное.
- Два знака: `std::cout << std::fixed << std::setprecision(2) << sum << " " << avg;` или `std::format("{:.2f} {:.2f}", sum, avg)`.
</details>

<details>
<summary>2.6 — Гистограмма из звёздочек</summary>

- Внешний цикл: прочитали `x`, напечатали `std::setw(3) << x << " | "`.
- Внутренний цикл печатает звёздочки: `for (int j = 0; j < x; ++j) std::cout << '*';`, затем перевод строки.
- При `x == 0` внутренний цикл не выполнится — получится пустой «столбик».
</details>

<details>
<summary>2.7 — Второй по величине</summary>

- Две переменные: `best` (максимум) и `second` (второй). Инициализируйте их первыми двумя числами (большее — в `best`).
- Для каждого следующего `x`: если `x > best` — `second = best; best = x;`; иначе если `x < best && x > second` — `second = x;`.
- Условие `x < best` защищает от повторов максимума: `9` во второй раз не должно стать «вторым».
</details>

<details>
<summary>2.8 — Мин, макс и среднее за проход</summary>

- Заведите `int count = 0; long long sum = 0; int mn, mx;`.
- Первое прочитанное число задаёт `mn` и `mx`; дальше обновляйте `if (x < mn) mn = x;` и `if (x > mx) mx = x;`.
- Среднее после цикла: `double avg = static_cast<double>(sum) / count;`, вывод — `std::fixed` + `setprecision(2)`.
</details>

## Проверьте себя (мини тест-план)

- **2.1:** `N = 0` — сумма `0`, цикл не выполняется ни разу.
- **2.2:** сразу `0` — количество `0`, сумма `0`; отрицательные числа в потоке.
- **2.3:** все числа отрицательные (`-5 -2 -9` → `-2`) — вот где ломается `best = 0`.
- **2.6:** значение `0` (пустой столбик); одно большое значение (`40` звёздочек); `N = 0`.
- **2.7:** максимум повторяется (`9 9 5` → `5`, а не `9`); ровно два разных числа; отрицательные.
- **2.8:** одно число (мин = макс = среднее); одинаковые числа; отрицательные (тест на инициализацию `mn`/`mx`).

**Тема закрыта,** когда все три способа чтения (по счётчику, до стоп-значения, до конца) вы пишете не задумываясь.
