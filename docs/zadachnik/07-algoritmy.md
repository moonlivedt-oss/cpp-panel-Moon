## Чему вы здесь научитесь

- Сортировать `vector` по возрастанию и по своему правилу (лямбда-компаратор).
- Считать элементы по условию (`count_if`) и суммировать (`accumulate`).
- Захватывать переменные в лямбду (`[avg]`).
- Сортировать вектор структур по нескольким полям сразу.

## Где это пригодится

Сортировка и фильтрация — хлеб любой обработки данных: топ-N результатов, поиск
подходящих записей, ранжирование. Лямбды и алгоритмы делают код короче и надёжнее
ручных циклов (меньше места для ошибки на единицу). Правило «сортировать по нескольким
критериям» встречается в любой таблице с сортировкой по колонкам.

## 7.1. Отсортировать по возрастанию 🟢

*Один вызов `sort` — и дальше открыты медиана, бинарный поиск, дедупликация. Сортировка почти всегда идёт первой.*

Дано `N` чисел. Напечатайте их по возрастанию в одну строку через пробел.

**Формат ввода.** `N` (0 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Числа по возрастанию через пробел.

**Пример:**
```
Ввод
5
3 1 4 1 5
Вывод
1 1 3 4 5
```

- **Тренирует:** базовый вызов `std::sort` над `vector`.
- **Где пригодится:** любой упорядоченный вывод; сортировка — предподготовка для медианы, бинарного поиска, дедупликации.

> **Как подступиться.** `std::sort(v.begin(), v.end());` — и печатайте.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests

5 3 1 4 1 5 => 1 1 3 4 5
3 -5 -1 -3 => -5 -3 -1
# края
1 42 => 42
4 9 9 9 9 => 9 9 9 9
```

```hints
Идея: Сортировать вручную не нужно — в стандартной библиотеке есть готовый алгоритм, которому достаточно указать диапазон.
План: Прочитайте числа в вектор, отсортируйте весь вектор и напечатайте через пробел.
Ключ: `std::sort(v.begin(), v.end());`
```

## 7.2. По убыванию 🟡

*Хотите порядок наоборот? Подскажите `sort`, кто раньше, лямбдой `a > b` — и получите любой свой порядок.*

То же, что и предыдущая, но по **убыванию**. Используйте `std::sort` с собственным
правилом сравнения (лямбдой).

**Формат ввода.** `N` (0 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Числа по убыванию через пробел.

**Пример:**
```
Ввод
5
3 1 4 1 5
Вывод
5 4 3 1 1
```

- **Тренирует:** лямбда-компаратор — своё правило «кто раньше».
- **Где пригодится:** «сначала самые дорогие/новые/крупные»; любое нестандартное упорядочивание.

> **Как подступиться.** Передайте третьим аргументом `[](int a, int b){ return a > b; }`.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# один элемент; повторы
5 3 1 4 1 5 => 5 4 3 1 1
1 42 => 42
4 2 2 1 3 => 3 2 2 1
```

```hints
Идея: `sort` можно подсказать, кто должен стоять раньше: вы передаёте ему своё правило сравнения.
План: Тот же код, что в 7.1, но третьим аргументом `sort` передайте лямбду, которая говорит «a раньше b, если a больше».
Ключ: `std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; });`
```

## 7.3. Сколько больше среднего 🔴

*Сначала узнаём среднее по всем, потом считаем, кто выше. Среднее лямбда «прихватывает» с собой в `[avg]`.*

Дано `N` чисел. Напечатайте, сколько из них **строго больше** среднего
арифметического всей последовательности.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Количество чисел, больших среднего.

**Пример:**
```
Ввод
5
1 2 3 4 100
Вывод
1
```

- **Тренирует:** два прохода (сначала среднее, потом счёт), `accumulate` + `count_if` с захватом.
- **Где пригодится:** статистика «выше среднего»: успеваемость, зарплаты, аномалии в данных.

> **Как подступиться.** Сначала посчитайте среднее по всем; потом посчитайте, сколько строго больше него. Среднее захватите в лямбду.

> **Разбор примера.** Среднее здесь `22`, больше него только `100`.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# если все равны — никто не больше среднего
5 1 2 3 4 5 => 2
3 10 10 10 => 0
4 1 2 3 100 => 1
```

```hints
Идея: Сначала нужно знать среднее по всем, и только вторым проходом — считать тех, кто выше. Среднее — дробное.
План: Сумму копите в `long long`, среднее получите делением в `double`; затем посчитайте элементы строго больше среднего — лямбде понадобится захватить `avg`.
Ключ: `std::count_if(v.begin(), v.end(), [avg](int x) { return x > avg; })`
```

> Не выходит и с подсказками? Решение с разбором — [внизу страницы](#решения-с-разбором). Открывай его, только когда правда застрял.

## 7.4. Медиана 🟡

*Один выброс — и среднее врёт, а медиана держится. После сортировки она просто стоит в центре.*

Дано `N` чисел (`N` нечётное). Медиана — это число, оказавшееся ровно посередине,
если все числа отсортировать. Напечатайте медиану.

**Формат ввода.** Нечётное `N` (1 ≤ N ≤ 99999), затем `N` целых чисел.

**Формат вывода.** Медиана.

**Пример:**
```
Ввод
5
7 1 3 9 5
Вывод
5
```

- **Тренирует:** сортировку как подготовительный шаг и обращение по центральному индексу.
- **Где пригодится:** медиана устойчивее среднего к выбросам — её используют в статистике зарплат, времени отклика, цен.

> **Как подступиться.** Отсортируйте, возьмите элемент с индексом `N / 2` (для нечётного `N` это ровно середина).

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests

```

```hints
Идея: В отсортированном наборе медиана стоит ровно посередине.
План: Отсортируйте вектор и возьмите элемент с индексом `N / 2` — для нечётного `N` это центр.
```

## 7.5. Топ-3 по баллам 🔴

*Настоящий рейтинг сортируют по двум ключам сразу: по баллам, а при равенстве — по имени.*

Даны `N` участников: имя и баллы. Напечатайте имена трёх лучших по баллам. При
равенстве баллов выше тот, чьё имя меньше по алфавиту. Если участников меньше трёх —
напечатайте всех.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` пар: имя (латиница) и целое число баллов.

**Формат вывода.** До трёх строк — имена лучших, по одному в строке, в порядке убывания баллов.

**Пример:**
```
Ввод
4
anna 40
boris 55
vera 55
igor 20
Вывод
boris
vera
anna
```

- **Тренирует:** сортировку вектора структур по двум критериям сразу.
- **Где пригодится:** лидерборды, топ-N результатов поиска, рейтинги с тай-брейком.

> **Как подступиться.** Заведите `struct`, отсортируйте правилом «по баллам убыв., при равенстве по имени возр.», выведите первые три.

> **Разбор примера.** `boris` и `vera` по 55; `boris` меньше по алфавиту, поэтому он первый.

```hints
Идея: Сортировка по двум ключам: главный — баллы по убыванию, при равенстве — имя по алфавиту. И участников может быть меньше трёх.
План: Сложите участников в `vector` структур, отсортируйте с правилом из двух ступеней, выведите первые `min(3, N)` имён.
Ключ: `return a.score != b.score ? a.score > b.score : a.name < b.name;`
```

## 7.6. Минимум и максимум одной строкой 🟢

*`min_element`/`max_element` найдут крайние значения без ручного цикла — только не забудьте `*`, иначе получите итератор.*

Дано `N` чисел. Напечатайте минимум и максимум, используя `std::min_element` и
`std::max_element`.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Два числа через пробел: минимум и максимум.

**Пример:**
```
Ввод
5
3 1 4 1 5
Вывод
1 5
```

- **Тренирует:** готовые алгоритмы поиска и разыменование итератора (`*`).
- **Где пригодится:** границы диапазона, экстремумы — без ручного цикла.

> **Как подступиться.** `min_element` возвращает **итератор** (указатель на элемент); значение достаётся звёздочкой `*`.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# один элемент; отрицательные
5 3 1 4 1 5 => 1 5
1 42 => 42 42
4 -5 0 5 2 => -5 5
```

```hints
Идея: Ручной цикл не нужен — есть алгоритмы, которые возвращают **место** наименьшего и наибольшего элемента. Значение достаётся звёздочкой.
План: Прочитайте вектор, вызовите поиск минимума и максимума на всём диапазоне и разыменуйте результаты.
Ключ: `int mn = *std::min_element(v.begin(), v.end());`
```

## 7.8. Слова по длине 🔴

*Сортируем не по самому значению, а по вычисленному ключу: сперва длина слова, а при равной длине — алфавит.*

Дано `N` слов. Напечатайте их отсортированными: сначала короткие, при равной длине —
по алфавиту. По одному слову в строке.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` слов (латиница).

**Формат вывода.** `N` строк — слова в нужном порядке.

**Пример:**
```
Ввод
4
banana kiwi fig apple
Вывод
fig
kiwi
apple
banana
```

- **Тренирует:** сортировку по вычисляемому ключу (длина) с тай-брейком по алфавиту.
- **Где пригодится:** ранжирование по нескольким критериям, «сначала короткие/дешёвые/новые».

> **Как подступиться.** Компаратор: если длины разные — сравниваем длины, иначе сравниваем сами строки.

```hints
Идея: Сортируем не по самому слову, а по «ключу»: сначала длина, при равной длине — алфавит.
План: Прочитайте слова в вектор; компаратор: если длины разные — сравнить длины, иначе сравнить строки; напечатайте по слову в строке.
Ключ: `if (a.size() != b.size()) return a.size() < b.size(); return a < b;`
```

## 7.9. Таблица лидеров 🔗🟡

*Четвёртое звено «Журнала забегов»: из сводки по игрокам строим рейтинг — сортировка по двум ключам и подсчёт по условию.*

Даны `N` забегов `имя золото` (как в 6.9). Посчитайте общее золото каждого игрока и напечатайте
топ-3: `место. имя всего` — по убыванию золота, при равенстве по алфавиту. Последней строкой
напечатайте `выше среднего: K` — сколько игроков набрали **строго больше** среднего по игрокам.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` пар: имя и целое число.

**Формат вывода.** До трёх строк рейтинга и строка про среднее.

**Пример:**
```
Ввод
5
Ari 50 Bo 30 Ari 20 Bo 90 Cy 70
Вывод
1. Bo 120
2. Ari 70
3. Cy 70
выше среднего: 1
```

- **Тренирует:** `map` → `vector` → `sort` с двумя ключами, `count_if` с захватом (темы 6 и 7 вместе).
- **Где пригодится:** лидерборды, рейтинги продавцов, «топ-N и сколько выше нормы».

> **Как подступиться.** Итоги по игрокам соберите в `map` (как в 6.9), перенесите в вектор пар, отсортируйте своим правилом, потом посчитайте тех, кто выше среднего.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
5\nAri 50 Bo 30 Ari 20 Bo 90 Cy 70 => 1. Bo 120\n2. Ari 70\n3. Cy 70\nвыше среднего: 1
1\nSolo 10 => 1. Solo 10\nвыше среднего: 0
4\nA 5 B 5 C 5 D 5 => 1. A 5\n2. B 5\n3. C 5\nвыше среднего: 0
3\nzed 1 amy 100 bob 50 => 1. amy 100\n2. bob 50\n3. zed 1\nвыше среднего: 1
```

```hints
Идея: Рейтинг строится в два этапа: сначала «сколько у каждого всего», потом «в каком порядке их показать». Сортировать `map` нельзя — сортируют вектор.
План: Соберите итоги в `map<string, long long>`, перенесите в `vector<pair<string, long long>>`, отсортируйте: золото по убыванию, имя по возрастанию. Среднее — сумма итогов, делённая на число игроков; дальше `count_if`.
Ключ: `return a.second != b.second ? a.second > b.second : a.first < b.first;`
```

## 7.10. Пары с суммой K 🔥

*Челлендж темы: перебор всех пар — это N² шагов, для 100 000 чисел — 10¹⁰. Нужен приём быстрее.*

Дано `N` чисел и число `K`. Сколько существует пар позиций `i < j`, для которых
`a[i] + a[j] == K`?

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` целых чисел (по модулю до 10^9), затем `K`.

**Формат вывода.** Количество пар (может быть большим — до ~5·10^9).

**Пример:**
```
Ввод
5
1 5 7 -1 5
6
Вывод
3
```

- **Тренирует:** замену перебора пар на подсчёт «сколько уже встречалось нужных партнёров»; выбор типа для большого ответа.
- **Где пригодится:** поиск совпадений в логах и транзакциях, «две суммы» — одна из самых частых задач на собеседованиях.

> **Как подступиться.** Идите по числам слева направо: для текущего `x` его партнёр — `K − x`. Если помнить, сколько раз каждое число уже встречалось, пары считаются за один проход.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
5\n1 5 7 -1 5\n6 => 3
4\n1 1 1 1\n2 => 6
3\n1 2 3\n10 => 0
6\n3 3 3 3 3 3\n6 => 15
4\n1000000000 -1000000000 0 0\n0 => 2
```

```hints
Идея: Для каждого числа `x` пара — это число `K − x`. Если знать, сколько таких чисел было **раньше**, не нужно перебирать пары.
План: Заведите `map<long long, long long>` «число → сколько раз встретилось». Для очередного `x` прибавьте к ответу `seen[K − x]`, затем учтите сам `x`. Ответ и суммы — в `long long`.
Ключ: `answer += seen[k - x]; ++seen[x];`
```

<summary>Полное решение 7.3 — Больше среднего</summary>

Ход мысли по шагам:

1. Сумму беру `std::accumulate(..., 0LL)` — `0LL` копит в `long long`.
2. Среднее дробное: `static_cast<double>(sum) / v.size()`.
3. Считаю подходящие через `count_if`, захватив среднее в лямбду `[avg]`; условие — строго `x > avg`.

```cpp
#include <iostream>
#include <vector>
#include <numeric>
#include <algorithm>

int main() {
    int n = 0;
    std::cin >> n;
    std::vector<int> v;
    for (int i = 0; i < n; ++i) {
        int x = 0;
        std::cin >> x;
        v.push_back(x);
    }

    long long sum = std::accumulate(v.begin(), v.end(), 0LL);   // 0LL — копим в long long
    double avg = static_cast<double>(sum) / static_cast<double>(v.size());

    auto count = std::count_if(v.begin(), v.end(),
                               [avg](int x) { return x > avg; });   // avg захвачено
    std::cout << count << "\n";
    return 0;
}
```


**Другой подход — без дробей: сравнение `x · n > sum`**

```cpp
#include <iostream>
#include <vector>

int main() {
    int n = 0;
    std::cin >> n;
    std::vector<long long> v(n);
    long long sum = 0;
    for (auto &x : v) { std::cin >> x; sum += x; }
    int count = 0;
    for (long long x : v)
        if (x * n > sum) ++count;            // x > sum/n  ⇔  x·n > sum (n > 0)
    std::cout << count << "\n";
    return 0;
}
```

> **Сравнение.** Вместо `x > sum / n` в дробях — равносильное `x · n > sum` в целых. Так не бывает сюрпризов округления `double` (например, когда все числа равны среднему). Вариант с `accumulate`/`count_if` выразительнее; целочисленный — надёжнее, когда важна точность равенства.
</details>

<summary>Полное решение 7.5 — Топ-3</summary>

Ход мысли по шагам:

1. Завожу `struct Participant { name; score; }` и читаю всех в `vector`.
2. Сортирую своим правилом: по баллам убыв., при равенстве — по имени возр.
3. Печатаю первые `min(3, размер)` имён.

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

struct Participant {
    std::string name;
    int score = 0;
};

int main() {
    int n = 0;
    std::cin >> n;
    std::vector<Participant> people;
    for (int i = 0; i < n; ++i) {
        Participant p;
        std::cin >> p.name >> p.score;
        people.push_back(p);
    }

    std::sort(people.begin(), people.end(), [](const Participant &a, const Participant &b) {
        return a.score != b.score ? a.score > b.score : a.name < b.name;   // балл убыв., имя возр.
    });

    std::size_t top = std::min<std::size_t>(3, people.size());
    for (std::size_t i = 0; i < top; ++i)
        std::cout << people[i].name << "\n";
    return 0;
}
```


**Другой подход — `std::partial_sort` — сортируем только топ**

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

struct Participant {
    std::string name;
    int score = 0;
};

int main() {
    int n = 0;
    std::cin >> n;
    std::vector<Participant> people(n);
    for (auto &p : people) std::cin >> p.name >> p.score;
    auto top = std::min<std::size_t>(3, people.size());
    std::partial_sort(people.begin(), people.begin() + top, people.end(),
                      [](const Participant &a, const Participant &b) {
                          return a.score != b.score ? a.score > b.score : a.name < b.name;
                      });
    for (std::size_t i = 0; i < top; ++i) std::cout << people[i].name << "\n";
    return 0;
}
```

> **Сравнение.** `partial_sort` упорядочивает только первые `k` мест — для топ-3 из 100 000 это заметно быстрее полной сортировки. Полная `sort` проще и нужна, если дальше печатается вся таблица.

<summary>Полное решение 7.8 — Слова по длине</summary>

Ход мысли по шагам:

1. Читаю слова в `vector<string>`.
2. Сортирую по вычисляемому ключу: если длины разные — по длине, иначе по алфавиту.
3. Печатаю по слову в строке.

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

int main() {
    int n = 0;

    });

    for (const std::string &w : words)
        std::cout << w << "\n";

```


**Другой подход — ключ-пара `(длина, слово)`**

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <utility>
#include <vector>

int main() {
    int n = 0;
    std::cin >> n;
    std::vector<std::string> words(n);

    std::sort(words.begin(), words.end(), [](const std::string &a, const std::string &b) {
```

<summary>Полное решение 7.9 — Таблица лидеров</summary>

`map` удобен для подсчёта, вектор — для сортировки по своему правилу. Среднее сравниваем без дробей: `total · players > sum` — то же, что `total > sum / players`, но без сюрпризов округления (см. «другой подход» к 7.3).

```cpp
#include <algorithm>
#include <iostream>
#include <map>
#include <string>
#include <utility>
#include <vector>

int main() {
    int n = 0;
    std::cin >> n;
    std::map<std::string, long long> total;
    for (int i = 0; i < n; ++i) {
        std::string name;
        long long gold = 0;
        std::cin >> name >> gold;
        total[name] += gold;
    }
    std::vector<std::pair<std::string, long long>> table(total.begin(), total.end());
    std::sort(table.begin(), table.end(), [](const auto &a, const auto &b) {
        return a.second != b.second ? a.second > b.second : a.first < b.first;
    });
    for (std::size_t i = 0; i < table.size() && i < 3; ++i)
        std::cout << i + 1 << ". " << table[i].first << " " << table[i].second << "\n";

    long long sum = 0;
    for (const auto &row : table) sum += row.second;
    long long players = static_cast<long long>(table.size());
    auto above = std::count_if(table.begin(), table.end(),
                               [sum, players](const auto &row) { return row.second * players > sum; });
    std::cout << "выше среднего: " << above << "\n";
    return 0;
}
```

**Другой подход — `partial_sort` и среднее в `double`**

```cpp
#include <algorithm>
#include <iostream>
#include <map>
#include <string>
#include <vector>

struct Row {
    std::string name;
    long long gold = 0;
};

int main() {
    int n = 0;
    std::cin >> n;
    std::map<std::string, long long> total;
    for (int i = 0; i < n; ++i) {
        std::string name;
        long long gold = 0;
        std::cin >> name >> gold;
        total[name] += gold;
    }
    std::vector<Row> rows;
    double sum = 0;
    for (const auto &[name, g] : total) { rows.push_back({name, g}); sum += static_cast<double>(g); }
    double avg = sum / static_cast<double>(rows.size());
    std::size_t top = std::min<std::size_t>(3, rows.size());
    std::partial_sort(rows.begin(), rows.begin() + top, rows.end(), [](const Row &a, const Row &b) {
        return a.gold != b.gold ? a.gold > b.gold : a.name < b.name;
    });
    for (std::size_t i = 0; i < top; ++i) std::cout << i + 1 << ". " << rows[i].name << " " << rows[i].gold << "\n";
    std::cout << "выше среднего: "
              << std::count_if(rows.begin(), rows.end(), [avg](const Row &r) { return static_cast<double>(r.gold) > avg; }) << "\n";
    return 0;
}
```

> **Сравнение.** `partial_sort` упорядочивает только топ-3 — быстрее на тысячах игроков. Среднее в `double` читается проще, но при равных итогах (все по 5) дробь может «чуть-чуть» разойтись; целочисленное сравнение этого риска не имеет.

<summary>Полное решение 7.10 — Пары с суммой K</summary>

Каждую пару считаем в момент, когда встречаем её правый элемент: партнёры левее уже лежат в словаре. Один проход и поиск в `map` — O(N log N) вместо N² пар. Ответ до ~5·10⁹ в `int` не влезает — `long long`.

```cpp
#include <iostream>
#include <map>
#include <vector>

int main() {
    int n = 0;
    std::cin >> n;
    std::vector<long long> a(n);
    for (auto &x : a) std::cin >> x;
    long long k = 0;
    std::cin >> k;

    std::map<long long, long long> seen;     // число → сколько раз встречалось левее
    long long answer = 0;
    for (long long x : a) {
        auto it = seen.find(k - x);
        if (it != seen.end()) answer += it->second;   // все партнёры слева
        ++seen[x];
    }
    std::cout << answer << "\n";
    return 0;
}
```

**Другой подход — сортировка и два указателя**

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    int n = 0;
    std::cin >> n;
    std::vector<long long> a(n);
    for (auto &x : a) std::cin >> x;
    long long k = 0;
    std::cin >> k;
    std::sort(a.begin(), a.end());
    long long answer = 0;
    std::size_t l = 0, r = a.size();
    while (r > 0 && l < r - 1) {
        long long s = a[l] + a[r - 1];
        if (s < k) ++l;
        else if (s > k) --r;
        else if (a[l] == a[r - 1]) {           // все числа между l и r одинаковые
            long long m = static_cast<long long>(r - l);
            answer += m * (m - 1) / 2;
            break;
        } else {                               // считаем блоки одинаковых с краёв
            long long cl = 0, cr = 0;
            long long vl = a[l], vr = a[r - 1];
            while (l < r && a[l] == vl) { ++l; ++cl; }
            while (r > l && a[r - 1] == vr) { --r; ++cr; }
            answer += cl * cr;
        }
    }
    std::cout << answer << "\n";
    return 0;
}
```

> **Сравнение.** Два указателя по отсортированному массиву не требуют словаря, но повторяющиеся числа приходится считать блоками — это самое хитрое место. Словарь «сколько встречалось» короче и почти не оставляет места для ошибки.

## Проверьте себя (мини тест-план)

- **7.1 / 7.2:** `N = 0` — пустой вывод; уже отсортированный массив; все одинаковые.
- **7.3:** все числа равны (никто не «больше среднего» → `0`); отрицательные числа.
- **7.4:** `N = 1` (медиана — само число); проверьте, что индекс именно `N / 2`.
- **7.5:** участников меньше трёх (вывести всех); тай-брейк по имени (равные баллы).
- **7.6:** `N = 1` (минимум равен максимуму); все одинаковые; отрицательные.
- **7.7:** ни одного чётного (`0`); все чётные; помните, что `0` — чётное.
- **7.8:** слова одинаковой длины (идут по алфавиту); уже отсортированный ввод.
