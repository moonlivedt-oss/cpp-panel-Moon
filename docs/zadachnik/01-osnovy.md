# Тема 1. Основы: типы, переменные, `const`

Это самый первый и самый важный кирпич. Почти все ошибки новичка растут отсюда:
«число вдруг стало отрицательным», «дробь округлилась в ноль», «ввёл цифру, а
получил другую». Разобравшись с типами один раз, ты перестанешь ловить эти баги
случайно и начнёшь предвидеть их заранее.

> 📖 **Опирается на разделы 1–3 справочника** ([теория в справочнике](../ref/01-osnovy.md)).
> Прочитай его до задач — там разобраны ровно те ловушки, на которых эти задачи и построены.

## Чему ты здесь научишься

- Выбирать правильный тип: `int`, `long long`, `double`, `char`, `std::string` — и понимать, **почему** именно его.
- Видеть три классические ловушки заранее: целочисленное деление, переполнение `int`, `char` как код символа.
- Управлять точностью вывода дробных чисел (`std::fixed`, `setprecision`).
- Давать числам имена через `const` — чтобы код объяснял себя сам.

## Где это пригодится

Это не абстракция — это фундамент любой программы, которая что-то считает:
подсчёт среднего балла, суммы в чеке, процентов, координат, времени. Ошибка в
выборе типа — самый частый «молчаливый» баг в реальном коде: программа не падает,
а просто выдаёт неверное число, и ты об этом узнаёшь последним.

## Как работать с темой

## 1.1. Средний рост 🟢

Даны три целых числа — рост трёх человек в сантиметрах. Напечатайте их
средний рост с одним знаком после запятой.

**Формат ввода.** Три целых числа от 50 до 250, через пробел.

**Формат вывода.** Одно число — средний рост, ровно с одной цифрой после точки.

**Пример:**
```
Ввод
180 175 178
Вывод
177.7
```

**Что тренирует:** целочисленное деление против дробного, форматированный вывод.
**Где пригодится:** любое усреднение — оценки, цены, показания датчиков, время отклика.
**Как подступиться:** сумма трёх `int` — тоже `int`. Чтобы среднее получилось дробным,
хотя бы один участник деления должен быть дробным.

> Осторожно: если делить три `int` на `3`, получится целое (потеряешь дробную часть).

## 1.2. Сосед по алфавиту 🟢

Дан один латинский символ и целое число `n`. Напечатайте символ, который стоит
на `n` позиций дальше в таблице символов.

**Формат ввода.** Символ (латинская буква) и целое число `n` (0 ≤ n ≤ 25), через пробел.

**Формат вывода.** Один символ.

**Пример 1:**
```
Ввод
a 3
Вывод
d
```
**Пример 2:**
```
Ввод
A 0
Вывод
A
```

**Что тренирует:** понимание, что `char` — это число (код символа), которое можно складывать.
**Где пригодится:** шифр Цезаря, генерация серийных номеров, перебор букв (A, B, C…), работа с таблицей символов.
**Как подступиться:** прибавь `n` к символу и напечатай результат **как символ**, а не как число.
**⭐ Бонус:** сделай мини-шифр Цезаря — сдвинь на `n` не один символ, а целую строку (`getline`), пробелы оставь на месте.

## 1.3. Рубли и копейки 🟢

Дана сумма в копейках — одно целое число. Напечатайте её в виде «рублей и копеек».

**Формат ввода.** Одно неотрицательное целое число — количество копеек (до 10^9).

**Формат вывода.** Строка вида `X руб. Y коп.`, где `Y` — от 0 до 99.

**Пример:**
```
Ввод
1099
Вывод
10 руб. 99 коп.
```

**Что тренирует:** пара «целочисленное деление `/` и остаток `%`» — разбиение величины на единицы.
**Где пригодится:** деньги (рубли/копейки), время (секунды → чч:мм:сс), любые единицы измерения (граммы → кг и г), верстка «X товаров на Y страниц».
**Как подступиться:** рубли — это `/ 100`, копейки — `% 100`. Эта пара `/` и `%` будет встречаться постоянно.

## 1.4. Длина окружности и площадь круга 🟢

Дан радиус круга. Напечатайте длину окружности и площадь круга, каждую —
с двумя знаками после запятой. Число π задайте как константу.

**Формат ввода.** Одно число (может быть дробным) — радиус, больше 0.

**Формат вывода.** Два числа через пробел: длина окружности и площадь, по два знака после точки.

**Пример:**
```
Ввод
2
Вывод
12.57 12.57
```

**Что тренирует:** `double`, именованные константы (`const`), точность вывода.
**Где пригодится:** любые формулы из физики, геометрии, финансов, где есть постоянный коэффициент (π, курс валют, ставка налога).
**Как подступиться:** радиус читай в `double`; π заведи как `const double PI = 3.14159265358979;` — чтобы «магическое число» получило имя.
**⭐ Бонус:** добавь объём шара `4/3 · π · r³` — и проследи, чтобы коэффициент был `4.0 / 3.0`, а не `4 / 3`.

> Совпадение двух чисел в примере — не случайность, проверь на радиусе `1` и `3`,
> числа станут разными.

## 1.5. Найди ошибку: сумма от 1 до n 🟡

Эта программа должна складывать все числа от 1 до `n`. Для маленьких `n` она
работает, а для `n` порядка 100000 выдаёт бессмыслицу (иногда отрицательную).
Найдите причину и исправьте.

```cpp
#include <iostream>

int main() {
  int n;
  std::cin >> n;
  int sum = 0;
  for (int i = 1; i <= n; ++i) {
    sum += i;
  }
  std::cout << sum << "\n";
}
```

**Формат ввода.** Одно целое число `n` (1 ≤ n ≤ 1 000 000).

**Формат вывода.** Сумма всех чисел от 1 до `n`.

**Пример:**
```
Ввод
100000
Вывод
5000050000
```

**Что тренирует:** распознавание переполнения `int` — самый коварный «молчаливый» баг.
**Где пригодится:** везде, где копится сумма или произведение больших чисел: счётчики, статистика, факториалы, суммы по большому массиву.
**Как подступиться:** программа логически верна. Значит, дело в **типе** накопителя — прикинь, какого размера будет ответ.

## 1.6. Из Цельсия в Фаренгейт 🟢

Дана температура в градусах Цельсия. Напечатайте её в градусах Фаренгейта
с одним знаком после запятой. Формула: `F = C × 9/5 + 32`.

**Формат ввода.** Одно число (может быть дробным) — температура в Цельсиях.

**Формат вывода.** Одно число — температура в Фаренгейтах, один знак после точки.

**Пример 1:**
```
Ввод
100
Вывод
212.0
```
**Пример 2:**
```
Ввод
0
Вывод
32.0
```

**Что тренирует:** `double` и главная ловушка целочисленного деления в формуле.
**Где пригодится:** любой перевод единиц (валюты, меры, единицы измерения) — тот же класс формул.
**Как подступиться:** пиши `9.0 / 5.0`, а не `9 / 5` — иначе целочисленное деление даст `1`.
**⭐ Бонус:** добавь Кельвин (`K = C + 273.15`) и найди температуру, при которой Цельсий и Фаренгейт равны (подсказка: это −40).

## 1.7. Цена со скидкой 🟡

Даны цена товара и процент скидки. Напечатайте итоговую цену с двумя знаками после запятой.

**Формат ввода.** Дробное число — цена, и целое число — процент скидки (0 ≤ процент ≤ 100), через пробел.

**Формат вывода.** Итоговая цена, два знака после точки.

**Пример:**
```
Ввод
1000 20
Вывод
800.00
```

**Что тренирует:** проценты, дробное деление, точность вывода денег.
**Где пригодится:** магазины, налоги, чаевые, любые расчёты «процент от суммы».
**Как подступиться:** заплатить нужно `(100 − процент)` процентов от цены; следи, чтобы деление было дробным.
**⭐ Бонус:** примени вторую скидку поверх первой и убедись сам: две скидки по 20% дают не 40%, а 36%.

---

## 1.8. Сумма квадратов 🔴

Напечатайте сумму `1² + 2² + … + n²`.

**Формат ввода.** Одно целое число `n` (1 ≤ n ≤ 100000).

**Формат вывода.** Сумма квадратов всех чисел от 1 до `n`.

**Пример:**
```
Ввод
3
Вывод
14
```

**Что тренирует:** переполнение при умножении — приём `1LL *`.
**Где пригодится:** статистика (дисперсия, среднеквадратичное), физика, любые суммы произведений.
**Как подступиться:** ответ огромный — копи в `long long`, а само `i * i` считай сразу в `long long`.
**⭐ Бонус:** проверь себя формулой `n·(n+1)·(2n+1)/6` — результат обязан совпасть с циклом (и в формуле тоже держи `long long`).

> `14`, потому что `1 + 4 + 9 = 14`. При `n = 100000` сумма — сотни триллионов.

# Подсказки

> 📖 Мало подсказки? Открой теорию темы: [раздел справочника](../ref/01-osnovy.md).

<details>
<summary>1.1 — Средний рост</summary>

- Сумма трёх `int` — тоже `int`. Чтобы получить дробное среднее, приведи к дробному
  хотя бы одну часть: `(a + b + c) / 3.0` (делитель `3.0`, а не `3`).
- Один знак после точки: `#include <iomanip>` и `std::cout << std::fixed << std::setprecision(1) << avg;`
  либо `std::format("{:.1f}", avg)` из `<format>`.
</details>

<details>
<summary>1.2 — Сосед по алфавиту</summary>

- Символ — это число. `char c; std::cin >> c;` затем `char result = c + n;`
  (компилятор может попросить `static_cast<char>(c + n)` — это нормально).
- Печатаешь `result` как символ: `std::cout << result;`.
</details>

<details>
<summary>1.3 — Рубли и копейки</summary>

- Рубли — это целочисленное деление на 100: `kopecks / 100`.
- Копейки — остаток: `kopecks % 100`.
- Большая сумма может не влезть в диапазон? 10^9 в `int` помещается, но если сомневаешься —
  бери `long long`, хуже не будет.
</details>

<details>
<summary>1.4 — Длина окружности и площадь</summary>

- Радиус читай в `double`. Длина окружности `2 * PI * r`, площадь `PI * r * r`.
- Два знака: `std::fixed` + `std::setprecision(2)` (из `<iomanip>`), либо `std::format("{:.2f}", x)`.
- При `r = 2` длина `≈ 12.57` и площадь `≈ 12.57` совпадают случайно — не пугайся.
</details>

<details>
<summary>1.5 — Найди ошибку: сумма от 1 до n</summary>

- Сумма 1..100000 это около 5 миллиардов — в `int` (примерно до 2.1 млрд) она **не помещается**,
  происходит переполнение, отсюда мусор и минусы.
- Замени тип накопителя: `long long sum = 0;`. Счётчик `i` можно оставить `int`.
- Это тот же класс ошибки, что и с факториалом: целочисленное переполнение.
</details>

<details>
<summary>1.6 — Из Цельсия в Фаренгейт</summary>

- Читай `C` в `double`. Формула: `double f = c * 9.0 / 5.0 + 32;`.
- Именно `9.0 / 5.0`: если написать `9 / 5`, компилятор посчитает это в целых числах и получит `1`.
- Один знак: `std::fixed` + `std::setprecision(1)`.
</details>

<details>
<summary>1.7 — Цена со скидкой</summary>

- Платим `(100 − percent)` процентов: `double result = price * (100 - percent) / 100.0;`.
- Делитель `100.0` (дробный) — иначе деление целочисленное.
- Два знака: `std::fixed` + `std::setprecision(2)`.
</details>

<details>
<summary>1.8 — Сумма квадратов</summary>

- Накопитель `long long sum = 0;`.
- В цикле: `sum += 1LL * i * i;`. Приставка `1LL` превращает умножение в `long long` — иначе `i * i`
  для больших `i` переполнит `int` ещё до прибавления.
</details>

## Проверь себя (мини тест-план)

Прежде чем считать тему закрытой, прогони свои решения на «злых» входах:

- **1.1:** одинаковые числа (`180 180 180` → `180.0`, а не `180`); проверь, что знак после точки ровно один.
- **1.3:** ноль копеек (`0` → `0 руб. 0 коп.`); ровно 100 (`100` → `1 руб. 0 коп.`); большое число.
- **1.4:** радиус `1` и `3` — числа должны стать разными.
- **1.5:** `n = 1` (ответ `1`), `n = 1000000` (ответ должен быть огромным и положительным).
- **1.6:** `0` → `32.0`; отрицательная температура (`-40` → `-40.0` — точка, где шкалы совпадают).
- **1.7:** скидка `0` (цена без изменений) и `100` (итог `0.00`).
- **1.8:** `n = 1` → `1`; `n = 100000` — число должно быть огромным и положительным (тест на `long long`).
