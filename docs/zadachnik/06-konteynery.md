# Тема 6. Контейнеры: vector, map, set, pair

Контейнеры — это готовые «умные хранилища» стандартной библиотеки. Вместо того чтобы
вручную городить массивы и счётчики, вы берёте `vector` (список), `map` (словарь
«ключ → значение»), `set` (множество уникальных) — и решаете задачу в несколько строк.
Это водораздел между «пишу как на паскале» и «пишу на C++».

> **Теория темы.** Опирается на разделы 11–15 справочника ([открыть теорию](../ref/06-konteynery.md)).
> Там про `vector`, `map` как счётчик, `set`, `pair` и типичные ловушки (`m[key]` создаёт ключ!).

> **В целых программах.** «Анализ текста» (`../examples/03-analiz-teksta.md`) — `map`-счётчик
> и топ по частоте; «Список дел» (`../examples/02-spisok-del.md`) — `vector` структур;
> «Телефонная книга» (`../examples/06-telefonnaya-kniga.md`) — `map` с сохранением между запусками.

## Чему вы здесь научитесь

- Хранить список значений в `vector` и обходить его.
- Считать частоты через `map` (`++freq[key]`) — приём номер один в обработке данных.
- Находить количество уникальных через `set`.
- Понимать, что `map` хранит ключи **отсортированными** — и как это использовать.

## Где это пригодится

`map`-счётчик — это буквально «сколько раз встретилось» для чего угодно: слова в
тексте, коды ошибок в логе, товары в заказах, голоса на выборах. `vector` — самый
частый контейнер вообще. `set` — «убрать дубликаты» и «сколько разных». Эти три
структуры покрывают огромную долю реальных задач обработки данных.

## 6.1. Массив наоборот 🟢

*`vector` — рабочая лошадка C++: сложили числа в список, а потом прошли его с конца.*

Дано `N` чисел. Напечатайте их в обратном порядке в одну строку через пробел.

**Формат ввода.** `N` (0 ≤ N ≤ 1000), затем `N` целых чисел.

**Формат вывода.** Те же числа в обратном порядке, через пробел.

**Пример:**
```
Ввод
5
1 2 3 4 5
Вывод
5 4 3 2 1
```

- **Тренирует:** заполнение `vector` и обход с конца.
- **Где пригодится:** «последние сначала» (лента новостей, история), базовая работа со списком.

> **Как подступиться.** Считайте в `vector`, затем печатайте от последнего индекса к нулевому.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests

5 1 2 3 4 5 => 5 4 3 2 1
3 -1 0 5 => 5 0 -1
# край: одно число; а при N=0 вывод пустой
1 42 => 42
```

```hints
Идея: Сначала нужно сохранить все числа — печатать с конца можно только то, что уже прочитано.
План: Прочитайте `N` чисел в вектор, затем пройдите его от последнего элемента к первому (или разверните и пройдите обычно), печатая через пробел.
Ключ: `std::reverse(v.begin(), v.end());`
```

## 6.2. Сколько различных 🟢

*Бросьте все числа в `set` — он молча выкинет повторы. Сколько осталось, столько и уникальных.*

Дано `N` чисел. Напечатайте, сколько среди них **различных**.

**Формат ввода.** `N` (0 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Количество различных значений.

**Пример:**
```
Ввод
6
3 1 3 2 1 3
Вывод
3
```

- **Тренирует:** `set` как хранилище уникальных значений.
- **Где пригодится:** «сколько уникальных посетителей», «сколько разных товаров», дедупликация.

> **Как подступиться.** Сложите все числа в `set` — он сам отбросит повторы; ответ — его размер.

```tests

```


## 6.3. Самое частое слово 🟡

*`map`-счётчик — приём номер один в обработке данных. А ключи в нём лежат по алфавиту, так что ничья решается сама.*

Дано `N` слов. Напечатайте слово, которое встречается чаще всего. Если таких
несколько, напечатайте наименьшее по алфавиту.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` слов (латиница, без пробелов).

**Формат вывода.** Одно слово — самое частое.

**Пример:**
```
Ввод
5
apple pear apple pear banana
Вывод
apple
```

- **Тренирует:** `map` как счётчик частот и поиск максимума с учётом правила при равенстве.
- **Где пригодится:** топ-запросы, самый популярный товар, анализ логов, «горячие» ключи.

> **Как подступиться.** Посчитайте частоты в `map`; `map` отсортирован по ключу, поэтому при обходе первым запомнится алфавитно меньшее.

> **Разбор примера.** `apple` и `pear` встречаются по 2 раза; `apple` меньше по алфавиту, поэтому он.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# самое частое слово
5 a b a c a => a
3 x y y => y
```

```hints
Идея: Считать, сколько раз встретилось каждое слово, удобно в словаре «слово → число». А ключи `map` хранит по алфавиту.
План: Посчитайте частоты; затем пройдите словарь и запоминайте слово с наибольшим счётчиком, обновляя только при строго большем — при равенстве останется слово раньше по алфавиту.
Ключ: `for (const auto &[word, count] : freq) if (count > best) { best = count; answer = word; }`
```

## 6.4. Ведомость оценок 🟡

*Оценки всего от 2 до 5 — значит, счётчик поместится в обычный маленький массив по индексу-оценке.*

Дано `N` оценок (числа от 2 до 5). Напечатайте, сколько раз встретилась каждая оценка
— по возрастанию оценки.

**Формат ввода.** `N` (0 ≤ N ≤ 100000), затем `N` чисел от 2 до 5.

**Формат вывода.** По одной строке на каждую оценку от 2 до 5 в формате `оценка: количество`. Печатайте все четыре оценки, даже если какой-то не было (тогда количество `0`).

**Пример:**
```
Ввод
6
5 4 5 3 5 4
Вывод
2: 0
3: 1
4: 2
5: 3
```

- **Тренирует:** массив-счётчик по фиксированному диапазону значений.

> **Как подступиться.** Заведите счётчик на индексы 2..5, увеличивайте по оценке, потом выведите все четыре — включая нулевые.

```hints
Идея: Оценки лежат в маленьком известном диапазоне 2..5 — сама оценка может быть номером ячейки счётчика.
План: Заведите массив счётчиков с запасом до индекса 5, увеличивайте ячейку с номером оценки, потом напечатайте все четыре строки — включая нулевые.
```

## 6.5. Победитель по очкам 🟡

*Чтобы найти чемпиона по очкам, контейнер не нужен: держите лучшее имя и лучший счёт, обновляйте на ходу.*

Даны `N` записей вида «имя очки». Напечатайте имя участника с наибольшим числом
очков. Гарантируется, что победитель один.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` пар: строка-имя и целое число очков.

**Формат вывода.** Имя победителя.

**Пример:**
```
Ввод
3
anna 40
boris 55
vera 33
Вывод
boris
```

- **Тренирует:** параллельное чтение пары «строка + число» и поиск максимума по одному полю.
- **Где пригодится:** «кто набрал больше всех», лидерборд, поиск рекордсмена в потоке данных.

> **Как подступиться.** Можно вообще без контейнера — держите `bestName` и `bestScore`, обновляйте при большем счёте.

```tests
# один участник
```


## 6.6. Первый неповторяющийся 🔴

*Кто встретился ровно один раз и раньше всех? Частоты подскажет `map`, а порядок сохранит `vector` — ответ на их стыке.*

Дано `N` чисел. Напечатайте **первое** (в порядке ввода) число, которое встречается
ровно один раз. Если такого нет — напечатайте `-1`.

**Формат ввода.** `N` (0 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Первое неповторяющееся число или `-1`.

**Пример:**
```
Ввод
6
4 5 4 6 5 7
Вывод
6
```

- **Тренирует:** совмещение двух проходов — сначала частоты (`map`), затем поиск в **исходном** порядке.
- **Где пригодится:** «первый уникальный запрос», обнаружение единичных событий, дедупликация с сохранением порядка.

> **Как подступиться.** Сохраните числа в `vector` и параллельно посчитайте частоты в `map`. Затем пройдите по `vector` (именно по нему — он хранит порядок ввода) и верните первое число с частотой 1.

> **Разбор примера.** В примере `4` и `5` повторяются, `6` — первое встретившееся с единственным вхождением.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# если неповторяющихся нет — минус один
5 1 2 2 3 1 => 3
3 7 7 7 => -1
4 5 5 6 6 => -1
```

```hints
Идея: Понадобятся две вещи сразу: сколько раз встретилось каждое число и в каком порядке они шли. Один контейнер хранит одно, другой — другое.
План: Первый проход: числа — в вектор, частоты — в `map`. Второй проход — по вектору (он хранит порядок): первое число с частотой 1 и есть ответ; не нашли — `-1`.
Ключ: `for (int x : v) if (cnt[x] == 1) { answer = x; break; }`
```

## 6.7. Суммы по категориям 🟡

*`total[категория] += сумма` — и `map` сам сложит всё по группам. Так рождается любой отчёт «итого по…».*

Даны `N` записей вида «категория сумма» (категория — слово). Для каждой категории
напечатайте её суммарное значение, по алфавиту категорий.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` пар: слово-категория и целое число.

**Формат вывода.** По строке на категорию (в алфавитном порядке): `категория сумма`.

**Пример:**
```
Ввод
4
food 100
transport 50
food 200
food 30
Вывод
food 330
transport 50
```

- **Тренирует:** `map` как аккумулятор по ключу (`total[key] += value`).
- **Где пригодится:** агрегация расходов, суммы продаж по товарам, любые отчёты «итого по группе».

> **Как подступиться.** `map<string, long long>`; прибавляйте сумму к нужному ключу; обойдите `map` в конце.

```hints
Идея: Нужен контейнер-копилка по ключу: к сумме категории прибавляем каждую новую запись. Если ключа ещё нет, он должен появиться сам с нулём.
План: Заведите `map<string, long long>`; для каждой пары прибавьте сумму к ячейке категории; в конце обойдите словарь — он уже по алфавиту.
Ключ: `total[cat] += amount;`
```

## 6.8. Пересечение множеств 🔴

*Сложите оба набора в `set` — дубликаты уйдут — и просто спросите, кто из первого встречается во втором.*

Даны два набора чисел. Напечатайте, сколько **различных** чисел встречается в обоих
наборах одновременно.

**Формат ввода.** `N`, затем `N` чисел; затем `M`, затем `M` чисел.

**Формат вывода.** Количество различных общих чисел.

**Пример:**
```
Ввод
3
1 2 3
4
2 3 4 5
Вывод
2
```

- **Тренирует:** два `set` и проверку принадлежности одного в другом.
- **Где пригодится:** общие элементы (общие друзья, совпадающие теги, пересечение прав доступа).

> **Как подступиться.** Оба набора — в `set` (это сразу убирает дубликаты); пройдите по первому и считайте тех, кто есть во втором.

> **Разбор примера.** Общие числа: `2` и `3` — их два.

## 6.9. Итоги забегов 🔗🟡

*Третье звено «Журнала забегов»: забегов много — собираем итоги по каждому игроку в `map`.*

Даны `N` забегов вида `имя золото`. Для каждого игрока напечатайте (по алфавиту имён)
строку `имя: забегов K, всего G, лучший B` — сколько у него забегов, сумма золота и лучший
результат.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` пар: имя и целое число золота.

**Формат вывода.** По строке на игрока, в алфавитном порядке имён.

**Пример:**
```
Ввод
4
Ari 50 Bo 30 Ari 20 Bo 90
Вывод
Ari: забегов 2, всего 70, лучший 50
Bo: забегов 2, всего 120, лучший 90
```

- **Тренирует:** `map` со значением-структурой: копить сразу несколько величин по ключу.
- **Где пригодится:** любые сводки «по пользователю»: статистика игроков, продажи по менеджерам, расходы по категориям с максимумом.

> **Как подступиться.** Ключ — имя, значение — `struct` из трёх полей. Лучший результат начинайте не с нуля — первый забег игрока и есть его первый «лучший».

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
4\nAri 50 Bo 30 Ari 20 Bo 90 => Ari: забегов 2, всего 70, лучший 50\nBo: забегов 2, всего 120, лучший 90
1\nСоло 5 => Соло: забегов 1, всего 5, лучший 5
3\nAri 10 Ari 30 Ari 20 => Ari: забегов 3, всего 60, лучший 30
3\nZed 1 Amy 2 Zed 3 => Amy: забегов 1, всего 2, лучший 2\nZed: забегов 2, всего 4, лучший 3
```


```cpp
    }

    return 0;
```

<summary>Полное решение 6.3 — Самое частое слово</summary>

Ход мысли по шагам:

1. Считаю частоты в `std::map<string,int>`: `++freq[word]`.
2. `map` хранит ключи по алфавиту, поэтому обхожу его по порядку.
3. Запоминаю слово со **строго** большим счётчиком — при равенстве первым останется алфавитно меньшее.

```cpp
#include <iostream>
#include <string>
#include <map>

int main() {
    int n = 0;
    std::cin >> n;

    std::map<std::string, int> freq;
    for (int i = 0; i < n; ++i) {
        std::string word;
        std::cin >> word;
        ++freq[word];
    }

    std::string answer;
    int best = 0;
    for (const auto &[word, count] : freq) {   // map отсортирован по ключу
        if (count > best) {                    // строгое > — при равенстве меньшее слово
            best = count;
            answer = word;
        }
    }

    std::cout << answer << "\n";
    return 0;
}
```


**Другой подход — `unordered_map` и явное правило ничьей**

```cpp
#include <iostream>
#include <string>
#include <unordered_map>

int main() {
    int n = 0;
    std::cin >> n;
    std::unordered_map<std::string, int> freq;
    for (int i = 0; i < n; ++i) {
        std::string word;
        std::cin >> word;
        ++freq[word];
    }
    std::string answer;
    int best = 0;
    for (const auto &[word, count] : freq)
        if (count > best || (count == best && word < answer)) {   // ничья — решаем сами
            best = count;
            answer = word;
        }
    std::cout << answer << "\n";
    return 0;
}
```

> **Сравнение.** `unordered_map` быстрее на миллионах слов, но хранит ключи в случайном порядке — «при равенстве меньшее» уже не получится бесплатно, правило ничьей приходится писать явно. `map` медленнее, зато порядок по алфавиту решает ничью сам.
</details>

<summary>Полное решение 6.6 — Первый неповторяющийся</summary>

Ход мысли по шагам:

1. Первый проход: сохраняю числа в `vector` (он хранит порядок ввода) и заодно считаю частоты в `map`.
2. Второй проход — по `vector`: возвращаю первое число с частотой 1.
3. Если такого нет — печатаю `-1`. По `map` идти нельзя: он отсортирован, порядок ввода в нём потерян.

```cpp
#include <iostream>
#include <vector>
#include <map>

int main() {
    int n = 0;
    std::cin >> n;

    std::vector<int> v;              // хранит порядок ввода
    std::map<int, int> cnt;          // хранит частоты
    for (int i = 0; i < n; ++i) {
        int x = 0;
        std::cin >> x;
        v.push_back(x);
        ++cnt[x];
    }

    int answer = -1;
    for (int x : v) {                // идём именно по vector — по порядку
        if (cnt[x] == 1) {
            answer = x;
            break;
        }
    }

    std::cout << answer << "\n";
    return 0;
}
```

<summary>Полное решение 6.9 — Итоги забегов</summary>

`stats[name]` создаёт запись с нулями при первой встрече, а ссылка `Stats &st` позволяет менять её прямо в словаре. Лучший результат задаёт первый забег (`st.runs == 0`), поэтому отрицательное или нулевое золото не сломает сравнение.

```cpp
#include <iostream>
#include <map>
#include <string>

struct Stats {
    int runs = 0;
    long long total = 0;
    int best = 0;
};

int main() {
    int n = 0;
    std::cin >> n;
    std::map<std::string, Stats> stats;
    for (int i = 0; i < n; ++i) {
        std::string name;
        int gold = 0;
        std::cin >> name >> gold;
        Stats &st = stats[name];                  // ссылка — меняем запись в самом словаре
        if (st.runs == 0 || gold > st.best) st.best = gold;
        ++st.runs;
        st.total += gold;
    }
    for (const auto &[name, st] : stats)
        std::cout << name << ": забегов " << st.runs << ", всего " << st.total << ", лучший " << st.best << "\n";
    return 0;
}
```

**Другой подход — три отдельных словаря**

<summary>Полное решение 6.10 — Группы анаграмм</summary>

Отсортированные буквы — «каноническая форма» слова: все анаграммы дают одну и ту же. Дальше это обычный подсчёт по ключу из темы 6.

```cpp
#include <algorithm>
#include <iostream>
#include <map>
#include <string>

int main() {
    int n = 0;
    std::cin >> n;
    std::map<std::string, int> groups;
    for (int i = 0; i < n; ++i) {
        std::string w;
        std::cin >> w;
        std::string key = w;
        std::sort(key.begin(), key.end());      // eat, tea, ate → aet
        ++groups[key];
    }
    int biggest = 0;
    for (const auto &[key, size] : groups) biggest = std::max(biggest, size);
    std::cout << groups.size() << " " << biggest << "\n";
    return 0;
}
```

```cpp
int main() {
    int n = 0;
    std::cin >> n;
    std::map<std::array<int, 26>, int> groups;
    int biggest = 0;
    for (int i = 0; i < n; ++i) {
        std::string w;
        std::cin >> w;
        std::array<int, 26> key{};              // сколько раз каждая буква
        for (char c : w) ++key[c - 'a'];
        biggest = std::max(biggest, ++groups[key]);
    }
    std::cout << groups.size() << " " << biggest << "\n";
    return 0;
}
```

> **Сравнение.** Счётчик букв строится за длину слова, а сортировка — за `L·log L`: на очень длинных словах счётчик быстрее. Сортированная строка проще и понятнее; массив-ключ показывает, что ключом `map` может быть любой сравнимый тип.

## Проверьте себя (мини тест-план)

- **6.1:** `N = 0` — пустой вывод; `N = 1` — одно число.
- **6.2:** все числа одинаковые (`1`); все разные; `N = 0` → `0`.
- **6.3:** все слова разные (ответ — алфавитно первое); одно слово повторяется.
- **6.4:** какой-то оценки нет вовсе (должна вывестись с `0`); `N = 0` — все нули.
- **6.5:** отрицательные очки у всех — вот где ломается `bestScore = 0`; один участник.
- **6.6:** все числа повторяются (`-1`); все уникальны (первое из ввода); `N = 0` → `-1`.
- **6.7:** одна категория; несколько категорий; проверьте суммирование повторов одной категории.
- **6.8:** нет общих (`0`); все общие; дубликаты во втором наборе (не считаются дважды).

**Тема закрыта,** когда `map`-счётчик вы пишете на автомате, а под задачу сразу выбираете `vector`/`map`/`set`.
