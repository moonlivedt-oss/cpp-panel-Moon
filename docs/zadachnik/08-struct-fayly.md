# Тема 8. struct, математика, файлы

Финальная тема связывает всё вместе. `struct` позволяет объединять несколько полей в
один объект («точка» = x + y, «прямоугольник» = ширина + высота с методом `area()`).
Плюс — математика (`<cmath>`, округление) и работа с файлами: программа учится
сохранять результат и читать данные извне, а не только из консоли.

> **Теория темы.** Опирается на разделы 19–21 справочника ([открыть теорию](../ref/08-struct-fayly.md)).
> Там про свой тип, методы, формулы, округление и чтение/запись файлов (`ifstream`/`ofstream`).

> **В целых программах.** «Расходы из файла» (`../examples/05-raskhody-csv.md`) — чтение и
> запись файлов; «Журнал оценок» (`../examples/08-zhurnal-ocenok.md`) — свой `struct` плюс файл.

## Чему вы здесь научитесь

- Объявлять `struct` с полями и **методами** (`area()`).
- Считать по формулам с `<cmath>` (`sqrt`) и округлять (`round`, `setprecision`).
- Писать в файл (`std::ofstream`) и читать из файла (`std::ifstream`).
- Проверять, что файл действительно открылся.

## Где это пригодится

`struct` — это то, как вы будете описывать «сущности» предметной области: пользователь,
заказ, точка, товар. Файлы — способ сохранять данные между запусками (настройки,
результаты, лог). Практически любая полезная программа читает вход и пишет выход в файл,
а не только в консоль. Это последний шаг к «настоящим» программам.

## 8.1. Расстояние между точками 🟡

*Точка — это два числа в одном `struct`. Соедините две точки — и теорема Пифагора выдаст расстояние.*

Заведите структуру `Point { double x, y; }`. Даны две точки на плоскости. Напечатайте
расстояние между ними с двумя знаками после запятой.

**Формат ввода.** Четыре числа: `x1 y1 x2 y2` (могут быть дробными).

**Формат вывода.** Расстояние, два знака после точки.

**Пример:**
```
Ввод
0 0 3 4
Вывод
5.00
```

- **Тренирует:** объявление `struct`, формулу с `sqrt`, точность вывода.
- **Где пригодится:** геометрия, графика, игры (столкновения), кластеризация, «ближайший объект».

> **Как подступиться.** Опишите `Point`, прочитайте две точки, примените теорему Пифагора через `std::sqrt`.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# нулевое расстояние; отрицательные координаты
0 0 3 4 => 5.00
1 1 1 1 => 0.00
-1 -1 2 3 => 5.00
```

```hints
Идея: Расстояние между точками — гипотенуза треугольника со сторонами «разница по x» и «разница по y».
План: Опишите `struct Point` из двух `double`, прочитайте две точки, посчитайте `dx`, `dy` и корень из суммы квадратов; выведите с двумя знаками.
Ключ: `std::sqrt(dx * dx + dy * dy)`
```

## 8.2. Округление до N знаков 🟡

*`setprecision` умеет брать не число, а переменную — и точность вывода можно менять прямо на ходу.*

Даны дробное число `x` и целое `n`. Напечатайте `x`, округлённое до `n` знаков после
запятой.

**Формат ввода.** Дробное число `x` и целое `n` (0 ≤ n ≤ 6) через пробел.

**Формат вывода.** Число `x`, округлённое до `n` знаков.

**Пример 1:**
```
Ввод
3.14159 2
Вывод
3.14
```
**Пример 2:**
```
Ввод
2.5 0
Вывод
3
```

- **Тренирует:** управление точностью через `setprecision(n)` с переменным `n`.
- **Где пригодится:** отображение цен, процентов, научных величин с нужной точностью.

> **Как подступиться.** `setprecision` умеет принимать переменную — задайте ей `n`.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# округление до нуля знаков; половина
3.14159 2 => 3.14
2.5 0 => 2
1.005 2 => 1.00
```

```hints
Идея: Точность вывода задаётся манипулятором, и ему можно передать не только число, но и переменную.
План: Прочитайте `x` и `n`, включите фиксированный формат и точность `n`, выведите `x`.
Ключ: `std::cout << std::fixed << std::setprecision(n) << x;`
```

## 8.3. Самый большой прямоугольник 🟡

*Пусть прямоугольник сам считает свою площадь методом `area()`. Это уже маленький шаг в сторону ООП.*

Заведите структуру прямоугольника со сторонами и **методом** `area()`. Даны `N`
прямоугольников. Напечатайте наибольшую площадь.

**Формат ввода.** `N` (1 ≤ N ≤ 1000), затем `N` пар «ширина высота» (целые, до 10000).

**Формат вывода.** Наибольшая площадь среди всех прямоугольников.

**Пример:**
```
Ввод
3
2 3
5 5
4 6
Вывод
25
```

- **Тренирует:** `struct` с методом, `vector` структур, поиск максимума по вычисляемому полю.
- **Где пригодится:** объект «умеет сам себя посчитать» — основа объектного стиля (площадь, цена со скидкой, полное имя).

> **Как подступиться.** Метод `area()` возвращает произведение сторон; ищите максимум `r.area()` по вектору.

> **Выбор типа.** Стороны до 10000, площадь до 10^8 — подумайте про тип, куда её класть.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests

```

```hints
Идея: Пусть прямоугольник сам знает свою площадь — метод внутри структуры. Тогда поиск максимума сравнивает «площади», а не стороны.
План: Опишите `Rect` с полями и методом `area() const`; прочитайте прямоугольники в вектор; найдите максимум `r.area()` циклом.
```

**Формат ввода.** `N` (0 ≤ N ≤ 1000), затем `N` целых чисел (до 100000).

**Результат.** Файл `squares.txt` с `N` строками — квадратами чисел.

**Пример.** При вводе `3` и `2 5 10` файл `squares.txt` должен содержать:

> **Как подступиться.** Откройте `ofstream`, проверьте, что открылся, и пишите в него так же, как в `cout`.

```hints
План: Откройте `ofstream` на `squares.txt`, проверьте открытие, в цикле читайте числа и пишите их квадраты по одному в строке.
```

## 8.5. Статистика из файла 🔴

*Данные бывают не только с клавиатуры. Файл читается тем же `>>`, пока читается — с этого начинается любая пакетная обработка.*

Рядом с программой лежит файл `data.txt`, в котором записаны целые числа (через
пробелы и переводы строк, сколько угодно). Прочитайте их и напечатайте количество
чисел, их сумму и среднее (с двумя знаками).

**Файл `data.txt` (пример):**
```
10 20
30 40
```

**Формат вывода.** Три величины через пробел: количество, сумма, среднее.

**Пример вывода для файла выше:**
```
4 100 25.00
```

- **Тренирует:** чтение файла до конца (`while (in >> x)`) и защиту от деления на ноль.
- **Где пригодится:** обработка входных данных из файла — логи, выгрузки, замеры; основа любой «пакетной» обработки.

> **Как подступиться.** Откройте `ifstream`, читайте в цикле как из `cin`; среднее считайте только при `count > 0`.

> **Где лежит файл.** Сначала создайте `data.txt` сами с любыми числами, потом запускайте программу. На вашей сборке файл ищется рядом с `.exe` — если не находится, положите его туда же, где лежит собранная программа (см. раздел 21 справочника).

```hints
Идея: Файл читается тем же `>>`, что и клавиатура, — «пока читается». А среднее нельзя считать, если чисел не было.
План: Откройте `ifstream`, проверьте открытие, в цикле `while (in >> x)` копите количество и сумму; при нуле чисел выведите нули, иначе — среднее с двумя знаками.
Ключ: `while (in >> x) { ++count; sum += x; }`
```

> Не выходит и с подсказками? Решение с разбором — [внизу страницы](#решения-с-разбором). Открывай его, только когда правда застрял.

## 8.6. Площадь круга через struct 🟢

*Тот же объектный приём в миниатюре: `Circle` хранит радиус и сам знает, как вычислить площадь.*

Заведите структуру `Circle` с полем-радиусом и **методом** `area()`. Дан радиус —
напечатайте площадь круга с двумя знаками после запятой.

**Формат ввода.** Одно число (может быть дробным) — радиус.

**Формат вывода.** Площадь круга, два знака после точки.

**Пример:**
```
Ввод
1
Вывод
3.14
```

- **Тренирует:** `struct` с методом и именованную константу π внутри него.
- **Где пригодится:** объектный стиль «объект сам умеет себя посчитать» — база для будущих классов.

> **Как подступиться.** Метод `area()` возвращает `π · r · r`; π заведите как `const double`.

```tests

2 => 12.57
# края
0 => 0.00
10 => 314.16
```

```hints
Идея: Круг хранит радиус и сам умеет посчитать свою площадь — это метод структуры, а π — именованная константа.
План: Опишите `Circle` с полем `r` и методом `area() const`, прочитайте радиус, выведите площадь с двумя знаками.
```

## 8.9. Журнал забегов из файла 🔗🔴

*Финальное звено цепочки: журнал лежит в файле, строки бывают битыми, а итоги нужны по каждому игроку со средним.*

Журнал `runs.txt` состоит из записей `имя;золото;шаги`, по одной в строке. Часть записей
испорчена: не хватает полей или вместо числа — текст. Разберите журнал в `struct Run`,
битые записи посчитайте и пропустите. Напечатайте `битых: M`, а затем по алфавиту имён
строки `имя: забегов K, среднее золото X.XX`.

> Чтобы задачу можно было проверить тестами, содержимое файла подаётся **на вход** программе
> (записи через пробел или перевод строки). В своей игре замените `std::cin` на `std::ifstream`.

**Формат ввода.** Записи `имя;золото;шаги` через пробельные символы.

**Формат вывода.** Строка `битых: M`, затем итоги по игрокам.

**Пример:**
```
Ввод
Ari;50;12 Bo;x;3 Ari;21;9 Cy;7
Вывод
битых: 2
Ari: забегов 2, среднее золото 35.50
```

- **Тренирует:** `struct` + разбор записи с проверками + `map` + форматированный вывод — темы 5–8 разом.
- **Где пригодится:** загрузка сохранений и логов: реальные файлы бывают битыми, и программа не должна падать.

> **Как подступиться.** Функция `bool parseRun(const std::string &s, Run &r)` отвечает «получилось ли»; числа проверяйте целиком (как `toInt` в квесте 8 «Подземелья»).

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests

a;1;1 b;;2 ;3;3 c;4;x => битых: 3\na: забегов 1, среднее золото 1.00
Bo;5;1 Ari;3;2 Bo;6;4 => битых: 0\nAri: забегов 1, среднее золото 3.00\nBo: забегов 2, среднее золото 5.50
```


## 8.10. Ближайшая пара точек 🔥

*Челлендж темы: среди множества точек найти две самые близкие. Структура, функция расстояния и аккуратный перебор.*

Даны `N` точек на плоскости. Найдите наименьшее расстояние между двумя **разными по номеру**
точками (совпадающие координаты дают расстояние `0`). Напечатайте его с тремя знаками после запятой.

**Формат ввода.** `N` (2 ≤ N ≤ 2000), затем `N` пар координат (целые, по модулю до 10^4).

**Формат вывода.** Наименьшее расстояние, три знака после точки.

**Пример:**
```
Ввод
3
0 0
3 4
1 1
Вывод
1.414
```

- **Тренирует:** `struct Point`, функцию расстояния и перебор пар `i < j` без повторов.
- **Где пригодится:** «ближайший враг», коллизии, кластеры на карте — задача номер один вычислительной геометрии.

> **Как подступиться.** Перебирайте пары `i < j` (каждую один раз). Корень не нужен до самого конца: сравнивать можно квадраты расстояний — они в целых и без погрешностей.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests

2\n5 5\n5 5 => 0.000
4\n0 0\n10 0\n0 10\n10 10 => 10.000
3\n-10000 -10000\n10000 10000\n0 1 => 14141.429
```

```hints
Идея: Нужно сравнить все пары, но каждую — один раз: вторую точку берите только из тех, что идут после первой.
План: Опишите `struct Point { long long x, y; }`. Двойным циклом `i < j` ищите минимум **квадрата** расстояния в целых числах; корень возьмите один раз в самом конце.
```

<summary>Полное решение 8.1 — Расстояние между точками</summary>

Ход мысли по шагам:

1. Завожу `struct Point { double x, y; }` и читаю две точки.

```cpp
    double x = 0.0;

    double dx = a.x - b.x;
    double dy = a.y - b.y;
    double dist = std::sqrt(dx * dx + dy * dy);   // теорема Пифагора

    std::cout << std::fixed << std::setprecision(2) << dist << "\n";
    return 0;
```

**Другой подход — `std::hypot`**

<summary>Полное решение 8.3 — Самый большой прямоугольник</summary>

Ход мысли по шагам:

1. Завожу `struct Rect` со сторонами и **методом** `area()` — объект сам считает свою площадь.
2. Внутри `area()` привожу к `long long` — привычка защищаться от переполнения (метод `const`, он только читает поля).
3. Читаю прямоугольники в `vector` и ищу максимум `r.area()`.

```cpp
#include <iostream>
#include <vector>

struct Rect {
    int w = 0;
    int h = 0;
    long long area() const {                 // const — метод только читает поля
        return static_cast<long long>(w) * h;
    }
};

int main() {
    int n = 0;
    std::cin >> n;
    std::vector<Rect> rects;
    for (int i = 0; i < n; ++i) {
        Rect r;
        std::cin >> r.w >> r.h;
        rects.push_back(r);
    }

    long long best = 0;
    for (const Rect &r : rects)
        if (r.area() > best) best = r.area();
    std::cout << best << "\n";
    return 0;
}
```


**Другой подход — `std::max_element` по площади**

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

struct Rect {
    int w = 0;
    int h = 0;
```

<summary>Полное решение 8.5 — Статистика из файла</summary>

Ход мысли по шагам:

1. Открываю `std::ifstream in("data.txt")` и проверяю открытие.
2. Читаю в цикле `while (in >> x)`, как из `cin`, копя сумму и счётчик.
3. Среднее считаю только при `count > 0` (защита от деления на ноль), печатаю с двумя знаками.

```cpp
#include <iostream>
#include <iomanip>
#include <fstream>

int main() {
    std::ifstream in("data.txt");
    if (!in) {
        std::cerr << "не удалось открыть data.txt\n";
        return 1;
    }

    int count = 0;
    long long sum = 0;
    int x = 0;
    while (in >> x) {              // читаем как из cin, пока читается
        ++count;
        sum += x;
    }

    if (count == 0) {             // защита от деления на ноль
        std::cout << "0 0 0.00\n";
        return 0;
    }

    double avg = static_cast<double>(sum) / count;
    std::cout << count << " " << sum << " "
              << std::fixed << std::setprecision(2) << avg << "\n";
    return 0;
}
```

```cpp
#include <iostream>
```
```cpp
#include <fstream>
#include <string>

        return 1;
```

```cpp
    std::string bestName;
    int bestScore = 0;
    bool first = true;

            bestScore = score;
            bestName = name;
            first = false;
        }
    }

    std::cout << bestName << "\n";
    return 0;
}
```

<summary>Полное решение 8.9 — Журнал забегов из файла</summary>

`parseRun` отделяет «формат записи» от «статистики»: её легко проверить отдельно и переиспользовать в игре с настоящим `ifstream`. Число считается правильным, только если прочитано **целиком** — `12abc` отбрасывается.

```cpp
#include <iomanip>
#include <iostream>
#include <map>
#include <sstream>
#include <string>

struct Run {
    std::string name;
    int gold = 0;
    int steps = 0;
};

bool toInt(const std::string &s, int &out) {
    std::istringstream in(s);
    char extra = 0;
    return static_cast<bool>(in >> out) && !(in >> extra);   // число — и ничего после
}

bool parseRun(const std::string &s, Run &r) {
    std::istringstream in(s);
    std::string gold, steps;
    if (!std::getline(in, r.name, ';') || !std::getline(in, gold, ';') || !std::getline(in, steps)) return false;
    return !r.name.empty() && toInt(gold, r.gold) && toInt(steps, r.steps);
}

struct Total {
    int runs = 0;
    long long gold = 0;
};

int main() {
    std::map<std::string, Total> totals;
    int broken = 0;
    std::string record;
    while (std::cin >> record) {
        Run r;
        if (!parseRun(record, r)) { ++broken; continue; }
        Total &t = totals[r.name];
        ++t.runs;
        t.gold += r.gold;
    }
    std::cout << "битых: " << broken << "\n";
    for (const auto &[name, t] : totals)
        std::cout << name << ": забегов " << t.runs << ", среднее золото " << std::fixed << std::setprecision(2)
                  << static_cast<double>(t.gold) / t.runs << "\n";
    return 0;
}
```

```cpp
    }
    std::cout << "битых: " << broken << "\n";
    for (const auto &[name, t] : totals)
        std::cout << name << ": забегов " << t.first << ", среднее золото " << std::fixed << std::setprecision(2)
                  << static_cast<double>(t.second) / t.first << "\n";
    return 0;
}
```

> **Сравнение.** `std::stoi` бросает исключение на «x», но **молча** принимает «12abc» — хвост приходится проверять вторым аргументом `pos`. Вариант с `toInt` короче и без исключений; исключения удобнее, когда ошибку нужно передать далеко наверх (тема 14 справочника).
</details>

<details>
<summary>Полное решение 8.10 — Ближайшая пара точек</summary>

Квадрат расстояния в целых числах точен, а корень монотонен: наименьший квадрат даёт наименьшее расстояние. Корень берём один раз в конце. Для N = 2000 это ~2 млн пар — мгновенно.

```cpp
#include <cmath>
#include <iomanip>
#include <iostream>
#include <vector>

struct Point {
    long long x = 0;
    long long y = 0;
};

long long dist2(const Point &a, const Point &b) {
    long long dx = a.x - b.x, dy = a.y - b.y;
    return dx * dx + dy * dy;                  // квадрат — в целых, без погрешностей
}

int main() {
    int n = 0;
    std::cin >> n;
    std::vector<Point> p(n);
    for (auto &pt : p) std::cin >> pt.x >> pt.y;
    long long best = dist2(p[0], p[1]);
    for (int i = 0; i < n; ++i)
        for (int j = i + 1; j < n; ++j)        // каждая пара — один раз
            best = std::min(best, dist2(p[i], p[j]));
    std::cout << std::fixed << std::setprecision(3) << std::sqrt(static_cast<double>(best)) << "\n";
    return 0;
}
```

**Другой подход — сортировка по x и отсечение**

```cpp
#include <algorithm>
#include <cmath>
#include <iomanip>
#include <iostream>
#include <vector>

struct Point {
    long long x = 0;
    long long y = 0;
};

int main() {
    int n = 0;
    std::cin >> n;
    std::vector<Point> p(n);
    for (auto &pt : p) std::cin >> pt.x >> pt.y;
    std::sort(p.begin(), p.end(), [](const Point &a, const Point &b) { return a.x < b.x; });
    long long best = -1;
    for (int i = 0; i < n; ++i)
        for (int j = i + 1; j < n; ++j) {
            long long dx = p[j].x - p[i].x;
            if (best >= 0 && dx * dx >= best) break;   // дальше по x — только дальше
            long long dy = p[j].y - p[i].y;
            long long d2 = dx * dx + dy * dy;
            if (best < 0 || d2 < best) best = d2;
        }
    std::cout << std::fixed << std::setprecision(3) << std::sqrt(static_cast<double>(best)) << "\n";
    return 0;
}
```

> **Сравнение.** После сортировки по `x` пары, у которых уже одна разница по `x` больше лучшего ответа, можно не смотреть — внутренний цикл обрывается рано. На случайных точках это в разы быстрее полного перебора; в худшем случае (все точки на одной вертикали) — не быстрее. Полный перебор проще и для N = 2000 достаточен.
</details>
