# Тема 4. Функции

Функция — это способ дать куску кода имя и переиспользовать его. С этого момента
твои программы перестают быть «простынёй» в `main` и начинают читаться как план:
«прочитай число → проверь простоту → посчитай». Здесь же — ссылки (изменить
переменную снаружи), возврат нескольких значений и рекурсия.

> 📖 **Опирается на раздел 9 справочника** ([теория в справочнике](../ref/04-funkcii.md)).
> Там про параметры, передачу по значению и по ссылке, лямбды и `std::optional`.

> 🔗 **В целой программе:** «Калькулятор» (`../examples/01-kalkulyator.md`) — как задача
> разбита на функции, меню и `switch`.

## Чему ты здесь научишься

- Выносить логику в функцию с осмысленной сигнатурой (`bool isPrime(int x)`).
- Понимать разницу «по значению» (копия) и «по ссылке» (`&`, сама переменная).
- Возвращать из функции сразу несколько значений через параметры-ссылки.
- Писать рекурсию с обязательным условием остановки.

## Где это пригодится

Ни одна программа больше пары экранов не живёт без функций. Функция — это единица
переиспользования и тестирования: написал `isPrime` один раз — используешь везде.
Ссылки лежат в основе того, как C++ передаёт большие объекты без копирования (это
важно для скорости). Рекурсия — естественный язык для деревьев, файловых систем,
разбора выражений.

## 4.1. Факториал функцией 🟢

Напишите функцию `factorial(n)`, которая возвращает произведение всех чисел
от 1 до `n`, и используйте её в `main`.

**Формат ввода.** Одно целое число `n` (0 ≤ n ≤ 20). Считаем, что `0! = 1`.

**Формат вывода.** Значение `n!`.

**Пример:**
```
Ввод
5
Вывод
120
```

**Что тренирует:** объявление функции с возвращаемым значением, выбор типа результата.
**Где пригодится:** комбинаторика (число сочетаний), вероятности, любая формула, которую хочется вызвать по имени.
**Как подступиться:** заведи накопитель `= 1` (не 0!) и умножай в цикле. Ответ большой — подумай про тип.

> До 20! — снова про выбор типа возвращаемого значения.

---

## 4.2. Обмен по ссылке 🟡

Напишите функцию `swapValues`, которая принимает две переменные **по ссылке**
и меняет их значения местами. В `main` прочитайте два числа, вызовите функцию
и напечатайте их после обмена.

**Формат ввода.** Два целых числа через пробел.

**Формат вывода.** Те же два числа в обратном порядке.

**Пример:**
```
Ввод
3 8
Вывод
8 3
```

**Что тренирует:** передача по ссылке (`int &a`) — изменение переменной вызывающего кода.
**Где пригодится:** любая функция, которая должна **менять** переданные данные (сортировки, обновление состояния), а не возвращать копию.
**Как подступиться:** сначала напиши **без** `&` и убедись своими глазами, что в `main` ничего не изменилось — это и есть смысл упражнения.

> Если функция принимает по значению (`int a, int b`) — она поменяет местами
> копии, а в `main` ничего не изменится. Ссылка (`int &a, int &b`) — то, что нужно.

## 4.3. Минимум и максимум сразу 🟡

Напишите функцию, которая по массиву чисел находит **и** минимум, **и** максимум.
Так как значений два, верните их через параметры-ссылки. Даны `N` чисел.

**Формат ввода.** `N` (1 ≤ N ≤ 1000), затем `N` целых чисел.

**Формат вывода.** Два числа через пробел: минимум и максимум.

**Пример:**
```
Ввод
5
4 -1 7 3 7
Вывод
-1 7
```

**Что тренирует:** возврат нескольких значений из одной функции через ссылки.
**Где пригодится:** когда результат — это пара/тройка величин (границы диапазона, координаты, «сколько и на какой позиции»).
**Как подступиться:** инициализируй `mn` и `mx` **первым элементом**, а не нулём — иначе на одних отрицательных ошибёшься.

---

## 4.4. НОД рекурсией 🔴

Напишите **рекурсивную** функцию, вычисляющую наибольший общий делитель двух
чисел по алгоритму Евклида: `gcd(a, b) = gcd(b, a % b)`, а `gcd(a, 0) = a`.

**Формат ввода.** Два целых положительных числа через пробел, каждое до 10^9.

**Формат вывода.** Их наибольший общий делитель.

**Пример:**
```
Ввод
48 36
Вывод
12
```

**Что тренирует:** рекурсия — функция вызывает сама себя, с условием остановки.
**Где пригодится:** сокращение дробей, работа с ритмами/периодами, а сам приём «свести задачу к меньшей такой же» — фундамент рекурсии.
**Как подступиться:** условие остановки (`b == 0`) должно стоять **до** рекурсивного вызова. `b` уменьшается каждый шаг, поэтому рекурсия конечна.

## 4.5. Сколько простых в отрезке 🟡

Напишите функцию `bool isPrime(int x)`, а затем в `main` посчитайте, сколько
простых чисел лежит в отрезке `[a, b]` включительно, вызывая эту функцию.

**Формат ввода.** Два целых числа `a` и `b` (2 ≤ a ≤ b ≤ 100000) через пробел.

**Формат вывода.** Количество простых чисел в отрезке.

**Пример:**
```
Ввод
10 20
Вывод
4
```

**Что тренирует:** разбиение задачи — маленькая функция делает `main` коротким и понятным.
**Где пригодится:** это главный приём программирования вообще — «спрятать сложное в функцию, чтобы главный код читался словами».
**Как подступиться:** сначала напиши `isPrime`, потом в `main` — простой цикл со счётчиком, который её вызывает.

> Простые в [10, 20]: 11, 13, 17, 19 — четыре штуки. Задача не про новый алгоритм,
> а про то, как одна маленькая функция делает `main` коротким и понятным.

## 4.6. Максимум из трёх — функцией 🟢

Напишите функцию `int max3(int a, int b, int c)`, которая возвращает наибольшее
из трёх чисел. В `main` прочитайте три числа и напечатайте результат её вызова.

**Формат ввода.** Три целых числа через пробел.

**Формат вывода.** Наибольшее из трёх.

**Пример:**
```
Ввод
3 7 5
Вывод
7
```

**Что тренирует:** вынесение логики в функцию, которая **возвращает** значение (а не печатает).
**Где пригодится:** любую повторяющуюся операцию удобно завернуть в функцию с понятным именем.
**Как подступиться:** внутри — тот же приём «текущий лучший»; `main` только читает и печатает.

## 4.7. Високосный год — функцией 🟡

Напишите функцию `bool isLeapYear(int year)`. Год високосный, если делится на 4,
но не на 100 — кроме годов, кратных 400 (они високосные). Прочитайте год и
напечатайте `YES` или `NO`.

**Формат ввода.** Одно целое число — год.

**Формат вывода.** `YES`, если год високосный, иначе `NO`.

**Пример 1:**
```
Ввод
2000
Вывод
YES
```
**Пример 2:**
```
Ввод
1900
Вывод
NO
```

**Что тренирует:** упаковку непростого логического условия в функцию с говорящим именем.
**Где пригодится:** календари, даты, финансовые периоды — `isLeapYear` пишут один раз и зовут везде.
**Как подступиться:** всё правило умещается в одно выражение с `&&`, `||` и остатками.

## 4.8. Степень рекурсией 🔴

Напишите **рекурсивную** функцию `long long power(int base, int exp)`, возвращающую
`base` в степени `exp` (считаем `exp ≥ 0`, а `base^0 = 1`).

**Формат ввода.** Два целых числа: `base` и `exp` (0 ≤ exp ≤ 62) через пробел.

**Формат вывода.** Значение `base` в степени `exp`.

**Пример:**
```
Ввод
2 10
Вывод
1024
```

**Что тренирует:** рекурсию с базовым случаем и уменьшающимся параметром.
**Где пригодится:** рекурсия — язык деревьев, разбора выражений, «раздели и властвуй».
**Как подступиться:** базовый случай `exp == 0` возвращает `1`; иначе `base` умножить на `power(base, exp − 1)`.

# Подсказки

> 📖 Мало подсказки? Открой теорию темы: [раздел справочника](../ref/04-funkcii.md).

<details>
<summary>4.1 — Факториал функцией</summary>

- Сигнатура: `long long factorial(int n)`. Внутри — цикл `for (int i = 1; i <= n; ++i) result *= i;`.
- Начальное значение `result = 1` (не 0!). Для `n == 0` цикл не выполнится и вернётся `1` — как и надо.
</details>

<details>
<summary>4.2 — Обмен по ссылке</summary>

- `void swapValues(int &a, int &b) { int t = a; a = b; b = t; }`.
- Амперсанд `&` в параметре означает «работать с самой переменной, а не с копией».
- В `main`: `swapValues(x, y);` — без всяких `&` в месте вызова.
</details>

<details>
<summary>4.3 — Минимум и максимум сразу</summary>

- Читай числа в `std::vector<int>` (или сразу обновляй min/max по ходу чтения).
- Функция: `void minMax(const std::vector<int> &v, int &mn, int &mx)`.
- Инициализируй `mn` и `mx` первым элементом (`v[0]`), а не нулём — иначе на одних
  отрицательных или одних больших числах ошибёшься.
</details>

<details>
<summary>4.4 — НОД рекурсией</summary>

- `int gcd(int a, int b) { if (b == 0) return a; return gcd(b, a % b); }`.
- Рекурсия сама остановится: `b` с каждым шагом уменьшается и рано или поздно станет 0.
- Числа до 10^9 помещаются в `int`, но `long long` тоже подойдёт и надёжнее.
</details>

<details>
<summary>4.5 — Сколько простых в отрезке</summary>

- Сначала функция: `bool isPrime(int x)` — вернуть `false` для `x < 2`, иначе перебирать
  делители, пока `i * i <= x`.
- В `main` — цикл `for (int k = a; k <= b; ++k) if (isPrime(k)) ++count;`.
- Смысл задачи: `main` читается как «пройди по отрезку и посчитай простые», а «как проверить простоту»
  спрятано в функции.
</details>

<details>
<summary>4.6 — Максимум из трёх функцией</summary>

- `int max3(int a, int b, int c) { int best = a; if (b > best) best = b; if (c > best) best = c; return best; }`.
- Функция именно `return`-ит результат; печатает его `main`. Так функцию можно переиспользовать где угодно.
</details>

<details>
<summary>4.7 — Високосный год функцией</summary>

- Одно выражение: `return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);`.
- Разбери на примерах: `2000` (кратно 400 → YES), `1900` (кратно 100, но не 400 → NO), `2024` (кратно 4, не 100 → YES).
</details>

<details>
<summary>4.8 — Степень рекурсией</summary>

- Базовый случай **до** рекурсии: `if (exp == 0) return 1;`.
- Шаг: `return base * power(base, exp - 1);`. `exp` убывает и дойдёт до 0.
- Возвращаемый тип `long long`: `2^62` в `int` не влезет.
</details>

## Проверь себя (мини тест-план)

- **4.1:** `n = 0` → `1`; `n = 20` → должно быть огромным (проверь `long long`).
- **4.2:** одинаковые числа (`5 5` → `5 5`); убедись, что вариант без `&` действительно не работает.
- **4.3:** `N = 1` (min == max); все отрицательные; все одинаковые.
- **4.4:** `gcd(17, 5)` → `1` (взаимно простые); `gcd(100, 100)` → `100`.
- **4.5:** `a == b` и это простое (`7 7` → `1`); отрезок без простых.
- **4.6:** все равны; максимум — первый аргумент; отрицательные.
- **4.7:** `2000` → `YES`, `1900` → `NO`, `2024` → `YES`, `2023` → `NO`.
- **4.8:** `exp = 0` → `1`; `2 10` → `1024`; проверь `long long` на `2 60`.
