# Тема 4. Функции

Функция — это способ дать куску кода имя и переиспользовать его. С этого момента
ваши программы перестают быть «простынёй» в `main` и начинают читаться как план:
«прочитай число → проверь простоту → посчитай». Здесь же — ссылки (изменить
переменную снаружи), возврат нескольких значений и рекурсия.

> **Теория темы.** Опирается на раздел 9 справочника ([открыть теорию](../ref/04-funkcii.md)).
> Там про параметры, передачу по значению и по ссылке, лямбды и `std::optional`.

> **В целой программе.** «Калькулятор» (`../examples/01-kalkulyator.md`) — как задача
> разбита на функции, меню и `switch`.

[← К списку тем и пути изучения](00-README.md)

> Определения функций темы (ссылки, лямбда, `optional`) — коротко в [Словаре функций](../ref/10a-slovar-funkcij.md#тема-4-функции).

## Чему вы здесь научитесь

- Выносить логику в функцию с осмысленной сигнатурой (`bool isPrime(int x)`).
- Понимать разницу «по значению» (копия) и «по ссылке» (`&`, сама переменная).
- Возвращать из функции сразу несколько значений через параметры-ссылки.
- Писать рекурсию с обязательным условием остановки.

## Где это пригодится

Ни одна программа больше пары экранов не живёт без функций. Функция — это единица
переиспользования и тестирования: написали `isPrime` один раз — используете везде.
Ссылки лежат в основе того, как C++ передаёт большие объекты без копирования (это
важно для скорости). Рекурсия — естественный язык для деревьев, файловых систем,
разбора выражений.

## 4.1. Факториал функцией 🟢

*Ваша первая функция: даём куску кода имя и зовём его из `main`. Остаётся решить, в какой тип поместится ответ.*

Напишите функцию `factorial(n)`, которая возвращает произведение всех чисел от 1 до
`n`, и используйте её в `main`.

**Формат ввода.** Одно целое число `n` (0 ≤ n ≤ 20). Считаем, что `0! = 1`.

**Формат вывода.** Значение `n!`.

**Пример:**
```
Ввод
5
Вывод
120
```

- **Тренирует:** объявление функции с возвращаемым значением и выбор типа результата.
- **Где пригодится:** комбинаторика (число сочетаний), вероятности, любая формула, которую хочется вызвать по имени.

> **Как подступиться.** Заведите накопитель `= 1` (не 0!) и умножайте в цикле. Ответ большой — подумайте про тип.

> **Выбор типа.** До 20! — снова про выбор типа возвращаемого значения.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# обычные
5 => 120
2 => 2
# края
0 => 1
20 => 2432902008176640000
```

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Выношу подсчёт в отдельную функцию `factorial` — так `main` читается словами.
2. Результат может быть огромным (20! ≈ 2·10¹⁸), поэтому тип — `long long`.
3. Накопитель начинаю с `1` (не с нуля — умножение на ноль всё обнулит). Для `n = 0` цикл не выполнится и вернётся `1` — как и надо (`0! = 1`).

```cpp
#include <iostream>

long long factorial(int n) {
    long long result = 1;
    for (int i = 2; i <= n; ++i)
        result *= i;
    return result;
}

int main() {
    int n = 0;
    std::cin >> n;
    std::cout << factorial(n) << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 4.2. Обмен по ссылке 🟡

*Хотите, чтобы функция поменяла сами переменные, а не их копии? Дайте ей ссылку — и `swap` заработает по-настоящему.*

Напишите функцию `swapValues`, которая принимает две переменные **по ссылке** и
меняет их значения местами. В `main` прочитайте два числа, вызовите функцию и
напечатайте их после обмена.

**Формат ввода.** Два целых числа через пробел.

**Формат вывода.** Те же два числа в обратном порядке.

**Пример:**
```
Ввод
3 8
Вывод
8 3
```

- **Тренирует:** передачу по ссылке (`int &a`) — изменение переменной вызывающего кода.
- **Где пригодится:** любая функция, которая должна **менять** переданные данные (сортировки, обновление состояния), а не возвращать копию.

> **Как подступиться.** Сначала напишите **без** `&` и убедитесь своими глазами, что в `main` ничего не изменилось — это и есть смысл упражнения.

> **По значению или по ссылке.** Если функция принимает по значению (`int a, int b`), она поменяет местами копии, а в `main` ничего не изменится. Ссылка (`int &a, int &b`) — то, что нужно.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# равные числа; отрицательное
3 7 => 7 3
5 5 => 5 5
-1 9 => 9 -1
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Ссылочные параметры (`int &a, int &b`) работают с самими переменными вызвавшего.

```c++
void swapValues(int &a, int &b) { int t = a; a = b; b = t; }
// в main: swapValues(x, y);
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Параметры беру **по ссылке** (`int &a, int &b`) — тогда функция меняет сами переменные, а не копии.
2. Обмен через временную: `t = a; a = b; b = t;`.
3. В `main` вызываю `swapValues(x, y)` — без всяких `&` в месте вызова.

```cpp
#include <iostream>

void swapValues(int &a, int &b) {   // & — работаем с самими переменными
    int t = a;
    a = b;
    b = t;
}

int main() {
    int x = 0, y = 0;
    std::cin >> x >> y;
    swapValues(x, y);
    std::cout << x << " " << y << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 4.3. Минимум и максимум сразу 🟡

*Что, если ответов сразу два — и минимум, и максимум? Тогда их удобно вернуть через параметры-ссылки.*

Напишите функцию, которая по массиву чисел находит **и** минимум, **и** максимум.
Так как значений два, верните их через параметры-ссылки. Даны `N` чисел.

**Формат ввода.** `N` (1 ≤ N ≤ 1000), затем `N` целых чисел.

**Формат вывода.** Два числа через пробел: минимум и максимум.

**Пример:**
```
Ввод
5
4 -1 7 3 7
Вывод
-1 7
```

- **Тренирует:** возврат нескольких значений из одной функции через ссылки.
- **Где пригодится:** когда результат — это пара/тройка величин (границы диапазона, координаты, «сколько и на какой позиции»).

> **Как подступиться.** Инициализируйте `mn` и `mx` **первым элементом**, а не нулём — иначе на одних отрицательных ошибётесь.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# одно число; отрицательные
5 3 1 4 1 5 => 1 5
1 42 => 42 42
3 -2 -9 -1 => -9 -1
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Прочитай числа в `vector`, а старт min/max бери с первого элемента (не с нуля).

```c++
int mn = v[0], mx = v[0];
for (int x : v) { if (x < mn) mn = x; if (x > mx) mx = x; }
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Читаю числа в `vector`.
2. Ответов два, поэтому возвращаю их через параметры-ссылки `int &mn, int &mx`.
3. Инициализирую `mn` и `mx` **первым** элементом (`v[0]`), а не нулём — иначе на одних отрицательных ошибусь.

```cpp
#include <iostream>
#include <vector>

void minMax(const std::vector<int> &v, int &mn, int &mx) {
    mn = v[0];                 // старт — с первого элемента
    mx = v[0];
    for (int x : v) {
        if (x < mn) mn = x;
        if (x > mx) mx = x;
    }
}

int main() {
    int n = 0;
    std::cin >> n;
    std::vector<int> v;
    for (int i = 0; i < n; ++i) {
        int x = 0;
        std::cin >> x;
        v.push_back(x);
    }

    int mn = 0, mx = 0;
    minMax(v, mn, mx);
    std::cout << mn << " " << mx << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 4.4. НОД рекурсией 🔴

*Рекурсия — это «сведи задачу к такой же, но поменьше». Евклид именно так и ищет НОД: `gcd(a, b) = gcd(b, a % b)`.*

Напишите **рекурсивную** функцию, вычисляющую наибольший общий делитель двух чисел
по алгоритму Евклида: `gcd(a, b) = gcd(b, a % b)`, а `gcd(a, 0) = a`.

**Формат ввода.** Два целых положительных числа через пробел, каждое до 10^9.

**Формат вывода.** Их наибольший общий делитель.

**Пример:**
```
Ввод
48 36
Вывод
12
```

- **Тренирует:** рекурсию — функция вызывает сама себя, с условием остановки.
- **Где пригодится:** сокращение дробей, работа с ритмами и периодами; сам приём «свести задачу к меньшей такой же» — фундамент рекурсии.

> **Как подступиться.** Условие остановки (`b == 0`) должно стоять **до** рекурсивного вызова. `b` уменьшается каждый шаг, поэтому рекурсия конечна.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# взаимно простые дают 1; большие числа
12 18 => 6
17 5 => 1
1000000000 8 => 8
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Классика рекурсии: база `b == 0` (ответ `a`), иначе сводим к `gcd(b, a % b)`.

```c++
long long gcd(long long a, long long b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Условие остановки — **до** рекурсивного вызова: `if (b == 0) return a;`.
2. Иначе свожу задачу к меньшей: `gcd(b, a % b)`.
3. `b` каждый шаг уменьшается, поэтому рекурсия конечна. Числа до 10⁹ держу в `long long` про запас.

```cpp
#include <iostream>

long long gcd(long long a, long long b) {
    if (b == 0) return a;          // база — до рекурсивного вызова
    return gcd(b, a % b);          // задача сводится к меньшей такой же
}

int main() {
    long long a = 0, b = 0;
    std::cin >> a >> b;
    std::cout << gcd(a, b) << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 4.5. Сколько простых в отрезке 🟡

*Главный приём всего программирования: спрятать сложное в функцию, чтобы `main` читался почти словами.*

Напишите функцию `bool isPrime(int x)`, а затем в `main` посчитайте, сколько простых
чисел лежит в отрезке `[a, b]` включительно, вызывая эту функцию.

**Формат ввода.** Два целых числа `a` и `b` (2 ≤ a ≤ b ≤ 100000) через пробел.

**Формат вывода.** Количество простых чисел в отрезке.

**Пример:**
```
Ввод
10 20
Вывод
4
```

- **Тренирует:** разбиение задачи — маленькая функция делает `main` коротким и понятным.
- **Где пригодится:** это главный приём программирования вообще — «спрятать сложное в функцию, чтобы главный код читался словами».

> **Как подступиться.** Сначала напишите `isPrime`, потом в `main` — простой цикл со счётчиком, который её вызывает.

> **Разбор примера.** Простые в [10, 20]: 11, 13, 17, 19 — четыре штуки. Задача не про новый алгоритм, а про то, как одна маленькая функция делает `main` коротким и понятным.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# границы отрезка включаются
2 10 => 4
10 20 => 4
2 2 => 1
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Вынеси проверку простоты в функцию, потом просто посчитай простые в `[a, b]`.

```c++
bool isPrime(int x) {
    if (x < 2) return false;
    for (int i = 2; i * i <= x; ++i) if (x % i == 0) return false;
    return true;
}
// в main: for (k = a..b) if (isPrime(k)) ++count;
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Сначала пишу маленькую функцию `bool isPrime(int x)` — проверку простоты.
2. В `main` остаётся простой цикл по `[a, b]` со счётчиком, который её зовёт.
3. Так `main` читается словами: «пройди по отрезку и посчитай простые», а «как проверить» спрятано в функцию.

```cpp
#include <iostream>

bool isPrime(int x) {
    if (x < 2) return false;
    for (int i = 2; i * i <= x; ++i)
        if (x % i == 0) return false;
    return true;
}

int main() {
    int a = 0, b = 0;
    std::cin >> a >> b;

    int count = 0;
    for (int k = a; k <= b; ++k)
        if (isPrime(k)) ++count;

    std::cout << count << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.

## 4.6. Совершенное число? 🟡

*Дайте проверке говорящее имя — `isPerfect` — и код станет самоочевидным. Внутри она сама переберёт делители.*

Число называют совершенным, если оно равно сумме своих делителей, меньших его самого
(например, `6 = 1 + 2 + 3`). Напишите функцию `bool isPerfect(int n)` и в `main`
напечатайте `YES` или `NO`.

**Формат ввода.** Одно целое число `n` (1 ≤ n ≤ 100000).

**Формат вывода.** `YES`, если число совершенное, иначе `NO`.

**Пример 1:**
```
Ввод
28
Вывод
YES
```
**Пример 2:**
```
Ввод
10
Вывод
NO
```

- **Тренирует:** проектирование функции-предиката, которая внутри сама перебирает делители.
- **Где пригодится:** любой критерий-проверка (`isValid`, `isAvailable`, `isPerfect`) — читаемый `main` строится из таких функций.

> **Как подступиться.** Внутри функции сложите делители от 1 до `n/2` (или до `√n` парами) и сравните сумму с `n`. Единицу к совершенным не относят.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# 6 и 28 совершенные; 12 и 1 — нет
6 => YES
28 => YES
12 => NO
1 => NO
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Сложи все делители, меньшие самого числа; равна сумма — число совершенное.

```c++
int sum = 0;
for (int d = 1; d <= n / 2; ++d) if (n % d == 0) sum += d;
// совершенное, если sum == n
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Проверку упаковываю в `bool isPerfect(int n)`.
2. Внутри складываю делители от 1 до `n/2` и сравниваю сумму с `n`.
3. Возвращаю `sum == n`. Для единицы сумма делителей — `0`, а `0 != 1`, поэтому она не совершенна.

```cpp
#include <iostream>

bool isPerfect(int n) {
    int sum = 0;
    for (int d = 1; d <= n / 2; ++d)
        if (n % d == 0) sum += d;
    return sum == n;
}

int main() {
    int n = 0;
    std::cin >> n;
    std::cout << (isPerfect(n) ? "YES" : "NO") << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 4.7. Високосный год — функцией 🟡

*Правило с исключениями (400, но не 100…) легко забыть. Соберите его один раз в `isLeapYear` — и зовите где угодно.*

Напишите функцию `bool isLeapYear(int year)`. Год високосный, если делится на 4, но
не на 100 — кроме годов, кратных 400 (они високосные). Прочитайте год и напечатайте
`YES` или `NO`.

**Формат ввода.** Одно целое число — год.

**Формат вывода.** `YES`, если год високосный, иначе `NO`.

**Пример 1:**
```
Ввод
2000
Вывод
YES
```
**Пример 2:**
```
Ввод
1900
Вывод
NO
```

- **Тренирует:** упаковку непростого логического условия в функцию с говорящим именем.
- **Где пригодится:** календари, даты, финансовые периоды — `isLeapYear` пишут один раз и зовут везде.

> **Как подступиться.** Всё правило умещается в одно выражение с `&&`, `||` и остатками.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# 1900 не високосный, 2000 — да (кратен 400)
2000 => YES
1900 => NO
2024 => YES
2023 => NO
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Весь критерий високосности — одна булева формула.

```c++
bool leap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Всё правило умещается в одно логическое выражение.
2. Год високосный, если делится на 4 и **не** на 100 — **или** делится на 400.
3. Прячу это в `bool isLeapYear(int year)` и зову из `main`.

```cpp
#include <iostream>

bool isLeapYear(int year) {
    return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
}

int main() {
    int year = 0;
    std::cin >> year;
    std::cout << (isLeapYear(year) ? "YES" : "NO") << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 4.8. Степень рекурсией 🔴

*Степень через саму себя: `base^exp` — это `base`, умноженное на `base^(exp−1)`. Осталось не забыть, где рекурсия остановится.*

Напишите **рекурсивную** функцию `long long power(int base, int exp)`, возвращающую
`base` в степени `exp` (считаем `exp ≥ 0`, а `base^0 = 1`).

**Формат ввода.** Два целых числа: `base` и `exp` (0 ≤ exp ≤ 62) через пробел.

**Формат вывода.** Значение `base` в степени `exp`.

**Пример:**
```
Ввод
2 10
Вывод
1024
```

- **Тренирует:** рекурсию с базовым случаем и уменьшающимся параметром.
- **Где пригодится:** рекурсия — язык деревьев, разбора выражений, «раздели и властвуй».

> **Как подступиться.** Базовый случай `exp == 0` возвращает `1`; иначе `base` умножить на `power(base, exp − 1)`.

> **Бонус.** Сделайте «быстрое возведение»: при чётном `exp` считайте `power(base, exp/2)` один раз и возведите в квадрат — так шагов станет не `exp`, а `log₂(exp)`.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# степень 0 равна 1; 2^62 у границы long long
2 10 => 1024
5 0 => 1
2 62 => 4611686018427387904
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Рекурсия по показателю: база `exp == 0` даёт 1, шаг умножает на `base` и уменьшает `exp`.

```c++
long long power(int base, int exp) {
    if (exp == 0) return 1;
    return base * power(base, exp - 1);
}
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Базовый случай **до** рекурсии: `if (exp == 0) return 1;`.
2. Шаг: `base * power(base, exp − 1)` — `exp` убывает и дойдёт до нуля.
3. Возвращаемый тип `long long`: `2⁶²` в `int` не поместится.

```cpp
#include <iostream>

long long power(int base, int exp) {
    if (exp == 0) return 1;                  // база
    return base * power(base, exp - 1);      // шаг: exp убывает
}

int main() {
    int base = 0, exp = 0;
    std::cin >> base >> exp;
    std::cout << power(base, exp) << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

# Подсказки

> **Мало подсказки?** Откройте теорию темы: [раздел справочника](../ref/04-funkcii.md).

<details>
<summary>4.1 — Факториал функцией</summary>

- Сигнатура: `long long factorial(int n)`. Внутри — цикл `for (int i = 1; i <= n; ++i) result *= i;`.
- Начальное значение `result = 1` (не 0!). Для `n == 0` цикл не выполнится и вернётся `1` — как и надо.
</details>

<details>
<summary>4.2 — Обмен по ссылке</summary>

- `void swapValues(int &a, int &b) { int t = a; a = b; b = t; }`.
- Амперсанд `&` в параметре означает «работать с самой переменной, а не с копией».
- В `main`: `swapValues(x, y);` — без всяких `&` в месте вызова.
</details>

<details>
<summary>4.3 — Минимум и максимум сразу</summary>

- Читайте числа в `std::vector<int>` (или сразу обновляйте min/max по ходу чтения).
- Функция: `void minMax(const std::vector<int> &v, int &mn, int &mx)`.
- Инициализируйте `mn` и `mx` первым элементом (`v[0]`), а не нулём — иначе на одних отрицательных или одних больших числах ошибётесь.
</details>

<details>
<summary>4.4 — НОД рекурсией</summary>

- `int gcd(int a, int b) { if (b == 0) return a; return gcd(b, a % b); }`.
- Рекурсия сама остановится: `b` с каждым шагом уменьшается и рано или поздно станет 0.
- Числа до 10^9 помещаются в `int`, но `long long` тоже подойдёт и надёжнее.
</details>

<details>
<summary>4.5 — Сколько простых в отрезке</summary>

- Сначала функция: `bool isPrime(int x)` — вернуть `false` для `x < 2`, иначе перебирать делители, пока `i * i <= x`.
- В `main` — цикл `for (int k = a; k <= b; ++k) if (isPrime(k)) ++count;`.
- Смысл задачи: `main` читается как «пройди по отрезку и посчитай простые», а «как проверить простоту» спрятано в функции.
</details>

<details>
<summary>4.6 — Совершенное число</summary>

- `bool isPerfect(int n)`: заведите `int sum = 0;` и переберите делители `for (int d = 1; d <= n / 2; ++d) if (n % d == 0) sum += d;`.
- Верните `sum == n`. Единица не совершенна: её сумма делителей (0) не равна 1.
- Быстрее — перебор до `√n` парами, но и `n/2` укладывается в лимит.
</details>

<details>
<summary>4.7 — Високосный год функцией</summary>

- Одно выражение: `return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);`.
- Разберите на примерах: `2000` (кратно 400 → YES), `1900` (кратно 100, но не 400 → NO), `2024` (кратно 4, не 100 → YES).
</details>

<details>
<summary>4.8 — Степень рекурсией</summary>

- Базовый случай **до** рекурсии: `if (exp == 0) return 1;`.
- Шаг: `return base * power(base, exp - 1);`. `exp` убывает и дойдёт до 0.
- Возвращаемый тип `long long`: `2^62` в `int` не влезет.
</details>

## Проверьте себя (мини тест-план)

- **4.1:** `n = 0` → `1`; `n = 20` → должно быть огромным (проверьте `long long`).
- **4.2:** одинаковые числа (`5 5` → `5 5`); убедитесь, что вариант без `&` действительно не работает.
- **4.3:** `N = 1` (min == max); все отрицательные; все одинаковые.
- **4.4:** `gcd(17, 5)` → `1` (взаимно простые); `gcd(100, 100)` → `100`.
- **4.6:** `6` → `YES`, `28` → `YES`, `1` → `NO`, `12` → `NO`.
- **4.7:** `2000` → `YES`, `1900` → `NO`, `2024` → `YES`, `2023` → `NO`.
- **4.8:** `exp = 0` → `1`; `2 10` → `1024`; проверьте `long long` на `2 60`.
