в C++ удобен — забудьте про `char[]` из старых учебников.

## Чему вы здесь научитесь

- Перебирать символы строки (`for (char c : s)`) и приводить регистр.
- Работать с индексами «с двух концов» (палиндром, разворот).
- Искать символ (`find`) и вырезать часть (`substr`).
- Читать строку целиком через `getline` и делить её на слова.

## Где это пригодится

Разбор текста — это ввод пользователя, парсинг конфигов (`ключ=значение`), обработка
CSV, поиск в логах, нормализация имён. Практически любая программа где-то трогает
строки. Приёмы «два указателя с краёв» и «найти разделитель и разрезать» универсальны
далеко за пределами строк.

## 5.1. Гласные в слове 🟢

*Пройтись по строке символ за символом — с этого начинается любой разбор текста. Здесь просто считаем гласные.*

`u`) в любом регистре.

**Формат вывода.** Количество гласных.

**Пример:**
```

Вывод
```

- **Где пригодится:** любой посимвольный анализ текста: подсчёт, фильтрация, статистика по буквам.

> **Как подступиться.** Пройдите по каждому символу; приведите к нижнему регистру; сравните с набором гласных.

**Формат ввода.** Одно слово без пробелов, до 100 символов.

**Формат вывода.** То же слово, записанное в обратном порядке.

**Пример:**
```
Ввод

Вывод

```

- **Тренирует:** обход строки с конца или готовый `std::reverse`.
- **Где пригодится:** разворот данных, проверка симметрии, база для более сложных строковых задач.

> **Как подступиться.** Есть два пути — `std::reverse` или ручной цикл с конца. Попробуйте оба.

> **Осторожно.** При ручном обходе индекс держите в `int` (`i >= 0`), иначе для беззнакового типа условие всегда истинно и цикл не остановится.

## 5.3. Палиндром? 🟡

*«Два указателя»: один идёт слева, другой справа, встречаются в центре. Разошлись символы — не палиндром.*

Определите, читается ли слово одинаково слева направо и справа налево.

**Формат ввода.** Одно слово без пробелов, до 100 символов.

**Формат вывода.** `YES`, если это палиндром, иначе `NO`.

**Пример 1:**
```
Ввод
level
Вывод
YES
```
**Пример 2:**
```
Ввод
world
Вывод
NO
```

- **Тренирует:** приём «два указателя» — движение с двух краёв к центру.
- **Где пригодится:** проверка симметрии, сравнение с зеркальной копией; «два указателя» — базовый алгоритмический приём для массивов.

> **Как подступиться.** Сравнивайте `word[left]` и `word[right]`, сдвигая границы к центру; расхождение — сразу `NO`.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# один символ — это палиндром
level => YES
hello => NO
a => YES
```

```hints
Идея: Сравнивайте символы парами: первый с последним, второй с предпоследним — и так к центру. Первое расхождение — сразу ответ.
План: Два индекса: левый с начала, правый — сразу за концом. Пока они не встретились, сравнивайте `word[left]` и `word[right - 1]` и сдвигайте оба к центру.
Ключ: `if (word[left] != word[right - 1]) { palindrome = false; break; }`
```

> Не выходит и с подсказками? Решение с разбором — [внизу страницы](#решения-с-разбором). Открывай его, только когда правда застрял.

## 5.4. Ключ и значение 🟡

*Найти `=` и разрезать строку надвое — так читаются конфиги, ссылки и всё в формате «ключ=значение».*

Дана строка вида `имя=значение` (без пробелов, ровно один знак `=`). Напечатайте имя
и значение на отдельных строках.

**Формат ввода.** Строка `ключ=значение`, например `count=42`.

**Формат вывода.** Две строки: сначала часть до `=`, потом часть после.

**Пример:**
```
Ввод
count=42
Вывод
count
42
```

- **Тренирует:** поиск разделителя (`find`) и разрезание строки (`substr`).
- **Где пригодится:** разбор конфигов (`.ini`, `.env`), параметров URL, CSV, любых форматов «поле=значение».

> **Как подступиться.** Найдите позицию `=`, возьмите часть до неё и часть после.

```hints
Идея: Всё, что до `=`, — ключ, всё после — значение. Значит, достаточно узнать, где стоит `=`.
План: Найдите позицию знака; первую часть возьмите с нуля длиной «позиция», вторую — с позиции + 1 до конца. Печатайте на разных строках.
Ключ: `std::size_t pos = s.find('=');`
```

## 5.5. Сколько слов в предложении 🔴

*`cin >> s` схватит только одно слово. Чтобы получить всю строку с пробелами, зовите `getline`.*

Дана строка с несколькими словами, разделёнными пробелами. Посчитайте количество
слов. Слова могут быть разделены несколькими пробелами подряд, а в начале и конце
строки пробелы тоже возможны.

**Формат ввода.** Одна строка (может содержать пробелы), до 1000 символов.

**Формат вывода.** Количество слов.

**Пример:**
```
Ввод
  привет   мир  как дела
Вывод
4
```

- **Тренирует:** чтение целой строки (`getline`) и разбиение на слова через поток.
- **Где пригодится:** подсчёт слов в тексте, токенизация ввода, обработка CSV с «грязными» пробелами.

> **Как подступиться.** `cin >> s` прочитает лишь одно слово — нужен `getline` на всю строку, а затем разбор.

> **Осторожно.** Здесь `std::cin >> s` не годится — он прочитает только одно слово. Нужна вся строка.

```hints
Идея: `cin >> s` читает одно слово, а нужна вся строка. А дальше «слово» — это то, что поток отдаёт при чтении `>>`: лишние пробелы он сам пропускает.
План: Прочитайте строку целиком через `getline`, заверните её в строковый поток и читайте из него слова в цикле, считая каждое.
Ключ: `std::istringstream iss(line); while (iss >> word) ++count;`
```

## 5.6. Инвертировать регистр 🟡

*Хотите поменять строку прямо на месте? Пройдитесь по ней по ссылке — `for (char &c : s)` — и меняйте каждый символ.*

Дана строка. Напечатайте её, поменяв регистр каждой буквы на противоположный:
строчные — в заглавные, заглавные — в строчные. Прочие символы не меняются.

**Формат ввода.** Одна строка (латиница, цифры, пробелы), до 200 символов.

**Формат вывода.** Та же строка с инвертированным регистром букв.

**Пример:**
```
Ввод
Hello World 42
Вывод
hELLO wORLD 42
```

- **Тренирует:** изменение символов строки «на месте» (`for (char &c : s)`) и функции `std::toupper`/`std::tolower`.
- **Где пригодится:** нормализация ввода, «шуточные» фильтры, преобразование текста по правилу.

> **Как подступиться.** Читайте всю строку через `getline`. Перебирайте символы **по ссылке**; для каждой буквы применяйте `toupper` или `tolower` в зависимости от её текущего регистра (`std::isupper`/`std::islower`).

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# цифры и пробелы не меняются
Hello World 123 => hELLO wORLD 123
ABCabc => abcABC
```

```hints
Идея: Менять символы строки можно прямо на месте, если перебирать их по ссылке. Для каждой буквы решаем: сейчас заглавная — делаем строчной, и наоборот.
План: Прочитайте строку целиком. В цикле `for (char &c : line)` проверьте регистр через `isupper`/`islower` и замените символ противоположным; цифры и пробелы не трогайте.
Ключ: `if (std::isupper(uc)) c = static_cast<char>(std::tolower(uc));`
```

## 5.7. Самый частый символ 🟡

*Двадцать шесть счётчиков — вот и вся частотная таблица. А идя по алфавиту, вы бесплатно решаете ничью в пользу меньшей буквы.*

Дана строка из строчных латинских букв. Напечатайте символ, который встречается чаще
всех. Если таких несколько, напечатайте наименьший по алфавиту.

**Формат ввода.** Одно слово из строчных латинских букв, до 1000 символов.

**Формат вывода.** Один символ — самый частый (при равенстве — наименьший).

**Пример:**
```
Ввод
banana
Вывод
a
```

- **Тренирует:** подсчёт частот и аккуратный разбор ничьей (правило выбора при равенстве).
- **Где пригодится:** статистика по данным, мода в выборке, простое сжатие, анализ логов.

> **Как подступиться.** Заведите массив счётчиков на 26 букв (`int cnt[26] = {}`), пройдитесь по строке, увеличивая `cnt[c - 'a']`. Затем найдите индекс с наибольшим счётчиком; перебирая от `'a'` к `'z'`, вы автоматически получите наименьший при равенстве.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# при равной частоте — наименьший символ
banana => a
abcabc => a
z => z
```

```hints
Идея: Букв всего 26 — значит, счётчики поместятся в обычный массив, где индекс — «номер буквы». Перебор от `a` к `z` сам решит ничью.
План: Пройдите строку, увеличивая счётчик `c - 'a'`. Потом найдите индекс с наибольшим счётчиком, обновляя его только при строго большем значении.
Ключ: `int cnt[26] = {}; for (char c : s) ++cnt[c - 'a'];`
```

## 5.9. Строка боя 🔗🟡

*Второе звено «Журнала забегов»: бой приходит строкой `ключ=значение` в любом порядке — разбираем её и зовём урон из 4.9.*

Дана строка из полей `hero=…`, `atk=…`, `def=…`, `roll=…` через пробелы, **в любом порядке**
(лишние пробелы возможны). Посчитайте урон по правилу из задачи 4.9 и напечатайте `Имя: урон`.
Если какого-то поля нет — напечатайте `ошибка: нет <поле>` для первого отсутствующего в порядке
`hero`, `atk`, `def`, `roll`.

**Формат ввода.** Одна строка.

**Формат вывода.** `Имя: урон` или сообщение об ошибке.

**Пример:**
```
Ввод
roll=18 hero=Ари def=3 atk=10
Вывод
Ари: 14
```

- **Тренирует:** разбор строки на поля (`istringstream`, `find`, `substr`) и сборку с функциями прошлой темы.
- **Где пригодится:** параметры командной строки, конфиги, сетевые сообщения «ключ=значение» в любом порядке.

> **Как подступиться.** Слова отдаст `istringstream`; каждое разрежьте по `=`. Где хранить найденные поля, решите сами (`map` из темы 6 тоже подойдёт, но хватит и четырёх переменных с флагами).

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
roll=18 hero=Ари def=3 atk=10 => Ари: 14
hero=Bo atk=10 def=3 roll=5 => Bo: 7
hero=Ари atk=10 roll=4 => ошибка: нет def
   hero=Кай   atk=2 def=9 roll=20    => Кай: 2
atk=5 def=1 roll=1 => ошибка: нет hero
```


## 5.10. Сжатие строки 🔥

*Челлендж темы: повторы подряд заменяем числом — так работают простейшие архиваторы и формат картинок BMP-RLE.*

Дана строка из латинских букв. Замените каждую серию одинаковых букв **подряд** на букву
и длину серии; если серия из одной буквы — пишите только букву. Например,
`aaabccdddd` → `a3bc2d4`.

**Формат ввода.** Одно слово (латиница), до 1000 символов.

**Формат вывода.** Сжатая строка.

**Пример:**
```
Ввод

Вывод

```

- **Тренирует:** проход по строке с «окном» из текущего символа и счётчика серии; сборку ответа в `std::string`.

<summary>Полное решение 5.3 — Палиндром</summary>

Ход мысли по шагам:

1. Приём «два указателя»: `left` идёт от начала, `right` — от конца.
2. Пока указатели не встретились, сравниваю пару `word[left]` и `word[right − 1]`; расхождение — сразу не палиндром.
3. Дошёл до центра без расхождений — палиндром. `right` держу «за последним символом», поэтому индексы беззнаковые и цикл безопасен.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string word;
    std::cin >> word;

    bool palindrome = true;
    for (std::size_t left = 0, right = word.size(); left + 1 < right; ++left, --right) {
        if (word[left] != word[right - 1]) {   // сравниваем края
            palindrome = false;
            break;
        }
    }
    std::cout << (palindrome ? "YES" : "NO") << "\n";
    return 0;
}
```

```cpp
    std::cout << (word == reversed ? "YES" : "NO") << "\n";

}
```

> **Сравнение.** Копия с `rbegin()/rend()` — самая короткая и понятная запись. Но она создаёт вторую строку и всегда проходит её целиком, а «два указателя» останавливаются на первом расхождении и не тратят памяти. Для слова разницы нет; для гигабайтного файла — есть.

<summary>Полное решение 5.6 — Инвертировать регистр</summary>

Ход мысли по шагам:

```cpp
#include <iostream>
#include <string>
#include <cctype>

        unsigned char uc = static_cast<unsigned char>(c);

            c = static_cast<char>(std::tolower(uc));
        else if (std::islower(uc))
            c = static_cast<char>(std::toupper(uc));
    }

    std::cout << line << "\n";
    return 0;
}
```

Ход мысли по шагам:

```cpp
    int best = 0;
    for (int i = 1; i < 26; ++i)
        if (cnt[i] > cnt[best]) best = i;   // строгое > даёт меньшую букву при равенстве

    std::cout << static_cast<char>('a' + best) << "\n";
    return 0;
}
```

<summary>Полное решение 5.9 — Строка боя</summary>

Разбор отделён от расчёта: сначала собираем поля в `map`, затем проверяем, что всё на месте, и только потом зовём `damage` — ту же функцию, что в 4.9.

```cpp
#include <algorithm>
#include <iostream>
#include <map>
#include <sstream>
#include <string>

int baseDamage(int atk, int def) { return std::max(1, atk - def); }
bool isCrit(int roll) { return roll >= 18; }
int damage(int atk, int def, int roll) {
    if (roll == 1) return 0;
    int d = baseDamage(atk, def);
    return isCrit(roll) ? d * 2 : d;
}

int main() {
    std::string line;
    std::getline(std::cin, line);
    std::istringstream iss(line);
    std::map<std::string, std::string> field;
    std::string w;
    while (iss >> w) {
        auto pos = w.find('=');
        if (pos != std::string::npos) field[w.substr(0, pos)] = w.substr(pos + 1);
    }
    for (const char *key : {"hero", "atk", "def", "roll"})
        if (!field.count(key)) {
            std::cout << "ошибка: нет " << key << "\n";
            return 0;
        }
    int dmg = damage(std::stoi(field["atk"]), std::stoi(field["def"]), std::stoi(field["roll"]));
    std::cout << field["hero"] << ": " << dmg << "\n";
    return 0;
```

<summary>Полное решение 5.10 — Сжатие строки</summary>

Два индекса: `i` — начало серии, `j` — первый символ после неё. Длина серии — `j − i`. Ответ собираем в строку, а не печатаем по кусочку: так его легко проверить или вернуть из функции.

```cpp
#include <iostream>
#include <string>

std::string compress(const std::string &s) {
    std::string out;
    std::size_t i = 0;
    while (i < s.size()) {
        std::size_t j = i;
        while (j < s.size() && s[j] == s[i]) ++j;   // j — первый символ после серии
        out += s[i];
        if (j - i > 1) out += std::to_string(j - i);
        i = j;
    }
    return out;
}

int main() {
    std::string s;
    std::cin >> s;
    std::cout << compress(s) << "\n";
    return 0;
}
```

**Другой подход — один проход со счётчиком**

```cpp
        out += s[i - 1];

}
```

> **Сравнение.** Один проход со счётчиком короче, но хитрее: граница `i <= s.size()` нужна, чтобы «закрыть» последнюю серию, — именно тут чаще всего ошибаются. Два индекса длиннее, зато каждая серия видна целиком.
</details>

## Проверьте себя (мини тест-план)

- **5.1:** слово без гласных (`bcd` → `0`); все заглавные.
- **5.2:** слово из одной буквы; слово-палиндром (`level` → `level`).
- **5.3:** одна буква (палиндром); чётная длина (`abba` → `YES`, `abca` → `NO`).
- **5.4:** пустое значение (`x=` → `x` и пустая строка); значение с цифрами.
- **5.5:** пустая строка (`0`); много пробелов подряд; пробелы по краям.
- **5.6:** только цифры и пробелы (не меняются); смешанный регистр.
- **5.7:** все буквы разные (ответ — `a`); явный лидер (`aaab` → `a`); ничья (`ab` → `a`).
- **5.8:** одно слово (выводится как есть); лишние пробелы между словами схлопываются.

**Тема закрыта,** когда «найти и разрезать» и «пройти по символам» вы делаете не подглядывая в справочник.
