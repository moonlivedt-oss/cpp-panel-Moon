# Тема 5. Строки

Текст — это данные, с которыми ты будешь работать чаще всего: имена, логины,
команды, строки файла. Здесь ты научишься перебирать символы, искать подстроку,
разрезать строку на части и читать строку целиком (с пробелами). `std::string`
в C++ удобен — забудь про `char[]` из старых учебников.

> 📖 **Опирается на раздел 10 справочника** ([теория в справочнике](../ref/05-stroki.md)).
> Там про `std::string`, поиск, `substr`, разбиение на слова и `getline`.

> 🔗 **В целых программах:** «Проверка пароля» (`../examples/09-parol.md`) — перебор символов
> и `<cctype>`; «Анализ текста» (`../examples/03-analiz-teksta.md`) — разбор строки на слова.

## Чему ты здесь научишься

- Перебирать символы строки (`for (char c : s)`) и приводить регистр.
- Работать с индексами «с двух концов» (палиндром, разворот).
- Искать символ (`find`) и вырезать часть (`substr`).
- Читать строку целиком через `getline` и делить её на слова.

## Где это пригодится

Разбор текста — это ввод пользователя, парсинг конфигов (`ключ=значение`),
обработка CSV, поиск в логах, нормализация имён. Практически любая программа
где-то трогает строки. Приёмы «два указателя с краёв» и «найти разделитель и
разрезать» — универсальны далеко за пределами строк.

---

## 5.1. Гласные в слове 🟢

Дано слово из латинских букв. Посчитайте, сколько в нём гласных (`a`, `e`, `i`,
`o`, `u`) в любом регистре.

**Формат ввода.** Одно слово без пробелов (латиница), длиной до 100 символов.

**Формат вывода.** Количество гласных.

**Пример:**
```
Ввод
Programming
Вывод
3
```

**Что тренирует:** перебор символов строки, приведение регистра, счётчик по условию.
**Где пригодится:** любой посимвольный анализ текста: подсчёт, фильтрация, статистика по буквам.
**Как подступиться:** пройди по каждому символу; приведи к нижнему регистру; сравни с набором гласных.

---

## 5.2. Переворот строки 🟢

Напечатайте слово задом наперёд.

**Формат ввода.** Одно слово без пробелов, до 100 символов.

**Формат вывода.** То же слово, записанное в обратном порядке.

**Пример:**
```
Ввод
hello
Вывод
olleh
```

**Что тренирует:** обход строки с конца или готовый `std::reverse`.
**Где пригодится:** разворот данных, проверка симметрии, база для более сложных строковых задач.
**Как подступиться:** два пути — `std::reverse` или ручной цикл с конца. Попробуй оба.

> При ручном обходе индекс держи в `int` (`i >= 0`), иначе для беззнакового типа
> условие всегда истинно и цикл не остановится.

---

## 5.3. Палиндром? 🟡

Определите, читается ли слово одинаково слева направо и справа налево.

**Формат ввода.** Одно слово без пробелов, до 100 символов.

**Формат вывода.** `YES`, если это палиндром, иначе `NO`.

**Пример 1:**
```
Ввод
level
Вывод
YES
```
**Пример 2:**
```
Ввод
world
Вывод
NO
```

**Что тренирует:** приём «два указателя» — движемся с двух краёв к центру.
**Где пригодится:** проверка симметрии, сравнение с зеркальной копией; «два указателя» — базовый алгоритмический приём для массивов.
**Как подступиться:** сравнивай `word[left]` и `word[right]`, сдвигая границы к центру; расхождение — сразу `NO`.

---

## 5.4. Ключ и значение 🟡

Дана строка вида `имя=значение` (без пробелов, ровно один знак `=`).
Напечатайте имя и значение на отдельных строках.

**Формат ввода.** Строка `ключ=значение`, например `count=42`.

**Формат вывода.** Две строки: сначала часть до `=`, потом часть после.

**Пример:**
```
Ввод
count=42
Вывод
count
42
```

**Что тренирует:** поиск разделителя (`find`) и разрезание строки (`substr`).
**Где пригодится:** разбор конфигов (`.ini`, `.env`), параметров URL, CSV, любых форматов «поле=значение».
**Как подступиться:** найди позицию `=`, возьми часть до неё и часть после.

---

## 5.5. Сколько слов в предложении 🔴

Дана строка с несколькими словами, разделёнными пробелами. Посчитайте
количество слов. Слова могут быть разделены несколькими пробелами подряд,
а в начале и конце строки пробелы тоже возможны.

**Формат ввода.** Одна строка (может содержать пробелы), до 1000 символов.

**Формат вывода.** Количество слов.

**Пример:**
```
Ввод
  привет   мир  как дела
Вывод
4
```

**Что тренирует:** чтение целой строки (`getline`) и разбиение на слова через поток.
**Где пригодится:** подсчёт слов в тексте, токенизация ввода, обработка CSV с «грязными» пробелами.
**Как подступиться:** `cin >> s` прочитает лишь одно слово — нужен `getline` на всю строку, а затем разбор.

> Здесь `std::cin >> s` не годится — он прочитает только одно слово. Нужна вся строка.

---

## 5.6. В верхний регистр 🟢

Дано слово. Напечатайте его целиком заглавными буквами.

**Формат ввода.** Одно слово (латиница), до 100 символов.

**Формат вывода.** То же слово заглавными буквами.

**Пример:**
```
Ввод
Hello
Вывод
HELLO
```

**Что тренирует:** изменение символов строки «на месте» (`for (char &c : s)`) и `std::toupper`.
**Где пригодится:** нормализация ввода (логины, коды), сравнение без учёта регистра.
**Как подступиться:** перебирай символы по ссылке (`&`), каждому присваивай его версию в верхнем регистре.

---

## 5.7. Сколько раз встречается символ 🟡

Даны слово и один символ. Напечатайте, сколько раз символ встречается в слове.

**Формат ввода.** Слово (без пробелов) и символ, через пробел.

**Формат вывода.** Количество вхождений символа.

**Пример:**
```
Ввод
banana a
Вывод
3
```

**Что тренирует:** перебор символов и сравнение с заданным.
**Где пригодится:** поиск, подсчёт разделителей, простая статистика по тексту.
**Как подступиться:** пройди по символам и увеличивай счётчик, когда символ совпал с искомым.

---

## 5.8. Развернуть слова в предложении 🔴

Дана строка из слов, разделённых пробелами. Напечатайте слова в обратном порядке,
разделяя одним пробелом.

**Формат ввода.** Одна строка со словами (латиница), до 1000 символов.

**Формат вывода.** Те же слова в обратном порядке, через один пробел.

**Пример:**
```
Ввод
the quick brown fox
Вывод
fox brown quick the
```

**Что тренирует:** `getline`, разбиение на слова и работу с `vector<string>`.
**Где пригодится:** обработка текста, переворот порядка элементов, разбор команд.
**Как подступиться:** собери слова в `vector`, затем разверни его и печатай по порядку.

# Подсказки

> 📖 Мало подсказки? Открой теорию темы: [раздел справочника](../ref/05-stroki.md).

<details>
<summary>5.1 — Гласные в слове</summary>

- Перебирай символы: `for (char c : word) { ... }`.
- Приведи к нижнему регистру для проверки: `char lc = std::tolower(static_cast<unsigned char>(c));`
  (из `<cctype>`), потом сравнивай `lc` с `'a'`, `'e'`, `'i'`, `'o'`, `'u'`.
- На каждой гласной увеличивай счётчик.
</details>

<details>
<summary>5.2 — Переворот строки</summary>

- Способ 1: `std::reverse(word.begin(), word.end());` из `<algorithm>`, потом вывести.
- Способ 2 (вручную): печатай символы с конца — `for (int i = word.size() - 1; i >= 0; --i) std::cout << word[i];`.
  Осторожно: индекс должен быть знаковым (`int`), иначе `i >= 0` для беззнакового всегда истинно.
</details>

<details>
<summary>5.3 — Палиндром</summary>

- Сравнивай пару символов «с краёв к центру»: `left = 0`, `right = size() - 1`.
- Пока `left < right`: если `word[left] != word[right]` — это не палиндром (`NO`), иначе сдвигай
  `++left; --right;`. Дошёл до центра без расхождений — `YES`.
- Или просто: сделай копию, переверни её и сравни со строкой (`==`).
</details>

<details>
<summary>5.4 — Ключ и значение</summary>

- Найди позицию знака: `std::size_t pos = s.find('=');`.
- Ключ — всё до неё: `s.substr(0, pos)`. Значение — всё после: `s.substr(pos + 1)`.
- Печатай каждую часть с новой строки.
</details>

<details>
<summary>5.5 — Сколько слов</summary>

- Читай всю строку: `std::string line; std::getline(std::cin, line);`.
- Самый простой способ посчитать слова — отдать строку в поток: `std::istringstream iss(line);`
  (из `<sstream>`), потом `std::string w; while (iss >> w) ++count;`. Оператор `>>` сам
  пропускает лишние пробелы.
</details>

<details>
<summary>5.6 — В верхний регистр</summary>

- Перебирай **по ссылке**, чтобы менять символы: `for (char &c : word)`.
- Каждому: `c = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));` (из `<cctype>`).
- Приведения нужны из-за того, что `toupper` работает с `int`.
</details>

<details>
<summary>5.7 — Сколько раз встречается символ</summary>

- Читай `std::string word; char target;` и `std::cin >> word >> target;`.
- Цикл: `for (char c : word) if (c == target) ++count;`.
</details>

<details>
<summary>5.8 — Развернуть слова</summary>

- Читай всю строку: `std::getline(std::cin, line);`.
- Разбей на слова через `std::istringstream` и собери в `std::vector<std::string>`.
- `std::reverse(words.begin(), words.end());`, затем печатай слова через пробел (без пробела после последнего).
</details>

## Проверь себя (мини тест-план)

- **5.1:** слово без гласных (`rhythm` → как минимум проверь `0` для `bcd`); все заглавные.
- **5.2:** слово из одной буквы; слово-палиндром (`level` → `level`).
- **5.3:** одна буква (палиндром); чётная длина (`abba` → `YES`, `abca` → `NO`).
- **5.4:** пустое значение (`x=` → `x` и пустая строка); значение с цифрами.
- **5.5:** пустая строка (`0`); много пробелов подряд; пробелы по краям.
- **5.6:** уже заглавное слово (`HI` → `HI`); слово из одной буквы.
- **5.7:** символа нет в слове (`0`); символ идёт подряд (`aaa a` → `3`).
- **5.8:** одно слово (выводится как есть); лишние пробелы между словами схлопываются.
