## Чему вы здесь научитесь

- Перебирать символы строки (`for (char c : s)`) и приводить регистр.
- Работать с индексами «с двух концов» (палиндром, разворот).
- Искать символ (`find`) и вырезать часть (`substr`).
- Читать строку целиком через `getline` и делить её на слова.

## Где это пригодится

Разбор текста — это ввод пользователя, парсинг конфигов (`ключ=значение`), обработка
CSV, поиск в логах, нормализация имён. Практически любая программа где-то трогает
строки. Приёмы «два указателя с краёв» и «найти разделитель и разрезать» универсальны
далеко за пределами строк.

## 5.1. Гласные в слове 🟢

*Пройтись по строке символ за символом — с этого начинается любой разбор текста. Здесь просто считаем гласные.*

Дано слово из латинских букв. Посчитайте, сколько в нём гласных (`a`, `e`, `i`, `o`,
`u`) в любом регистре.

**Формат ввода.** Одно слово без пробелов (латиница), длиной до 100 символов.

**Формат вывода.** Количество гласных.

**Пример:**
```

Вывод

- **Где пригодится:** любой посимвольный анализ текста: подсчёт, фильтрация, статистика по буквам.

> **Как подступиться.** Пройдите по каждому символу; приведите к нижнему регистру; сравните с набором гласных.

<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Иду по каждому символу слова через `for (char c : word)`.
2. Привожу символ к нижнему регистру, чтобы `A` и `a` считались одинаково. `std::tolower` кормлю через `unsigned char` — так безопаснее.
3. Сравниваю с набором гласных и считаю совпадения.

#include <iostream>

    std::cin >> word;

    int count = 0;

        if (lc == 'a' || lc == 'e' || lc == 'i' || lc == 'o' || lc == 'u')
            ++count;
    }
    std::cout << count << "\n";
    return 0;
}
```

## 5.3. Палиндром? 🟡

*«Два указателя»: один идёт слева, другой справа, встречаются в центре. Разошлись символы — не палиндром.*

Определите, читается ли слово одинаково слева направо и справа налево.

**Формат ввода.** Одно слово без пробелов, до 100 символов.

**Формат вывода.** `YES`, если это палиндром, иначе `NO`.

**Пример 1:**
```
Ввод
level
Вывод
YES
```
**Пример 2:**
```
Ввод
world
Вывод
NO
```

- **Тренирует:** приём «два указателя» — движение с двух краёв к центру.
- **Где пригодится:** проверка симметрии, сравнение с зеркальной копией; «два указателя» — базовый алгоритмический приём для массивов.

> **Как подступиться.** Сравнивайте `word[left]` и `word[right]`, сдвигая границы к центру; расхождение — сразу `NO`.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# один символ — это палиндром
level => YES
hello => NO
a => YES
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Иди двумя индексами навстречу — с начала и с конца — и сравнивай символы.

```c++
bool ok = true;
for (std::size_t l = 0, r = word.size(); l + 1 < r; ++l, --r)
    if (word[l] != word[r - 1]) { ok = false; break; }
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Приём «два указателя»: `left` идёт от начала, `right` — от конца.
2. Пока указатели не встретились, сравниваю пару `word[left]` и `word[right − 1]`; расхождение — сразу не палиндром.
3. Дошёл до центра без расхождений — палиндром. `right` держу «за последним символом», поэтому индексы беззнаковые и цикл безопасен.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string word;
    std::cin >> word;

    bool palindrome = true;
    for (std::size_t left = 0, right = word.size(); left + 1 < right; ++left, --right) {
        if (word[left] != word[right - 1]) {   // сравниваем края
            palindrome = false;
            break;
        }
    }
    std::cout << (palindrome ? "YES" : "NO") << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 5.4. Ключ и значение 🟡

*Найти `=` и разрезать строку надвое — так читаются конфиги, ссылки и всё в формате «ключ=значение».*

Дана строка вида `имя=значение` (без пробелов, ровно один знак `=`). Напечатайте имя
и значение на отдельных строках.

**Формат ввода.** Строка `ключ=значение`, например `count=42`.

**Формат вывода.** Две строки: сначала часть до `=`, потом часть после.

**Пример:**
```
Ввод
count=42
Вывод
count
42
```

- **Тренирует:** поиск разделителя (`find`) и разрезание строки (`substr`).
- **Где пригодится:** разбор конфигов (`.ini`, `.env`), параметров URL, CSV, любых форматов «поле=значение».

> **Как подступиться.** Найдите позицию `=`, возьмите часть до неё и часть после.

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Найди позицию `=` через `find`, затем две части — `substr` до и после неё.

```c++
std::size_t pos = s.find('=');
std::cout << s.substr(0, pos) << "\n";     // ключ
std::cout << s.substr(pos + 1) << "\n";    // значение
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Нахожу позицию разделителя: `pos = s.find('=')`.
2. Ключ — часть до него: `s.substr(0, pos)`.
3. Значение — часть после: `s.substr(pos + 1)`. Печатаю каждую с новой строки.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s;
    std::cin >> s;

    std::size_t pos = s.find('=');
    std::cout << s.substr(0, pos) << "\n";     // ключ
    std::cout << s.substr(pos + 1) << "\n";    // значение
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.

## 5.5. Сколько слов в предложении 🔴

*`cin >> s` схватит только одно слово. Чтобы получить всю строку с пробелами, зовите `getline`.*

Дана строка с несколькими словами, разделёнными пробелами. Посчитайте количество
слов. Слова могут быть разделены несколькими пробелами подряд, а в начале и конце
строки пробелы тоже возможны.

**Формат ввода.** Одна строка (может содержать пробелы), до 1000 символов.

**Формат вывода.** Количество слов.

**Пример:**
```
Ввод
  привет   мир  как дела
Вывод
4
```

- **Тренирует:** чтение целой строки (`getline`) и разбиение на слова через поток.
- **Где пригодится:** подсчёт слов в тексте, токенизация ввода, обработка CSV с «грязными» пробелами.

> **Как подступиться.** `cin >> s` прочитает лишь одно слово — нужен `getline` на всю строку, а затем разбор.

> **Осторожно.** Здесь `std::cin >> s` не годится — он прочитает только одно слово. Нужна вся строка.

<details>
<summary>Подсказка посильнее — каким инструментом разбирать</summary>

Считать пробелы вручную не нужно. Заверни прочитанную строку в `std::istringstream` (нужен `#include <sstream>`) — оператор `>>` сам выдаёт слова по одному и пропускает любые пробелы, в том числе лишние по краям и между словами:

```c++
std::istringstream iss(line);
std::string word;
int count = 0;
while (iss >> word) ++count;   // ровно столько слов и было
```

</details>

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# лишние пробелы по краям и между словами не должны сбивать счёт
one two three => 3
  hello   world   => 2
single => 1
```

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. `std::cin >> s` схватил бы одно слово — читаю всю строку через `std::getline`.
2. Отдаю строку в `std::istringstream` — поток сам разобьёт её по пробелам.
3. Считаю, сколько слов вытянул оператор `>>` (лишние пробелы он пропускает сам).

```cpp
#include <iostream>
#include <string>
#include <sstream>

int main() {
    std::string line;
    std::getline(std::cin, line);      // вся строка целиком, с пробелами

    std::istringstream iss(line);
    int count = 0;
    std::string word;
    while (iss >> word)                // >> сам пропускает лишние пробелы
        ++count;

    std::cout << count << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 5.6. Инвертировать регистр 🟡

*Хотите поменять строку прямо на месте? Пройдитесь по ней по ссылке — `for (char &c : s)` — и меняйте каждый символ.*

Дана строка. Напечатайте её, поменяв регистр каждой буквы на противоположный:
строчные — в заглавные, заглавные — в строчные. Прочие символы не меняются.

**Формат ввода.** Одна строка (латиница, цифры, пробелы), до 200 символов.

**Формат вывода.** Та же строка с инвертированным регистром букв.

**Пример:**
```
Ввод
Hello World 42
Вывод
hELLO wORLD 42
```

- **Тренирует:** изменение символов строки «на месте» (`for (char &c : s)`) и функции `std::toupper`/`std::tolower`.
- **Где пригодится:** нормализация ввода, «шуточные» фильтры, преобразование текста по правилу.

> **Как подступиться.** Читайте всю строку через `getline`. Перебирайте символы **по ссылке**; для каждой буквы применяйте `toupper` или `tolower` в зависимости от её текущего регистра (`std::isupper`/`std::islower`).

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# цифры и пробелы не меняются
Hello World 123 => hELLO wORLD 123
ABCabc => abcABC
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Читай всю строку `getline`, меняй каждый символ по ссылке (`char &c`), классифицируя через `<cctype>`.

```c++
#include <cctype>
for (char &c : line) {
    unsigned char uc = (unsigned char)c;
    if (std::isupper(uc))      c = (char)std::tolower(uc);
    else if (std::islower(uc)) c = (char)std::toupper(uc);
}
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Читаю всю строку через `getline`.
2. Иду по символам **по ссылке** (`for (char &c : line)`) — чтобы менять строку на месте.
3. Заглавную делаю строчной, строчную — заглавной; прочие символы не трогаю. `<cctype>` кормлю через `unsigned char`.

```cpp
#include <iostream>
#include <string>
#include <cctype>

int main() {
    std::string line;
    std::getline(std::cin, line);

    for (char &c : line) {             // & — меняем саму строку
        unsigned char uc = static_cast<unsigned char>(c);
        if (std::isupper(uc))
            c = static_cast<char>(std::tolower(uc));
        else if (std::islower(uc))
            c = static_cast<char>(std::toupper(uc));
    }

    std::cout << line << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.

## 5.7. Самый частый символ 🟡

*Двадцать шесть счётчиков — вот и вся частотная таблица. А идя по алфавиту, вы бесплатно решаете ничью в пользу меньшей буквы.*

Дана строка из строчных латинских букв. Напечатайте символ, который встречается чаще
всех. Если таких несколько, напечатайте наименьший по алфавиту.

**Формат ввода.** Одно слово из строчных латинских букв, до 1000 символов.

**Формат вывода.** Один символ — самый частый (при равенстве — наименьший).

**Пример:**
```
Ввод
banana
Вывод
a
```

- **Тренирует:** подсчёт частот и аккуратный разбор ничьей (правило выбора при равенстве).
- **Где пригодится:** статистика по данным, мода в выборке, простое сжатие, анализ логов.

> **Как подступиться.** Заведите массив счётчиков на 26 букв (`int cnt[26] = {}`), пройдитесь по строке, увеличивая `cnt[c - 'a']`. Затем найдите индекс с наибольшим счётчиком; перебирая от `'a'` к `'z'`, вы автоматически получите наименьший при равенстве.

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# при равной частоте — наименьший символ
banana => a
abcabc => a
z => z
```

<details>
<summary>Подсказка посильнее — с чего начать</summary>

Счётчик на 26 букв `cnt[c - 'a']`; перебор от `'a'` к `'z'` со строгим `>` сам даёт меньшую букву при равенстве.

```c++
int cnt[26] = {};
for (char c : s) ++cnt[c - 'a'];
int best = 0;
for (int i = 1; i < 26; ++i) if (cnt[i] > cnt[best]) best = i;
// ответ: (char)('a' + best)
```

</details>

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Завожу 26 счётчиков — по одному на каждую букву.
2. Иду по строке, увеличивая `cnt[c - 'a']`.
3. Ищу индекс с наибольшим счётчиком, перебирая от `'a'` к `'z'` со строгим `>` — при равенстве так автоматически возьмётся меньшая буква.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s;
    std::cin >> s;

    int cnt[26] = {};
    for (char c : s)
        ++cnt[c - 'a'];

    int best = 0;
    for (int i = 1; i < 26; ++i)
        if (cnt[i] > cnt[best]) best = i;   // строгое > даёт меньшую букву при равенстве

    std::cout << static_cast<char>('a' + best) << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

## 5.8. Развернуть слова в предложении 🔴

*Разберите строку на слова в `vector` — и дальше это уже знакомая задача: перевернуть последовательность.*

Дана строка из слов, разделённых пробелами. Напечатайте слова в обратном порядке,
разделяя одним пробелом.

**Формат ввода.** Одна строка со словами (латиница), до 1000 символов.

**Формат вывода.** Те же слова в обратном порядке, через один пробел.

**Пример:**
```
Ввод
the quick brown fox
Вывод
fox brown quick the
```

- **Тренирует:** `getline`, разбиение на слова и работу с `vector<string>`.
- **Где пригодится:** обработка текста, переворот порядка элементов, разбор команд.

> **Как подступиться.** Соберите слова в `vector`, затем разверните его и печатайте по порядку.

<details>
<summary>Подсказка посильнее — каким инструментом разбирать</summary>

Тот же приём, что в 5.5: раздели строку через `std::istringstream` (нужен `#include <sstream>`), только складывай слова в `std::vector<std::string>`. Дальше — `std::reverse` и печать через пробел:

```c++
std::istringstream iss(line);
std::vector<std::string> words;
std::string w;
while (iss >> w) words.push_back(w);
std::reverse(words.begin(), words.end());
// осталось напечатать words через один пробел
```

</details>

Написал решение — прогони его на этих входах (нажми «копировать», вставь в программу), особенно на краях:

```tests
# одно слово остаётся собой
one two three => three two one
hello world => world hello
word => word
```

<details>
<summary>Полное решение с разбором — открывай, только если застрял</summary>

Ход мысли по шагам:

1. Читаю всю строку через `getline`.
2. Разбиваю на слова через `istringstream` и собираю в `vector<string>`.
3. Разворачиваю вектор `std::reverse` и печатаю слова через пробел.

```cpp
#include <iostream>
#include <string>
#include <sstream>
#include <vector>
#include <algorithm>

int main() {
    std::string line;
    std::getline(std::cin, line);

    std::istringstream iss(line);
    std::vector<std::string> words;
    std::string w;
    while (iss >> w)
        words.push_back(w);

    std::reverse(words.begin(), words.end());

    bool first = true;
    for (const std::string &word : words) {
        if (!first) std::cout << " ";
        std::cout << word;
        first = false;
    }
    std::cout << "\n";
    return 0;
}
```

Открывай это, только когда правда застрял — весь смысл в том, чтобы пройти путь «затык → идея → код» самому.
</details>

# Подсказки

> **Мало подсказки?** Откройте теорию темы: [раздел справочника](../ref/05-stroki.md).

<details>
<summary>5.1 — Гласные в слове</summary>

- Перебирайте символы: `for (char c : word) { ... }`.
- Приведите к нижнему регистру для проверки: `char lc = std::tolower(static_cast<unsigned char>(c));` (из `<cctype>`), потом сравнивайте `lc` с `'a'`, `'e'`, `'i'`, `'o'`, `'u'`.
- На каждой гласной увеличивайте счётчик.
</details>

<details>
<summary>5.2 — Переворот строки</summary>

- Способ 1: `std::reverse(word.begin(), word.end());` из `<algorithm>`, потом вывести.
- Способ 2 (вручную): печатайте символы с конца — `for (int i = word.size() - 1; i >= 0; --i) std::cout << word[i];`. Осторожно: индекс должен быть знаковым (`int`), иначе `i >= 0` для беззнакового всегда истинно.
</details>

<details>
<summary>5.3 — Палиндром</summary>

- Сравнивайте пару символов «с краёв к центру»: `left = 0`, `right = size() - 1`.
- Пока `left < right`: если `word[left] != word[right]` — это не палиндром (`NO`), иначе сдвигайте `++left; --right;`. Дошли до центра без расхождений — `YES`.
- Или проще: сделайте копию, переверните её и сравните со строкой (`==`).
</details>

<details>
<summary>5.4 — Ключ и значение</summary>

- Найдите позицию знака: `std::size_t pos = s.find('=');`.
- Ключ — всё до неё: `s.substr(0, pos)`. Значение — всё после: `s.substr(pos + 1)`.
- Печатайте каждую часть с новой строки.
</details>

<details>
<summary>5.5 — Сколько слов</summary>

- Читайте всю строку: `std::string line; std::getline(std::cin, line);`.
- Самый простой способ посчитать слова — отдать строку в поток: `std::istringstream iss(line);` (из `<sstream>`), потом `std::string w; while (iss >> w) ++count;`. Оператор `>>` сам пропускает лишние пробелы.
</details>

<details>
<summary>5.6 — Инвертировать регистр</summary>

- Читайте всю строку: `std::getline(std::cin, line);`.
- Перебирайте **по ссылке**: `for (char &c : line) { ... }`.
- Внутри: `if (std::isupper(static_cast<unsigned char>(c))) c = std::tolower(...); else if (std::islower(...)) c = std::toupper(...);` (всё из `<cctype>`, с приведением к `unsigned char`).
</details>

<details>
<summary>5.7 — Самый частый символ</summary>

- Счётчики: `int cnt[26] = {};`. Проход: `for (char c : s) ++cnt[c - 'a'];`.
- Найдите лучший индекс: заведите `int best = 0;` и `for (int i = 1; i < 26; ++i) if (cnt[i] > cnt[best]) best = i;`.
- Строгое `>` (а не `>=`) при переборе от `'a'` даёт наименьший символ при равенстве. Ответ — `char('a' + best)`.
</details>

<details>
<summary>5.8 — Развернуть слова</summary>

- Читайте всю строку: `std::getline(std::cin, line);`.
- Разбейте на слова через `std::istringstream` и соберите в `std::vector<std::string>`.
- `std::reverse(words.begin(), words.end());`, затем печатайте слова через пробел (без пробела после последнего).
</details>

## Проверьте себя (мини тест-план)

- **5.1:** слово без гласных (`bcd` → `0`); все заглавные.
- **5.2:** слово из одной буквы; слово-палиндром (`level` → `level`).
- **5.3:** одна буква (палиндром); чётная длина (`abba` → `YES`, `abca` → `NO`).
- **5.4:** пустое значение (`x=` → `x` и пустая строка); значение с цифрами.
- **5.5:** пустая строка (`0`); много пробелов подряд; пробелы по краям.
- **5.6:** только цифры и пробелы (не меняются); смешанный регистр.
- **5.7:** все буквы разные (ответ — `a`); явный лидер (`aaab` → `a`); ничья (`ab` → `a`).
- **5.8:** одно слово (выводится как есть); лишние пробелы между словами схлопываются.

**Тема закрыта,** когда «найти и разрезать» и «пройти по символам» вы делаете не подглядывая в справочник.
