## Собираем по шагам

Не пугайся длины готового файла ниже — он вырос из нескольких строк. Вот тот же калькулятор по стадиям: сначала минимум, что уже работает, потом закрываем дыры.

### Шаг 1. Меню и одна операция

Самое маленькое, что уже запускается: цикл с меню и сложение. Ввод пока «наивный» — через голый `cin`.

```cpp
#include <iostream>

int main() {
  int choice = 0;
  do {
    std::cout << "\n1 - сложение\n0 - выход\nВыбор: ";
    std::cin >> choice;
    if (choice == 1) {
      double a = 0, b = 0;
      std::cin >> a >> b;
      std::cout << a + b << "\n";
    }
  } while (choice != 0);
}
```

```console
1 - сложение
0 - выход
Выбор: << 1
<< 2 3
5
```

Работает — но введи букву вместо числа, и программа зациклится: `cin` не смог прочитать, а `choice` остался прежним.

### Шаг 2. Безопасный ввод и защита от деления на ноль

Две дыры первой версии: ввод не проверяется, а деление на ноль ломает программу. Закрываем обе — выносим чтение в `readDouble`, а деление проверяем **до** операции.

```cpp {6-7}
double readDouble(const std::string &prompt) {
  double value = 0.0;
  while (true) {
    std::cout << prompt;
    if (std::cin >> value) return value;   // чтение удалось
    std::cin.clear();                      // снимаем флаг ошибки...
    std::cin.ignore(10000, '\n');          // ...и выкидываем плохой ввод
    std::cout << "Это не число. Ещё раз.\n";
  }
}
```

Подсвечены две строки, ради которых всё затевалось: без `clear()` + `ignore()` цикл крутился бы вечно на первой же букве.

Дальше остаётся навесить остальные операции, `enum class` для читаемого `switch` и вернуть из `power` признак «посчитать не смог» — и получается файл ниже.

## Код целиком

```cpp
// Калькулятор с меню.
// Показывает: do-while меню, enum class, switch, функции, защита от деления на ноль.

#include <windows.h>        // только Windows: русские буквы в консоли

#include <cmath>            // std::isinf, std::isnan
#include <cstdlib>          // std::exit
#include <format>           // std::format
#include <iostream>         // std::cin, std::cout
#include <limits>           // std::numeric_limits — для cin.ignore
#include <string>           // std::string

// Пункты меню. enum class даёт числам имена: Divide понятнее, чем 4.
enum class Operation {
  Add = 1,
  Subtract = 2,
  Multiply = 3,
  Divide = 4,
  Power = 5,
  Quit = 0
};

// Читает целое число. Не выйдет, пока пользователь не введёт именно число.
int readInt(const std::string &prompt) {
  int value = 0;
  while (true) {
    std::cout << prompt;
    if (std::cin >> value) {                 // поток в условии = «чтение удалось?»
      std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
      return value;
    }
    if (std::cin.eof()) {                    // ввод кончился (Ctrl+Z или конец файла)
      std::cout << "\nВвод закончился.\n";   // без неё цикл крутился бы вечно
      std::exit(0);
    }
    std::cin.clear();                        // снимаем флаг ошибки
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');  // чистим буфер
    std::cout << "Это не число. Попробуйте снова.\n";
  }
}

// То же самое для дробных: калькулятор должен уметь 2.5
double readDouble(const std::string &prompt) {
  double value = 0.0;
  while (true) {
    std::cout << prompt;
    if (std::cin >> value) {
      std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
      return value;
    }
    if (std::cin.eof()) {                    // ввод кончился (Ctrl+Z или конец файла)
      std::cout << "\nВвод закончился.\n";   // без неё цикл крутился бы вечно
      std::exit(0);
    }
    std::cin.clear();
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
    std::cout << "Это не число. Попробуйте снова.\n";
  }
}

void printMenu() {
  std::cout << "\n=== Калькулятор ===\n"
            << "1 - сложение\n"
            << "2 - вычитание\n"
            << "3 - умножение\n"
            << "4 - деление\n"
            << "5 - возведение в степень\n"
            << "0 - выход\n";
}

// Возводит в степень своим циклом, чтобы не тянуть std::pow ради целой степени.
// Возвращает false, если посчитать нельзя — тогда result не трогается.
bool power(double base, int exponent, double &result) {
  if (base == 0.0 && exponent < 0)      // ⚠️ 0^-2 это 1/0 — деление на ноль.
    return false;                       //    Ловим ДО вычислений, иначе выйдет inf

  double value = 1.0;
  int times = (exponent < 0) ? -exponent : exponent;   // модуль показателя
  for (int i = 0; i < times; ++i)
    value *= base;

  if (exponent < 0)                     // отрицательная степень = 1 / положительная
    value = 1.0 / value;

  if (std::isinf(value) || std::isnan(value))   // ⚠️ 10^400 не влезает даже в double
    return false;                               //    и дальше заразит все расчёты

  result = value;
  return true;
}

int main() {
  SetConsoleCP(CP_UTF8);
  SetConsoleOutputCP(CP_UTF8);

  bool running = true;
  while (running) {                       // главный цикл: меню показывается снова и снова
    printMenu();
    int choice = readInt("Выбор: ");
    Operation op = static_cast<Operation>(choice);   // число -> пункт меню

    if (op == Operation::Quit) {          // выход проверяем ДО ввода чисел:
      std::cout << "Пока!\n";             // спрашивать операнды для выхода незачем
      running = false;
      continue;                           // на следующий виток, где цикл и закончится
    }

    // Сюда попадаем только для настоящих операций
    double a = readDouble("Первое число: ");
    double b = 0.0;
    if (op != Operation::Power)           // у степени второй операнд целый, спросим отдельно
      b = readDouble("Второе число: ");

    switch (op) {
    case Operation::Add:
      std::cout << std::format("{} + {} = {}\n", a, b, a + b);
      break;
    case Operation::Subtract:
      std::cout << std::format("{} - {} = {}\n", a, b, a - b);
      break;
    case Operation::Multiply:
      std::cout << std::format("{} * {} = {}\n", a, b, a * b);
      break;
    case Operation::Divide:
      if (b == 0.0)                       // ✅ проверка ДО деления
        std::cout << "На ноль делить нельзя\n";
      else
        std::cout << std::format("{} / {} = {:.4f}\n", a, b, a / b);
      break;
    case Operation::Power: {              // фигурные скобки: внутри case объявляется переменная
      int exponent = readInt("Степень (целая): ");
      double result = 0.0;
      if (power(a, exponent, result))
        std::cout << std::format("{} ^ {} = {}\n", a, exponent, result);
      else if (a == 0.0)
        std::cout << "Ноль в отрицательной степени — это деление на ноль\n";
      else
        std::cout << "Результат не помещается в double\n";
      break;
    }

    case Operation::Quit:                 // сюда не попадём, но перечислить надо —
      break;                              // иначе -Wall предупредит о необработанном варианте
    default:
      std::cout << "Нет такого пункта меню\n";
      break;
    }
  }
  return 0;
}
```

## Разбор: почему сделано именно так

**Проверку «выход» делаем до вопроса про числа.** Если бы сначала спрашивали операнды, а потом смотрели на пункт меню, то на «выход» программа сперва потребовала бы два числа. Мелочь, но именно из таких мелочей складывается ощущение «программа тупая».

**`enum class Operation` вместо голых чисел.** В `switch` написано `case Operation::Divide`, а не `case 4`. Читать можно без бумажки с расшифровкой, а компилятор вдобавок предупредит, если добавить новый пункт и забыть его обработать.

**`case Operation::Quit: break;` выглядит лишним, но нужен.** До него выполнение не дойдёт — выход обработан выше. Но если вариант не перечислить, `-Wall` выдаст `enumeration value 'Quit' not handled in switch`. Пустой `case` с комментарием — честный способ сказать «я про него помню».

**Фигурные скобки вокруг `case Operation::Power`.** Внутри объявляется переменная `exponent`. Без скобок компилятор ругается: `jump to case label crosses initialization`. Правило простое: объявляешь переменную внутри `case` — оборачивай его в `{ }`.

**Деление проверяется на ноль, и именно `b == 0.0`.** Для целых деление на ноль обрывает программу без сообщения, для дробных даёт `inf` — оба варианта плохие, поэтому проверка стоит до операции.

**`power` написана циклом, а не через `std::pow`.** Так видно, что возведение в степень — это просто повторное умножение. Плюс `pow` работает с дробными и для целых степеней иногда даёт `7.999999` вместо `8`.

**Степень умеет отказываться считать — и это найдено тестом, а не придумано.** Первая версия `power` возвращала `double` и не проверяла ничего. На вводе `0` и степени `-2` она печатала `0 ^ -2 = inf`: отрицательная степень — это `1 / 0`, то есть деление на ноль, которое для дробных не роняет программу, а тихо даёт бесконечность. На `10 ^ 400` выходило то же самое — результат не помещается в `double`. Поэтому функция теперь возвращает `bool`, а результат отдаёт через ссылку: «посчитал» и «не смог» стали разными ответами. Тот же приём, что у `parseLine` в [Расходах](05-raskhody-csv.md).

**`readInt` и `readDouble` почти одинаковые — и это нормально.** Их можно было бы объединить через шаблон, но шаблоны ты ещё не проходил, а копия из десяти строк честнее непонятной конструкции.

## Что попробовать изменить

1. Добавь пункт «остаток от деления» (`%`). Подумай: он работает только с целыми — как быть, если пользователь ввёл `7.5`?
2. Сохрани последний результат и добавь пункт «продолжить с ним» — тогда можно считать цепочкой.
3. Веди историю: `std::vector<std::string>` со строками вида `2 + 3 = 5`, и пункт «показать историю».
4. Добавь квадратный корень (`std::sqrt` из `<cmath>`) — не забудь про отрицательные числа.
5. Сложное: сделай, чтобы при делении на ноль программа не просто ругалась, а предлагала ввести другой делитель.
