# 9. Проверка пароля

> **Что показывает:** `std::getline` (видит пробелы), перебор символов строки, классификацию символов через `<cctype>`, набор запрещённых символов, функцию-проверку, которая возвращает подробный отчёт, а не просто «да/нет».
> **Готовый файл:** [code/pass.cpp](code/pass.cpp) — открой и нажми `Ctrl+Alt+R`.
> Собирается без единого предупреждения со всеми строгими флагами.

---

Типичное задание: пользователь придумывает пароль, а программа проверяет его по правилам — длина в заданных пределах, нет запрещённых символов, есть цифра и буквы обоих регистров. Здесь именно это, и главное — программа не просто говорит «неверно», а перечисляет, **что** не так.

## Как устроена программа

- **`struct Report`** — отчёт: какие правила нарушены (по пунктам, а не один `bool` — чтобы сказать, **что** не так).
- **`isDigitCh` / `isUpperCh` / `isLowerCh`** — обёртки над `<cctype>`: один символ — цифра / заглавная / строчная?
- **`check`** — проверяет пароль по всем правилам и заполняет отчёт.
- **`explain`** — печатает, что именно не так (или «подходит»).
- **`main`** — в цикле: спросить пароль → проверить → объяснить, пока не подойдёт (или пустая строка — выход).

## Код целиком

```cpp
// Проверка пароля по правилам.
// Показывает: std::getline (видит пробелы), перебор символов строки,
//             классификацию символов через <cctype>, набор запрещённых
//             символов, функцию-проверку, которая возвращает отчёт, а не просто
//             «да/нет».

#include <windows.h> // только Windows: русские буквы в консоли

#include <cctype>   // std::isdigit, std::isupper, std::islower
#include <cstddef>  // std::size_t
#include <iostream> // std::cin, std::cout
#include <string>   // std::string, std::getline

// Правила собраны в одном месте — поменять требование потом легко.
constexpr std::size_t kMinLength = 8;
constexpr std::size_t kMaxLength = 20;

// Что вводить нельзя: пробел, табуляция и кавычки часто ломают формы и базы
// данных.
const std::string kForbidden = " \t\"'`\\";

// Отчёт о проверке: какие правила нарушены. Разбито по пунктам, а не одним
// bool, чтобы сказать пользователю не «неверно», а что именно не так.
struct Report {
  bool tooShort = false;
  bool tooLong = false;
  bool hasForbidden = false;
  // первый встреченный запрещённый символ — чтобы назвать его в сообщении
  char forbiddenChar = 0;
  bool noDigit = false;
  bool noUpper = false;
  bool noLower = false;
  bool ok = false;
};

// Один символ — цифра? заглавная? строчная? Заворачиваем <cctype> так, чтобы не
// забыть про static_cast<unsigned char>: isdigit и родня требуют значение,
// представимое как unsigned char. Передать голый char — UB на символах вроде
// байтов кириллицы в UTF-8: у signed char они отрицательные.
bool isDigitCh(char c) {
  return std::isdigit(static_cast<unsigned char>(c)) != 0;
}
bool isUpperCh(char c) {
  return std::isupper(static_cast<unsigned char>(c)) != 0;
}
bool isLowerCh(char c) {
  return std::islower(static_cast<unsigned char>(c)) != 0;
}

Report check(const std::string &password) {
  Report r;
  r.tooShort = password.size() < kMinLength;
  r.tooLong = password.size() > kMaxLength;

  bool digit = false;
  bool upper = false;
  bool lower = false;
  for (char c : password) { // проходим строку символ за символом
    if (!r.hasForbidden && kForbidden.find(c) != std::string::npos) {
      r.hasForbidden = true; // запомнили первый запрещённый и его самого
      r.forbiddenChar = c;
    }
    if (isDigitCh(c))
      digit = true;
    else if (isUpperCh(c))
      upper = true;
    else if (isLowerCh(c))
      lower = true;
  }
  r.noDigit = !digit;
  r.noUpper = !upper;
  r.noLower = !lower;

  // Годится, только когда не нарушено ни одно правило.
  r.ok = !r.tooShort && !r.tooLong && !r.hasForbidden && !r.noDigit &&
         !r.noUpper && !r.noLower;
  return r;
}

void explain(const Report &r) {
  if (r.ok) {
    std::cout << "OK: пароль подходит.\n";
    return;
  }
  std::cout << "Не годится:\n";
  if (r.tooShort)
    std::cout << "   - слишком короткий (нужно минимум " << kMinLength << ")\n";
  if (r.tooLong)
    std::cout << "   - слишком длинный (максимум " << kMaxLength << ")\n";
  if (r.hasForbidden) {
    std::cout << "   - есть запрещённый символ: ";
    if (r.forbiddenChar == ' ')
      std::cout << "пробел";
    else if (r.forbiddenChar == '\t')
      std::cout << "табуляция";
    else
      std::cout << "'" << r.forbiddenChar << "'";
    std::cout << "\n";
  }
  if (r.noDigit)
    std::cout << "   - нет ни одной цифры\n";
  if (r.noUpper)
    std::cout << "   - нет заглавной буквы\n";
  if (r.noLower)
    std::cout << "   - нет строчной буквы\n";
}

int main() {
  SetConsoleCP(CP_UTF8);
  SetConsoleOutputCP(CP_UTF8);

  std::cout << "Придумай пароль: " << kMinLength << "-" << kMaxLength
            << " символов, латиница и цифры,\n"
            << "хотя бы одна цифра, одна заглавная и одна строчная буква,\n"
            << "без пробелов и кавычек. Пустая строка — выход.\n";

  std::string password;
  while (true) {
    std::cout << "\nПароль: ";
    if (!std::getline(std::cin, password)) { // ввод кончился (Ctrl+Z) — выходим
      std::cout << "\nВвод закончился.\n";
      break;
    }
    if (password.empty()) {
      std::cout << "Выход.\n";
      break;
    }
    Report r = check(password); // getline берёт строку целиком —
    explain(r); // значит пробелы внутри увидим и отвергнем
    if (r.ok)
      break; // подошёл — больше спрашивать незачем
  }
  return 0;
}
```

<details>
<summary>Разбор: что за команды в этой программе</summary>

- **`constexpr std::size_t kMinLength = 8;`** — правила-константы в одном месте: поменять требование потом легко. `constexpr` — значение известно ещё при компиляции.
- **`const std::string kForbidden`** — набор запрещённых символов (пробел, табуляция, кавычки, слэш) одной строкой.
- **`for (char c : password)`** — перебор строки символ за символом. См. [перебор символов](../ref/05-stroki.md#перебор-символов).
- **`kForbidden.find(c) != std::string::npos`** — «есть ли символ `c` среди запрещённых»; `find` вернёт позицию или `npos`. См. [поиск в строке](../ref/05-stroki.md#поиск).
- **`std::isdigit(static_cast<unsigned char>(c))`** (и `isupper` / `islower`) — «это цифра / заглавная / строчная?». `static_cast<unsigned char>` обязателен: на байтах кириллицы обычный `char` отрицателен, и без каста — неопределённое поведение.
- **`struct Report { bool tooShort = false; … };`** — отчёт из флажков вместо одного «да/нет»: так можно перечислить **все** нарушения разом.
- **`password.size()`** — длина строки; тип `std::size_t` (беззнаковый), поэтому и пределы длины держим в нём. Зачем — [тема 1](../ref/01-osnovy.md#stdsize_t--почему-компилятор-ругается-на-vsize).
- **`std::getline(std::cin, password)`** — прочитать **всю строку** с пробелами: только так пробел в пароле можно увидеть и отвергнуть.

</details>

## Что происходит при запуске

_Ввод: `abc` → `my pass 12A` → `mypassword1` → `MyPass12`_

```
Придумай пароль: 8-20 символов, латиница и цифры,
хотя бы одна цифра, одна заглавная и одна строчная буква,
без пробелов и кавычек. Пустая строка — выход.

Пароль: Не годится:
   - слишком короткий (нужно минимум 8)
   - нет ни одной цифры
   - нет заглавной буквы

Пароль: Не годится:
   - есть запрещённый символ: пробел

Пароль: Не годится:
   - нет заглавной буквы

Пароль: OK: пароль подходит.
```

Одна проверка сразу назвала три причины, другая — одну. Так пользователь чинит пароль за один заход, а не угадывает правило за правилом.

## Разбор: почему сделано именно так

**`std::getline`, а не `std::cin >> password`.** Один из пунктов задания — запретить пробелы. Но `cin >> password` останавливается на первом же пробеле: ввод `my pass` он прочитал бы как `my`, а `pass` оставил в буфере — «пароль с пробелом» просто не проверить, потому что до него не добраться. `getline` берёт всю строку целиком, вместе с пробелами, и тогда их можно честно отвергнуть.

**Правила — константы наверху.** `kMinLength`, `kMaxLength`, `kForbidden` собраны в одном месте. Задание меняется («теперь минимум 10, и нельзя запятую») — правишь одну строку, а не ищешь числа по всему коду.

**`std::isdigit(static_cast<unsigned char>(c))` — каст не для красоты.** Функции из `<cctype>` требуют значение, представимое как `unsigned char`. Обычный `char` на многих компиляторах знаковый, и байты кириллицы в UTF-8 у него отрицательные — передать такой в `isdigit` напрямую это неопределённое поведение (на практике — от мусора до вылета). Каст к `unsigned char` убирает проблему. Это стандартная ловушка, о ней стоит помнить всегда, когда трогаешь `is*`-функции.

**`Report` вместо голого `bool`.** Функция могла бы вернуть просто «да/нет», но тогда пользователю нечего сказать, кроме «неверно». Отчёт по пунктам позволяет перечислить все нарушения разом. Тот же приём, что у функции `power` в [калькуляторе](01-kalkulyator.md): разделить «получилось» и «что именно пошло не так».

**`password.size()` — это `std::size_t`, поэтому и `kMinLength` тоже.** `size()` возвращает беззнаковый тип. Если сравнить его с обычным `int`, строгий флаг `-Wsign-conversion` справедливо заругается на сравнение знакового с беззнаковым. Держим пределы длины в `std::size_t` — и сравнение честное, без предупреждений.

**Проверка «запрещённый символ» помнит только первый.** `if (!r.hasForbidden && ...)` — как только нашли первый плохой символ, флаг ставится, и дальше в этом `if` уже не заходим. Сообщение показывает один пример, а не список из десяти пробелов; для «почини вот это» одного примера достаточно.

**Что считается «буквой» — по байтам, а не по смыслу.** `isupper`/`islower` работают с одним байтом. Латинские буквы и цифры это ровно один байт, так что для пароля из латиницы всё точно. А вот русская буква в UTF-8 — несколько байт, и ни один из них не «заглавная буква» в смысле `isupper`. Для этого задания так и надо (пароль просят латиницей), но если однажды понадобится считать буквы любых алфавитов — это уже отдельная тема про кодировки.

## Что попробовать изменить

1. Добавь правило «хотя бы один спецсимвол» (например из набора `!@#$%&*`). Заведи в `Report` поле `noSpecial` и проверяй по образцу `kForbidden`.
2. Сделай запрещённые символы настраиваемыми: в начале спроси у пользователя строку «какие символы запретить» и положи её в переменную вместо `kForbidden`.
3. Посчитай «силу» пароля числом от 0 до 100 (длиннее и разнообразнее — больше) и нарисуй полоску из `#` под ответом.
4. Запрети три одинаковых символа подряд (`aaa`). Понадобится в цикле помнить предыдущий символ и счётчик повторов.
5. Сложное: вынеси каждое правило в `struct Rule { std::string имя; bool (*проверка)(const std::string&); }` и сложи их в `std::vector<Rule>`. Тогда новое правило добавляется одной строкой, а `check` просто идёт по списку — см. [функции](../ref/04-funkcii.md) и [строки](../ref/05-stroki.md).


## Попробуй сам

Сначала — как `check` за один проход замечает цифру, заглавную и строчную букву:

# Что есть в пароле "aB3"
std::string password = "aB3";
bool digit = false, upper = false, lower = false;
for (char c : password) {
    if (c >= '0' && c <= '9') digit = true;
    else if (c >= 'A' && c <= 'Z') upper = true;
    else if (c >= 'a' && c <= 'z') lower = true;
}
std::cout << digit << upper << lower;

Теперь четвёртая идея — три одинаковых символа подряд, вместе с основными правилами:

```challenge
@id c15mqgm4
@type run
@hint Заведи три флага (`hasDigit`, `hasUpper`, `hasLower`) и проверяй символ через `std::isdigit` / `std::isupper` / `std::islower` — с `static_cast<unsigned char>`.
@hint Для «трёх подряд» храни предыдущий символ и длину текущей серии: совпал — `++run`, иначе `run = 1`.
Проверь пароль: длина не меньше 8, есть цифра, есть заглавная и строчная латинская буква, нет трёх одинаковых символов подряд. Напечатай `ok` или через пробел нарушения в таком порядке: `short digit upper lower repeat`.
---
#include <iostream>
#include <string>

int main() {
    std::string p;
    std::cin >> p;
    // твой код: флаги digit/upper/lower; для repeat — помни предыдущий символ и длину серии
}
---
# вход => ожидаемый вывод
Abcdefg1 => ok
abc => short digit upper
AAAbbb111 => repeat
Password => digit
aaaa => short digit upper repeat
---
#include <cctype>
#include <iostream>
#include <string>

int main() {
    std::string p;
    std::cin >> p;
    bool hasDigit = false, hasUpper = false, hasLower = false, repeat = false;
    int run = 0;
    char prev = '\0';
    for (char c : p) {
        unsigned char u = static_cast<unsigned char>(c);
        if (std::isdigit(u)) hasDigit = true;
        if (std::isupper(u)) hasUpper = true;
        if (std::islower(u)) hasLower = true;
        run = (c == prev) ? run + 1 : 1;
        prev = c;
        if (run >= 3) repeat = true;
    }
    std::string out;
    auto add = [&out](const std::string &word) {
        if (!out.empty()) out += ' ';
        out += word;
    };
    if (p.size() < 8) add("short");
    if (!hasDigit) add("digit");
    if (!hasUpper) add("upper");
    if (!hasLower) add("lower");
    if (repeat) add("repeat");
    std::cout << (out.empty() ? "ok" : out) << "\n";
}
```
