# Частые вопросы

> Что делать, когда «у меня не так»: серые материалы, сбой видеокарты, пропавшая трава, не тот персонаж — с причинами и лечением.

---

## Объект или трава стали серыми

**Что видно.** Объект однотонно-серый, как пластилин. Иногда с клетчатым узором.

**Причина.** Материал **не скомпилировался**, и Unreal подставил запасной `DefaultMaterial`. Это не «текстура не загрузилась» — сломан именно материал.

**Как найти ошибку.**

1. **Окно → Журнал выходных данных**, в поиске набери имя материала (например `M_Foliage`).
2. Ищи строку `Failed to compile Material` — под ней будет причина в скобках.
3. Или открой материал двойным кликом — внизу редактора материалов панель **Stats** покажет ошибку красным.

**Реальный случай из этого проекта.** Трава стала серой после того, как я добавил ветер. Я сначала подумал на ветер, но лог сказал:

```
(Node TextureSampleParameter2D) Sampler type is Masks, should be Color
for /Engine/EngineResources/WhiteSquareTexture
```

У параметра шероховатости стоял тип сэмплера **Masks** (линейные данные), а текстурой по умолчанию — белый квадрат движка в формате **sRGB** (цвет). Такие вещи несовместимы → весь материал не собирался. Лечение: текстура по умолчанию с правильными настройками. Подробности — в [главе 5](proekt/05-material-listvy-i-veter.md#история-одной-серой-травы).

> **Мораль:** когда что-то сломалось — сначала лог, потом гипотезы. Я потратил время, отключая ветер, хотя лог сразу говорил правду.

## Сбой видеокарты (Device Removed)

**Что видно.** Окно «Произошёл программный сбой ГП или устройство D3D удалено», редактор закрывается.

**Причина.** Видеокарта не уложилась в 2 секунды на кадр (Windows считает её зависшей и перезапускает драйвер — это называется TDR). В этом проекте так случилось, когда трава была слишком густой: после пересборки материала Unreal строил сотни тысяч пучков сразу.

**Что делать.**

| Шаг | Как |
|---|---|
| Уменьшить нагрузку | `grass.DensityScale 0.5`, меньше дальность травы (см. [главу 4](proekt/04-trava-i-kamni.md)) |
| Перед тяжёлыми правками | выключать траву: `grass.Enable 0`, после — `grass.Enable 1` |
| Освободить память | закрыть браузер и лишние программы — у тебя было свободно всего ~3 ГБ ОЗУ |
| Обновить драйвер | с сайта NVIDIA |
| После сбоя | при запуске «Восстановить наборы» → **Пропустить восстановление**, если всё было сохранено |

## Трава не появляется

| Проверь | Почему |
|---|---|
| Камера близко к земле? | ландшафтная трава строится только вокруг камеры, дальше ~35 м её нет |
| `grass.Enable 1`? | возможно, траву выключили командой |
| Ты не в площадке под дом? | там трава убрана специально (круг ~14 м) |
| Ландшафту назначен `MI_Terrain`? | трава берётся из узла `LandscapeGrassOutput` в материале |
| Склон не крутой? | на гравии и скалах травы нет по задумке |

## При Play появляется не Emanuel

1. Кнопка **Blueprint** на панели инструментов → внизу меню должно быть **«GameMode: редактировать BP_EmanuelGameMode»**. Или **Окно → Параметры мира** (Window → World Settings) → **GameMode Override** = `BP_EmanuelGameMode`.
2. В `BP_EmanuelGameMode` → **Default Pawn Class** = `BP_EmanuelPlayer`.
3. На уровне должен быть **PlayerStart** — точка, где появляется игрок.

## Персонаж стоит в T-позе или не двигается

Тело MetaHuman повторяет позу **невидимого манекена** (`Mesh`). Если сломалось:

| Проверь в BP_EmanuelPlayer | Должно быть |
|---|---|
| `Body` прикреплён к | `Mesh` (в дереве компонентов — дочерний) |
| `Body` → Anim Class | `ABP_MetaHuman_m_med_nrw_Retargeting` |
| `Mesh` → Anim Class | `ABP_Unarmed` |
| `Mesh` → Visible | выключено |
| `Mesh` → Visibility Based Anim Tick Option | **Always Tick Pose and Refresh Bones** |

Последний пункт важен: невидимый меш по умолчанию **не считает анимацию** ради экономии — и тело замирает.

## Shift не переключает на шаг

Шаг сделан через «аккорд» в Enhanced Input ([глава 7](proekt/07-personazh.md#шаг-на-shift)). Если не работает — открой `Content/Input/IMC_Default`, проверь, что есть `IA_Walk` на **Left Shift** и копии `W A S D` с модификатором **Scalar 0.35** и триггером **Chorded Action → IA_Walk**.

## Редактор долго открывается / «компилирует шейдеры»

Нормально после больших изменений: шейдеры собираются один раз и кэшируются (папка `DerivedDataCache`). Счётчик справа внизу показывает, сколько осталось. Не удаляй `DerivedDataCache` без причины — всё придётся собирать заново.

## Можно ли удалить SourceArt

Игре он не нужен. Но без него нельзя пере-импортировать текстуры и модели или перезапустить скрипты. Держи, места он занимает немного (~500 МБ).
