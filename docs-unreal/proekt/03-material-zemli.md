### За 30 секунд

- Материал считает цвет **каждой точки** земли отдельно — как маленькая программа.
- **Маска** — число 0…1 в каждой точке: «насколько здесь скала». Всё умное в материале — способы получить хорошую маску.
- Маски берутся из **шума** (пятна), **нормали** (крутизна склона) и **расстояния** (круг).
- **Lerp** смешивает два слоя по маске: 0 — первый, 1 — второй.
- Числа выносят в **параметры**, а ландшафту дают **инстанс** — и крутят ползунки без компиляции.

## Материал — это программа для пикселя

Материал в Unreal — это **граф узлов**, который для каждой точки экрана отвечает на вопросы: какого цвета точка? куда смотрит её поверхность? насколько она блестит? Узлы соединяются проводами слева направо, справа — выходы: **Base Color**, **Normal**, **Roughness** и другие.

Открой `Content/Terrain/M_Terrain` двойным кликом — увидишь этот граф. В нём около 400 узлов, но устроен он из повторяющихся кусочков. Разберём по одному.

```
 координаты ─┬─→ 7 слоёв текстур (цвет, нормаль, шероховатость, высота)
 ландшафта   │
             ├─→ шум ──→ маски пятен (лес, хвоя, грязь, пашня)
             │
 нормаль ────┴─→ маски склонов (гравий, скала)
                         │
                         ▼
          смешивание слоёв по маскам + по высоте
                         │
          вариация цвета, тинт, дальность
                         ▼
          Base Color · Normal · Roughness · маски травы
```

## Маска — главное слово главы

Представь, что над всей землёй лежит прозрачная плёнка, и на ней в каждой точке написано число от 0 до 1. Это **маска**.

```console
маска «скала» (вид сверху, участок 8×4 м):

  0   0   0  .2  .6   1   1   1      ← справа крутой склон
  0   0   0  .1  .5  .9   1   1
  0   0   0   0  .3  .7   1   1
  0   0   0   0  .1  .4  .8   1
  └ ровный луг ┘   └ переход ┘  └ скала ┘
```

Где маска 0 — рисуем луг, где 1 — скалу, где 0.5 — смесь пополам. Вот и весь секрет. Узел, который это делает, — **Lerp**:

```
результат = A × (1 − маска) + B × маска
            луг                скала
```

Маски можно **перемножать** («лес И не склон» = маска леса × (1 − маска склона)) и **накладывать по очереди** (сначала лес поверх луга, потом грязь поверх результата…). Из этих двух действий собран весь `M_Terrain`.

## Шаг 1. Координаты и тайл

Узел **LandscapeLayerCoords** даёт координаты точки на ландшафте: `(0,0)` — угол ландшафта, `1` = один квад = 1 метр (масштаб ландшафта 100). Разделив координаты на `Meadow_TileMeters = 2`, получаем UV, при которых текстура луга повторяется каждые 2 метра.

Для каждого из 7 слоёв — свой тайл и свои 5 выборок текстуры: цвет вблизи, цвет издали, нормаль, шероховатость, высота. Итого 35 текстурных выборок.

> **Почему не упёрлись в лимит.** У видеокарты есть лимит — 16 **сэмплеров** на материал. У всех выборок я поставил **Sampler Source → Shared: Wrap**: они пользуются одним общим сэмплером, и лимит не мешает.

<details>
<summary>🔎 Подробнее: почему LandscapeLayerCoords, а не позиция в мире</summary>

Позиция точки в мире (`Absolute World Position`) в Unreal 5 хранится **с двойной точностью** (Large World Coordinates), чтобы миры могли быть огромными. Видеокарте для текстур нужны обычные числа, и преобразование может давать «дрожание» на больших координатах.

`LandscapeLayerCoords` — координаты **внутри ландшафта**: от его угла, в квадах. Числа маленькие, точные, и не зависят от того, где ландшафт стоит в мире. Для узоров на земле это надёжнее.

Минус: эти координаты есть только у ландшафта. Для домов и камней берут UV или `WorldAlignedTexture` — см. [курс «Строим дом», этап 3](../igry/03-materialy-doma.md).

</details>

## Шаг 2. Маски пятен из шума

Узел **Noise** выдаёт плавный случайный узор, похожий на облака: значения от 0 до 1. Если взять только места, где шум больше порога, получатся пятна:

```
шум:      0.2  0.4  0.6  0.8  0.6  0.4  0.3
порог 0.5:  ·    ·    █    █    █    ·    ·      ← пятно леса
```

Формула мягкого порога (в материале — узлы Subtract → Divide → Saturate):

```
маска = saturate((шум − порог) / мягкость)
```

- **порог** (`ForestAmount_Threshold`) — чем меньше, тем больше пятен;
- **мягкость** (`PatchSoftness`) — ширина перехода на краю;
- **размер** (`ForestPatchSize_m`) — масштаб шума: 90 м — крупные массивы, 20 м — мелкие пятна.

**Чтобы края не были круглыми кляксами**, к крупному шуму подмешан мелкий (`PatchEdgeDetail = 0.35`): край пятна становится рваным, как у настоящей поляны.

| Слой | Размер пятен | Порог |
|---|---|---|
| ForestGround (лес) | 90 м | 0.43 |
| Needles (хвоя, только внутри леса) | 18 м | 0.42 |
| MudLeaves (грязь) | 22 м | 0.66 |
| Soil (пашня) | 45 м | 0.80 |

Хвоя умножается на маску леса — поэтому иголки бывают **только в лесу**.

## Шаг 3. Маски склонов

Узел **VertexNormalWS** — нормаль поверхности ландшафта (куда «смотрит» земля). Её компонента `Z`:

- `1` — поверхность горизонтальна (смотрит вверх);
- `0` — вертикальная стена.

Значит, `1 − Z` растёт с крутизной: 0 на ровном, 0.13 на склоне 30°, 0.23 на 40°. Дальше тот же мягкий порог:

| Слой | Начало (`…SlopeStart`) | Примерно |
|---|---|---|
| Gravel | 0.10 | склоны круче 26° |
| Rock | 0.17 | круче 34° |

## Смешивание по высоте

Наивное смешивание двух слоёв — полупрозрачное: грязь «просвечивает» сквозь траву, как наложенные фото. В жизни так не бывает: камни **торчат** сквозь грязь.

Поэтому маска сдвигается картой высоты верхнего слоя:

```
alpha = saturate(((маска + (высота − 0.5) × влияние) − 0.5) × контраст + 0.5)
```

Где у камня высоко — он «побеждает» раньше, где впадина — позже. Край пятна получается из отдельных камешков и листьев.

- `HeightBlendInfluence = 0.7` — насколько высота важна;
- `HeightBlendContrast = 4` — насколько резкий переход.

Слои накладываются по очереди: **луг → лес → хвоя → пашня → грязь → гравий → скала**. Каждый следующий кладётся поверх предыдущих узлом **Lerp** (линейная интерполяция: `A·(1−alpha) + B·alpha`). Так считается и цвет, и нормаль, и шероховатость.

<details>
<summary>🔎 Подробнее: смешивание по высоте на числах</summary>

Возьмём край пятна гравия, где маска = **0.5** (ровно половина). Влияние 0.7, контраст 4.

| Точка | Высота камешка | (h − 0.5) × 0.7 | маска + это | (… − 0.5) × 4 + 0.5 | alpha |
|---|---|---|---|---|---|
| вершина камня | 0.9 | +0.28 | 0.78 | 1.62 | **1** (обрезано) |
| середина | 0.5 | 0 | 0.5 | 0.5 | **0.5** |
| впадина | 0.1 | −0.28 | 0.22 | −0.62 | **0** (обрезано) |

На одной и той же маске 0.5 вершины камней уже **полностью гравий**, а впадины — **ещё полностью трава**. Так край пятна собирается из отдельных камешков, а не из полупрозрачной дымки.

Чем больше **контраст**, тем резче — камешки «выскакивают» чётко. Чем больше **влияние**, тем дальше от края пятна они пробиваются.

</details>

## Борьба с повторением

Текстура размером 2 м на поле 2 км повторяется 1000 раз. Издалека это видно как сетку. Три приёма:

| Приём | Как | Параметры |
|---|---|---|
| **Крупнее вдали** | дальше 15 м цвет берётся из той же текстуры, но с тайлом в 5 раз больше | `FarFadeStart_cm`, `FarFadeLength_cm`, `FarTilingScale` |
| **Макро-вариация** | ещё один шум размером 160 м слегка осветляет/затемняет землю | `MacroVariationSize_m`, `MacroVariationAmount` |
| **Сглаживание нормалей вдали** | дальние нормали наполовину выпрямляются — нет мерцания | `FarNormalFlatten` |

Расстояние до камеры даёт узел **PixelDepth**.

## Ползунки MI_Terrain

`M_Terrain` — это «шаблон». Менять его каждый раз долго: каждая правка — перекомпиляция шейдеров. Поэтому на ландшафте стоит **инстанс** `MI_Terrain` — копия с ползунками. Открой его, поставь галочку у параметра, двигай — изменения видны сразу, без компиляции.

| Группа | Параметр | Сейчас | Что делает |
|---|---|---|---|
| Blend | `ForestAmount_Threshold` | 0.43 | меньше → больше леса |
| Blend | `ForestPatchSize_m` | 90 | размер лесных массивов |
| Blend | `NeedlesAmount_Threshold` | 0.42 | меньше → больше хвои в лесу |
| Blend | `MudAmount_Threshold` | 0.66 | меньше → больше грязи |
| Blend | `SoilAmount_Threshold` | 0.80 | меньше → больше пашни |
| Blend | `PatchSoftness` | 0.3 | ширина перехода краёв |
| Blend | `PatchEdgeDetail` | 0.35 | рваность краёв (0 — гладкие кляксы) |
| Blend | `GravelSlopeStart` | 0.10 | меньше → гравий на более пологих склонах |
| Blend | `RockSlopeStart` | 0.17 | меньше → больше скал |
| Blend | `HeightBlendContrast` | 4 | резкость краёв по высоте |
| _слой_ | `<Слой>_TileMeters` | 1.5–6 | размер текстуры |
| _слой_ | `<Слой>_Tint` | цвет | подкраска слоя (луг сделан зеленее) |
| Terrain | `ColorTint` | белый | подкраска всей земли |
| Terrain | `MacroVariationAmount` | 0.25 | сила пятен светлее/темнее |
| Terrain | `RoughnessMultiplier` | 1 | общая шероховатость |
| House | `HouseCenterX_m` и др. | — | [площадка под дом](08-ploshchadka-pod-dom.md) |

> **Важно:** изменения в `MI_Terrain` пересчитывают и траву. Если меняешь много подряд — сначала `grass.Enable 0` в консоли, в конце `grass.Enable 1`.

## Квест 1. Свой ландшафт

**Нужно:** учебный уровень и `M_MyRock` из [главы 2](02-teksturi-i-import.md#квест-свой-материал-на-кубе). Вторую текстуру — траву — импортируй так же из `SourceArt/Terrain/sparse_grass/` (`T_MyGrass_D/N/R/H`).

### Шаг 1. Создать ландшафт

1. Открой `Lvl_Practice`. Выдели и удали серый пол (`Floor`) — `Delete`.
2. Режим **Ландшафт**: `Shift+2` (или список «Режим «Выбор»» → Ландшафт).
3. Слева вкладка **Управление** (Manage) → **Новый**. Настройки для черновика:
   - **Section Size** — `63×63 квадов`;
   - **Number of Components** — `4 × 4`;
   - остальное — по умолчанию. Получится ландшафт ~250×250 м — маленький и лёгкий.
4. Нажми **Создать** внизу. Появилась плоская серая (клетчатая) земля.

### Шаг 2. Слепить холмы

1. Вкладка **Скульптинг** (Sculpt) → инструмент **Sculpt**.
2. **Brush Size** — `2000`, **Tool Strength** — `0.3`.
3. Води зажатой левой кнопкой — земля поднимается. `Shift` + ЛКМ — опускается.
4. Сделай один пологий холм и один крутой обрыв — нам нужны оба.
5. Инструмент **Smooth** — сгладить острые края.

### Шаг 3. Материал «трава на ровном, камень на склонах»

1. Каталог → `Practice` → правый клик → **Материал** → `M_MyTerrain`, открой.
2. Поставь узлы (правый клик по графу → поиск):

```console
[LandscapeLayerCoords] ──┬──▶ UVs [T_MyGrass_D] ──RGB──▶ A ┐
  (Mapping Scale = 3)    └──▶ UVs [T_MyRock_D]  ──RGB──▶ B ├─[Lerp]──▶ Base Color
                                                            │
[VertexNormalWS] ─▶ [Component Mask: B] ─▶ [One Minus] ─▶ [Multiply × 8] ─▶ [Saturate] ─▶ Alpha
```

   - **LandscapeLayerCoords** → в Сведениях узла **Mapping Scale** = `3` (тайл 3 м).
   - **VertexNormalWS** — куда смотрит поверхность. Его **Component Mask** — оставь только **B** (это Z — «вверх»).
   - **One Minus** — превращает «насколько смотрит вверх» в «насколько крутой».
   - **Multiply** на `8` и **Saturate** — делают переход резче и обрезают до 0…1.
**3.** Сохрани. Выдели ландшафт (клик по земле в режиме Выбор, `Shift+1`) → Сведения → **Landscape Material** → `M_MyTerrain`.

**Должно получиться:** ровное — трава, крутой обрыв — камень, между ними плавный переход.

> 💡 **Поиграй с числом в Multiply.** 2 — камень почти везде размыт, 30 — резкая граница. Это и есть «мягкость» маски.

### Шаг 4. Нормали и шероховатость тоже

Сейчас смешан только цвет. Сделай ещё два **Lerp** с той же Alpha: `T_MyGrass_N`/`T_MyRock_N` → **Normal**, `T_MyGrass_R`/`T_MyRock_R` (выход R) → **Roughness**. Провод Alpha можно тянуть из одного узла Saturate в три Lerp сразу.

```checklist
Квест 1 готов, если:
- на учебном уровне свой ландшафт с пологим холмом и крутым обрывом
- ровное — трава, крутое — камень, переход плавный
- цвет, нормаль и шероховатость смешаны одной маской
- понимаю, зачем One Minus и Saturate
```

## Квест 2. Пятна по шуму

**Цель:** добавить пятна грязи на ровной траве и вынести всё в ползунки.

1. Импортируй `brown_mud_leaves_01` из `SourceArt/Terrain` как `T_MyMud_D` (только цвет — для тренировки хватит).
2. В `M_MyTerrain` поставь узел **Noise**. В его Сведениях: **Scale** = `0.001`, **Output Min** = `0`, **Output Max** = `1`, **Levels** = `3`. (Noise умножает координаты в **сантиметрах** на Scale: 0.001 даёт пятна порядка 10 м. 0.02 — уже полуметровые крапинки.)
3. Сделай маску пятен — это тот же «мягкий порог», что в разборе выше:

```console
[Noise] ─▶ [Subtract: B = Threshold] ─▶ [Divide: B = Softness] ─▶ [Saturate] ─▶ маска грязи
```

   Threshold и Softness — **Scalar Parameter** (`S` + клик): `MudThreshold = 0.6`, `MudSoftness = 0.1`.
**4.** Новый **Lerp**: A — результат «трава/камень» из квеста 1, B — `T_MyMud_D`, Alpha — маска грязи → в **Base Color**.
**5.** Сохрани. Создай инстанс `MI_MyTerrain`, назначь его ландшафту.
**6.** Открой `MI_MyTerrain`, двигай `MudThreshold` от 0.3 до 0.9 и `MudSoftness` от 0.02 до 0.5.

**Должно получиться:** пятна грязи на земле; меньше Threshold — больше грязи; больше Softness — размытее края.

> ⚠ **Осторожно.** Если грязь лезет и на скалы — это не баг: маски не знают друг о друге. Умножь маску грязи на `(1 − маска камня)` перед Lerp — грязь останется только на ровном. Так и сделано в `M_Terrain` («открытая земля»).

```checklist
Квест 2 готов, если:
- пятна грязи появляются по шуму
- MudThreshold и MudSoftness — ползунки в MI_MyTerrain
- грязь не лезет на склоны (маски перемножены)
- могу объяснить формулу saturate((шум − порог) / мягкость)
```

## Типовые ошибки

| Симптом | Причина | Лечение |
|---|---|---|
| вся земля одного слоя | Alpha не подключена или всегда 0/1 | проверь провод в Alpha; убери лишний Saturate |
| склоны и ровное поменялись местами | забыт One Minus | Normal Z = 1 на ровном — нужно перевернуть |
| пятна огромные/крошечные | масштаб шума | Scale в Noise (у меня — через деление координат) |
| сетка/повторение видно издалека | один тайл на всё | «крупнее вдали» и макро-вариация (см. выше) |
| каждая правка ползунка — долгая компиляция | меняешь материал, а не инстанс | крути инстанс `MI_…` |
| земля чёрная/клетчатая | материал не назначен или с ошибкой | Сведения ландшафта → Landscape Material; окно Stats в редакторе материала |

## Проверь себя

```quiz
В: Зачем инстанс материала, если можно менять сам материал?
+ Ползунки инстанса меняются мгновенно, без перекомпиляции шейдеров
- Ландшафт не принимает обычные материалы
- Инстанс быстрее рисуется видеокартой
= Материал — шаблон. Любая правка шаблона — компиляция. Параметры инстанса подставляются на лету.

В: Компонента Z узла VertexNormalWS на ровном месте равна…
+ 1 — поверхность смотрит вверх
- 0
- 0.5
= Нормаль ровной земли смотрит строго вверх: (0, 0, 1). На вертикальной стене Z = 0.

В: Как сделать, чтобы скалы в MI_Terrain появлялись уже на склонах 25°?
+ RockSlopeStart ≈ 0.09, потому что 1 − cos(25°) ≈ 0.09
- RockSlopeStart = 25
- RockSlopeStart = 0.25
= Маска склона — это 1 − Z нормали, а Z = cos(угла). Переводим градусы в эту шкалу.

В: Почему грязь в prog2 не «просвечивает» сквозь траву, как полупрозрачная плёнка?
+ Используется смешивание по высоте: верхний слой появляется сначала на выступах
- Грязь нарисована кистью
- У грязи Blend Mode = Masked
= Маска сдвигается картой высоты — край пятна собирается из отдельных камешков и листьев.

В: Маска леса = 0.8, маска склона = 0.5. Чему равна «лес, но не на склоне»?
+ 0.4 = 0.8 × (1 − 0.5)
- 1.3
- 0.3
= «И не» = умножить на (1 − другая маска).
```

```cards
В: Что такое маска?
О: Число от 0 до 1 в каждой точке: «насколько здесь этот слой».

В: Что делает Lerp?
О: Смешивает A и B по Alpha: 0 — A, 1 — B, между — плавно.

В: Формула мягкого порога?
О: saturate((значение − порог) / мягкость).

В: Как получить крутизну склона?
О: 1 − Z от VertexNormalWS.

В: Как сделать «лес И не склон»?
О: Перемножить маску леса на (1 − маска склона).

В: Зачем Shared: Wrap у текстурных выборок?
О: Чтобы 35 выборок пользовались одним сэмплером и не упёрлись в лимит 16.
```
