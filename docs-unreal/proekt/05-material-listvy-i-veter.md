### За 30 секунд

- Листва = **Masked** (пиксель есть/нет по альфа-каналу) + **Two Sided Foliage** (свет проходит насквозь) + **Two Sided**.
- **Per Instance Random** — случайное число на каждый пучок → свой оттенок у каждого.
- **Ветер** — выход **World Position Offset**: сдвигаем вершины по синусу времени, сильнее — выше от земли.
- Тип сэмплера у параметра текстуры должен совпадать с текстурой по умолчанию — иначе материал не соберётся и всё станет **серым**.

## Зачем свой материал

При импорте glTF Unreal сам создал материалы — инстансы универсального `M_GLTF`. Для камней они подошли. А трава получилась **плоской, жёлтой и с синим блеском вдали**:

- свет не проходил сквозь травинки — они выглядели как пластик;
- блеск (specular) отражал небо на тонких листьях — синие искры;
- все пучки одного цвета — поле как ковёр.

Поэтому для листвы сделан свой **мастер-материал** `Content/Foliage/M_Foliage`, а у каждой травы — его инстанс `MI_grass_medium_01`, `MI_fern_02` и т. д. с её текстурами.

## Настройки материала (панель Сведения)

| Настройка | Значение | Зачем |
|---|---|---|
| Blend Mode | **Masked** | пиксели с альфой < 0.33 не рисуются — так получаются травинки из картинки |
| Shading Model | **Two Sided Foliage** | свет проходит насквозь: лист против солнца светится |
| Two Sided | ✔ | лист виден с обеих сторон |
| Used with Nanite / Instanced Static Meshes | ✔ | можно использовать на траве с Nanite |

## Граф

```
BaseColor (текстура) ──RGB──× вариация ──× Tint ──→ Base Color
                     │                    └──× SubsurfaceStrength ─→ Subsurface Color
                     └──A──────────────────────────────────────────→ Opacity Mask
Normal (текстура) ─────────────────────────────────────────────────→ Normal
Roughness (текстура) ──G── × RoughnessScale ── clamp(0.55…1) ──────→ Roughness
0.25 ──────────────────────────────────────────────────────────────→ Specular
ветер (ниже) ──────────────────────────────────────────────────────→ World Position Offset
```

- **Альфа-канал** цветовой текстуры — это форма травинок. Белое — травинка, чёрное — дырка.
- **Subsurface Color** — цвет света, прошедшего *сквозь* лист. Взят тот же цвет, но темнее (×0.6).
- **Roughness из канала G**: в glTF шероховатость лежит в зелёном канале (так принято в формате).
- **clamp 0.55…1** — трава не бывает глянцевой; это и убрало синие искры.
- **Specular 0.25** вместо стандартных 0.5 — меньше блика.

### Случайный оттенок

Узел **PerInstanceRandom** выдаёт каждому экземпляру (каждому пучку) своё случайное число 0…1. Через **Lerp** между двумя цветами — `ColorVariationA` (зеленее) и `ColorVariationB` (желтее) — каждый пучок получает свой оттенок. Поле перестаёт быть ковром.

## Ветер

**World Position Offset** (WPO) — выход материала, который **сдвигает вершины** модели. Сдвигаешь верх травинок туда-сюда во времени — получается ветер.

```
вес    = saturate(высота_вершины_в_модели / WindHeight_cm)     ← основание стоит, верх гнётся
фаза   = PerInstanceRandom × 2π                                 ← пучки не в такт
угол   = Time × WindSpeed + фаза
сдвиг  = (sin(угол), 0.5×cos(угол), 0) × WindStrength_cm × вес
```

| Узел | Роль |
|---|---|
| **PreSkinnedPosition** → Mask(B) | высота вершины внутри модели (0 у земли) |
| **Time** | секунды с начала игры |
| **PerInstanceRandom** | случайная фаза для каждого пучка |
| **Sine**, **Cosine** | качание туда-сюда, по кругу |
| **Append** | собрать числа в вектор (X, Y, Z) |
| **Multiply** | масштабы |

### Ползунки ветра

Открой любой инстанс, например `Foliage/grass_medium_01/…/Materials/MI_grass_medium_01`:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `WindStrength_cm` | 5 | амплитуда качания, см |
| `WindSpeed` | 1.6 | скорость |
| `WindHeight_cm` | 40 | на какой высоте качание полное |

Чтобы поменять у **всей** травы сразу — меняй значения по умолчанию в самом `M_Foliage` (выдели узел параметра → Default Value). Дальше 30 м ветер выключается сам (`World Position Offset Disable Distance` в типах травы) — экономия видеокарты.

> **Есть готовое.** В Unreal есть функция **SimpleGrassWind** (ПКМ → поиск). Я сначала взял её, но собрал ветер из базовых узлов, чтобы ты видел, что внутри, — и чтобы можно было крутить формулу.

<details>
<summary>🔎 Подробнее: ветер по кадрам</summary>

Возьмём травинку: вершина на высоте 40 см (вес = 1), середина — 20 см (вес 0.5), основание — 0. Сила 5 см, скорость 1.6, фаза пучка 0.

| Время, с | угол = 1.6 × t | sin | сдвиг вершины по X | сдвиг середины |
|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 0 |
| 0.5 | 0.8 | 0.72 | **3.6 см** | 1.8 см |
| 1.0 | 1.6 | 1.00 | **5.0 см** | 2.5 см |
| 2.0 | 3.2 | −0.06 | −0.3 см | −0.15 см |
| 3.0 | 4.8 | −1.00 | **−5.0 см** | −2.5 см |

Вершина качается на ±5 см, середина — вдвое меньше, основание стоит. Полный цикл — 2π / 1.6 ≈ **3.9 с**. Соседний пучок со случайной фазой в этот момент может быть в противоположной точке — поле «волнуется», а не марширует.

`0.5 × cos` по Y добавляет второе, меньшее качание вбок — травинка описывает эллипс, а не ходит по прямой.

</details>

## История одной серой травы

После добавления ветра вся трава стала **ровно серой**. Как я искал причину — урок отладки:

| Шаг | Что сделал | Вывод |
|---|---|---|
| 1 | снимок «чистого цвета» (Base Color) без освещения | серая и там → дело не в свете, а в материале |
| 2 | отключил ветер | всё ещё серая → ветер не виноват |
| 3 | статистика материала: 0 инструкций | материал **не скомпилирован** |
| 4 | открыл **правильный** лог (сначала смотрел лог прошлого запуска!) | нашёл ошибку |

Ошибка:

```
(Node TextureSampleParameter2D) Sampler type is Masks, should be Color
for /Engine/EngineResources/WhiteSquareTexture
```

У параметра `Roughness` тип сэмплера — **Masks** (линейные числа), а текстура по умолчанию — белый квадрат движка в **sRGB**. Несовместимо → материал не собирается → движок рисует запасной серый `DefaultMaterial`.

Почему первая версия материала с той же ошибкой показывала зелёную траву, я точно не выяснил: скорее всего, тогда в кэше остался ранее собранный шейдер, а полная пересборка вскрыла проблему. Лечение: текстурами по умолчанию в мастер-материале стали текстуры самой травы — у них уже правильные настройки (функция `default_textures` в `Scripts/setup_foliage.py`).

> **Правило:** у `Texture Sample Parameter` тип сэмплера и текстура по умолчанию должны совпадать: Color ↔ sRGB, Masks / Linear ↔ без sRGB, Normal ↔ Normalmap.

## Квест: свой материал листвы

**Цель:** собрать `M_MyFoliage` и надеть его на **копию** папоротника.

> ⚠ **Осторожно.** Меши травы общие для всего проекта. Поменяешь материал у оригинального `fern_02_a` — изменится и трава в `num1`. Поэтому работаем с копией.

### Шаг 1. Копия меша

1. Каталог → `Content/Foliage/fern_02/…/StaticMeshes` → правый клик по `fern_02_a` → **Дублировать** → перетащи копию в `Practice` (или сразу «Переместить сюда»), имя `SM_MyFern`.
2. Перетащи `SM_MyFern` из каталога на свой уровень 5–6 раз.

### Шаг 2. Материал

1. `Practice` → правый клик → **Материал** → `M_MyFoliage`. Открой.
2. Кликни по пустому месту графа — слева Сведения **самого материала**:
   - **Blend Mode** → `Masked`;
   - **Shading Model** → `Two Sided Foliage`;
   - **Two Sided** ✔.
3. Поставь **Texture Sample Parameter 2D** (`T` + клик, потом правый клик → «Преобразовать в параметр» или ищи сразу `TextureSampleParameter2D`):
   - имя `BaseColor`, Texture = `fern_02_diff…` (возьми из папки `Foliage/fern_02/…/Textures`), Sampler Type = **Color**;
   - выход **RGB** → **Base Color**, выход **A** (альфа) → **Opacity Mask**.
4. Ещё один параметр `Normal` с текстурой `fern_02_nor_gl`, Sampler Type = **Normal** → **Normal**.
5. Сохрани. Перетащи `M_MyFoliage` на один из папоротников на уровне.

**Должно получиться:** листья папоротника с вырезами по форме (не квадраты); против солнца листья светятся.

> 💡 Если папоротник выглядит квадратными пластинками — не подключена **Opacity Mask** или Blend Mode остался Opaque.

### Шаг 3. Просвет и оттенок

1. **Multiply**: BaseColor RGB × `0.6` (Constant, клавиша `1` + клик) → во вход **Subsurface Color**.
2. **Per Instance Random** → Alpha узла **Lerp** между двумя **Vector Parameter**: `ColorA` (0.8, 1.0, 0.6) и `ColorB` (1.1, 1.0, 0.7). Результат умножь на BaseColor RGB перед Base Color.

### Шаг 4. Ветер (короткий путь)

1. Правый клик → `SimpleGrassWind` (это готовая **функция материала**).
2. Входы: `WindIntensity` — Scalar Parameter `0.3`; `WindSpeed` — `0.5`; `WindWeight` — узел **TexCoord** → Component Mask **G** → **One Minus** (верх листа сильнее, если UV снизу вверх).
3. Выход → **World Position Offset**. Сохрани и смотри — листья качаются.

> 📖 **Длинный путь** — собрать ветер самому из Time, Sine, Per Instance Random, как в `M_Foliage` ([разбор выше](#ветер)). Сделай его в боссе главы.

### Шаг 5. Инстанс

Создай `MI_MyFern` из `M_MyFoliage`, назначь копии папоротника через её Сведения → **Материалы**. Покрути `ColorA/B` и `WindIntensity` в инстансе.

```checklist
Квест готов, если:
- папоротник с вырезанными листьями, без квадратов
- листья просвечивают против солнца
- у каждого экземпляра свой оттенок
- листья качаются, сила ветра — ползунок в инстансе
- оригинальный fern_02_a не тронут
```

## Типовые ошибки

| Симптом | Причина | Лечение |
|---|---|---|
| квадратные пластинки вместо листьев | нет Opacity Mask / Blend Mode = Opaque | Masked + альфа в Opacity Mask |
| весь объект серый | материал не скомпилировался | Журнал выходных данных → `Failed to compile Material` |
| «Sampler type is Masks, should be Color» | тип сэмплера ≠ текстура | поменяй Sampler Type или текстуру по умолчанию |
| листья чёрные с обратной стороны | Two Sided выключен | Two Sided ✔ |
| синие искры вдали | слишком гладкие листья, блик отражает небо | Roughness ≥ 0.55, Specular ≈ 0.25 |
| ветер «отрывает» траву от земли | вес ветра у основания не 0 | вес = высота вершины / высоту, основание = 0 |
| все пучки качаются в такт | нет случайной фазы | + Per Instance Random к аргументу синуса |

## Проверь себя

```quiz
В: Почему у травы Blend Mode = Masked, а не Translucent?
+ Masked — пиксель либо есть, либо нет: дёшево, с тенями и Nanite. Translucent намного дороже
- Translucent не умеет прозрачность
- Так требует Landscape Grass
= Полупрозрачность — для стекла и воды. Для листьев хватает «есть/нет».

В: Как сделать ветер сильнее только у папоротников?
+ Открыть MI_fern_02 и поставить больше WindStrength_cm
- Поменять WindStrength_cm в M_Foliage
- Поменять плотность в LGT_ForestFloor
= Инстанс меняет параметры только у своих объектов. Мастер-материал — у всех.

В: Что такое World Position Offset?
+ Выход материала, который сдвигает вершины модели на видеокарте
- Позиция актора на уровне
- Смещение текстуры
= Модель не меняется — меняется, где видеокарта рисует её вершины в этот кадр.

В: Трава стала ровно серой. Первое действие?
+ Открыть Журнал выходных данных и искать Failed to compile Material
- Отключить ветер
- Пересоздать траву
= Сначала лог, потом гипотезы — урок из «истории одной серой травы».
```

```cards
В: Три настройки материала листвы?
О: Blend Mode = Masked, Shading Model = Two Sided Foliage, Two Sided ✔.

В: Откуда форма листа в Masked-материале?
О: Из альфа-канала текстуры → Opacity Mask.

В: Что даёт Per Instance Random?
О: Случайное число 0…1 на каждый экземпляр: оттенок, фаза ветра.

В: Какой выход материала качает траву?

```

## Босс главы

```boss
# Ветер своими руками
@id ue-boss-05
Замени SimpleGrassWind в M_MyFoliage на свой ветер из базовых узлов.

1. Вес = высота вершины над основанием: **Pre Skinned Position** → Component Mask **B** → Divide на параметр `WindHeight` (см) → Saturate.
2. Угол = **Time** × `WindSpeed` + **Per Instance Random** × 6.283.
3. Сдвиг = (sin(угол), 0.5 / cos(угол), 0) × `WindStrength` × вес. Векторы собираются узлом **Append**.
4. Результат → World Position Offset.
5. Добавь **порывы**: умножь силу на `0.6 + 0.4 × sin(Time × 0.3)` — ветер то усиливается, то стихает.

<details>
<summary>Подсказка</summary>

Посмотри, как это собрано в `Content/Foliage/M_Foliage` (нижняя часть графа) — открой его рядом и повторяй узел за узлом. У узлов Sine и Cosine поставь **Period** = 6.283, тогда аргумент — в радианах.

</details>
```
