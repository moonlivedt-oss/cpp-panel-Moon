# Строим дом: о курсе

> Практический курс: шаг за шагом строишь настоящий дом в своём мире — от черновых кубиков до двери на клавишу E, света, мебели, участка с забором и игры в .exe. Каждый этап учит новой части Unreal.

**К концу курса:** на площадке в `num1` стоит твой дом из двух комнат: с окнами, крышей и материалами, дверью, которая открывается на `E`, светом с выключателем, мебелью и ящиком, который можно толкать. К дому ведёт дорожка, вокруг забор. Над дверью появляется подсказка «Нажми E», а всё вместе собрано в игру, которую можно отправить другу.

## Как устроен курс

Это как «Подземелье» в методичке по C++: **одна постройка на весь курс**. На каждом этапе ты добавляешь в дом что-то новое — и по пути изучаешь ровно ту тему Unreal, которая для этого нужна.

У каждого этапа одинаковое устройство:

| Блок | Что это |
|---|---|
| **Чему научишься** | список тем и ссылки в справочник — «где почитать, если не понятно» |
| **Что понадобится** | что должно быть готово до начала |
| **Шаги** | что делать, по одному действию |
| **🔎 Подробнее** | раскрывающиеся блоки: детальный разбор «почему так» — открывай, если интересно или не понял |
| **Должно получиться** | как проверить, что всё верно |
| **Чек-лист** | отметь галочками — прогресс сохраняется |
| **Если не получилось** | частые проблемы этапа и как их лечить |
| **Проверь себя** | вопросы с вариантами |
| **Бонус** | для тех, кому мало: улучшение уже без пошаговых подсказок |

> 💡 **Не обязательно понимать всё сразу.** Сначала сделай по шагам — пусть работает. Потом открой «🔎 Подробнее» и разберись, почему работает. Так запоминается лучше, чем наоборот.

## План дома

Дом стоит на [площадке без травы](../proekt/08-ploshchadka-pod-dom.md) в `num1`, перед точкой появления игрока. Вид сверху (одна клетка = 1 м, игрок смотрит в сторону −X — на рисунке вверх):

```console
             X = −29 м  ┌──────────────────────────┐   ← задняя стена
                        │        спальня           │
                        │   (кровать, полка)       │
             X = −26.5  ├──────────────┐  ┌────────┤   ← внутренняя стена
                        │              дверной    │      с проёмом
                        │   гостиная    проём      │
           окно ═══════ │ (диван, стол, ящик)      │
                        │                          │
             X = −21 м  └─────────┐  ┌─────────────┘   ← передняя стена
                                  дверь                    с дверью (клавиша E)
                                   ║
                                   ║  дорожка
                                   ║
             X = −2 м          ★ PlayerStart
                     Y = −5 м ←──────────────→ Y = +5 м
```

| Параметр | Значение |
|---|---|
| Размер дома | 8 × 10 м (по X — 8, по Y — 10) |
| Высота стен | 3 м |
| Толщина стен | 20 см |
| Входная дверь | 120 × 220 см, по центру передней стены |
| Окно | 120 × 100 см, низ на высоте 90 см от пола |
| Внутренний проём | 100 × 210 см |
| Крыша | двускатная, 30° |

> 💡 Хочешь дом другой формы — пожалуйста! Но на первых двух этапах лучше повтори по размерам: так легче сверяться. Свой дом — отличный бонус после курса.


<details>
<summary>🔎 Подробнее: зачем резервная копия и что копировать</summary>

Unreal хранит проект как папку. Если что-то испортилось безнадёжно — удобно просто вернуть копию.

| Папка | Копировать? | Почему |
|---|---|---|
| `Content` | **да** | все твои ассеты и уровни |
| `Config` | **да** | настройки проекта |
| `Scripts`, `docs`, `SourceArt` | **да** | скрипты, методичка, исходники |
| `prog2.uproject` | **да** | файл проекта |
| `Saved` | нет | логи, автосохранения, снимки — пересоздаются |
| `Intermediate` | нет | временные файлы сборки |
| `DerivedDataCache` | нет | кэш шейдеров (большой, пересоберётся сам) |

Удобно делать копию в начале каждого этапа: `prog2_backup_etap3` и т. п. Когда освоишься — лучше перейти на **систему контроля версий** (Git + Git LFS или Perforce), но это отдельная тема.

</details>
