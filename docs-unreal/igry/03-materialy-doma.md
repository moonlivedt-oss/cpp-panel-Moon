# Этап 3. Материалы дома

> Штукатурка на стенах, деревянный пол и черепица на крыше. Сам скачиваешь текстуры с Poly Haven, импортируешь, собираешь один мастер-материал с текстурами «по миру» (World Aligned) и три инстанса.

**К концу этапа:** дом перестал быть серым: стены — светлая штукатурка, пол — доски, крыша — черепица. И текстура нигде не растянута, хотя все детали — один и тот же куб с разным масштабом.

> ✅ **Проверено в редакторе.** M_House собран строго по шагам: имена узлов и входов (`TextureObject`, `TextureSize`, `XYZ Texture`) совпадают, материал компилируется без ошибок, на временном доме текстура идёт по кускам стены с окном сплошным рисунком — без растяжения и швов. У текстур `beige_wall_001`, `wood_floor`, `clay_roof_tiles_02` на Poly Haven есть все нужные карты в 2K (JPG и PNG).

## Чему научишься

- скачивать и импортировать **PBR-набор** — [Текстуры и импорт](../proekt/02-teksturi-i-import.md);
- почему текстура на кубе **растягивается** при масштабе и как это исправить;
- **Texture Object Parameter** и **функции материала** (`WorldAlignedTexture`, `WorldAlignedNormal`);
- **мастер-материал** и **инстансы** — один граф на весь дом — [Материалы](../ref/03-materialy.md);
- **слоты материалов** у меша.

## Что понадобится

- [этап 2](02-steny-okna-krysha.md): дом с окном и крышей;
- браузер и ~60 МБ места.

## Шаг 1. Опыт: почему текстура растягивается

1. Каталог → создай папки `House/Textures` и `House/Materials`.
2. Возьми свой `MI_MyRock` из [главы 2](../proekt/02-teksturi-i-import.md#квест-свой-материал-на-кубе) (или любой материал с текстурой) и перетащи на `Wall_Back`.
3. Присмотрись: камни на стене **сплющены** — растянуты в 10 раз по длине и в 3 по высоте.
4. Верни стене серый материал (`Ctrl+Z`).

<details>
<summary>🔎 Подробнее: почему так происходит</summary>

У куба есть **UV-развёртка** — «выкройка», по которой текстура натягивается на грани. У стандартного куба каждая грань получает текстуру **целиком**, от угла до угла: UV от 0 до 1.

Когда ты растягиваешь куб масштабом `10` по Y, грань становится в 10 раз длиннее — а UV остаются от 0 до 1. Одна копия текстуры размазывается на 10 метров.

Два решения:

| Способ | Как | Плюсы и минусы |
|---|---|---|
| Свой тайл на каждую стену | параметр Tiling U/V в каждом инстансе | просто, но для каждой стены свой инстанс и подбор чисел |
| **Текстура по миру** (World Aligned) | координаты текстуры берутся не из UV, а из **положения точки в мире** | одна текстура одинакового размера на любом кубе с любым масштабом |

Мы берём второй: он для таких «коробочных» построек идеален.

</details>

> 🧪 **Посчитай сам**, прежде чем ставить в редакторе. TextureSize — сколько сантиметров стены покрывает одна копия текстуры.

```challenge
@id ue-dom3-tile
@type predict
@hint Длина стены / размер одной копии.
Задняя стена длиной 1000 см, TileSize = 200. Сколько копий текстуры на ней уложится?
---
float wallLength = 1000;   // см
float tileSize   = 200;    // см на одну копию
float copies = wallLength / tileSize;
---
5
```

## Шаг 2. Скачать текстуры

Сам, на сайте — это тоже навык:

1. Открой в браузере `polyhaven.com/a/beige_wall_001`.
2. Справа: разрешение **2K**, формат **JPG** (для цвета) — нажми **Download** (скачается архив или набор файлов; если предложит выбрать карты — нужны **Diffuse**, **Normal (GL)**, **Rough**).
3. Повтори для `wood_floor` и `clay_roof_tiles_02`.
4. Распакуй всё в `prog2/SourceArt/House/` — по папке на набор.

<details>
<summary>🔎 Подробнее: какое разрешение и формат выбирать</summary>

| Разрешение | Размер набора | Когда |
|---|---|---|
| 1K | ~5 МБ | мелкие предметы, далёкие объекты |
| **2K** | ~15 МБ | стены, пол — то, что видно с пары метров |
| 4K | ~60 МБ | крупный план, кинематографичные кадры |

Формат: **JPG** для цвета (лёгкий, сжатие незаметно), **PNG** для нормалей и шероховатости (без артефактов сжатия). EXR — 32-битные данные, для домика избыточно.

Лицензия Poly Haven — **CC0**: можно использовать в любом проекте, даже коммерческом, без указания автора.

</details>

## Шаг 3. Импорт и настройка

1. Перетащи файлы трёх наборов в `House/Textures`. Переименуй по правилу: `T_Wall_D/N/R`, `T_Floor_D/N/R`, `T_Roof_D/N/R`.
2. Настрой каждую — как в [главе 2](../proekt/02-teksturi-i-import.md#почему-у-каждой-карты-свои-настройки):

| Текстура | sRGB | Compression | Flip Green |
|---|---|---|---|
| `*_D` | ✔ | Default | — |
| `*_N` | ✘ | Normalmap | ✔ |
| `*_R` | ✘ | Masks | — |

> 💡 9 текстур по одной — долго. Выдели все `*_N` → правый клик → **Действия с ресурсами → Массовое редактирование через матрицу свойств** — и поставь настройки сразу трём.

```fillcode
// Настройки текстур — впиши Compression точно как в Unreal
*_D:  sRGB ✔,  Compression = [[Default]]
*_N:  sRGB ✘,  Compression = [[Normalmap]],  Flip Green ✔
*_R:  sRGB ✘,  Compression = [[Masks]]
```

## Шаг 4. Мастер-материал `M_House`

Один материал на весь дом, а отличия (какая текстура, какой размер) — в инстансах.

1. `House/Materials` → правый клик → **Материал** → `M_House` → открой.
2. Поставь узлы (правый клик по графу → поиск):

```console
[Texture Object Parameter «BaseColorTex»] ─▶ TextureObject ┐
[Vector Parameter «TileSize» = 200,200,200] ─▶ TextureSize ├─[WorldAlignedTexture]─ XYZ Texture ─▶ [× Tint] ─▶ Base Color
                                                           ┘
[Texture Object Parameter «NormalTex»] ─▶ TextureObject ┐
[TileSize] ─────────────────────────────▶ TextureSize   ├─[WorldAlignedNormal]─ XYZ Texture ─▶ Normal
                                                        ┘
[Scalar Parameter «Roughness» = 0.8] ──────────────────────────────────────────────────────▶ Roughness
```

   - **Texture Object Parameter** — это «слот для текстуры», который потом заполняется в инстансе. Поставь им по умолчанию `T_Wall_D` и `T_Wall_N`.
   - **WorldAlignedTexture** и **WorldAlignedNormal** — готовые функции движка (ищи по имени).
   - `Tint` — Vector Parameter (1, 1, 1) и узел Multiply.
**3.** Кликни по пустому месту графа → в Сведениях материала проверь, что галочка **Tangent Space Normal** **включена** (так по умолчанию — не трогай её).
**4.** Сохрани. Дождись компиляции.

<details>
<summary>🔎 Подробнее: что делает WorldAlignedTexture внутри</summary>

Функция берёт **положение точки в мире** (в сантиметрах) и делит на `TextureSize`. Получаются координаты, которые не зависят ни от UV, ни от масштаба куба: стена длиной 10 м получит 5 копий текстуры размера 200 см, а стена 3 м — полторы.

Но координат три (X, Y, Z), а текстура плоская. Поэтому функция делает **три проекции**:

- сверху (по X, Y) — для пола и крыши;
- спереди (по X, Z) — для стен, смотрящих вдоль Y;
- сбоку (по Y, Z) — для стен, смотрящих вдоль X;

и смешивает их по **нормали** поверхности: горизонтальная грань берёт верхнюю проекцию, вертикальная — боковую. Это называется **трипланарная проекция** (triplanar). Цена — три выборки текстуры вместо одной.

Выход `XYZ Texture` — все три проекции, смешанные. `XY Texture` — только сверху, `Z Texture` — только бока (если нужно что-то одно).

</details>

<details>
<summary>🔎 Подробнее: Tangent Space Normal и вход WorldSpace</summary>

Нормаль из текстуры можно задать в двух «системах координат»:

| Пространство | Что значит | Кто поворачивает по грани |
|---|---|---|
| **касательное** (tangent space) | «наклон относительно самой грани» | Unreal, сам |
| **мировое** (world space) | «наклон относительно мира» | уже повёрнута |

Галочка материала **Tangent Space Normal** говорит Unreal, какую нормаль ты подаёшь на вход **Normal**: включена — касательную, выключена — мировую.

У `WorldAlignedNormal` есть вход-переключатель **WorldSpace**. По умолчанию он **выключен**, и функция выдаёт нормаль в **касательном** пространстве — как раз под включённую галочку материала. Поэтому оставляем всё по умолчанию.

Если когда-нибудь подашь на вход WorldSpace `true` (константу-переключатель), функция выдаст мировую нормаль — тогда галочку Tangent Space Normal нужно **снять**. Главное — чтобы они совпадали; несовпадение даёт кривой рельеф: свет на камнях будто «не оттуда».

> ✅ Проверено в редакторе: функция в UE 5.8 описывает вход так — «This switch defaults to false».

Если запутался — можно временно **не подключать нормаль**: штукатурка и без неё выглядит прилично.

</details>

## Шаг 5. Три инстанса

1. Правый клик по `M_House` → **Создать экземпляр материала** → `MI_House_Wall`. Ещё два: `MI_House_Floor`, `MI_House_Roof`.
2. Открой каждый и включи параметры:

| Инстанс | BaseColorTex | NormalTex | TileSize | Roughness |
|---|---|---|---|---|
| `MI_House_Wall` | `T_Wall_D` | `T_Wall_N` | 200, 200, 200 | 0.85 |
| `MI_House_Floor` | `T_Floor_D` | `T_Floor_N` | 150, 150, 150 | 0.6 |
| `MI_House_Roof` | `T_Roof_D` | `T_Roof_N` | 150, 150, 150 | 0.7 |

## Шаг 6. Покрасить дом

1. Разблокируй группу (правый клик → Группы → Разблокировать).
2. Выдели все стены (в Структуре с `Ctrl`) → перетащи `MI_House_Wall` в Сведения → **Материалы → Элемент 0** (при нескольких выделенных назначится всем).
3. `Floor` → `MI_House_Floor`, обе плиты крыши → `MI_House_Roof`.
4. Заблокируй группу обратно. Сохрани.

**Должно получиться:** на всех стенах штукатурка одного масштаба — на длинной задней и на коротких кусках у окна одинаково. Пол — доски, крыша — черепица.

- три инстанса с разными текстурами и размерами

- понимаю, почему обычный UV растягивается, а World Aligned — нет

## Если не получилось

| Что видно | Причина | Что сделать |
|---|---|---|
| весь дом серый | M_House не скомпилирован | Журнал выходных данных / Stats в редакторе материала |
| текстура «плывёт», когда дом двигают | это свойство World Aligned: она привязана к миру | нормально; для движущихся объектов — обычные UV |
| рельеф кривой, свет «не оттуда» | галочка Tangent Space Normal не совпадает со входом WorldSpace | по умолчанию: галочка ✔, WorldSpace не подключён |
| доски на полу огромные | TileSize в сантиметрах | 100–150 для пола |
| на стыке двух кубов текстура сдвинута | разные TileSize в инстансах | один инстанс на все стены |
| черепица идёт поперёк ската | проекция сверху не знает направления ската | бонус: повернуть текстуру |

> 🧪 **Весь дом стал серым?** Подсказки по одной:

```hints
Идея: Серый цвет — это «материал по умолчанию»: Unreal рисует его, когда твой материал не собрался.
План: Открой `M_House` и посмотри панель **Показатели** внизу. Красная строка — ошибка. Частая причина — не тот тип сэмплера у текстуры или неподключённый вход функции.
Ключ: Ошибки ищи в **Показателях** и в **Журнале выходных данных** по слову `Failed to compile Material`. Исправил — **Применить** и сохранить.
```

## Проверь себя

```quiz
В: Стена масштабом (0.2, 10, 3) с обычным материалом. Почему текстура растянута?
+ UV куба от 0 до 1 на каждой грани, а грань стала в 10 раз длиннее
- Текстура слишком маленького разрешения
- Не включён sRGB
= Масштаб растягивает геометрию, но не UV — одна копия текстуры на всю грань.

В: Что задаёт TextureSize у WorldAlignedTexture?
+ Сколько сантиметров мира покрывает одна копия текстуры
- Разрешение текстуры в пикселях
- Размер куба
= 200 = одна копия на каждые 2 метра стены, независимо от масштаба куба.

В: Зачем Texture Object Parameter, а не Texture Sample Parameter?
+ Функция WorldAlignedTexture сама делает выборку и ждёт на вход объект текстуры
- Texture Sample не умеет параметры
- Так быстрее
= Texture Object — сама текстура как «аргумент», без выборки. Выборку делает функция.

В: Сколько выборок текстуры делает трипланарная проекция?
+ Три — по одной на каждую ось
- Одну
- Шесть
= Цена красоты — втрое больше выборок. Для домика это не страшно.
```

## Бонус

```boss
# Цоколь и наличники
@id ue-dom-03
Сделай дом «настоящим»: каменный низ стен и деревянные наличники вокруг окна.

1. Скачай `castle_brick_02_white` (или любой камень), сделай `MI_House_Stone` из того же `M_House`.
2. Добавь вдоль низа всех наружных стен полосу-цоколь: куб толщиной 24 см (чуть толще стены), высотой 50 см.
3. Вокруг окна — рамка из 4 тонких кубов (10 × 4 см сечение) с деревянным инстансом (`MI_House_Wood` из `wood_floor` или `brown_planks_05`).
4. Цвет рамы — тёмно-зелёный через **Tint** — без новых текстур.

<details>
<summary>Подсказка</summary>

Цоколь толщиной 24 при стене 20 выступает на 2 см с каждой стороны — так не будет мерцания. Его центр по Z: 20 + 50/2 = 45. Для Tint попробуй (0.15, 0.35, 0.2) — белая древесина станет зелёной краской.

</details>
```
