# Этап 8. Подсказки на экране

> Подходишь к двери — внизу экрана «Нажми E — открыть дверь», к выключателю — «Нажми E — свет». Учимся Widget Blueprint (UMG): дизайнер интерфейса, привязки, переменные виджета, Create Widget и Add to Viewport. В бонусе — интерфейсы блюпринтов.

**К концу этапа:** игрок всегда понимает, с чем можно взаимодействовать: у каждой двери и выключателя появляется своя подсказка, а когда отходишь — она исчезает.

> ✅ **Частично проверено в редакторе.** `WBP_Hint` создаётся из User Widget, у виджета есть Add to Viewport / Remove from Parent / Is In Viewport. Узел **Create Widget** скрипту недоступен — показ подсказки проверишь сам на шаге 3.

## Чему научишься

- **Widget Blueprint** — интерфейс в Unreal (система **UMG**);
- **Дизайнер** виджета: Canvas Panel, Text, **якоря** (anchors);
- переменные и функции **внутри виджета**;
- **Create Widget**, **Add to Viewport**, **Remove from Parent**;
- текст как **Instance Editable** переменная — одна логика, разные надписи.

## Что понадобится

- [этап 5](05-svet-v-dome.md) и [этап 4](04-dver.md): `BP_Door` и `BP_LightSwitch` с зонами и Enable Input.

## Шаг 1. Виджет подсказки

1. `House/Blueprints` → правый клик → **Пользовательский интерфейс → Blueprint виджета** (Widget Blueprint) → родитель **User Widget** → имя `WBP_Hint` → открой.
2. Откроется **Дизайнер** (вкладка Designer). Слева **Палитра**.
3. Перетащи из Палитры **Canvas Panel** в поле (это корень — «холст» размером с экран). Новый виджет в Unreal 5 создаётся **пустым**; если холст у тебя уже есть — пропусти этот пункт.
4. Перетащи **Text** на холст. В Сведениях текста:
   - **Якоря** (Anchors) → выбери «низ по центру» (картинка с точкой внизу посередине);
   - **Position X** `0`, **Position Y** `-120`, **Alignment** `0.5, 1` (выравнивание по центру-низу);
   - **Size To Content** ✔;
   - **Text** → `Нажми E`;
   - **Font → Size** `28`; **Shadow Offset** `2, 2`, **Shadow Color** — чёрный, полупрозрачный.
5. Вверху Сведений текста — поставь галочку **Is Variable**, имя `HintText`.
6. **Компилировать → Сохранить.**

<details>
<summary>🔎 Подробнее: якоря — почему подсказка не уезжает на других экранах</summary>

**Якорь** — точка экрана, к которой «привязан» элемент. Позиция задаётся **относительно якоря**.

| Якорь | Позиция (0, −120) значит | На широком мониторе |
|---|---|---|
| левый верхний угол (по умолчанию) | 120 пикселей **выше** верха экрана — не видно | — |
| **низ по центру** | 120 пикселей над серединой нижнего края | всегда по центру внизу |

Без правильного якоря интерфейс «съезжает» при другом разрешении: на ноутбуке надпись в центре, на широком мониторе — сбоку.

**Alignment** (0.5, 1) — какая точка самого элемента совпадает с позицией: центр по горизонтали, низ по вертикали. Тогда текст любой длины стоит ровно по центру.

</details>

## Шаг 2. Функция «поменять текст»

Пусть виджет умеет показывать любую надпись.

1. Переключись на вкладку **График** (Graph) виджета.
2. **Мой Blueprint → Functions → +** → `SetHint`.
3. Выдели функцию → в Сведениях **Inputs → +** → имя `Message`, тип **Text**.
4. В графе функции: перетащи переменную `HintText` → из неё `SetText (Text)` → **In Text** ← `Message`. Белые провода: вход функции → SetText.
5. **Компилировать → Сохранить.**

<details>
<summary>🔎 Подробнее: Text, String и Name — в чём разница</summary>

| Тип | Для чего | Пример |
|---|---|---|
| **Text** | всё, что **видит игрок**: поддерживает перевод на другие языки | «Нажми E» |
| **String** | обычная строка для логики и отладки | имя файла, Print String |
| **Name** | короткий идентификатор, быстрое сравнение | имя сокета, тег |

Правило: надписи интерфейса — всегда **Text**. Тогда игру потом можно будет перевести (инструмент локализации Unreal работает именно с Text).

</details>

## Шаг 3. Показывать у двери

Открой `BP_Door`.

1. **Variables → +** `HintMessage` (тип **Text**, Instance Editable 👁). Компилируй, поставь значение по умолчанию: `Нажми E — дверь`.
2. **Variables → +** `HintWidget` (тип **WBP_Hint → Object Reference**).
3. В цепочке **Begin Overlap**, после `Enable Input`:
   - `Create Widget`: **Class** = `WBP_Hint`, **Owning Player** ← Get Player Controller 0;
   - из **Return Value** → `Set HintWidget` (сохраняем, чтобы потом убрать);
   - → `Add to Viewport`;
   - → `HintWidget` → `Set Hint` (Message ← `HintMessage`).
4. В цепочке **End Overlap**, после `Disable Input`:
   - `HintWidget` → `Is Valid` → `Remove from Parent`.
5. **Компилировать → Сохранить** → ▶ Play → подойди к двери.

```console
Begin Overlap ─▶ Cast ─▶ Enable Input ─▶ Create Widget (WBP_Hint) ─▶ Set HintWidget ─▶ Add to Viewport ─▶ Set Hint (HintMessage)
End Overlap   ─▶ Cast ─▶ Disable Input ─▶ Is Valid (HintWidget) ─▶ Remove from Parent
```

<details>
<summary>🔎 Подробнее: жизнь виджета — Create, Add, Remove</summary>

| Узел | Что делает | Аналогия |
|---|---|---|
| **Create Widget** | создаёт объект виджета в памяти | напечатал листовку |
| **Add to Viewport** | показывает на экране | приклеил на стену |
| **Remove from Parent** | убирает с экрана | снял со стены |

Если не сохранить виджет в переменную (`HintWidget`), потом его не найти, чтобы убрать — надпись останется навсегда. Если вызывать Create Widget при каждом входе, не убирая старый, надписи будут накладываться друг на друга.

Хороший вариант — создать виджет **один раз** (на BeginPlay или при первом входе) и потом только показывать/прятать (**Set Visibility**). Это бонус-улучшение.

</details>

## Шаг 4. То же для выключателя

1. Скопируй переменные `HintMessage` и `HintWidget` в `BP_LightSwitch` (или создай заново).
2. Повтори шаг 3 в его событиях Overlap.
3. На уровне у выключателя гостиной поставь **Hint Message** = `Нажми E — свет в гостиной`, у спальни — `…в спальне`.

**Должно получиться:** у двери внизу «Нажми E — дверь», у выключателей — свои надписи; отошёл — исчезли.

## Если не получилось

| Что видно | Причина | Что сделать |
|---|---|---|
| надписи нет | якорь сверху, текст за экраном | якорь «низ по центру», Position Y отрицательный |
| надпись не исчезает | виджет не сохранён в переменную | Set HintWidget после Create Widget |
| надписи накладываются | Create Widget при каждом входе без удаления | убери в End Overlap или создавай один раз |
| везде «Нажми E» | HintMessage не передаётся | вызов SetHint после Add to Viewport |
| в Сведениях нет Hint Message | нет Instance Editable | глаз 👁 у переменной, компиляция |
| ошибка «Accessed None HintWidget» | Remove без проверки | Is Valid перед Remove from Parent |

## Проверь себя

```quiz
В: Зачем якорь «низ по центру» для подсказки?
+ Чтобы надпись была по центру внизу на любом разрешении экрана
- Чтобы текст стал крупнее
- Без якоря виджет не компилируется
= Позиция считается от якоря; без него интерфейс съезжает на других экранах.

В: Какой тип переменной для надписей, которые видит игрок?
+ Text
- String
- Name
= Text поддерживает локализацию.

В: Что делает Add to Viewport?
+ Показывает созданный виджет на экране
- Создаёт виджет
- Удаляет виджет
= Создание (Create Widget) и показ (Add to Viewport) — разные шаги.

В: Почему виджет сохраняют в переменную HintWidget?
+ Чтобы потом найти его и убрать с экрана
- Иначе он не покажется
- Так он быстрее рисуется
= Без ссылки виджет нельзя будет удалить — он останется навсегда.
```

## Бонус

```boss
# Интерфейс «Можно взаимодействовать»
@id ue-dom-08
Сейчас логика подсказки скопирована в двери и выключатели. Сделай её общей.

1. Каталог → **Blueprint → Интерфейс Blueprint** (Blueprint Interface) → `BPI_Interactable`. Функции: `Interact` и `GetHint` (выход — Text).
2. В `BP_Door` и `BP_LightSwitch`: **Параметры класса → Implemented Interfaces → +** → `BPI_Interactable`. Реализуй `Interact` (открыть/переключить) и `GetHint`.
3. Перенеси **подсказку и E** в `BP_EmanuelPlayer`: каждые 0.1 с делай **Line Trace** из камеры вперёд на 300 см; если попал в актор, который реализует `BPI_Interactable`, — показывай его `GetHint`, а на E вызывай `Interact`.
4. Из дверей и выключателей убери зоны, Enable Input и виджеты — они больше не нужны.

<details>
<summary>Подсказка</summary>

Проверка «реализует ли» — узел **Does Implement Interface**. Вызов — **Interact (Message)** (с иконкой конверта): он вызывается у любого актора и молча ничего не делает, если интерфейса нет. Line Trace: **Line Trace By Channel**, Start — `FollowCamera → Get World Location`, End — Start + `Get Forward Vector` × 300. Так делают взаимодействие почти во всех играх: смотришь на предмет — видишь подсказку.

</details>
```
