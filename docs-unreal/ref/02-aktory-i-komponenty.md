# Акторы, компоненты, уровни

> Из чего состоит мир Unreal: уровень, акторы, компоненты, ассеты — и чем они отличаются. Как ставить объекты, чем Static отличается от Movable, как группировать — и World Partition, которым разбит твой ландшафт.

## Четыре слова

| Слово | Что это | Пример в проекте |
|---|---|---|
| **Ассет** | файл в Content: «чертёж» или ресурс | `M_Terrain`, `SKM_Manny_Simple`, `T_Meadow_D` |
| **Уровень** (Level, Map) | мир, в котором стоят объекты | `num1` |
| **Актор** (Actor) | всё, что стоит на уровне | `DirectionalLight`, `Landscape`, `PlayerStart` |
| **Компонент** (Component) | «деталь» актора | у персонажа: капсула, меш, камера, движение |

**Ассет ≠ актор.** `SM_Камень` в Каталоге ресурсов — чертёж. Перетащил во вьюпорт — на уровне появился актор, который **ссылается** на этот чертёж. Поставил 100 камней — один ассет, сто акторов.

## Как поставить актор на уровень

Четыре способа — выбирай любой, результат одинаковый: в мире появляется актор, а в Структуре — его строка.

| Способ | Как | Когда удобно |
|---|---|---|
| **Кубик с плюсом** | кнопка на верхней панели → Фигуры / Освещение / Базовые… ([картинка](07-menyu.md#кнопка-кубик-с-плюсом-быстрое-добавление)) | быстро поставить куб, свет, PlayerStart |
| **Панель расстановки акторов** | Окно → Расстановка акторов. Слева откроется панель с поиском и вкладками: недавние, базовые, свет, фигуры, эффекты, объёмы… Перетащи нужное в мир | ставишь много разных вещей подряд |
| **Перетащить из Каталога** | взять файл в Каталоге ресурсов и бросить в мир | свои модели, блюпринты, звуки |
| **ПКМ по миру** | выдели файл в Каталоге → ПКМ в нужном месте мира → в разделе «Расстановка акторов» выбери его | поставить точно в точку под курсором |

**Что получится из файла**, если его перетащить:

| Тип файла | Какой актор появится |
|---|---|
| Static Mesh (`SM_…`) | StaticMeshActor — неподвижная модель |
| Skeletal Mesh (`SKM_…`) | SkeletalMeshActor — модель со скелетом |
| Blueprint (`BP_…`) | экземпляр этого блюпринта |
| Звук | AmbientSound — источник звука в точке |

> 💡 **Заменить сразу много объектов.** Выдели в Каталоге новый файл (например, другую модель камня), выдели в мире старые камни → ПКМ → **Заменить выбранные акторы на…** Позиции сохранятся, поменяется только модель.

## Компоненты

Актор сам по себе — пустая коробка с позицией. Всё умение — в компонентах:

| Компонент | Что даёт |
|---|---|
| **Static Mesh** | неподвижная модель (камень, стена) |
| **Skeletal Mesh** | модель со скелетом и анимацией (персонаж) |
| **Capsule / Box Collision** | столкновения |
| **Camera** | камера |
| **Light** (Point, Spot, Directional) | свет |
| **Character Movement** | ходьба, прыжки, гравитация |
| **Audio** | звук |

Компоненты складываются **деревом**: дочерний движется вместе с родителем. Так у персонажа: капсула → меш → тело → одежда ([глава 7](../proekt/07-personazh.md#шаг-3-ретаргетинг-тело-повторяет-за-манекеном)).

## Трансформ

У каждого актора и компонента — **Location** (где), **Rotation** (как повёрнут), **Scale** (размер). Координаты — **в сантиметрах**. Ось `Z` — вверх, `X` — вперёд, `Y` — вправо.

| Rotation | Ось | Смысл |
|---|---|---|
| Roll (X) | вперёд | крен |
| Pitch (Y) | вправо | наклон вверх/вниз (солнце!) |
| Yaw (Z) | вверх | поворот налево/направо |

## Подвижность: Static, Stationary, Movable

У моделей и источников света в Сведениях, сразу под Преобразованиями, есть переключатель **Подвижность** (Mobility) из трёх кнопок: **Статичный / Неподвижный / Подвижный**. Он говорит движку, **будет ли объект меняться во время игры**. Если не находишь — набери `mobility` в поиске Сведений.

| Значение | Простыми словами | Подходит для |
|---|---|---|
| **Статичный** (Static) | «прибит гвоздями»: в игре не двигается и не меняется | стены, пол, камни, дом |
| **Неподвижный** (Stationary) | стоит на месте, но может **меняться**: свет — менять яркость и цвет, включаться/выключаться | лампа, которую выключают |
| **Подвижный** (Movable) | можно двигать, вращать, удалять, менять как угодно | **дверь**, ящик с физикой, всё, что ездит |

> ⚠ **Частая ошибка новичка.** Сделал дверь, а в игре она не открывается, и в Журнале ругань про Mobility? Значит, она **Статичный**. Поставь **Подвижный**. Для физики (ящик, который можно толкнуть) — тоже Movable.

> 📖 **Зачем вообще Static, если можно всё сделать Movable?** Со старым «запечённым» светом Static-объекты получают тени заранее, бесплатно для игры. У тебя свет динамический (Lumen), поэтому разница меньше, но Static всё равно честнее говорит движку «этот объект не трогай» — оставляй его для стен и декора.

## Группы

Выделил несколько объектов (`Ctrl` + клик) и хочешь, чтобы они всегда двигались вместе — сгруппируй их.

| Действие | Как |
|---|---|
| **Сгруппировать** | `Ctrl+G` или ПКМ → Сгруппировать |
| **Разгруппировать** | `Shift+G` |
| **Подвинуть одну часть группы** | ПКМ по группе → **Разблокировать**, подвинь, потом **Заблокировать** обратно |
| **Добавить объект в группу** | выдели группу и объект → ПКМ → Добавить в группу |
| **Перенести центр группы** | зажми `Alt` и кликни **СКМ** туда, где должен быть центр |

**Цвет скобок** вокруг группы подсказывает её состояние: **зелёные** — заблокирована (двигается целиком), **красные** — разблокирована (можно трогать части).

> 💡 Группа не выделяется целиком, а кликаются отдельные объекты? Включи **выделение групп**: `Ctrl+Shift+G`.

**Группа, папка или блюпринт?**

| | Папка в Структуре | Группа | Блюпринт |
|---|---|---|---|
| двигаются вместе | нет | да | да |
| для чего | порядок в списке | собрать несколько вещей на этом уровне | многоразовый объект: поставил «дом» 5 раз |
| логика (открыть дверь) | нет | нет | **да** |

## World Partition

Мир 2×2 км целиком в память не помещается — точнее, незачем. **World Partition** режет мир на ячейки и загружает только те, что рядом с камерой/игроком.

Поэтому твой ландшафт — это один актор **Landscape** (общие настройки, материал) и **64 куска `LandscapeStreamingProxy`**, каждый подгружается отдельно. Материал назначается на главный `Landscape` — куски берут его оттуда.

Окно **World Partition** (Окно → World Partition) показывает карту ячеек: можно выделить область и загрузить/выгрузить её в редакторе.

**One File Per Actor.** Каждый актор уровня хранится отдельным файлом в `Content/__ExternalActors__/num1/…`. Поэтому при сохранении пишется много мелких файлов — это нормально.

## Игровые классы

| Класс | Роль |
|---|---|
| **Pawn** | то, чем можно управлять |
| **Character** | Pawn с капсулой и ходьбой |
| **PlayerController** | «руки игрока»: читает ввод, управляет Pawn |
| **GameMode** | правила: кем играть, где появляться |
| **PlayerStart** | точка появления |

## Проверь себя

```quiz
В: На уровне 100 одинаковых камней. Сколько ассетов меша?
+ Один — 100 акторов ссылаются на один чертёж
- 100
- Ни одного
= Ассет — чертёж, актор — постройка по нему.

В: Объект повёрнут по Pitch = −30. Это…
+ наклон носом вниз на 30°
- поворот налево на 30°
- крен вбок
= Pitch — наклон вверх/вниз, Yaw — налево/направо, Roll — крен.

В: Зачем ландшафт разбит на 64 куска?
+ World Partition грузит только куски рядом с камерой/игроком
- Так быстрее рисуются текстуры
- Это ошибка импорта
= Огромный мир целиком в памяти не нужен.

В: Дверь в игре не открывается, в Журнале ошибка про Mobility. Что поменять?
+ Mobility: Static → Movable
- Масштаб двери
- Материал двери
= Static-объекты в игре двигать нельзя. Всё, что движется, — Movable.

В: Лампа должна выключаться, но стоять на месте. Какая подвижность ей подходит?
+ Stationary (или Movable)
- Только Static
- Подвижность не важна
= Stationary — стоит на месте, но может менять яркость и выключаться.

В: Перетащил из Каталога ассет SM_Rock. Что появилось на уровне?
+ StaticMeshActor — актор с этой моделью
- Копия файла SM_Rock
- Блюпринт
= Ассет остаётся один, на уровне появляется актор, который на него ссылается.

В: Скобки вокруг группы стали красными. Что это значит?
+ Группа разблокирована — можно двигать части по отдельности
- В группе ошибка
- Группа удалена
= Зелёные — заблокирована, красные — разблокирована.
```

```cards
В: Ассет или актор: M_Terrain?
О: Ассет (лежит в каталоге).

В: Ассет или актор: DirectionalLight на уровне?
О: Актор.

В: В каких единицах координаты Unreal?
О: В сантиметрах; Z — вверх.

В: Что такое компонент?
О: «Деталь» актора: меш, свет, камера, коллизия, движение.

В: Три значения Mobility?
О: Static (не меняется), Stationary (стоит, но меняется), Movable (двигается).

В: Сгруппировать / разгруппировать?
О: Ctrl+G / Shift+G.
```
