## Мир и объекты

| Термин | Простыми словами | В проекте |
|---|---|---|
| **Уровень** (Level, Map) | один мир, отдельный файл `.umap` | `num1` |
| **Актор** (Actor) | любой объект, который стоит на уровне | солнце, ландшафт, PlayerStart |
| **Компонент** (Component) | «деталь» актора: меш, свет, камера, коллизия | у персонажа — Capsule, Mesh, CameraBoom |
| **Ассет** (Asset) | файл в каталоге: чертёж или ресурс | `M_Terrain`, `T_Meadow_D` |
| **Трансформ** (Transform) | где стоит, как повёрнут, какого размера | Сведения → Преобразования |
| **Pivot** (опорная точка) | точка, вокруг которой объект вращается и по которой ставится | у камней сначала была «не там» |
| **Меш** (Mesh) | 3D-модель: вершины и треугольники | `stone_01` |
| **Static Mesh** | неподвижная модель | камни, трава |
| **Skeletal Mesh** | модель со скелетом, которую можно анимировать | тело Emanuel, манекен |
| **LOD** (Level of Detail) | упрощённые версии модели для дальних расстояний | у MetaHuman — несколько уровней |
| **Nanite** | технология UE5: модель сама упрощается до нужной детализации | вся трава и камни |
| **World Partition** | мир режется на ячейки, грузятся только нужные | 64 куска ландшафта |
| **Outliner / Структура** | окно-список всех акторов уровня | — |
| **Details / Сведения** | окно свойств выделенного | — |

## Материалы и текстуры

| Термин | Простыми словами | В проекте |
|---|---|---|
| **Текстура** | картинка, которую «натягивают» на поверхность | `T_Meadow_D` |
| **PBR** | материалы по законам физики: цвет, шероховатость, металличность отдельно | все материалы |
| **Base Color** / Diffuse / Albedo | цвет поверхности без света и теней | `_diff` |
| **Normal map** | картинка, которая хранит микрорельеф | сиреневые `_N` |
| **Roughness** | шероховатость: 0 — зеркало, 1 — матовое | `_R` |
| **Height / Displacement** | высота микрорельефа | `_H`, для смешивания слоёв |
| **sRGB** | «цветовая» кривая яркости; только для цвета | вкл. только у `_D` |
| **UV** | координаты на текстуре (0…1), по которым её берут | «тайл» |
| **Тайл** (Tiling) | сколько метров покрывает одна копия текстуры | `Meadow_TileMeters = 2` |
| **Материал** | граф узлов: как из текстур и чисел получить поверхность | `M_Terrain` |
| **Узел** (Node, Expression) | один «блок» в графе материала или блюпринта | Lerp, Noise |
| **Инстанс материала** (MI) | копия материала с ползунками, без перекомпиляции | `MI_Terrain` |
| **Параметр** | число/цвет/текстура, которые меняются в инстансе | `RockSlopeStart` |
| **Маска** | число 0…1 в каждой точке: «где здесь лес» | маски слоёв |
| **Lerp** | смешать A и B по маске: 0 — A, 1 — B | смешивание слоёв |
| **Сэмплер** (Sampler) | способ взять значение из текстуры | Shared: Wrap |
| **Шейдер** | программа для видеокарты, в которую компилируется материал | «компиляция шейдеров» |
| **Masked** | режим, где пиксель либо есть, либо нет | трава |
| **Two Sided Foliage** | модель освещения для листьев: свет проходит насквозь | `M_Foliage` |
| **WPO** (World Position Offset) | сдвиг вершин из материала | ветер |

## Повтори слова

```cards
В: Чем ассет отличается от актора?
О: Ассет — файл-чертёж в Каталоге ресурсов. Актор — объект на уровне, сделанный по чертежу. Один ассет — много акторов.

В: Что такое инстанс материала?
О: Копия материала с ползунками-параметрами. Меняется мгновенно, без компиляции шейдеров.

В: Зачем Lerp?
О: Смешать A и B по маске: где маска 0 — A, где 1 — B, между — плавно.

В: У какой карты включают sRGB?
О: Только у цвета (Base Color). Нормаль, шероховатость, высота — данные, sRGB выключен.

В: Что решает GameMode?
О: Правила игры, в том числе кем играет игрок (Default Pawn Class).

В: Что такое Nanite?
О: Технология UE5: модели сами упрощаются до нужной детализации, поэтому можно ставить сотни тысяч объектов.

В: Что такое ретаргетинг?
О: Перенос анимации с одного скелета на другой — так Emanuel использует анимации манекена.

В: Чем Input Action отличается от Input Mapping Context?
О: Action — «что хочет игрок» (прыгнуть). Mapping Context — «какой клавишей» (Пробел → прыгнуть).
```
